# 쌍계 — 끊긴 귀환로 · v0.6.0

플레이: https://herothgf-cell.github.io/project-a/

PC와 휴대폰에서 브라우저만으로 실행합니다. Node 설치는 개발할 때만 필요합니다. 시작 화면의 v0.6.0을 확인하세요. 기존 저장은 이어하기로 유지됩니다.

## 이번 변경
흑발·도포·장검의 무협 주인공, 정면/측면/뒷면과 대각선 방향 처리, 주요 NPC 초상과 필드 인물, 잔디·돌길·기와·수목 질감을 개선했습니다.

제3장 완료 후 현실 서린에게 대화하면 제4장 끊긴 귀환로가 시작됩니다. 청운 귀환로에서 파문 받아내기, 잔향 귀환, 결계 억제 또는 일반 전투 후 권양기 우회로 연화를 구조합니다. 실제 통행로가 열리고 연화가 청운촌에 돌아옵니다. 구한 방법은 다음 현실 지역 귀환 부두의 보호/잔향 협공/공격 예고 억제 효과로 이어집니다.

강호 소식은 사건에 반응하는 NPC 시뮬레이션입니다. 실제 온라인 유저 채팅이나 서버 접속자가 아닙니다. 모바일에서는 버튼으로 읽습니다.

## 조작과 저장
WASD/방향키 이동 · J 공격 · K/L 공통 무공 · Q/R 개인 무공 · F 오의 · Space/Shift 회피 · E 상호작용 · 1 회복약 · I 장비 · M 지도 · Esc 메뉴.
모바일은 조이스틱과 화면 버튼을 사용합니다. 저장 version5이며 이전 v1~4를 읽습니다. 브라우저별 저장이므로 기기 이동에는 메뉴의 저장 파일 내보내기/불러오기를 사용하세요.

## 검증과 한계
npm run check, npm test, npm start. 다섯 Playwright Chromium HTTP/실제 저장소 검사가 배포를 보호합니다. build-info.json에 게시 버전과 커밋이 기록됩니다.

다섯 독립 시점과 반전을 조합한 8방향 표현입니다. 모든 방향의 걷기/공격 프레임을 각각 그린 최종 애니메이션은 아니며 일부 배경은 벡터 기반입니다. 실제 저사양 Android/iPhone Safari 장기 프레임·배터리는 미검증입니다.

## 통합된 성능 진단
일반 플레이 화면은 동일하며 URL에 `?perf=1`을 붙인 경우에만 진단 HUD를 표시합니다. `feat/v04-perf-hud`의 변경을 v0.6에 통합했습니다. 기록은 메모리에만 유지하며 전송하지 않습니다. 배포 전 다섯 HTTP 브라우저 스위트를 실행합니다.
