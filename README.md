# 쌍계 — 두 세계의 호흡

현재 게임: **v0.15.0** · 최신 기획 정리: **2026-10-12**

**[최신 기획 문서](docs/planning/README.md)**에서 스토리·시스템·개발 방향을 확인하세요. 이전 설정과 버전별 작업 기록은 **[별도 보관함](docs/archive/README.md)**에 있습니다.

신규 여정은 현실 출발 → 무림 도착·백련 구조 → 삼재검법 튜토리얼 → 화산행 10개 던전 → 치료·제자 선택 → 천흔 보스 → 첫 현실 귀환입니다. 이미지·대사 → 준비 → 다음 던전으로 진행하며, 배운 기술을 직접 단축키에 배치합니다. 성장 소식은 읽음 기반 레드닷으로 안내합니다.

## 실행

Node.js 20 이상에서 저장소 루트의 `npm start` 또는 `node server.cjs`를 실행하고 서버가 출력하는 주소를 여세요. npm이 없더라도 Node가 있으면 후자로 실행할 수 있습니다. 추가 제품 의존성 설치는 필요하지 않습니다.

새 흐름은 **새로운 여정**으로 확인합니다. 기존 캠페인 저장의 이어하기는 이전 진행과 투자를 보존합니다. 중요한 저장은 테스트 전에 내보내세요.

## 개발 확인

`npm test`, `npm run check`, `npm run check:revision`, `npm run check:world`. 브라우저 검사는 저장소 테스트와 Pages 워크플로의 환경을 따릅니다. 명령 목록은 실행·통과 보고가 아닙니다.

현재 신규 범위는 첫 현실 귀환까지입니다. 슬롯 수·전투량·효과는 검증안이고 장면은 기존 이미지를 재사용합니다. 현실 전투/트리·3장 이후 신규 연결·나머지 매화 23초식은 후속입니다.

[작업 규칙](AGENTS.md)에 따라 main에서 작업합니다. 문서 변경과 게임 구현·테스트·배포 결과를 구분합니다.
