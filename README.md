# 쌍계 — 잔월의 서약 · v0.3.0

현실과 무림을 오가며 익힌 무공으로 두 세계의 균열을 공략하는 오리지널 1인용 액션 RPG입니다. 원작 웹툰의 인물, 대사, 그림을 사용하지 않습니다.

## 바로 플레이
https://herothgf-cell.github.io/project-a/

PC와 휴대폰에서 위 주소를 엽니다. 플레이할 때 Node 설치는 필요 없습니다. 화면 아래/메뉴의 버전이 v0.3.0인지 확인하세요. 기존 페이지가 남아 있으면 PC에서 Ctrl+F5로 새로고침하세요.

## 이번 버전
- 진행 안내: 올바른 적 이름, 방향 화살표, 상태별 목표, 승리 후 귀환/보고.
- 액션: 3연격, 월영참/천뢰격, 검 궤적, 피해 숫자, 피격 반응, 공격 예고, 보스 보호막.
- 터치: 이동+공격 동시 입력, 공격 길게 누르기, 대화/포커스/취소 때 입력 초기화.
- 그림: 애니메이션 캐릭터, 도시 건물, 백련문 기와집, 대숲, 폐사, 항만을 직접 그린 벡터 그래픽으로 교체.
- 6개 지역 / 2개 챕터: 기존 기지·청운촌·죽림·지하역 + 월영 폐사·침식된 항만.
- 보급과 강화, 무료 휴식, 지도, 무공/장비창, 선택형 효과음, 화면 효과 줄이기.
- 기존 v1 저장을 읽고 v2로 이전. 손상된 저장은 사용자 확인 전 덮어쓰지 않습니다.

## 진행 순서
제1장: 서린 → 경계석 → 백련 → 흑풍 죽림 호위/두목 → 백련(천뢰격) → 현실 서린 → D급 균열 감시자.

제2장: 기지 서린 → 무림 백련 → 월영 폐사(호위 → 인장 3개 → 수문장) → 백련(경계 공명) → 현실 서린 → 침식된 항만(호위 → 침식 닻 2개 → 집행관).

제1장을 끝낸 저장은 기지에서 서린에게 말하면 제2장이 시작됩니다. 경계 공명은 지속 효과로 공격력 +6 및 받는 피해 15% 감소를 줍니다. 던전에서 후퇴하거나 쓰러지면 호위/봉인은 초기화되지만 이미 완료한 이야기와 성장 단계는 유지됩니다.

## 조작
WASD/방향키 이동 · J 연환검(길게) · K 월영참 · L 천뢰격 · Space/Shift 회피 · E 대화/출입구 · 1 회복약 · I 장비 · M 지도 · Esc 메뉴.

모바일은 왼쪽 조이스틱과 오른쪽 공격/무공 버튼을 함께 사용합니다. 세로/가로 모두 지원합니다. 소리는 상단 ♪ 버튼으로 켭니다. 자동 저장은 브라우저별 로컬 저장이며 PC/휴대폰 간 자동 공유되지 않습니다. 메뉴의 저장 파일 다운로드/불러오기로 옮기세요.

## 개발/검증
Node 20 이상에서 `npm start`, `npm test`, `npm run check`. 런타임 의존성 설치는 없습니다.

브라우저 검사 도구는 개발용입니다:
```sh
python -m pip install playwright==1.57.0
python -m playwright install chromium
# 다른 터미널에서 npm start를 실행한 상태
python tests/browser_smoke.py --url=http://127.0.0.1:3000/
```

`main` 변경 시 GitHub Actions가 구문/Node 테스트, 실제 HTTP 브라우저·저장 검사를 통과한 경우에만 Pages에 배포합니다. 게임 파일 7개만 게시하며 개발 문서·테스트·서버는 사이트에 올리지 않습니다. `/build-info.json`으로 게시 버전과 커밋을 확인할 수 있습니다.

모듈: `world.js` 콘텐츠, `game.js` 시뮬레이션/저장, `art.js` 그림, `render.js` 화면, `app.js` 조작/대화, `style.css` 반응형 UI. 개발 결정과 검증 범위는 `docs/verification-v03.md`에 있습니다.
