## 이번 변경: 퀘스트가 주는 기술이 아니라 전투에서 먼저 움직이는 힘
제1장 공통 무공을 배운 뒤, 일반 전투에서도 기연의 조짐을 경험할 수 있습니다. 사부에게 보고하기 전 현장에서 각성을 받아들이면 Q/R/F 기술을 바로 사용할 수 있습니다. 제3장까지 새로 밀 필요는 없습니다.

- **파문검:** 실제 적의 공격이 닿기 직전, 기본 공격을 직접 눌러 맞받아칩니다. 공격 버튼을 누르고 있는 자동 연타만으로는 증거가 쌓이지 않습니다.
- **잔영보:** 자신을 노린 공격에서 회피한 후 그 공격자에게 돌아가 반격합니다. 빈 땅에서 반복 대시하는 것은 행적이 아닙니다.
- **경계봉인:** 전장에 있는 선택형 `바람이 멎은 틈` 가까이에서 적의 공격 예고가 다가올 때 E / 대화·이동으로 흐름에 손을 댑니다. 평온할 때 조사만 해서는 무공을 받지 않습니다.

첫 성공은 실제 전투 효과와 이름 없는 조짐으로 나타나며, 이어진 사건에서 각성 장면이 열립니다. 화면에는 실제 장소·상대·행동을 기록합니다. **강제로 계열을 정하지 않습니다.** `지금은 이 감각만 기억한다`로 보류하고, 나의 기연 도감에서 다시 받아들일 수 있습니다. 이미 다른 계열을 쓰고 있다면 안전한 거점에서 전환합니다.

기존 v0.4 계열은 삭제되지 않습니다. 기존 계열을 쓰며 새 현장 행적도 쌓을 수 있습니다. 기록이 없는 예전 저장에 가짜 각성 사연을 만들어 붙이지 않습니다. 기존 비경 시험은 선택적 체험으로 남기며, 이미 현장에서 각성한 사람은 제3장에서 사부에게 기술을 다시 받을 필요가 없습니다.

## 그래픽
제공된 오리지널 컨셉을 바탕으로 따뜻한 질감의 잔디·불규칙한 흙길·돌길·기와·나무, 큰 초상화 대화창, 고전 RPG형 필드 중심 UI를 적용했습니다. 실제 플레이 캐릭터에 생성 컨셉의 페인팅 자세를 사용합니다. 상업 게임 원본 에셋을 복사하지 않았습니다. 정확한 출처와 구현 한계는 `docs/art-provenance-v05.md`에 있습니다.

## 그대로 유지한 콘텐츠
총 8개 지역·3개 챕터, 공통 월영참/천뢰격, 개인 기연 세 계열과 9개 기술, 보급/강화/휴식/지도/저장 파일 이동.

| 계열 | Q | R | F · 기세 100 |
|---|---|---|---|
| 파문검 | 파문세 | 역류참 | 파천반월 |
| 잔영보 | 잔영각 | 귀환보 | 월흔난무 |
| 경계봉인 | 쇄경진 | 봉맥인 | 만경고정 |

WASD/방향키 이동 · J 기본 검격 · K/L 공통 무공 · Space/Shift 회피 · E 상호작용 · 1 회복약 · I 장비 · M 지도 · Esc 메뉴. 모바일은 화면 버튼과 조이스틱을 사용합니다. 오의 기세는 실제 적 타격과 기연 행동으로 모읍니다.

## 저장 / 성능
저장 v4이며 v1~v3를 읽습니다. 획득 무공·이야기·실제 행적은 유지하고 재접속하면 거점에서 시작합니다. 진행 중인 임시 시험과 미완료 던전은 초기화합니다. 브라우저 간 자동 동기화는 없으며 메뉴의 저장 파일 내보내기/불러오기를 사용합니다.
이펙트 낮음/보통/높음과 화면 효과 줄이기를 유지합니다. 실제 저사양 기기의 장시간 프레임·배터리는 아직 검증하지 않았습니다.

## 개발
`npm run check`, `npm test`, `npm start`. 런타임 패키지 설치가 필요하지 않습니다.

브라우저 검사는 개발 환경에서 Playwright 1.57.0 + Chromium을 설치하고 서버 실행 후 진행합니다.
```sh
python tests/browser_smoke.py --url=http://127.0.0.1:3000/
python tests/fate_browser.py --url=http://127.0.0.1:3000/
python tests/legend_browser.py --url=http://127.0.0.1:3000/
```
GitHub Actions가 전체 테스트를 통과해야 Pages를 갱신합니다. 사이트에는 13개 게임 파일과 build-info.json만 배포하고 개발 문서/테스트/서버를 제외합니다.
