## v0.10.1 — 알림·전투·입력 개선

- 플레이 HUD의 제작 검수 배너를 제거했습니다. 후보 아트의 실제 검수 상태는 개발용 아트 검수 화면에 남아 있습니다.

- **첫 계승 공지**: 파문검·잔영보·경계봉인은 계열별 첫 수락 시 약 7초간 상단 공지를 표시합니다. “이 여정의 첫 계승 · 싱글플레이 연출”이며, 불러오기·재수련 시 반복하지 않습니다.
- **현실 반복 의뢰**: 첫 D급 균열 공략 후 현실 기지의 **현장 의뢰** → **의뢰 수주**. 균열 잔당 4명 처치 → 기지 귀환 → **보상 수령**으로 금화 80 / 경험치 100 / 마정석 2를 받습니다. 반복 시 적 체력·피해가 5%씩 최대 50% 강화됩니다. 본편 진행·클리어 횟수는 변하지 않습니다.
- **안내 수정**: 무공 해석의 “이어가기”를 “이 해석 장착”으로 바꿨습니다. 장착 후에는 귀환·본편을 안내하며 운기조식을 퀘스트 목적지로 표시하지 않습니다.
- **화면 간소화**: 채팅형 소식창·다른 여정·AI 전투 동행을 제거하고 도겸의 조언은 유지합니다.

의뢰 완료 전 후퇴·쓰러짐·전투 저장 불러오기는 보상 없이 의뢰를 중단합니다. 완료 후 아직 받지 않은 보상은 저장됩니다. 현재 현실 성장 콘텐츠는 반복 의뢰 1종이며, 공식 헌터 승급·정예/방어 의뢰는 후속 범위입니다.

기획 기준: [상세 플레이 기획서 v2.1 개편안](docs/superpowers/specs/2026-10-01-growth-discovery-design.md). 원본 v2.0 DOCX는 수정하지 않았습니다.

## v0.9에서 유지하는 개선

- 현재 세계 주인공의 모든 기본 동작을 로드·디코딩한 뒤 조작을 허용합니다. 세계 전환에도 적용하며 실패 시 재시도할 수 있습니다. 최적화된 주인공 아틀라스는 세계당 약 57 MiB의 디코딩 메모리를 사용하고, 현재 세계 동작을 128 MiB 이미지 캐시 안에 유지합니다.
- 7장면 인트로와 5장 원화, 청운촌 응급처치·부축, 건너뛰기·이어하기·진행을 보존하는 회상을 추가했습니다.
- 성장 화면을 상태 / 무공 / 행적으로 통합하고 능력치 출처, 발견·계승·해석 상태를 구분합니다. 계열별 첫 계승 공지만 한 번 표시합니다.
- 기본 입력을 오른손 배치로 바꾸고 메뉴에 키 변경·충돌 교환·기존 배치를 제공합니다. 아래 이전 버전 설명의 Q/R/F는 새 기본 배치 U/O/P에 대응합니다.
- E급 개인 등급과 C급 현장 인증을 구분하고 주요 대사·전승·선택 탐험 안내와 실제 귀환 판정을 보정했습니다. 당시 저장 형식은 v7이며 이전 진행을 유지합니다.

로컬 프로토타입: PowerShell에서 `$env:ART_REVIEW='1'; npm start` 후 `http://127.0.0.1:3000/art-play.html`. `npm test`, `npm run check`로 회귀 검사를 실행합니다. Playwright와 Chrome이 설치된 환경에서는 `node tests/v09.browser.cjs`로 실제 브라우저 흐름을 검사합니다.

## 이번 여정: 관찰이 먼저, 이름은 나중에
공통 무공을 배운 뒤 청운촌 남동쪽 **환서정**에 선택적으로 방문할 수 있습니다. **D 기감 / Tab 관찰 수첩**을 사용하세요. 모바일에는 기감·수첩 버튼이 있습니다. 기감으로 드러난 물건을 G로 조사하고, 파동이 모일 때 공격·회피·석판·수로의 반응을 직접 살펴보세요.

물건을 읽는 것만으로 기술이 지급되지 않습니다. 여정별로 세 물건의 위치가 달라지며, 저장·재접속 시 같은 배치를 유지합니다. 모든 여정에서 모든 주요 해석에 접근할 수 있습니다. 기록에는 확인한 장소·현상만 남기고 숨은 조건의 남은 횟수는 표시하지 않습니다.

## 같은 무공의 여섯 해석
새 직업 여섯 개가 아니라, 기존 세 기연 계열의 Q/R 운용을 바꾸는 선택지입니다. 해당 계열을 이미 익혀야 사용할 수 있으며 기존 기술은 삭제하거나 약화하지 않습니다. 해석 발견 시 수락/보류가 가능하고, 환서정 또는 거점에서 무료로 바꿉니다. 거점에서는 기본 운용으로 돌아갈 수도 있습니다.

| 계열 | 해석 | 실제 변화 |
|---|---|---|
| 파문검 | 역파 · 반전검 | R 뒤 다음 기본 공격에 전방 관통 검격. 빗나가도 축적 소모 |
| 파문검 | 잔파 · 수호진 | Q에 4초 수호 공간. 안의 플레이어 피해 감소 |
| 잔영보 | 회향 · 귀환보 | R 귀환점 원형 검격과 짧은 무적 |
| 잔영보 | 먹향 · 재현검 | 돌아가지 않고 잔향에 0.45초 뒤 검격을 맡김 |
| 경계봉인 | 정박 · 불동인 | Q 결계 6초 유지, 실제 공격 예고를 속박 |
| 경계봉인 | 유전 · 도류인 | R에 방향 유도. 끊은 공격 기운을 주변으로 흘림 |

## 제5장 · 기록에 없는 귀환자
제4장 최종 보고를 마친 뒤 **현실 서린에게 대화**하면 시작합니다. 환서정의 기록과 현실의 관측이 왜 다른지 확인합니다. 연화는 실제로 자신을 구한 방식에 맞춰 후일담과 글을 남깁니다.

발견한 해석을 받아들여 서린에게 돌아오면 **공명 관측소**가 열립니다. 관측 장치 가까이에서 기감을 펼치고, 새 해석의 실제 효과를 적에게 사용해 몸의 기록을 재현하세요. 그 후 보스를 제압하고 서린에게 보고하면 **C급 현장 인증**이 남습니다. 먼저 적을 모두 처치했더라도 입구의 잔류 파형으로 다시 재현할 수 있습니다. 잔류 파형은 숙련·금화·전리품을 주지 않습니다.

도겸은 현장 조언 NPC입니다. AI 동행과 지원 사격은 제거했으며, 기술 재현은 플레이어가 직접 수행합니다.

## 성장과 현실 전리품
- 실제 전투에 쓰인 공통 무공과 세 기연 계열에 숙련이 남습니다. 각 항목은 30까지, 한 적/행동에는 제한된 횟수만 기록하며 허공 사용과 임시 시험으로 성장하지 않습니다.
- **유수심법**은 공격 사이 호흡을 고르면 내력을 더 회복하고, **집중심법**은 잠깐 호흡 뒤 첫 직접 검격에 내력 6을 써 힘을 모읍니다. 거점에서 무료 변경합니다.
- 숙련 합계 8, 두 세계의 실전, 직접 발견한 해석이 모이면 거점에서 **첫 경지 돌파**가 가능합니다. 레벨과 별개로 체력 +12, 내력 +8, 공격력 +2가 남습니다. 이번 범위는 첫 돌파 하나입니다.
- 무림 일반 적 16 / 보스 110, 현실의 기존 재료 지급 적은 46 / 보스 200금화를 줍니다. 반복 의뢰는 처치 16씩 4명과 보고 76으로 총 140금화, 보고 경험치 100입니다. 기감 범위는 모두 340입니다.

## 화면 정리

상시 채팅형 소식창과 다른 여정 탭은 제거했습니다. 직접 겪은 사건은 성장 → 행적에 남으며, 계열별 첫 계승은 상단 공지로 강조합니다. 실제 서버 최초나 다른 유저에게 방송하는 기능은 아닙니다.

## 조작 / 저장 / 성능
방향키 이동 / A 공격 / Q·W 공통 무공 / E·R 기연 무공 / F 오의 / S·Shift 회피 / G 상호작용 / D 기감 / Tab 관찰 수첩 / 1 회복약 / I 성장 / M 지도 / F1 도움말 / Esc 메뉴. 메뉴의 입력 설정에서 변경할 수 있습니다.

저장 version 9이며 v1~8을 읽습니다. 이전 진행·무공·제4장 결과는 유지하고 없던 개인 관찰 기록을 만들어 넣지 않습니다. 기존 지역은 재접속하면 안전한 거점에서 시작하며, 6·7장의 신규 지역은 검증된 진입점에서 현재 단계를 재도전합니다. 잔향·수호진·진행 중 실험 같은 일시 상태는 초기화합니다. 브라우저·기기 간 자동 계정 동기화는 없으므로 저장 파일 내보내기/불러오기를 사용하세요.

`?perf=1`에서만 성능 진단을 표시합니다. 값은 로컬 메모리에만 있고 서버로 보내지 않습니다. 모바일 화면 효과 옵션과 기존 자동 품질 저하도 유지합니다.

## v0.8.0 당시 변경 이력 (소식·모집 UI는 v0.10에서 제거)
이번 버전은 새 챕터 대신 A~F의 플레이 표현을 개선합니다. 기존 12지역·5장·저장 version6을 유지합니다.

- 실제 이동 거리로 다리의 보행 주기를 갱신하고, 손/검/검기의 위치·방향을 같은 동작 시점에서 계산합니다. 공격의 기존 피해 판정·쿨다운은 유지합니다. 기존 그림을 분절해 움직이는 방식이며 새로운 8방향 손그림 프레임 전체를 만든 것은 아닙니다.
- 현실은 평지붕·유리·콘크리트·도로/횡단보도·전술복·드론/침식체, 무림은 기와·목재·자연·도포 인물을 사용합니다. 색만 바꾸는 대신 별도 렌더러로 분리했습니다. 현대 보급소의 대화 초상도 구분합니다.
- PC는 좌상단 인물/체력, 우상단 지도/목표, 하단 기술, 우측 소식의 먹색/남청색·금색 프레임으로 정리합니다. 모바일은 소식과 도움말을 전투가 멈추는 별도 창에서 읽습니다.
- 세계간 포털에는 도착할 세계의 실루엣, 입자, 문틀, 목적지를 표시하고, 지역 출입구와 크기/모양을 구분합니다.
- **H / 도움말**에서 **길잡이 켜고 직접 해보기**를 누르면 현재 가능한 단계와 목적지를 안내합니다. **B 기감 → 가까이 E 조사 → N 수첩 → 물건의 현상에 반응**을 실제 상태에 따라 설명합니다. 안내를 끄거나 다시 켤 수 있으며, 도움말만 읽었다고 기연을 지급하지 않습니다. 선택 탐험의 정답 힌트는 요청한 길잡이에서만 보여 줍니다.
- 소식의 **전체 / 월드 / 서버 / 모집 / 시스템** 탭 모두 **“실제 멀티 채팅이 아닌 연출 시뮬레이션입니다.”**를 표시합니다. 모집은 AI 도겸 동행 안내이며 실제 매칭이 아닙니다. 실제 메시지 전송·접속자 수·외부 채팅 통신은 없습니다. 최근 소식은 현재 여정의 실제 사건만 표시합니다.

전체 맵의 새 손그림 원화, 새 인물의 모든 전용 애니메이션 프레임, 실제 멀티플레이는 이번 범위가 아닙니다. 컨셉 이미지의 정보 배치/분위기와 세계 구분을 적용한 플레이 가능한 프로토타입입니다.
