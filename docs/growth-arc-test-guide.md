# v0.12.4 첫 성장 개선 · 테스트 안내

이 문서는 새 성장 흐름이 적용된 v0.12.4 기준이다. 공개 게임에서 버전 표시가 v0.12.4인지 확인한 뒤 테스트한다.

## 테스트 시작 상태
- 새 게임 또는 기연을 아직 계승하지 않은 기존 저장: 새 흐름을 적용한다.
- 기존 저장에서 Q/R/F를 이미 계승한 캐릭터: 기술과 이전 전장 수치를 보존한다. 첫 Q 잠금 테스트는 새 캐릭터로 진행한다.
- 기존 저장이 이미 3장 기연 조사에 진입했다면 해당 조사를 이어간다. 완료한 이야기를 강제로 되돌리지 않는다.

## 실제 플레이 순서와 개선 표시
| 순서 | 장소·행동 | 확인할 변화 |
|---|---|---|
| 1 | 2장 항만 위협 제압 → 현실 기지 서린과 대화 | **개선** 검격 흔적만 보고 기연을 받으러 가는 대신, 귀환 통로의 새 파형을 재조사한다. 1·2장 승리는 유지된다. |
| 2 | 현실 던전 입구 → 「균열 재조사 · 귀환 통로 방어」 → 입장 | **신규** 최대 12초 대응. 적을 모두 정리하면 최소 3초 뒤 압력 때문에 철수한다. 무적의 적을 때리는 구조가 아니다. |
| 3 | 철수 장면 → 현실 기지 서린에게 보고 | **신규** 통로 방어는 실패하지만 대응 횟수가 회수 시간을 확보한 행적으로 남는다. 사망 재시도나 금화·경험치 손실이 없다. |
| 4 | 청운촌 백련과 대화 → 무림 탐험지 입구 → 무명 비경 | **개선** 실패한 압력을 다룰 원리를 찾는다. 세 흔적 중 하나를 직접 시험한다. |
| 5 | 흔적 조사 → 공명 시험 시작 → Q 대응 성공 → 기본 공격으로 잔상 제압 | **개선** 파문은 받아내기, 잔영은 예고에서 이탈, 봉인은 예고 억제. Q만 사용할 수 있다. R/F는 미습득이다. |
| 6 | 청운촌 백련에게 증명한 기연 수락 → 현실 귀환 | **개선** Q만 체득. 첫 정상 귀환 시 현실 Q를 자동 장착하고 적응된 기술 이름을 보여 준다. 기존 다른 장착은 덮어쓰지 않는다. |
| 7 | 서린과 대화 → 현실 던전 입구 → 경계의 심장 | **개선** 호위 제압 → 두 매듭 E로 해제 → 포식자의 통로 압력에 Q로 실제 대응 → J/K/L로 마무리. Q를 허공에 쓰면 증명되지 않는다. |
| 8 | 3장 보고 → 4장 구조와 귀환 부두 완료 → 서린에게 보고 | **유지·보완** 기존 구조 이야기와 수동 권양기 우회로 유지. 잔영 계열은 Q로 교각 울림을 벗어나는 방식으로도 구조할 수 있다. |
| 9 | 청운촌 백련과 대화 → 별도 Q→R 실습 | **신규** Q 준비 효과를 실제로 만들고 R을 잔상에 적중시키면 체득. 대화만으로 R을 지급하지 않는다. |
| 10 | 5장 해석 진화 → 6장 무료 심법 심화 | **유지** 기존 두 세계 성장·해석·실전 연계를 이어간다. |
| 11 | 7장 공동 대응 → 천흔 중심부 위협 제압 | **개선** 실전 완료 상태가 확인되면 F를 체득한다. 기세 100에서 사용한다. 기존 대피 통로/정예 차단 준비 선택은 이 7장에 유지한다. |

## 몬스터 조정
새 성장 흐름에만 적용하며, 플레이어 레벨에 따라 추가로 오르지 않는다.

| 지역 | 체력 | 피해 | 이유 |
|---|---:|---:|---|
| 통로 재조사 | 적 3명, 각 80 | 각 12 | 짧은 대응·철수 장면. 처치 금화/경험치를 지급하지 않는다. |
| 경계의 심장 | 기존 생성값 × 0.85 | 기존 생성값 × 0.85 | Q·기본 공격·K/L만으로 첫 재도전을 진행한다. |
| 청운 귀환로 | 기존 생성값 × 0.85 | 기존 생성값 × 0.90 | R 이전 구조 구간의 전투 부담을 줄인다. |
| 귀환 부두 | 기존 생성값 × 0.85 | 기존 생성값 × 0.90 | Q 중심 운용에 맞춘다. |
| 다른 지역 / 기존 계승 저장 | 기존 수치 | 기존 수치 | 기존 후반 밸런스와 전장 저장을 보존한다. |

## 반드시 확인할 항목
- 문서의 Q/R/F는 첫 기연/후속/오의 슬롯 이름이다. 입력 설정의 프리셋에 따라 실제 키가 바뀌므로 화면 버튼의 키 표시를 따른다.
- 파문/잔영/봉인 각각 첫 시험을 Q만으로 끝낼 수 있는지.
- 현실 Q의 성공이 이전 실패와 연결되어 느껴지는지. 허공 사용은 진행 조건이 아니다.
- 공격과 회피의 대응이 철수 기록에 남고, 철수 후 금화·경험치가 유지되는지.
- 체득 이후 R/F 잠금 문구와 실제 사용 조건이 일치하는지.
- 잔영 구조는 울림의 가장자리에서 바깥쪽을 향해 Q로 이탈한다. 중앙에서 막힌 교각 쪽으로 돌진하면 성공하지 않는다. 수동 권양기 우회도 남아 있다.
- 철수 시도 도중 저장은 시간을 처음부터 재시작한다. R 실습 도중 저장은 기존 시험과 동일하게 마을에서 실습을 재시작한다.
- 조정된 전장 저장/로드에서 적 최대 체력, 처치·매듭 상태가 바뀌지 않는지.
