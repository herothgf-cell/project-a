# v0.12.0 세계별 성장·전투 출시 검토

## 구현과 저장

현실·무림의 레벨/경험치/숙련/장착/운용을 분리하고, 무림 영구 성취의 미반영 항목만 현실 귀환에 정착한다. 원본 v1 저장은 읽기 전용이며 v0.11.0 보관판은 복사본, 개편판은 v10, localhost 개발 시작점은 test.v10 슬롯을 사용한다. 이전 기록을 임의 분배하지 않는다.

성장 첫 화면의 심법·돌파, 초상화의 현재 세계 상태, 현실 대응 장착과 소식/레드닷을 연결했다. 새 판에는 현장 의뢰와 구 강화 환급 UI가 없다. 보고 전 NPC가 무림 사건을 아는 대사를 분리했다. 후반 장 보상은 현실/무림 경험치를 각각 명시한다.

## 검사 기록

- Node 단위/통합 검사 522개 통과. 새 게임부터 5장·6장까지 세 계열, 7장은 세 계열×두 운용 조합의 실제 모델 효과·처치·보고와 저장 복원 검사 포함. 이동과 적 배치는 테스트에서 배치하므로 사람의 무보조 완주 기록이 아니다.
- Python 기존 7종은 고정 보관판의 기존 규칙을 검사한다. 세계 전환 선로딩 완료 후 입력하도록 테스트 대기를 보완했으며 대화는 마지막 페이지까지 넘긴다.
- JS 브라우저 19종 통과. 구 성장 트리/경제/이야기 회귀는 보관판, 입력·길 안내·대화·새 저장·현실 기술·소식/성장 화면은 개편판 대상으로 나눴다. 개편판에서 아트 실패 후 재시도, 저장소 용량 실패 시 기존 원문 보존, 세 계열 5/6장 저장 이어하기를 별도 확인했다.
- 로컬 시작점 HTTP 접근 제한과 공개 빌드 제외, 최신/보관판 런타임 포함 및 자산 해시 검사 통과. 공개 배포 완료 여부는 Pages 작업과 공개 build-info 검증으로 별도 확정한다.
- Chrome 데스크톱 및 390×844, 360×640, 844×390 화면, 확대 글씨, 실제 프레임의 원거리 예고를 확인했다. 실물 휴대폰·저사양 기기 성능이나 사람이 느끼는 재미를 보장하는 검사는 아니다.

## 전투와 아트 판단

같은 적과 입력 기회로 측정한 전후 값은 [밸런스 검토](world-growth-balance-review.md)에 기록했다. 자동 입력에서는 대응 사용 후 받은 피해가 18→0, 전투 시간 1.75→1.40초였지만 전체 난이도/재미 평가는 후속 실제 플레이 피드백이 필요하다.

- **이번 시제품에 필수인 추가 이미지 없음:** 흡수 대기 원, 이동 경로/잔상, 단일 대상 억제 연결선과 지속 표시, 강타·원거리 예고를 코드로 표시한다. 억제 기술에 무림의 광역 결계 이미지가 재생되던 표현은 대상 한 명의 표시로 분리했다.
- **추가 제작 권장:** 현실 전용 흡수·가속·억제 동작, 후속 타격과 오의의 고유 동작, 현실 전용 스킬 아이콘. 현재 캐릭터 동작은 기존 공격·시전·회피 아틀라스를 재사용한 임시 표현이다. 기존 월영참/천뢰격 글자 아이콘도 새 기본 현실 기술의 전용 그림으로 교체하면 세계 구분이 더 명확해진다.
- **재사용 가능:** 현재 지역 배경, NPC 초상화, 몬스터 원화. 압박/강타/원거리는 현재 같은 원화를 역할·예고로 구분하므로 정식 품질에서는 역할별 실루엣 변형을 권장한다.
- 사용자 미추적 아트 후보와 Unity 파일은 변경·배포 대상에 넣지 않았다. 새 이미지는 제작하지 않았다.

## 릴리스 경계

독립 검토의 중요 문제 5건을 재현 테스트 후 수정했다: 후반 지역 저장 복원 시 군집 유지, 한 세계 레벨 상한과 무관한 양쪽 장 보상, 비교 체험의 영구 숙련 보상 차단, 현실 오의의 자기 기세 환급 차단, 소식에서 실제 해석 상세로 연결 및 읽음 상태 공유. 최종 브라우저 검사에 소식 상세 회귀를 추가했다.

### 구현 중 판단과 검증 한계

- Git-bash 전용 스킬 스크립트 대신 PowerShell/Node로 같은 검증을 실행했다. 해당 스킬 스크립트 자체는 검증하지 않았다.
- 새 제목/저장 슬롯 연결은 저장 형식 10 구현과 함께 작업했다. 첫 작업 커밋 단독으로는 새 진입 UI 검증을 포함하지 않는다.
- 비교 전투는 첫 측정부터 피해 감소 기준을 충족했다. 실패 결과를 인위적으로 만들지 않았으므로 개선 전 실패 측정은 없다.
- 로컬 장 시작점은 전체 여정 검증 도우미와 함께 마지막 통합 단계에서 구현했다. 전투 작업 커밋 단독에는 해당 도구가 없다.
- 자동 검사로 실물 저사양 기기 성능과 재미를 확정하지 않는다. 실제 플레이 피드백이 추가로 필요하다.
- 코드 검토와 공개 배포 검증을 분리했다. Pages 성공 및 공개 런타임 해시 확인 전에는 배포 완료로 보지 않는다.

### 후속 보완

- minor (deferred): 5장 이후 늦게 연화의 귀환을 확인하면 서린에게 해당 부가 사실을 보고하는 대화가 열리지 않는다. 필수 진행은 막지 않으며 후속 대화 보완으로 남긴다.

2026-10-01 원격 main 확인 시 추가 원격 커밋 없음. 최종 독립 검토와 승인된 파일 커밋 후 main을 푸시하고 기존 GitHub Pages 파이프라인으로 배포한다. 이 문서만으로 공개 배포 완료를 주장하지 않는다.
