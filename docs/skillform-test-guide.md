# 무공 조합 수련장 테스트

2026-10-13 · 로컬 개발 실험. 기본 초식 제작, 세 연계와 현실 적용을 기존 전투 규칙으로 시험한다. 본편 이야기와 저장 데이터에는 반영하지 않는다.

## 실행

저장소에서 `npm run start:skillform` 또는 `node scripts/start-skillform.cjs`를 실행하고 아래 주소를 연다.

<http://127.0.0.1:3103/__dev/skillform?dev=1>

포트를 바꾸려면 PowerShell에서 `$env:PORT='3104'`를 지정한 뒤 실행한다. 기존 개발 게임 화면에도 ‘무공 조합 실험’ 링크가 있다. 일반 서버와 공개 빌드에는 실험 페이지가 포함되지 않는다.

## 권장 시험 순서

1. **월영참**: 형 ‘베기’ → 기 ‘기본 운기’ → 운 ‘즉시 전개’ → 의 ‘전방 범위’를 선택한다. ‘초식 구성 저장’ → ‘기본 초식 시험’ → **K**로 적중하면 체득한다.
2. 새 계열 선택 → ‘원리 배우기’ → 화면의 표준형 네 요소를 직접 구성한다. ‘기본 초식 시험’에서 **Q**로 실제 예고에 대응하면 체득한다.
3. ‘실험 숙련’을 **3성**으로 설정하면 세 연계를 모두 시험할 수 있다. ‘연계 초안 저장’ → ‘무림 연계 시험’ → **Q 대응 후 K 검격**으로 원리를 증명한다.
4. ‘현실에 적용’ → ‘현실 연계 시험’에서 같은 원리가 다른 세계에서도 작동하는지 본다. ‘현실 기본형 비교’는 **Q 대응 후 K 또는 J 적중**까지 진행한다. 받은 피해·타격 횟수·내력 사용·시간이 기록된다.

| 기본 초식 | 형 / 기 / 운 / 의 | Q의 성공 조건 | 월영참과 연결한 결과 |
|---|---|---|---|
| 파문세 | 받아내기 / 반탄기 / 충격 축적 / 자신 중심 | 붉은 예고가 끝나기 약 0.5초 전 Q로 받아내기 | 반류일선: 받은 충격을 전방 직선의 최대 두 적에게 방출 |
| 잔영각 | 보법 / 잔향 / 순간 전개 / 출발점에 흔적 | 예고가 끝나기 직전 Q로 원 밖을 벗어나기 | 유영잔참: 떠난 위치에 지연 검격. 현재 위치의 검격은 포기 |
| 쇄경진 | 진법 / 봉합기 / 유지 / 지정 지점 | 적이 공격을 예고하는 동안 Q로 끊기 | 이맥봉류: 억제한 적을 K로 치고 다른 적에게 남은 억제를 최대 2초 전이 |

잔영각은 먼저 조준한 방향으로 이동한다. 현실 기본형의 검격은 현재 위치에서 나가므로 Q 이후 적을 향해 다시 조준하거나 방향키로 돌아선다. 유영잔참은 출발점을 공격하므로 적을 등져도 그 자리에 적이 있어야 적중한다.

## 조작과 제한

- 방향키/WASD 이동, 마우스 조준, Q 준비, K 검격, J 일반 공격, Space 회피. 모바일은 전장 아래 방향·기술 버튼을 사용한다.
- Esc 일시 정지. 창을 벗어나면 자동 정지하며 전장을 클릭하거나 기술 버튼을 누르면 계속한다.
- 미학습 요소·불호환 조합은 이유를 표시하고 저장하지 않는다. 각 축 하나, 기본 원형 하나, 체득한 기본 초식 두 개의 연계만 허용한다. R/F 및 연계끼리의 중첩은 불가하다.
- 반류일선은 1성, 유영잔참은 2성, 이맥봉류는 3성부터 연결한다. 실험은 1·3·5성 설정을 제공하며 숙련에 따라 조정 폭을 제한한다. 숙련을 낮춰 조건을 잃은 연계는 초안·증명·현실 적용을 해제한다.
- 네 기본 초식과 세 연계는 계열마다 한 개씩 보관한다. 변경은 기존 초안을 대체한다. 전투 중에는 편집할 수 없다.
- 체력 **180**, 적 피해 **6**, 공격 예고 **1.6초**, 내력 **100 / 초당 12 회복**. 재시도는 무료이며 실패해도 배움은 남는다. 처치·조합으로 본편 재화나 숙련을 얻지 않는다.

## 저장과 구현 범위

브라우저의 `dualworld.experiment.skillform.v1`에 실험 진행만 저장한다. 손상된 원문은 자동으로 덮어쓰지 않는다. ‘실험 초기화’는 확인 후 이 키만 초기화한다. 새로고침 시 전투 준비 효과와 예약 검격은 복원하지 않고 거점으로 돌아온다.

기존 WorldGame/FateRules/RealitySkills를 별도 인스턴스에서 실행한다. 이번 범위는 독립 수련 UI·전장이다. 본편 1~3장 사건 재작성, 기존 저장 가져오기, 장기 숙련 파밍, 1~9성 전체 성장, 모든 자유 조합은 포함하지 않는다. 이 제한은 기획서 전체가 제품에 통합되었다는 뜻과 구분한다.

## 검증

- `node --test tests/*.test.cjs`: 기존 게임 회귀 및 제작/저장/전투/개발 경로 검사.
- `npm run test:browser:skillform`: Playwright와 Chrome 필요. 실제 UI 입력으로 월영참, 세 기본 초식, 세 무림·현실 연계, 기본형 비교, 모바일, 저장 실패·손상·초기화 격리를 검사한다.
