# v0.7 검증 및 구현 경계

## 기반과 요구
원격 main a25872353ee7949086b74b5a3faffd3bc1a0afad, tree 7cd0007ff970fdf7fe5f24ab6161b489413db7dd를 확인하고 동일한 로컬 트리에서 시작했다. 사용자 제공 「로그인 무림 상세 정리」의 발견·성장·두 세계 연동 구조를 재해석한 오리지널 쌍계 콘텐츠다. 원작 사건/인물/능력 목록 전체를 옮기거나 원작의 모든 사실을 검증한 작업은 아니다.

## 검증 방법 구분
로컬 Chromium의 http://127.0.0.1:3000/ 탐색은 ERR_BLOCKED_BY_ADMINISTRATOR로 차단되어 재시도/우회하지 않았다. 로컬 UI는 인라인 문서 + 저장 shim으로 검증한다. GitHub Actions는 동일한 런타임을 일반 HTTP와 native localStorage로 6개 suite 모두 검사한다. 상태 준비에 모델 fixture를 사용하고 입력/DOM/충돌/저장 결과를 검사하는 자동화이며 무보조 전체 수동 플레이 인증은 아니다. 배포 후 검사도 공개 주소의 실제 바이트/버전 검사이며 실제 기기의 장시간 플레이 인증과 다르다.

## 유지와 한계
성능 HUD는 ?perf=1 전용이며 개인정보/플레이 내용을 전송하지 않는다. 이전 시각효과/캐시/자동품질저하를 유지한다. 아트는 기존 무협 그림에 게임 내 물건과 이펙트를 추가한 것으로 전체 지역 원화/완전한 방향별 프레임 작업이 아니다. 별도 리뷰 에이전트가 없어 작성자가 자체 검토했다. 온라인 서버/유일 직업/접속자/실시간 유저 채팅/거래소는 없고 게임 안에 시뮬레이션임을 명시했다. 숙련은 제한된 4항목, 경지는 첫 돌파, 등급은 이번 C급 현장 인증 하나다. 장기 난도/경제 밸런스와 실제 Android/iPhone 발열/배터리는 미검증이다.
