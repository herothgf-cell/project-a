# v0.6 통합 검증

기준 main: 51ca33f9dc76728e809e19501117773d044e1bb7.
성능 진단 브랜치: 865b4172364a69bf0181b78a25534ee80f5ec84d.

이전 게시 작업은 Node 101개와 HTTP 브라우저 30개 시나리오 묶음까지 통과했으나, 후보 Git tree 생성에서 HTTP 403으로 중단되어 main과 배포가 갱신되지 않았다. 이번에는 이미 검증한 v0.6 파일의 Git blob 해시를 확인해 복구하고, 성능 진단 브랜치의 변경을 3-way로 합쳤다. Actions는 테스트와 blob 출력만 담당하고, 최종 커밋과 main 갱신은 연결된 GitHub 쓰기 도구로 처리한다.

통합본 검사: npm run check, npm test, browser_smoke.py, fate_browser.py, legend_browser.py, v06_browser.py, perf_browser.py를 모두 성공한 뒤 이 문서를 생성했다. 브라우저 검사는 HTTP와 실제 localStorage를 사용하며 데스크톱 및 390x844 / 360x640 / 844x390 터치 화면을 포함한다. 테스트 준비를 위해 게임 상태를 설정하므로 무보조 전체 수동 플레이 인증은 아니다.

기본 URL과 ?perf=0에는 진단 HUD가 없고 ?perf=1에서만 평균/최근 프레임 시간, 느린 프레임 누적, 자동 품질 저하 여부, 품질, viewport와 DPR이 표시된다. 값은 메모리에만 유지하며 개인정보와 플레이 내용을 수집하지 않는다. 기존 자동 품질 저하 판단은 변경하지 않는다.

v0.6에는 무협풍 인물과 다섯 시점/반전을 조합한 8방향 표현, NPC 초상, 제4장 끊긴 귀환로, 구조 결과에 따른 길/인물/다음 현실 전투 변화, NPC 소식 시뮬레이션이 포함된다. NPC 소식은 실제 유저 채팅이 아니다. 모든 방향의 프레임별 손그림 애니메이션은 아니며 일부 배경은 벡터다.

실제 저사양 Android / iPhone Safari의 장기 프레임, 발열, 배터리 소모는 미검증이다. 배터리 값은 이 HUD가 측정하지 않는다. Pages 배포 성공은 이 문서 생성 이후 별도로 Actions와 배포된 build-info.json에서 확인해야 한다.
