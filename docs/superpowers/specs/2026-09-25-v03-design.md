# 쌍계 v0.3 — 안내, 액션, 세계 확장

## Intent and authorization
The user explicitly delegated scope and implementation: improve guidance/combat first, then replace graphics and add a new chapter, on the existing main/Pages project. No intervening approval round is requested. Existing saves and play URL must survive. Base main: 0beef1fa46235f6bcac55bea89e2beac2e86a698.

## Design decisions
Keep a zero-dependency static HTML/Canvas game, not Unity or a framework migration. Use original illustrated vector scenery rather than network-dependent images. Replace primitive circles with animated humanoids, distinct roofs, roads, bamboo, temple ruins and harbor infrastructure. Six areas, two chapters. Retain Korean text and keyboard/touch parity. No multiplayer, paid hosting, accounts, or external analytics.

## Phase A: playable first chapter
Repair boss HUD selector and enemy label; state-aware objective, compass, off-screen marker; explicit return/report action after victory. Three-hit combo, directional sword arcs, different moon/thunder effects, damage text, hit flash, boss telegraph and guard shield; cooldown and mana feedback. Hold attack, independent multi-pointer joystick/attack, clear input on dialogs, blur, cancel and visibility loss. Pause while hidden or dialog open. Save migration and corruption preservation. Hub supplies and upgrades make gold useful.

## Phase B: visual replacement
Six coherent illustrated maps with walkable roads and solid building footprints, Y-sorted character/environment drawing. Hero, manager, mentor, bandits, spirits, masked guardians and named bosses have distinct silhouettes. Design style: midnight jade/gold illustrated wuxia adventure; no original webtoon assets. UI: narrow journal rail, uncluttered playfield, touch controls, readable text, responsive portrait/landscape. Mini-map and full map identify the same objective. Reduced motion setting disables shake and ambient motion.

## Phase C: Chapter 2 / 잔월의 서약
Progress 0..6 remains compatible. At 6 report to 서린 to begin 7; at 7 visit 백련 to enter 8. In 월영 폐사 (ruins), clear guardians, activate 3 seals, defeat 월영 수문장 →9. Report to 백련 →10 and learn passive 경계 공명 (training 3; stronger shared attack and 15% incoming reduction). Return to 서린 →11, unlock 침식된 항만 (harbor). Clear guardians, disable 2 anchors, defeat 흑조 집행관 →12. Victory result offers return and next objective. Replay old dungeons never regresses progress. Ruins/harbor objects are encounter-local; defeat/retreat resets encounter, quest milestones remain. This explicit reset is explained on retreat.

## Contracts
`world.js`: AREAS, QUESTS, SKILLS, VERSION constants; immutable content definitions.
`game.js`: DOM-free Game, stats(), target() always {label,x,y,id}, objective(), enter(), interact(), act(), step(), buy(), retreat(), save(), static load(). Effect lifetime owned by game, never renderer.
`render.js`: WorldRenderer draws model only; cached terrain, camera, mini-map, screen target marker.
`app.js`: DOM, dialog queue, input, autosave, accessible buttons; no test-only hooks.
Saved key stays dualworld.save.v1. Version 1 accepted, version 2 exported. Safe-hub resume. Invalid data must not be overwritten until explicit new-game confirmation. Back up imported/migrated save. Max level 80, upgrades 10, potions 99; resource ranges validated.
