# 「쌍계 홀로 건너는 사람」 게임 스토리 교체안

상태: 구현 전 검토안. 게임 코드와 공개 배포는 변경하지 않았다.

## 기준과 목적

기준 원고는 [쌍계 홀로 건너는 사람](../../ssanggye-exclusive-worlds-story.md)이다. 함께 확인한 [개작 검토](../../ssanggye-exclusive-worlds-review.md)는 설정의 의도를 설명하는 보조 자료다. 파일 수정 시각 기준으로 기존 확장 원고보다 뒤에 저장되었고, 사용자가 최근 대화에서 교체 기준으로 지정한 원고이기도 하다. 이전 검토 이후 새로운 판본이 생겼다는 의미는 아니다.

현재 배포 커밋 d14cb2a에는 이 원고의 전면 교체가 아직 반영되지 않았다. 이번 작업은 원고를 다시 고치는 작업이 아니라 게임의 이야기와 진행을 원고에 맞추는 작업이다. 원고 자체는 보존한다.

유저가 확인할 결과는 다음과 같다.

- 윤서만 자취방과 폐사당을 왕래한다. 현실 인물은 끝까지 무림을 알지 못한다.
- 새로운 11장 이야기를 시작부터 결말까지 플레이할 수 있다.
- 무공 습득·창안·현실 적용과 최근 추가한 여섯 항목은 유지된다.
- 기존 저장의 무공·성장·재화는 사라지지 않는다. 새 이야기 완료나 보상은 자동 지급하지 않는다.
- 개발용 순차 테스트는 계속 로컬에서만 제공한다.

## 보존할 무공 규칙

월영참·천뢰격·파문세·잔영각·쇄경진, 반류일선·유영잔참·이맥봉류를 보존한다. 섬광검·횡월검·축기결·측행보와 축산참·주작측검도 그대로 보존한다. 형·기·운·의를 직접 선택하며 구성 즉시 습득한다. 선택 실습과 수동 종료, 획득 필터, 완료 연출, 낮은 전투 난이도를 유지한다.

원고의 비껴돌림은 반류일선을 이름만 바꾸어 대체하지 않는다. 원고 말미의 게임 적용 지침에 따라 첫 창안 사건은 플레이어가 만든 유효 창안과 실제 운용을 인정한다. 이음도 이번 스토리 교체만으로 새 공격 버튼이나 자동 획득 무공을 추가하지 않는다. 후반 사건은 힘과 행동을 다음 동작에 남기는 운용을 서사로 다루며, 현재 구현에서 확인 가능한 엄호·이동·제어 행동으로 완료한다.

신규 플레이 스타일 숙련도 시스템은 별도 기획으로 남긴다. 이야기 교체에 필요하다는 이유로 임의의 숙련도나 반복 횟수를 추가하지 않는다.

## 왕래와 시간의 게임 적용안

원고의 여섯 시간은 게임 내 시간이다. 실시간 여섯 시간을 기다리게 하지 않는다. 활동 중 게임 시간은 흘러가고, 자취방·객점의 명시적 휴식이나 일을 선택하면 안내된 시간이 경과한다. 메뉴·일시정지·앱 종료 중에는 진행되지 않는다. 기본 속도는 플레이 1분에 게임 시간 10분으로 제안한다. 대기만을 위해 켜 둘 필요 없이 남은 시간만큼 쉬는 선택을 제공한다.

왕래 가능 시점은 도착 시각부터 6시간 뒤다. 목적지까지 걷거나 임무를 수행한 시간도 포함한다. UI는 현재 시각과 남은 시간을 함께 보여 준다. 양쪽에 별도의 시간 흐름을 만들지 않는다.

왕래는 자취방 ↔ 폐사당의 고정 상호작용만 허용한다. 열 호흡은 중단 가능한 진행 표시로 제공하며 프로토타입에서는 10초로 표현한다. 움직임·피격·취소·위치 이탈 시 호흡 진행을 초기화한다. 호흡 완료 전에 이동·왕래 시각·비용을 확정하지 않는다. 동반 시도 이벤트는 시작 단계에서 실패하고 누구도 이동시키지 않는다.

세계 전환은 HP·MP를 보존하고 목적 세계의 최대치를 초과하면 그 최대치까지만 제한한다. 회복은 휴식·치료·회복약 같은 명시적 행동에서만 발생한다. 기존 거점 진입 시 자동 회복도 새 이야기에서는 명시적 휴식으로 분리한다. 새 부상 수치 시스템을 만들지 않고 후반의 부상은 현재 체력 상태와 임무 역할 제한으로 표현한다. 대기 시간 종료만으로 부상을 삭제하지 않는다.

왕래 재사용 대기와 현재 시각은 저장하며, 호흡 진행은 저장하지 않는다. 로드 시 호흡은 처음부터 다시 시작한다. 이동 실패나 저장 실패 때는 이전 지역과 왕래 시간을 보존한다.

## 인물의 지식과 세계별 기록

- 현대: 민재는 계측과 현장 영상, 지우는 현대에서 재현한 예측과 임무 실적, 정순은 생활 변화만 안다.
- 무림: 소연·담희·서하는 윤서의 먼 고향과 부재만 안다. 차도겸도 현대를 모른다.
- 백련은 6장의 고백과 확인 이후에만 윤서의 왕래를 안다. 그 이전 대사에 현대·헌터 지식을 넣지 않는다.
- 유적은 에너지 전달 장치다. 사람 수송 시설이나 공동 사업으로 설명하지 않는다.
- 현대 보고·뉴스와 무림 기록을 별도로 관리한다. 원고의 두 권의 수첩은 플레이어가 보는 구분 UI로 표현할 수 있지만, 내용이 기관이나 NPC에게 자동 공유되지 않는다.

## 진행과 저장의 변경 방식

새 이야기의 진행은 버전이 있는 독립 상태에 저장한다. 단계는 장 번호만으로 보상하지 않고 의미가 있는 사건 ID로 기록한다. 예: 첫 구성, 첫 현실 재현, 구조 완료, 무림 장치 정지, 현대 작업 엄호 완료. 각 보상은 이벤트당 한 번만 지급한다.

기존 progress/fate/chapter4/journey/laterStory/cycleOne을 단순히 같은 숫자의 새 장에 대응시키지 않는다. 기존 값은 저장 호환에 남기되 새 이야기에서는 옛 대사·목표·강제 이벤트를 호출하지 않는다. 전투·무공의 필요한 기능을 사건 해금 어댑터로 연결하고 새 진행과 옛 진행을 동시에 증가시키지 않는다. 기존 R/F·심법 보상은 새 사건에 명시적으로 매핑하여 지급한다.

구버전 저장은 최초 로드 때 그대로 보존하고 이전 기록 백업을 제공한다. 이어하기 시에는 새 이야기 전환 안내에서 다음 행동을 명확히 선택하게 한다.

1. 보유 성장 유지하여 새 이야기 시작: 무공·요소·창안·증명·재화·장비·기존 성장 보상을 유지하고 이야기만 1장부터 진행한다. 이미 받은 성장 보상은 중복 지급하지 않는다. 이미 배운 무공은 장면에서 확인만 하고 다시 구성하도록 강제하지 않는다.
2. 기존 기록 보관: 원본 슬롯을 수정하지 않고 타이틀로 돌아간다. 새 이야기 시작은 별도 새 여정으로 가능하다.

이번 버전에서 구버전 본편을 새 이야기로 위장해 계속 진행시키는 모드는 만들지 않는다. 자동 전환이나 자동 초기화는 금지한다. 깨진 저장은 덮어쓰지 않고 기존 복구 UX를 사용한다.

새 게임은 새 이야기만 시작한다. 인트로 건너뛰기는 새 인트로에 필요한 사건만 확정하며 월영참·신규 무공·재화를 미리 지급하지 않는다. 진행 보상과 현재 체력 등은 건너뛰기 안내와 일치시킨다.

## 무공 획득 경로 연결

기초 사사는 여울장 백련, 신규 섬광검·횡월검·축기결도 같은 교습 화면에 연결한다. 측행보와 세 대응 계열의 흔적은 탐사에서 발견한다. 무공 습득 자체와 시나리오를 한 번에 자동 완료하지 않는다.

기존 비경의 형·기, 전투 행동으로 운, 현지 의뢰로 의를 얻는 기능은 보존한다. 마을 방어·인질 구출·비석 봉인은 여울장 주변의 선택 의뢰로 설정을 정리한다. 서하의 본편 구출을 잔영각 획득 의뢰와 동일한 사건으로 취급하지 않는다.

신규 여섯 항목은 본편의 필수 열쇠가 아니다. 첫 창안과 현실 재현은 기존 세 창안 또는 신규 두 창안 중 해당 시점에 배운 것으로 진행할 수 있다. 축기결·측행보의 원리 성취는 해당 창안 조건으로만 유지한다.

## 코드 변경 경계와 검증

이야기 데이터·진행 모듈을 분리해 새 이벤트가 옛 모듈의 여러 prototype wrapper를 동시에 발동시키지 않게 한다. 지도·목표·대화·임무·수첩·뉴스가 동일한 새 진행을 참조해야 한다. 렌더링용 portrait/role 내부 ID는 유지할 수 있지만 표시 이름과 대사는 새 인물의 역할에 맞춘다. 새 인물의 얼굴을 기존 다른 인물의 얼굴로 확정하지 않고 초상화가 없는 경우 중립 표시를 쓴다.

구현 단위는 다음 순서로 나눈다. 앞 단위만 완료된 빌드는 공개하지 않고 11장 통과 후 배포 대상으로 삼는다.

1. 새 사건·시간·왕래·저장 이관과 1~3장.
2. 습득·창안의 사건 연결, 4~7장과 세계별 정보 제한.
3. 8~11장의 구조·두 최종전·결말, 기존 보상과 R/F 해금 연결.
4. 전체 UI 대사/목표 대조, 구버전 저장 이관, 로컬 개발 시작점과 전체 회귀.

완료 검증은 다음을 포함한다.

- 새 여정에서 11장 결말까지 실제 상호작용으로 도달.
- 첫 구성·각 창안·현실 재현이 본편과 로컬 순차 테스트 양쪽에서 동작.
- 무공과 재화 보존, 구버전 원본 보관, 보상 중복 없음, 저장 실패 복구.
- 고정점 밖 왕래 거부, 6시간 경계값, 열 호흡 중단, 부상 보존, 앱 종료로 시간 우회 불가.
- 현실 NPC 대화/뉴스에 무림을 아는 내용이 나오지 않음. 백련의 사전 지식도 금지.
- 감독관의 세계 간 이동·공동 통로·공동 기관이 신규 플레이에서 노출되지 않음.
- 특정 신규 무공 없이도 최종 엄호 임무 완료 가능.
- 실패 후 이미 완료한 준비 보존, 선택 실습 자동 종료 없음, 쉬운 전투 유지.
- 공개 산출물에 개발용 시작점·순차 테스트가 포함되지 않음.

## 이번 검토에서 확정할 게임 적용안

원고의 세계관과 인물·사건은 기준 원고대로 반영한다. 추가 확인 대상은 게임으로 옮길 때 필요한 다음 세 가지다.

1. 6시간을 게임 시간으로 처리하고 명시적 휴식으로 넘길 수 있게 하는 방식.
2. 기존 저장은 보존하고, 성장 유지 여부를 안내한 뒤 새 이야기를 시작하는 방식.
3. 비껴돌림·이음을 기존 무공 이름에 덮어쓰지 않고 플레이어의 창안 선택을 인정하는 방식.

이 문서가 승인되면 구체적인 구현 계획과 테스트 작업을 작성한다. 공개 배포는 별도 요청이 있을 때 진행한다.
