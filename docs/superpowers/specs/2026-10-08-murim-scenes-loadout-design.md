# 무림 1~2장 — 장면 연결과 스킬 단축키 설계

상태: 사용자 승인 방향을 구체화한 설계 검토안. 게임 코드는 아직 변경하지 않았다.
기준: DOC-17, D-028~032. 이번 범위와 충돌하는 옛 설정은 신규 여정에 적용하지 않는다.

## 1. 확정된 요구

- 현실에서 첫 무림 진입까지의 인트로를 유지한다. 이후는 이미지·대사로 새 사건을 진행한다.
- 백련 구조 → 추적자의 습격 → 삼재검법 응급 전수 → 이동/공격/회피 튜토리얼 → 화산행 10개 던전 → 치료/제자 선택 → 천흔 보스 → 첫 현실 귀환.
- 장면 → 다음 던전 → 장면을 기본 동선으로 삼는다. 던전 입구에서 장/목적지를 고르는 방식은 신규 본편 진행에서 제거한다.
- 중간 사건에 문파와 등장인물을 배치한다. 성장 UI를 열기 위한 NPC와 반복 보고만 요구하는 NPC는 두지 않는다.
- 스탯/스킬 확인을 레드닷으로 유도한다. 튜토리얼 전투 학습 기회를 늘린다.
- 미습득 스킬 비노출은 **전투 단축키**에 적용한다. 미습득 기술 이름·아이콘·예고 슬롯을 전투 HUD에 표시하지 않는다. 이 요청을 스킬 트리 비노출로 해석하지 않는다.
- 습득한 기술을 사용자가 골라 단축키에 배치한다. 이전 설정과 안내가 새 여정에 섞이지 않아야 한다.
- 기존 확정: 자유 분산 투자, 영구 투자 환불 금지, 제자 거절/기연 없이 진행 가능, 저장·완료 이력 보존.

## 2. 이번 상세 설계 제안

### 스킬 단축키

키와 기술을 분리한다. 기본 공격/회피는 항상 제공하고, 현재 기술 수에 맞춰 선택 기술 슬롯 2개로 먼저 검증한다. 슬롯 수는 확정 요구가 아니다. 기본 키는 기존 사용자 입력 설정을 존중한다.

`배운 기술 → 단축키 설정 → 슬롯 선택 → 적용`을 제공한다. 이미 같은 기술을 배치한 다른 슬롯을 선택하면 교환하고, 해제도 가능하다. 전투 HUD에는 배치한 습득 기술만 보이며 빈 슬롯 편집은 설정 화면에서만 한다. 신규 습득은 알림으로 안내하고 기존 배치를 임의 교체하지 않는다. 횡검과 매화노방도 직접 배치해야 하며, 첫 획득 시 배치 방법을 짧게 안내한다.

장착 변경은 안전한 준비 구간에서 가능하며 투자·성취를 변경하지 않는다. 재배치/해제로 기술의 재사용 대기시간을 초기화할 수 없다. 쿨다운과 비용은 슬롯이 아닌 기술에 속한다. 키보드/터치/접근성 설명 모두 같은 슬롯 해석을 사용한다. 미습득·미장착 기술은 남아 있는 옛 키로도 발동하지 않는다.

투자 트리에는 기존의 선행 조건/다음 효과를 유지한다. 미습득 기술 숨김을 트리까지 확대하지 않는다. 패시브는 전투 슬롯 장착 대상이 아니다. 디아블로2 참조는 직접 기술을 선택하는 방식에 한하며 마우스 좌/우 기술 전환 체계 전체를 복제하지 않는다.

### 인트로와 중간 사건

기존 intro-0/1의 현실 출발·경계석 반응과 첫 도착 상황을 활용한다. 이후는 새 장면 ID를 사용한다. 기존 intro-4~6의 즉시 귀환·서린 보고·안전 왕복 개통은 신규 여정에서 호출하지 않는다. 백련의 소속 직위나 추적자 정체를 새로 확정하지 않는다.

아래 사건은 구체화 제안이며 인물 이름·대사·전투 배치는 검증안이다. 기존 문파 배치 시점은 활용하되 새로운 계보를 확정하지 않는다.

| 구간 | 장면의 원인과 다음 행동 |
|---|---|
| 첫 도착/튜토리얼 | 백련 지혈 중 추적자가 접근. 약해진 백련에게 삼재검법을 배워 탈출한다. 천흔 접근을 미루고 화산 치료를 택한다. |
| 죽림 → 초소 | 추적을 떨치고 화산 방면 길목을 확보한다. 최초 성장 재료와 UI 안내를 제공한다. |
| 초소 → 잔도 | 남궁의 여행자가 봉쇄된 길을 함께 살피며 검의 거리 운용을 보여준다. 배움은 선택, 통행은 투자와 무관하다. |
| 잔도 → 계곡 | 무너진 길을 우회해야 하며 백련의 부상이 서두를 이유가 된다. |
| 계곡 → 역참 | 무당의 여행자와 추격을 피할 시간을 확보한다. 호흡/내공의 배움과 휴식을 연결한다. |
| 역참 → 돌계단 | 역참을 지키는 적을 돌파하고 산길 진입로를 찾는다. |
| 돌계단 → 협곡 | 아미의 여행자와 위험한 길목을 건넌다. 보법의 의미를 보여주되 특정 기술 투자를 요구하지 않는다. |
| 협곡 → 운무 숲길 | 매복을 피해 백련과 동행할 경로를 확보한다. |
| 숲길 → 외곽 관문 | 운무 속 추적을 끊고 화산 관문으로 향한다. |
| 관문 → 산문 | 부상자 치료를 요청하고 마지막 접근로를 돌파한다. 기능 안내용 관문 NPC를 추가하지 않는다. |
| 산문 완료 | 치료 장면 뒤 백련이 제자를 제안. 수락하면 매화 제1초식, 거절해도 귀환 여정은 동일하게 열린다. |
| 천흔 옛길 → 검은 진영 | 위험을 확인하고 천흔 진입로를 연다. 선택 기연 기회는 본편과 별도 선택으로 둔다. |
| 검은 진영 → 수문장 | 적대 무리를 물리쳐 천흔에 접근하고 귀환을 가로막는 보스를 제압한다. |
| 첫 귀환 | 현실에 처음 돌아와 서린을 만난다. 이 이전에는 왕복 보고/현실 성장 과제가 열리지 않는다. |

기존 인트로와 같은 이미지·화자·대사 표현을 사용한다. 적합한 자산을 재사용하되 옛 사건 설명이 들어간 이미지는 사용하지 않는다. 주요 만남은 충분한 장면, 일반 이동은 짧은 전환으로 구성한다. 새 이미지가 필요하면 제작 항목으로 명시하고 텍스트 대체를 이미지 구현 완료로 보고하지 않는다.

### 준비·실패·알림

장면 끝에 성장 확인과 다음 지역 진행을 제공한다. 자동 강제 입장은 하지 않는다. 사망/철수 시 현 여정의 안전한 준비 상태로 돌아가며 완료 지역의 보상은 중복 지급하지 않는다. 재도전과 저장은 유지한다. 선택 기연은 준비 화면에서 진입/건너뛰기를 명시하며 지나온 장 선택을 필수 동선으로 만들지 않는다.

튜토리얼은 이동/기본 공격 → 예고 공격과 회피 → 종합 실전으로 나눠 검증한다. 우선 3차례에 2/2/3명, 총 7명의 전투 후보를 사용한다. 수치·적 종류는 확정 사항이 아니다. 회피 타이밍 성공이나 스킬 투자는 진행 잠금 조건이 아니다. 미완료 조작 학습은 적을 전멸시킨 뒤에도 재시도할 수 있어야 한다.

레드닷은 최초 기능 안내·새 재료 획득·새 기술/학습 기회별 미확인 기록에 기반한다. 해당 정보를 확인하면 해제하고 재료 전부 사용을 요구하지 않는다. 읽음 상태도 저장한다. 전투 중에는 짧은 획득 안내만 보여준다.

## 3. 구현 경계와 상태

- 장면 데이터/표현: 신규 여정 전용 데이터와 기존 이미지·대화 렌더러를 연결한다. 구 제목 매칭으로 옛 대사를 자동 삽입하지 않는다.
- 진행: `murim-journey.js`가 장면 ID/페이지/다음 지역/선택/완료를 소유한다. 화면 닫기나 이미지 로딩 완료가 보상 지급 조건이 되어서는 안 된다.
- 성장: `murim-growth.js`의 해금·성취·투자 원장은 보존한다. 장착은 별도 상태로 관리하고 실제 습득 여부를 모델에서 검증한다.
- 입력: 현재 `controls.js`의 키 재지정과 기술 장착을 분리한다. `app.js`의 버튼/키 입력/도움말/접근성 문구는 동일한 장착 조회를 사용한다.
- 저장: 새 여정의 선택 필드로 장면 진행/장착/읽음 기록을 추가한다. 이미 진행한 v0.14 저장은 완료 기록에 맞는 다음 사건으로 연결하며 튜토리얼·제자 선택·보상을 다시 적용하지 않는다. 기존 습득 기술은 종전 배치에 대응시켜 이관하고 미습득 슬롯만 숨긴다. 새 게임의 신규 습득은 직접 배치 원칙을 따른다.
- 구 저장 호환 코드는 이력 보존 목적으로 분리한다. 새 게임·새 여정 이어하기·회상·도움말·메뉴에서 구 캠페인으로 우회하지 않는다. 보존용 코드가 존재하는 것과 새 여정에서 옛 설정을 노출하는 것을 구분한다.
- 비동기 장면/지역 준비 실패는 현재 상태를 보존하고 재시도를 제공한다. 취소나 다른 저장 불러오기 후 늦은 응답은 무시한다. 저장 실패 시 선택·장착·투자 변경은 취소한다.

## 4. 옛 설정 혼입 방지 기준

| 신규 여정에서 제외 | 신규 기준 |
|---|---|
| 초반 즉시 귀환/두 번째 방문/안전 왕복 개통 | 2장 보스 후 첫 현실 귀환 |
| 별도 화산 전수자 인정을 받아야 다음 진행 | 백련 응급 전수와 치료 후 제자 선택 |
| 월영참/천뢰격/연환검 등 공통 UI의 옛 기술명 | 현재 습득 기술의 실제 이름으로 버튼·설정·도움말 통일 |
| 미습득 Q/W 버튼과 옛 기연 키 설명 | 습득하고 배치한 기술만 전투 HUD에 표시 |
| 성장 안내 NPC/여정 선택 NPC/반복 보고 | 메뉴 알림과 사건 완료에 따른 다음 지역 연결 |
| 현실 트리·헌터 승급·3장 이후 퀘스트 유입 | 첫 현실 귀환까지 범위 제한 |

## 5. 검증 및 완료 기준

1. 실제 브라우저에서 현실 인트로부터 첫 귀환까지 장면 순서와 이미지 표시를 확인한다. 읽기/건너뛰기 모두 사건 상태가 동일하되 제자 선택은 자동 수락하지 않는다.
2. 미습득/미장착 기술이 버튼·탭 이동·접근성 문구·키 발동에 없는지 확인한다. 배치/교환/해제/재접속, 기존 키 설정과 모바일 입력을 검증한다.
3. 재배치로 쿨다운이 초기화되지 않고 투자·성취는 변하지 않는지 확인한다.
4. 10개 던전과 문파 사건, 제자 수락/거절, 기연 획득/미획득, 미투자 경로를 확인한다. 던전 선택 NPC를 거쳐야만 진행되는 경로가 없어야 한다.
5. 레드닷 읽음/신규 획득/재접속과 미사용 재료 유지, 각 장면 전후 저장/사망/철수/취소/로딩 실패를 검증한다.
6. v0.14 진행 저장과 구 저장의 투자·성취·완료·보상 원장을 비교한다. 장면 재생과 재접속으로 보상/제자 선택이 중복되지 않아야 한다.
7. 신규 여정 전용 화면뿐 아니라 도움말·입력 설정·회상·기본 공격 이름까지 혼입 검사를 한다. 360px 화면과 데스크톱을 확인한다.
8. 자동 검증과 별도로 튜토리얼 전투량·장면 길이·투자 체감을 플레이 검토한다. 자동 완주를 재미 검증으로 보고하지 않는다.

## 6. 실제 상태

이 문서는 설계안이다. 위 장면/장착/레드닷/튜토리얼 증가는 아직 구현·테스트·배포되지 않았다. 사용자 확정 요구와 제안 슬롯 수·전투 수치·중간 사건 상세를 구분한다.
