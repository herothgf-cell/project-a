# v0.8 — 보이는 두 세계

사용자가 A~F 개선안 전체의 직접 개발·main 반영·배포를 승인했다. B-3의 고정 문구는 “실제 멀티 채팅이 아닌 연출 시뮬레이션입니다.”이다.

## 범위
- A: 이동 거리 기반 보행, 방향별 분절 자세, 몸/손/칼/검기를 같은 순간과 좌표계로 그리기. 기존 전투 판정·쿨다운·반격 타이밍은 유지한다.
- B: 좌상단 초상/체력, 우상단 지도/목표, 하단 기술, 잉크색/금색 통일, 이야기 대화와 수첩 모달을 구분한다. 뉴스 전체/월드/서버/모집/시스템 필터와 최근 소식. 실제 통신 기능이나 가짜 입력창은 만들지 않는다.
- C/D: AREAS.world를 유일한 세계 구분 근거로 삼는다. 현실의 모든 건물은 평지붕/유리/콘크리트, 인물은 제복/전술복, 적은 드론/침식체. 무림은 기존 그림 인물/기와/목재/자연을 사용한다. 주인공의 익힌 검술은 두 세계에서 유지한다.
- E: 세계간 장치와 지역 출입구를 구분한다. 목적지, 잠금 상태, 다른 세계의 실루엣, 프레임, 동심원/입자를 표현한다. 전환 안내에 출발/도착 세계를 명시한다.
- F: B/N/H 안내, 선택형 길잡이와 단계별 실제 상태(접근/기감/조사/현상/해석)를 연결한다. 기감을 가르치는 것과 기연을 지급하는 것을 구분한다. 숨은 조건 카운트/무료 기연 지급 없음.

## 제한
새 챕터와 서버는 추가하지 않는다. 저장 version6와 기연·제5장 진행을 보존한다. 시각 동작은 기존 그림 조각의 관절 애니메이션이며 신규 8방향 손그림 프레임 전체가 아니다. 전체 나르실리온급 배경 원화 제작이라고 주장하지 않는다. 저사양 효과 줄이기/진단 HUD를 보존한다.

## 완료 기준
자동검사 + 실제 HTTP 브라우저 검사에서 기존 여정과 모바일 입력 유지. 도시와 무림 스크린샷, 캐릭터 방향/이동/공격, 뉴스 문구 및 각 탭, 선택형 기감 실습, 저장/이어하기 확인. 배포 후 버전/커밋/모든 실행파일 해시 대조.
