# 쌍계 상세 플레이 기획서 v2.1 — 발견과 성장 개편

기준: v0.9.0 / 기존 v2.0 인트로·세계관·12지역·5장 유지. 이 문서는 사용자가 승인한 추가 개편의 구현 기준이며 원본 DOCX를 덮어쓰지 않는다.

## 핵심 경험

본편은 인물과 사건, 기연은 선택적인 발견과 계승, 숙련은 실제 사용에 의한 강화, 현실 의뢰는 무공을 활용하는 반복 실전으로 역할을 나눈다. 포인트로 기연을 구매하지 않는다. 기존 획득·숙련·구조·인증·저장을 보존한다.

## 성장 규칙

- 레벨당 최대 체력 +18, 최대 내력 +5, 공격력 +3. 레벨 알림에 실제 상승량을 표시하고 상태창에 다음 레벨 수치를 보여준다. 최대 80레벨은 다음 성장 없음으로 표시한다.
- 공통 검술 및 세 계열 숙련은 기존 0~30 값을 유지한다. 5/10/20/30 달성마다 해당 계열의 실제 피해 +3%, 누적 최대 +12%. 기본 공격·월영참·천뢰격은 공통 검술, 계승 기술·오의·해석 피해는 해당 계열의 숙련만 적용한다. 표시 공격력 자체에는 더하지 않는다. 시험에서는 숙련 보상을 적용하지 않는다.
- 숙련 획득의 유효 타격·방어 조건과 적당 최대 3회 제한은 유지한다. 기존 저장도 이미 달성한 숙련 보상을 자동 적용하되 보상을 중복 지급하거나 수치를 저장하지 않는다.
- 심법은 운용 방식, 경지는 영구 기본 능력치 성장이다. 첫 경지 조건과 보상은 유지한다.

## 무공 UI

성장 화면에 연결된 아이콘 노드: 공통 학습 흐름 / 세 기연 계열 / 각 계열 기술과 오의 / 기술 변형. 연결선은 학습 흐름과 변형 대상 관계를 구분한다. 클릭 또는 터치 시 설명·현재 키·비용·재사용·숙련 효과·기본 대비 변형을 표시한다. 미발견 계열과 해석은 이름·정답을 숨긴다. 모바일은 한 열로 흐르고 모든 조작은 44px 이상.

발견/계승 가능/계승 완료/장착 중을 구분한다. `이어가기` 대신 `이 해석 장착`, 성공 시 `장착 중`. 다른 계열, 시험 중, 위험 지역에서 거부될 때 이유를 안내한다. 장착 뒤에는 귀환이나 자유 탐험 안내로 전환한다. 운기조식은 회복 기능이며 기본 퀘스트 목적지가 아니다.

## 최초 계승

기존 현장 관찰→발현→수락/보류 조건 유지. 수락 시에만 이름을 공개하고 화면 상단 공지를 약 7초 표시한다. 문구: `윤서님이 잃어버린 무공 「이름」을 계승했습니다.` 하단에 `이 여정의 첫 계승 · 싱글플레이 연출`. 실제 서버 최초·접속자에게 전송했다는 주장은 하지 않는다. 계열별 한 번만 강조하며 불러오기·재수련·회상으로 재발행하지 않는다. 기록은 행적에 남는다. 모션 감소 설정을 존중하고 전투 입력을 빼앗지 않는다.

## 현실 현장 의뢰 1종

현실 기지의 의뢰판에서 `균열 잔당 토벌` 수주. 본편 첫 D급 균열 완료(progress >= 6) 후 개방. 기존 균열 맵에 의뢰 전용 적 4명을 배치하며 본편 보스·봉인·퀘스트·클리어 횟수를 바꾸지 않는다. 초기 적 체력 170, 피해 12, 반복 완료마다 5% 증가(10회까지). 기본 무공만으로도 완료 가능하다.

수주→적 4명 처치→기지 귀환→의뢰판 보상 수령. 보상 금화 80 / 경험치 100 / 마정석 2. 의뢰 적은 별도 전리품을 주지 않으며 실전 숙련은 정상 획득한다. 수령은 한 번만 가능. 완료 전 후퇴·사망·지역 이탈은 중단하고 재수주 가능. 전투 중 저장을 불러오면 의뢰를 중단하여 처치 수와 재생성된 적이 어긋나지 않게 한다. 완료 후 미수령 저장은 유지한다. 공식 헌터 승급, 방어 의뢰, 정예 의뢰는 후속 범위다.

## 화면 정리와 호환

상시 채팅형 소식창·다른 여정 탭 제거. 중요한 알림은 상단 공지/토스트/행적에 남긴다. 도겸은 현장 조언 NPC로 유지하되 AI 전투 동행과 지원 사격은 제거한다. 예전 companion 저장값은 읽을 수 있어야 하며 성장·인증은 유지한다. 방어 해석은 플레이어 자신을 보호하는 효과가 유지된다.

저장 v8에 의뢰 상태만 추가하고 v1~v7 로드를 유지한다. 잘못된 의뢰 상태·음수·무한 수치·중복 보상을 거부한다. 실제 온라인 시스템, 새 아트 제작, 원본 DOCX 덮어쓰기와 공개 배포는 이번 범위가 아니다.

## 사용자 승인 후속 개선 — v0.10.1

- 레벨업은 상단 3초 비차단 연출과 실제 능력치 증가량으로 표시한다. 계승 공지는 7초이며 대화·메뉴를 닫은 뒤 표시한다. 두 알림 모두 백그라운드 탭에서 시간을 소모하지 않고 입력·전투를 멈추지 않는다. 이미 계승한 저장에는 가짜 최초 기록을 새로 만들지 않는다.
- 기본 입력: 방향키 이동, Q/W 공통 무공, E/R 기연 무공, A 기본 공격, S 회피, D 기감, F 오의, G 상호작용, 1 회복약. 이전 기본 배치는 전환하되 직접 변경한 배치와 명시적으로 선택한 기존 배치는 유지한다.
- 몬스터는 별도 예고가 있는 2연속 베기·돌진·원거리 2연사, 보스는 광역 패턴을 섞는다. 후속 타격도 회피할 시간을 준다. 죽림의 기본 체력/피해는 기존 대비 1.2/1.15배, 이후 지역은 1.35/1.25배로 한다. 플레이어 레벨에 맞춰 적을 강화하지 않는다. 시험과 의뢰 전용 체력·피해 규칙은 유지한다.
- 플레이 화면의 제작 검수 배너는 제거하되 실제 후보 아트 검수 상태는 개발용 검수 화면에 유지한다.

검증: Node 398개 통과, 기존 Python 브라우저 7종과 v09/v010 브라우저 흐름 통과. 별도 feedback 브라우저 테스트로 대화 종료 후 계승 공지, 비차단 레벨업, 백그라운드 시간 보존을 검사한다. 데스크톱/390px 연출을 시각 확인했다. 자동 검사는 조작·규칙 회귀를 검증하며 실제 플레이 난이도 선호나 장기 밸런스를 보증하지 않는다. 로컬 변경이며 공개 배포하지 않았다.
