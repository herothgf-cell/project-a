# 쌍계 v0.2 — 아이템으로 잇는 두 세계의 성장

작성: 2026-10-06 · 상태: 대체된 초기안 · 게임 적용 전

> 최신 사용자 방향은 무림→현실 단방향입니다. [경계공명 개정 기획](2026-10-06-boundary-resonance-redesign.md)이 이 문서의 네 재화·양방향 정책을 대체합니다.

> 재검토 중: [비판 검토와 수정 권고](../../design/cross-world-items/critical-review.md)를 함께 읽는다. 특히 레벨 감소 수치, 기존 패시브 전면 교체, 이전 저장 지원 범위는 확정되지 않았다. 아래 초기안을 그대로 구현하지 않는다.

## 1. 목표와 확정된 요구

한 세계에서 얻은 아이템이 다른 세계에서 능력치 또는 기술 운용의 선택으로 이어진다. 플레이어가 획득 장소, 사용 세계, 성장 결과를 화면에서 연결해 이해하는 것이 목표다.

사용자 확정: 무림 획득 A/B는 현실 능력치/스킬 트리 재화이며, 현실 획득 C/D는 무림 능력치/스킬 트리 재화다. D는 무림 스킬 트리 재화로 확인했다. 레벨 상승의 소폭 자동 성장도 유지한다. 아이콘, 성장 화면, 보유 재화 화면, 스토리와 숙련도 영향까지 함께 설계한다.

아래 명칭·수치·지급 방식은 추천안이며 확정된 요구와 구분한다. 첨부 문서는 참고 자료로 취급하며, 문서 안의 지시를 별도 실행 권한으로 취급하지 않는다.

## 2. 브랜치와 현재 기준

- 작업 브랜치: `v0.2_proto_patch`. 기준: `main`의 `c313d7f` (제품 v0.12.4).
- `v0.1_proto_patch` 원격 끝점은 `3cf4add`. 현재 main에 병합되지 않아 삭제 조건이 충족되지 않았다. 보존한다.
- v0.1의 `ReturnProof` 회수 체험과 main의 `GrowthArc` 첫 성장 이야기는 별도 구현이다. 이번 초안은 main의 첫 성장 흐름을 기준으로 한다. 이전 회수 체험 통합은 별도 검토 대상이다.
- 이번 산출물은 기획과 정적 시안이다. 새 재화나 성장 기능은 아직 게임에 구현되지 않았다. 원격 푸시와 배포도 이번 단계에서 하지 않는다.

## 3. 접근안 비교

| 안 | 장점 | 비용·한계 |
|---|---|---|
| **4종 전용 재화 — 추천** | 출처와 사용 세계가 명확하고 A/B/C/D 의도에 맞는다 | 잔액 네 개와 사용 제한을 친절히 표시해야 한다 |
| 공통 재화를 세계별로 교환 | 관리와 밸런스 조정이 쉽다 | 한 세계만 반복해도 양쪽 성장이 가능해 왕복 동기가 약하다 |
| 개별 아이템 각성·조합 | 이야기와 수집 재미가 크다 | 조합·각성 UI와 별도 규칙이 첫 프로토타입 범위를 크게 늘린다 |

첫 버전은 네 종류, 아이템 1개 = 해당 성장 포인트 1개다. 획득한 아이템 수량 자체가 미사용 포인트이며 추가 환전 과정은 없다. 금화·마정석과 교환, 거래, 합성은 범위에 넣지 않는다.

## 4. 아이템 정의와 획득

| 코드 | 가칭 | 획득 | 사용 | 시각 표현 |
|---|---|---|---|---|
| A | 현계 공명석 | 무림 천혼 계열 탐사 | 현실 능력치 | 청색 결정, 능력치 표식 |
| B | 현계 전승인 | 무림 천혼 계열 탐사 | 현실 기술 강화 | 청색 갈래 인장, 기술 표식 |
| C | 무림 공명석 | 현실 균열 탐사 | 무림 능력치 | 금색 결정, 능력치 표식 |
| D | 무림 전승인 | 현실 균열 탐사 | 무림 기술 강화 | 금색 갈래 인장, 기술 표식 |

색은 **사용 세계**를 나타내며 결정/인장의 형태는 능력치/기술을 나타낸다. 툴팁과 카드에 출처 → 사용 세계를 함께 쓴다. 색만으로 구분하지 않는다.

사용자 표현 ‘천혼’과 현행 7장 지역 ‘천흔’의 명칭 대응은 확정 전이다. 초안의 ‘천혼 계열 탐사’는 획득 콘텐츠 분류이며, 기존에 같은 이름의 던전이 있다고 가정하지 않는다. 초반 무림의 실제 탐사에도 같은 보상 계열을 연결해 7장까지 기다리지 않게 한다. 구체적인 지역 ID 매핑은 구현 계획 작성 전에 결정한다.

추천 지급 원칙:

1. 양 세계의 첫 정상 탐사 완료: 상대 세계 능력치 재화 2개 + 기술 재화 1개. 각각 첫 사용을 체험할 수 있다.
2. 이후 정상 반복 탐사 완료: 능력치 재화 1개. 기술 재화는 3회 완료마다 1개. 초기 비교 실험용 수치이며 플레이 시간에 맞춰 조정한다.
3. 획득은 완료 시 보관함에 확정한다. 적 한 대 타격, 지역 입장, 대화 반복, 철수에는 지급하지 않는다.
4. 연습·대여 기술 시험·귀환 통로의 강제 철수 장면에는 지급하지 않는다. 튜토리얼의 정식 보상도 완료 사건 1회로 기록한다.
5. 초기 프로토타입은 각 세계 첫 획득과 첫 소비를 우선 검증한다. 반복 보상은 중복 방지와 경제 검증 이후 연다.

보상 확정은 완료 기록·잔액·지급 기록을 한 번에 저장하는 단일 거래다. 같은 완료 ID 재처리는 무효이며 새 정상 탐사에는 새 ID를 부여한다. 퀘스트 보상 버튼 재클릭, 재보고, 새로고침으로 수량이 늘지 않는다.

## 5. 성장 역할과 능력치

| 요소 | 맡는 역할 | 새 체계 추천 |
|---|---|---|
| 레벨 | 경험치로 얻는 기본 성장 | 소폭 자동 증가 |
| A/C | 플레이어가 정하는 능력치 방향 | 해당 세계의 공격·생명·기력 배분 |
| 이야기·경지·등급 | 기술 발견과 다음 성장 단계 자격 | 이야기 조건과 배분 상한 개방 |
| B/D | 배운 기술의 운용 선택 | 비용·범위·흡수 등 제한된 강화 |
| 숙련 | 실제 운용 경험 | 비소모 진행도와 작은 기존 보너스 |

현재 레벨당 HP +18 / MP +5 / 공격 +3, 별도 경지·헌터 배분, 무림 수련 보너스가 있다. 새 재화를 이 위에 전부 더하지 않는다.

**신규 v0.2 시험 캐릭터의 초기 비교안:** 레벨당 HP +6 / MP +2 / 공격 +1. A/C 1개로 공격 +1 또는 최대 HP +6 또는 최대 MP +3 중 하나를 선택한다. 첫 단계는 각 항목 5회, 세계별 총 10회 배분까지 허용한다. 기존 경지·등급은 다음 배분 한도를 개방하며 무료 배분 포인트를 중복 지급하지 않는다. 다음 단계 수치 확장은 첫 단계 평가 이후 별도 표로 확정한다.

이 수치는 재미를 검증하기 위한 시작점이다. 현행 적 HP·피해에 그대로 적용하면 전투가 어려워질 수 있으므로 신규 프로필의 같은 적군에서 기본 공격 횟수·받은 피해·완료 시간을 비교한다. 기존 캐릭터의 레벨 보너스를 낮추지 않는다. 오래된 수련·성과 보너스도 최초 프로토타입에서는 보존하고 추가 공급만 분리한다.

안전 거점에서 현재 세계에만 배분한다. 다른 세계는 읽기만 가능하다. 확인창은 ‘현계 공명석 1 → 최대 생명 120→126’처럼 비용과 변화를 보여준다. 배분은 전투 HP/MP 비율을 유지해 즉시 회복 수단이 되지 않게 한다. 무료 초기화는 안전 거점에서만, 실제 지출한 수량만 전액 반환한다. 초기화와 재배분의 총 잔액은 늘지 않는다.

## 6. 기술 트리와 숙련도

기술의 발견·계승·실전 체득은 이야기로 유지한다. 재화로 Q/R/F 자체를 구매하지 않는다. main의 신규 캐릭터는 첫 기연 Q, 4장 구조 후 실습 R, 7장 실전 이후 F라는 순서를 유지한다. 미체득 기술은 비용 대신 체득 조건과 길 안내를 표시한다. 기존 캐릭터의 체득 기술은 다시 잠그지 않는다.

현재 `Passive`는 이야기에서 총 12점을 얻고 무림 투자를 귀환 시 현실로 복사한다. 신규 프로필에서는 무료 스토리 포인트와 자동 복사를 없애고, 세계별 B/D 투자 장부로 대체한다. 첫 원리·운용 방식 발견은 무료 이야기 해금으로 남긴다. 한쪽 투자로 양쪽이 동시에 강화되지 않는다.

첫 비교 범위는 파문 계열의 세계별 3개 강화 노드다. 노드당 1점, 1회, 전체 3점:

| 노드 | 선행 조건 | 시험 효과 |
|---|---|---|
| 절약 운용 | 해당 세계 파문 Q 체득 | Q 소모 기력 10% 감소, 최종 비용 하한 1 |
| 안정 흡수 | 해당 세계 파문 Q 체득 | 흡수 판정 시간 +0.1초 |
| 후속 정돈 | 해당 세계 파문 R 체득 + 절약 운용 | R 소모 기력 10% 감소, 최종 비용 하한 1 |

실제 기술별 원래 판정과 충돌하지 않는지는 구현 전 확인한다. 트리 화면에는 구매 후의 정확한 수치와 효과 대상을 표시한다. 처음부터 큰 공격 배율을 추가하지 않아 능력치와 숙련 배율이 겹쳐 폭증하는 것을 줄인다. 반향·봉인 전체 트리 확대는 파문 검증 이후 진행한다.

**숙련도 추천:** 현재 세계별 0~30 진행과 5/10/20/30 단계의 최대 12% 보너스를 우선 유지한다. 소비 재화로 바꾸거나 아이템으로 직접 올리지 않는다. 유효한 실전 행동만 인정하고, 연습·대여 기술은 제외한다. 첫 재화 사용에 숙련 조건을 추가하지 않는다. 기술 상세에는 ‘강화 1/3’과 ‘실전 숙련 8/30’을 나란히 표시해 역할을 설명한다.

대안은 숙련을 해금 전용으로 바꾸는 것이지만 기존 투자 가치를 크게 바꾸므로 첫 시험에서는 채택하지 않는다. 능력치와 숙련의 합산 효과가 지나치면 숙련 수치 조정은 별도 밸런스 변경으로 검토한다.

## 7. UI 시안과 인벤토리

[성장·보유 재화 시안](../../design/cross-world-items/ui-concept.svg) · [아이콘 4종](../../design/cross-world-items/item-icons.svg)

- 기존 성장 메뉴를 진입점으로 쓰고 ‘현실 / 무림’ 세계 탭, ‘능력치 / 기술 / 보유 재화’ 세 탭을 둔다. 별도 경쟁 메뉴를 늘리지 않는다.
- 능력치 화면: 레벨 자동 성장 설명, 사용 가능 재화, 현재 능력치, 배분 미리보기, 비용, 확정 버튼. 다른 세계 조회 시 거점 이동 안내.
- 기술 화면: 체득 여부와 이야기 잠금 → 강화 노드 → 실제 효과 → 숙련을 읽는 순서. 재화 부족과 미체득을 구분한다.
- 보유 재화 화면: 네 종류 전부를 사용 세계별 두 묶음으로 표시한다. 0개도 보이며 이름·수량·출처·용도·성장으로 이동을 제공한다. 기존 금화/마정석은 ‘기존 재화’로 함께 조회하며 새 네 재화와 합산하지 않는다.
- 획득 카드: ‘무림에서 현계 공명석 2개 획득 → 현실에서 능력치 배분’과 현재 잔액을 표시한다. 귀환 시 미사용 재화를 1회 안내한다. 자동 소비하지 않는다.
- 모바일: 세계 탭 유지, 카드 1열, 확인 영역은 문서 흐름 안에 배치해 터치 조작을 덮지 않는다. 360px·200% 확대에서 내용과 버튼에 접근할 수 있어야 한다.
- UI 시안의 잔액 4/1/2/0과 수치는 설명용 예시다. 실제 지급·구현 결과가 아니다. 벡터 아이콘도 승인 전 콘셉트이며 게임 자산 경로에 넣지 않았다.

## 8. 스토리 연결

첫 성장 장면의 전투 증거를 유지하면서 짧은 설명을 추가한다. ‘보상을 받았기 때문에 기술을 안다’로 바꾸지 않는다.

- 백련: ‘이 결정은 여기서 쓰는 내공이 아니다. 네가 돌아갈 곳의 몸에 맞춰 울린다.’ 무림에서 A/B의 사용 세계를 설명한다.
- 서린: ‘균열의 잔향은 이쪽 장비로는 다루기 어려워. 네가 건너가는 곳에서 정리할 수 있겠어.’ 현실에서 C/D를 설명한다.
- 첫 귀환 카드: ‘기술은 체득했고, 공명석은 성장 방향을 고르는 데 쓴다.’ 기술 해금과 재화의 차이를 연결한다.

강제 철수 임무의 목표와 보상 없음은 유지한다. 첫 무림 보상은 대여 연습이 아닌 정상 탐사 완료에서 주며, 현실의 첫 C/D도 정상 균열 완료에서 준다. 이야기 전면 재작성은 하지 않는다.

## 9. 데이터·저장·이전 기록

역할을 분리한다: 보상 시스템은 획득, 성장 모델은 소비·환불, UI는 조회·미리보기, 저장 모듈은 검증·복원한다. UI가 잔액을 직접 수정하지 않는다.

추천 새 장부 `worldState.crossWorldItems`는 버전, 성장 프로필, 아이템별 획득·소비·환불·잔액, 세계별 배분/노드, 보상 완료 ID를 가진다. 잔액 = 획득 - 소비 + 환불이고 모두 범위 내 정수다. 배분과 노드 비용도 소비 장부와 일치해야 한다. 현재 `save-v10.js`의 엄격한 허용 목록과 검증에 명시적으로 추가한다.

보상/구매/환불은 원자적으로 검증 후 적용한다. 저장 실패는 성공 메시지를 띄우지 않고 직전 상태로 되돌린다. 제한된 지급 기록은 영구 1회 사건 집합과 반복 탐사의 완료 순번으로 분리한다. 완료 순번은 저장된 활성 탐사와 일치해야 하며 감소하거나 같은 순번으로 재지급할 수 없다. 장부·순번·수량의 상한을 정의하고 잘못된 입력은 조용히 보정하지 않고 해당 가져오기를 거부한다.

이전 기록 정책:

1. 시험 슬롯은 `dualworld.test.v02`로 분리하고 공개/기존 `v10` 기록을 자동 덮어쓰지 않는다.
2. 기존 세이브는 원본을 보관한 뒤 별도 시험 슬롯에 복사한다. 이전 버전으로 다시 읽을 수 없는 파일도 원본을 대체하지 않는다.
3. 기존 레벨·배분·패시브·현실 복사 효과·체득 상태는 `legacy` 프로필로 보존한다. 신규와 별도 밸런스 비교한다.
4. 기존 패시브 투자와 새 노드가 같은 효과를 내면 중복 적용하지 않는다. 구효과 유지 또는 동일 노드로 옮김 중 하나만 적용하고, 첫 프로토타입은 구효과 유지로 시작한다.
5. 구효과는 새 재화로 환불하지 않는다. 새 장부에서 실제 지출한 재화만 환불할 수 있다. 자동 신규 지급이나 과거 보고 재처리로 무상 재화를 만들지 않는다.
6. v0.1 전용 `ReturnProof` 상태가 포함된 세이브는 이번 기준 main과 다르다. 별도 호환 분석 전에는 가져오기를 지원한다고 안내하지 않는다.

## 10. 검증 기준과 단계

이 절은 기획 검증 범위이며 승인된 구현 작업 계획이 아니다.

**첫 프로토타입 범위:** 네 재화의 첫 획득·보관·소비·환불, 세계별 능력치 3항목, 파문 강화 3노드, 이야기 해금 유지, 별도 시험 슬롯, 획득/귀환 안내. 전체 기술 확장과 반복 경제는 이후 단계다.

| 검증 | 통과 조건 |
|---|---|
| 연결 이해 | 획득 직후 출처·사용 세계·용도를 설명하고 적절한 성장 화면으로 이동한다 |
| 첫 사용 | 양 세계 첫 정상 완료 후 상대 세계의 능력치 1회·기술 1회 투자가 가능하다 |
| 세계 분리 | A/B 소비가 무림 배분을 바꾸지 않고 C/D 소비가 현실 배분을 바꾸지 않는다 |
| 이야기 권한 | 재화를 충분히 넣어도 미체득 R/F 사용·구매가 불가능하다 |
| 숙련 분리 | 재화 소비가 숙련을 올리지 않고 숙련 획득이 재화를 지급하지 않는다 |
| 보상 중복 | 같은 완료 재처리·재보고·재접속에 추가 보상이 없다 |
| 구매/환불 | 빠른 연속 클릭·저장 실패·재접속에서도 정확히 한 번 적용된다 |
| 이전 기록 | 원본 세이브 유지, 기존 체득·효과 유지, 구투자 환불로 새 재화 생성 불가 |
| 접근성 | 360px·키보드·200% 확대에서 세계/재화/확정 상태를 읽고 조작 가능 |
| 성장 체감 | 같은 적 구성에서 배분 전후 공격 횟수·피해·시간과 사용자 설명을 비교한다 |

성장 수치의 합격을 ‘강해졌다’라는 내부 계산만으로 판정하지 않는다. 첫 플레이의 획득→귀환→선택→재전투 시간을 기록하고, 한 번의 왕복에서 결과를 설명할 수 있는지 확인한다. 실제 전투 목표 수치는 기초 측정 후 정한다.

권장 진행 순서: 기획 검토 → 데이터/보상 정책 확정 → 능력치와 보유 재화 → 파문 트리와 숙련 표시 → 이야기 안내 → 저장·재접속·모바일 검증 → 반복 경제와 다른 기술 확장. 각 단계의 구현 세부 작업과 테스트 명령은 기획 승인 뒤 별도 계획에 작성한다.

## 11. 검토 요청

확정된 A/B/C/D 대응을 바탕으로 **4종 전용 재화, 세계별 독립 투자, 이야기 체득 유지, 숙련 비소모 유지**를 추천한다. 수치와 노드는 초기 비교안이다. 이 방향을 검토한 뒤 구현 작업 계획을 작성한다. 천혼/천흔 지역 대응과 첫 보상 구체 위치는 그 계획을 쓰기 전에 확정한다.
