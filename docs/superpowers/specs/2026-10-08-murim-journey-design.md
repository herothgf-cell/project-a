# 무림 1~2장 집중 개편 설계

## 사용자 목표와 확정 범위
현실에서 무림에 떨어진 윤서는 부상한 백련을 돕는다. 천흔과 마교 활동을 조사하던 백련을 쫓아온 정체불명 추적자 때문에, 응급처치 후에도 무공이 약해진 백련이 삼재검법을 급히 전수한다. 이동·공격·회피와 스탯·스킬 UI를 익힌다. 현실 귀환이 당면 목표지만 천흔은 위험하므로 백련 치료를 위해 10개 무림 던전을 넘어 화산으로 간다. 여러 문파 인물을 만나 성장 방향을 선택한다.
2장은 치료를 마친 백련의 제자 제안으로 시작한다. 수락하면 이십사수매화검법과 제1초식, 거절하면 미획득. 양쪽 모두 성장·선택 기연 기회를 거쳐 천흔 보스를 제압하고 현실에 돌아온다. 이번 새 여정은 첫 귀환에서 끝나며 3장 이후/현실 전투·트리 개편은 제외한다. 확정 투자 초기화 금지와 기존 저장 보존은 유지한다.

## 설계 판단과 검증안
- ‘삼재겁법’은 삼재검법으로 해석한다. 백련의 기초/제자 전수는 최신 요청을 우선하며 이전 별도 전수자 경로는 구 저장에서만 유지한다. 화산 내 지위·개인 과거를 새로 확정하지 않는다.
- 공통 기초 이후 검술·보법·내공 3개 분기에 자유 투자한다(사용자 후속 답변 확정). 문파 인물은 해당 기초의 수련 기회를 전한다. 문파 가입 강제나 원전의 정식 무공 계보라고 주장하지 않는다.
- 무림 스탯 재료 ‘단련석’, 스킬 재료 ‘수련첩’은 고정 최초 완료 보상. 레벨 기본 성장과 별도다. 실제 수치·적 구성·분기 효과·등장 인물 이름은 모두 검증안.
- 10개 던전은 별도 목적지/완료/보상 ID와 배치·적 조합을 가진다. 기존 무림 아트를 재사용한다. 2장 귀환 길은 3개 전장과 별도 선택 기연 전장으로 검증한다.
- 선택 기연 ‘천흔 호흡’은 이번 초반 성장 검증용 영구 보너스다. 파문 전체 기연·R/F 체계의 추가 개편은 하지 않는다. 미획득·제자 거절로도 귀환 가능하다.

## 구조
`murim-journey.js`: 새 여정 상태/지역/진행/목표/보상/선택. `murim-growth.js`: 재료 원장/영구 투자/기술 해금과 효과. `murim-journey-ui.js`: 10개 여정 목록, 튜토리얼, 3열 스킬 트리와 스탯 배분. WorldGame은 선택적 worldState.murimJourney가 있는 게임만 새 모델에 연결한다. 새 게임은 새 여정, 구 저장은 원래 흐름과 이력을 보존한다. 테스트/기존 전체 여정은 명시적 classic 시작 경로로 계속 검증한다.

## 진행과 실패 복구
intro → tutorial → road(1~10 순차 해금) → treatment → choice → return(1~3) → complete. 실전 튜토리얼은 움직임/유효 기본 공격/실제 회피 사용을 각각 기록한다. 위험한 예고 타이밍 성공을 본편의 숨은 잠금으로 사용하지 않는다. 스탯·스킬 UI 확인과 투자 권유는 안내하되 특정 투자 강제는 하지 않는다. 전장 사망/철수는 안전 거점으로, 최초 완료와 투자/보상은 유지한다. 재진입·재로드·반복 상호작용으로 재료가 중복 지급되지 않는다. 완료 후에도 재료 확인은 가능하다.

## 호환·안전
새 필드는 선택적으로 추가한다. 기존 저장의 진행/성장/투자를 임의 환산하거나 초기화하지 않는다. 새 전장은 레거시 검증에 안전 거점으로 투영 후 실제 전장을 복원한다. 세부 검증은 단계/선행/선택/보상 원장·정수 범위 일치를 확인한다. UI 저장 실패 시 기존 commitGrowth 트랜잭션으로 되돌린다. 기존 안내 버그는 화산 소개 후 던전 입구를 가리키도록 별도 회귀 검사한다.

## 완료 기준
새 게임에서 UI/현장 입력으로 튜토리얼 완료, 10개 지역별 고유 사건과 최초 보상, 선택 투자 효과, 치료 전 제자/현실 진입 금지, 수락/거절 모두 귀환, 선택 기연 미획득/획득 모두 귀환, 중간 저장·사망·재완료 보상 보존, 구 저장 4종 및 기존 회귀 통과. 360px 모바일/데스크톱 UI와 안내 대상 일치 검증. 사람의 난이도 체감/최종 밸런스는 미확정으로 보고한다.
