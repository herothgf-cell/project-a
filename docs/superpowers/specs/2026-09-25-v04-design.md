# 쌍계 v0.4 — 나의 전설

## 목적과 승인 범위
사용자가 기획·리스트·개발을 위임했다. 진행 안내 → 기연 3계열 → 무공 연출 → 그래픽 → 기연 이야기 → 검증까지 이 세션에서 실행한다. 별도 Codex 인계나 승인 대기는 하지 않는다. 기존 main a959644와 1·2장, 브라우저 저장 키, Pages 주소를 보존한다.

## 핵심 경험
주어진 직업을 메뉴에서 고르는 대신, 흔적 발견 → 임시 무공 시험 → 실제 전투 행동으로 증명 → 사부에게 수락 → 현실에서 활용 → 별호 완성으로 연결한다. 모든 유저가 세 계열 모두 체험 가능하며 동시에 장착하는 개인 계열은 하나다. 서버 전역 유일 직업/온라인 멀티플레이/생성형 무한 스토리를 주장하지 않는다.

## 제3장: 이름 없는 전설
제2장 완료(progress=12) 후 서린 대화 → 백련 대화 → 무명 비경 진입.
비경의 부러진 검/겹쳐진 발자국/봉합된 비석을 조사하면 각각 파문검/잔영보/경계봉인의 임시 공명과 시험이 열린다. 핵심 행동 1회 성공과 시험 잔상 제압을 모두 달성하면 그 길의 증거를 얻는다. 기본 공격만으로는 시험을 통과할 수 없으며 UI에 조건을 명시한다.
백련에게 돌아와 증명한 계열 하나를 수락한다. 두 액티브와 오의를 얻으며 다른 증명 계열로 무료 재수련할 수 있다. 현실의 서린 → 경계의 심장 → 보스 공략 → 서린 보고로 계열별 별호·대사·기록을 완성한다.

## 무공 (첫 릴리스: 계열당 액티브 2 + 오의 1)
|계열|Q|R|F (기세 100)|
|---|---|---|---|
|파문검|파문세: 0.7초 받아내기, 성공시 힘 축적·반격|역류참: 축적된 힘을 소비하는 전방 검격|파천반월: 큰 반원 검격·보스 자세 붕괴|
|잔영보|잔영각: 충돌을 지키는 돌진·5초 잔향|귀환보: 지나온 자리가 연결된 경우 복귀·잔향 협공|월흔난무: 3회 시간차 협공|
|경계봉인|쇄경진: 4초 결계, 적 속도/공격 진행 억제·위험 완화|봉맥인: 최대 2명 속박·피해, 보스 속박 시간 감소|만경고정: 넓은 범위 억제·공격 예고 해제|
기본기·회피는 유지한다. 오의는 실제 타격·기연 성공으로 얻는 기세를 소비한다. 쿨다운/내력/잠금 조건을 UI와 모델 양쪽에서 검증한다.

## 구현 경계
fate.js는 DOM-free 기연 상태·스토리·전투 규칙. game.js에 명시적 lifecycle hook/공통 피격 함수를 추가한다. fate-art.js는 Canvas 전용 연출. 기존 art/render는 연결과 실루엣·환경 개선을 담당한다. app.js는 조작과 대화, 인게임 기연 도감·수락·재수련을 담당한다.
저장 version=3; v1/v2는 기본 기연 상태로 마이그레이션한다. 시험/잔향/결계/시각효과는 저장하지 않고 거점 복귀한다. 영구 기연 경로·증거·진행·행적은 보존한다. 손상된 저장을 자동 덮어쓰지 않는다.

## 그래픽과 접근성
계열별 금백/청자/청록 문양, 캐릭터 검·의상 장식, 오의 타이틀, 충격선/잔향/봉인진. 도시 네온·비 반사, 무림 안개·잎새·석판, 비경 문양·심장 균열. 위험 예고는 VFX보다 판독 우선. 효과 낮음/보통/높음, reduced-motion, 파티클·잔향 상한, 저프레임 자동 시각 품질 감소. 품질 설정은 피해와 공격 타이밍을 바꾸지 않는다.

## 완료 기준
세 계열 모두 실제 시험부터 최종 보고까지 수행 가능한 모델 테스트. 기존 33 테스트 유지. PC/모바일 브라우저에서 시작/기연 UI/키보드·멀티터치/쿨다운/오의/저장/8지역 렌더 확인. GitHub CI 통과 후 Pages 배포; 실패를 숨기거나 테스트를 건너뛰지 않는다. 실제 모바일 기기의 성능·Safari 검증과 자동화 에뮬레이션은 구분해서 보고한다.
