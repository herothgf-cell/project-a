# v0.7 — 기록에 없는 귀환자 / 설계

## 승인된 방향과 자료 구분
사용자가 앞선 추가요소 제안 전체를 바탕으로 main에서 한 번에 구현·커밋·푸시·배포하도록 요청했다. 첨부 `로그인 무림 상세 정리.txt`의 기감(228~232), 성장축(281~323), 두 세계 연동(398~441), NPC 기억(451~466), 현상 선행의 기연(470~503), 가상 기록(507~559)을 설계의 출발점으로 삼는다. 다음 사건·인물·수치·구현은 원작 설정이 아닌 쌍계용 창작이다. 숨겨진 조건의 X/Y 표시는 쓰지 않는다. 서버 최초/실제 유저 사칭은 제외한다.
