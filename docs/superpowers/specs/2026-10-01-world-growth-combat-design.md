# 쌍계 세계별 성장과 전투 개편 최종 검토안

이 문서는 v0.11.0의 세계 공통 성장 구조를 개편하고, 성장 전후의 전투 차이와 성장 기능의 접근성을 개선하는 개발 기준이다. 목표는 같은 캐릭터가 배경만 바꾸는 경험이 아니라, 무림에서 익힌 원리가 현실에서 다른 능력으로 나타나고 현실의 경험이 다시 무림의 문제 해결에 쓰이는 경험이다.

사용자는 이 문서 제시 후 “개발 진행해줘 mian브랜치 커밋 / 푸시 다시 배포까지”라고 승인했다. 이 문서의 저장 정책, 구체적인 기술 운용과 전투 검증 기준을 구현 계획의 기준으로 사용한다. 현재 배포는 main 커밋 18bb836의 v0.11.0이며 설계 승인은 구현 완료를 의미하지 않는다.

## 범위와 유지 사항

- main에서 직접 작업하고 별도 브랜치나 worktree를 만들지 않는다.
- 기존 1장부터 7장까지의 중심 사건과 인물을 유지한다. 정보 전달 순서와 새 기술의 사건 해결 조건은 함께 수정한다.
- 세계별 성장, 귀환 성과, 현실 대응 기술, NPC 보고, 성장 UI, 소식과 레드닷, 전투 밀도와 역할, 회복약 안내를 이번 개편에 포함한다.
- 현장 의뢰는 새 버전에서 수주·보고·목표·진입 버튼을 제거한다. 반복 의뢰 없이 본편을 완료할 수 있도록 성장량을 맞춘다.
- 새 장, 장비 파밍, 추가 경지 단계, 정식 헌터 승급, 멀티플레이, 서버 최초 경쟁은 추가하지 않는다.
- 방향키 이동과 QWER ASDF 전투, G 상호작용, 키 변경, 키보드 대화 선택을 유지한다. 대화 버튼에 별도 단축키 배지를 다시 붙이지 않는다.
- 자동 이동은 추가하지 않는다. 이전에 고친 길 안내, UI 클릭 차단, 글씨 크기와 비차단 레벨 알림을 유지한다.
- 사용자 소유의 미추적 아트 후보·Unity·참고 파일은 수정하거나 승격하지 않는다. 새로운 이미지 제작은 이번 구현에 자동 포함하지 않는다.

## 기존 저장은 보관하고 새 성장으로 시작

기존 저장의 성장 기록을 현실과 무림으로 추정 분배하지 않는다. 새 저장은 별도 키와 버전 10으로 만들며 기존 dualworld.save.v1 원문을 읽기 전용으로 보존한다. 구 저장이 있으면 시작 화면에서 이전 기록 보관 안내와 JSON 내보내기를 제공한다. 손상된 구 저장도 원문 내보내기는 가능해야 한다.

새 게임과 이어하기는 새 저장만 사용한다. 구 저장을 새 저장 가져오기에 넣으면 지원하지 않는 이전 기록임을 설명하고 현재 기록을 덮어쓰지 않는다. 새 게임 재시작은 기존 새 저장이 있을 때만 명시적으로 확인받는다. 구 저장을 새로 만든 빈 데이터로 덮어쓰거나 자동 삭제하지 않는다.

이전 빌드는 v0.11.0 규칙을 사용하는 별도 legacy 경로로 고정해 비교 플레이할 수 있게 한다. 저장 연결부만 별도 보관판 키로 분리하고 최초 실행에 구 저장 원문을 복사한다. 이후 보관판 진행은 복사본에만 쓰며 원본과 개편판 저장에는 접근하지 않는다. 새로운 런타임과 뒤섞이지 않게 자산 경로와 캐시도 분리하며 보관판임을 표시한다. 서로 다른 출처의 배포 주소 사이에는 브라우저 저장이 자동 공유되지 않으므로 JSON 내보내기와 가져오기를 안내한다.

개발용 시작점은 새 게임, 5장 완료, 6장 완료를 제공한다. 테스트 전용 실행에서만 노출하고 별도 테스트 저장을 사용한다. 본 플레이 기록에 실제로 하지 않은 계승이나 사건을 넣지 않는다. 시작점은 새 성장 규칙으로 생성하고 테스트 데이터라는 표시를 유지한다.

## 세계별 성장 데이터

현실과 무림은 각각 레벨·경험치·장착 기술을 보관한다. 현재 세계의 값만 전투 계산과 HUD에 적용한다. 전환은 다른 세계 기록을 덮어쓰지 않는다. 공통 level과 xp를 양쪽에 복사하는 방식은 사용하지 않는다.

설정상 두 명의 윤서나 별도 육체가 되는 것은 아니다. 같은 사람이 세계마다 힘을 끌어내는 방식이 다르고, 익힌 원리가 다른 세계에서 적응한 결과가 전승이라는 설명으로 일관시킨다.

| 항목 | 무림 | 현실 |
| --- | --- | --- |
| 기본 성장 | 무림 전투와 해당 세계 퀘스트 경험치 | 현실 전투와 해당 세계 퀘스트 경험치 |
| 능력치 출처 | 무림 레벨, 수련, 경지 | 현실 레벨, 정착한 전승 성과 |
| 기술 | 기존 공통 무공, 기연 계열, 해석 | 기본 전투와 계열별 현실 대응 기술 |
| 운용 | 유수 또는 집중심법 | 대응하는 회복 또는 집중 운용 |
| 사회적 표시 | 경지 | E급 헌터와 별도의 현장 자격 |

윤서의 인물 정보, 이야기, 발견한 사실, 금화, 회복약 수량은 공유한다. 경제까지 두 벌로 늘리지 않는다. 무림 숙련과 현실 기술 숙련은 구분하고, 현실 타격이 무림 숙련 수치를 직접 올리지는 않는다. 첫 경지의 두 세계 실전 조건에는 현실 실전 기록을 사용한다.

경험치의 귀속은 보고 장소가 아니라 퀘스트 보상 정의에 고정한다. 두 세계가 함께 관련된 장의 완료 보상은 보상창에 세계별 지급량을 명시한다. 처치는 해당 전투 세계 경험치만 준다. 허공 공격, 잔류 파형, 연습과 테스트 시작점은 영구 성취를 새로 지급하지 않는다.

세계별 최대 레벨은 80으로 유지하고 다음 레벨 경험치는 70 + 현재 레벨 × 45로 시작한다. 기본 체력 120, 자원 80, 공격력 16과 레벨당 체력 18·자원 5·공격력 3을 초기 비교 기준으로 사용한다. 현실 능력치에 무림 수련과 경지 보너스를 직접 더하지 않는다. 전투 검수에 따른 조정은 변경 전후와 근거를 기록한다.

안전 거점 진입 시 현재 세계 최대 체력과 자원으로 회복한다. 전투 중 세계 전환은 추가하지 않는다. 전환 시 일시 강화, 반격 대기, 연계 창, 타격 예약은 종료하고 장착·영구 성과는 유지한다. 회복과 최대치 변경 때문에 체력이나 자원이 상한을 넘지 않아야 한다.

## 귀환 성과와 중복 방지

정산 대상은 현재 공격력이나 체류 시간이 아니라 고유한 영구 성취다. 각 성취의 발견과 현실 반영을 별도로 기록하고, 현실 귀환 시 미반영 성취만 자동 적용한다. 결과창을 닫거나 다시 열어도 보상이 달라지지 않는다. 저장 실패 시 실패 안내를 표시하고 이미 저장된 원본을 파괴하지 않는다.

초기 전승 보상은 다음 표로 시작한다. 수치는 새 시제품 검수 기준이며 실제 전투 확인 후 같은 총성장 범위 안에서 조정할 수 있다.

| 무림 성취 | 현실 변화 | 반복 제한 |
| --- | --- | --- |
| 무림 레벨 5와 10 도달 | 각 최대 체력 5 증가 | 구간당 한 번 |
| 계열 숙련 5와 10 달성 | 각 현실 공격력 1 증가 | 계열과 구간별 한 번 |
| 첫 경지 돌파 | 최대 체력 10, 최대 자원 5 증가 | 첫 돌파 한 번 |
| 기연 최초 계승 | 해당 현실 대응 기술 발현 가능 | 계열별 한 번 |
| 새로운 해석 발견 | 대응 기술 설명에 원리 기록과 현실 재현 목표 추가 | 해석별 한 번, 단순 발견으로 공격력 지급 없음 |

현실 레벨은 전승으로 상승하지 않는다. 계열·심법을 바꾸거나 이미 발견한 해석을 재장착하는 것은 성취가 아니다. 이미 받은 보정도 회수하지 않는다. 금화 환급과 귀환 성과를 같은 정산 이름으로 섞지 않는다. 새 게임에는 기존 강화 환급·기존 성장 보정·정산 잔액을 표시하지 않는다.

새 변화가 있으면 원인, 이전 값, 이후 값과 현실 기술의 상태를 소식에 남긴다. 전투 중에는 비차단 알림만 보여주고 큰 결과창을 강제로 열지 않는다. 새 변화 없는 왕복에는 결과창과 새 소식을 만들지 않는다. 적 수에 따른 경험치 증가와 전승 보너스를 함께 검수해 현실 자체 성장이 무의미해지지 않게 한다.

## 현실 대응 기술과 첫 발현

공통 기본 공격·회피는 항상 쓸 수 있다. 무림 기술을 현실에서 이름만 바꿔 그대로 실행하지 않는다. 현실 기술도 동일한 입력 체계에 배치하되 세계별 장착을 기억하고 기술 설명과 효과를 바꾼다. 새 계열 획득으로 기존 장착을 강제로 교체하지 않는다.

| 계열 | 무림의 원리 | 현실의 대표 대응 |
| --- | --- | --- |
| 파문검 | 받아내고 파문을 축적해 방출 | 충격 흡수 후 다음 수동 공격 강화. 여러 파문 축적 대신 한 번의 대응 기회 |
| 잔영보 | 잔향을 남기고 그 위치로 귀환 | 긴급 가속으로 현재 위험 구역을 벗어나고 회피 직후 공격 강화. 과거 위치 귀환 없음 |
| 경계봉인 | 결계와 속박으로 기운 제어 | 지정 방향의 가까운 적 하나에 균열 억제를 걸어 재생과 공격 예고를 차단. 광역 결계와 구분 |

첫 계승 계열이 무엇이든 현실 귀환 후 안전한 비교 전투에서 그 대응을 한 번 실행하도록 안내한다. 임시 사용은 가능하되 실제 방어·회피·억제 성공으로 정착한다. 실패·패배·떠나기는 재도전 가능하며 기술을 빼앗지 않는다. 이후 계열도 발현 가능과 정착 상태를 구분하되 긴 강제 튜토리얼은 반복하지 않는다.

각 계열의 보조 기술과 오의는 대표 대응의 강화·후속 동작으로 구성하고 원본의 위치 귀환이나 광역 결계를 무조건 복사하지 않는다. 정확한 비용·대기시간·피해 배율은 구현 계획의 전투 표에서 고정한다. 세 계열 모두 본편을 완료할 수 있어야 하며 한 계열만 완성한 채 다른 계열의 현실 진행을 막는 배포는 하지 않는다.

현실에서 정착시킨 대응 원리와 실전 기록은 무림에서 확인할 수 있게 한다. 현실 전승 공격력을 무림에 다시 환산하지 않는다. 현실 실전은 첫 경지의 두 세계 조건과 7장의 현장 준비에 기여하며 이미 구현한 세계 간 사건 변화는 유지한다.

## 기존 사건과 NPC 정보 전달

서린은 현실에서 관측한 신호와 윤서가 보고한 사실만 안다. 무림에서 발생했다는 이유로 인물의 이름·구조 결과·가게 재개업을 자동으로 알지 않는다. 사건 완료, 윤서의 직접 확인, 서린에게 보고를 구분한다. 대화 건너뛰기는 끝의 명시적인 보고 행동을 대신 실행하지 않는다.

4장 시작은 현실 부두의 이상 신호 조사로 소개한다. 윤서는 무림에서 고립된 연화와 귀환로 문제를 직접 알게 된다. 귀환 후 윤서의 구조 보고와 서린의 현실 관측이 이어진다. 청운촌에서 재회했다는 사실은 실제 확인 이후에만 보고한다. 서린이 소식을 다른 경로로 들었다는 대사는 제거한다.

5장은 무림에서 발견한 원리가 현실 대응 기술에 재현되는지를 조사한다. 단순히 기술 버튼을 누르는 것으로 인증하지 않고 해당 원리의 실제 효과를 검사한다. 새 기술과 해석의 대응 목록을 한곳에 둬 목표·판정·설명이 서로 다르지 않게 한다. 특정 해석에서 정착 기술이 아직 없다면 발현 경로를 먼저 안내한다.

6장 쌍계 호흡은 무림의 공통 무공과 기연뿐 아니라 현실의 기본 전투와 대응 기술 사이에도 적용한다. 유수 계통은 유효 연계 후 다음 자원 기술 비용 감소, 집중 계통은 준비된 수동 공격 후 대응 기술로 재생 억제라는 원리를 유지한다. 기존 4초 연계 창과 무료 8초 보조, 억제 6초를 유지해 비교한다.

7장의 무림 준비는 현실 안전 영역과 파동 간격을 실제로 바꾸고, 현실 안정 결과는 무림 중심부 접근으로 이어진다. 물리적 변화는 즉시 발생할 수 있지만 NPC가 사건 내용을 설명하는 것은 윤서의 전달 이후다. 이미 완료한 현장 준비는 패배·귀환·저장에 보존한다. 이야기 본문과 화면용 대사표를 함께 정리해 제목 기반 대사 교체가 과거 문장을 되살리지 않게 한다.

## 화면과 성장 행동의 분리

HUD 초상화를 접근 가능한 버튼으로 만들고 캐릭터 상태를 연다. 필드 캐릭터 클릭에는 메뉴를 붙이지 않는다. UI 위의 클릭·우클릭은 공격·회피로 전달되지 않는다.

| 화면 | 첫 화면의 내용 | 실행 기능 |
| --- | --- | --- |
| 상태 | 현재 세계 레벨·경험치·체력·자원·공격력, 헌터 등급 또는 경지 | 다른 세계 비교와 능력치 출처 펼치기 |
| 무공 또는 스킬 | 현재 세계 장착, 보유 계열, 숙련, 해석 또는 대응 원리 | 계열 변경과 해석 장착 |
| 성장 | 경지 카드와 심법 또는 현실 운용 카드 | 거점에서 즉시 돌파와 운용 변경 |
| 소식 | 읽지 않은 성장·해금·귀환 변화 | 해당 상세 화면으로 바로 이동 |
| 행적과 수첩 | 실제 사건, 확인한 사실, 보고 기록 | 읽기와 관찰 안내 |

상태 화면에는 긴 숙련 목록과 돌파 조건을 모두 나열하지 않는다. 성장의 돌파·심법 카드와 실행 버튼은 좁은 화면에서도 첫 화면에서 접근할 수 있게 한다. 전투 중 변경 불가는 이유와 거점 안내를 보여주되 기능을 숨기지 않는다. 기존 중복 변경 경로는 해당 단일 화면으로 연결한다.

최초 획득은 계승하기, 보유 계열 변경은 변경하기, 현재 계열은 현재 운용 중으로 표시한다. 같은 계열을 다시 수락하는 버튼은 비활성화한다. 보유 계열이 하나면 변경 진입을 생략하되 보유 기술은 볼 수 있다. 무공 연습·최초 계승·계열 변경·해석 장착을 별도 행동으로 표시한다. 신규 스킬 설명에 표시하는 입력은 고정 E/R/F가 아니라 사용자 키 설정을 따른다.

## 소식과 레드닷

소식은 실제 플레이어의 변화만 기록한다. 채팅·가상 유저·전 세계 방송은 넣지 않는다. 레드닷은 읽지 않은 항목을 나타내고 돌파 가능 같은 실행 상태와 구분한다. 상태·성장·무공 메뉴와 소식이 동일한 항목의 읽음 상태를 공유한다.

- 최초 기술·해석·운용 해금, 돌파 조건 첫 충족, 새 귀환 성과만 소식으로 만든다.
- 반복 처치·골드 획득·매 타격·같은 심법 재선택은 기록하지 않는다.
- 목록을 열었다는 이유만으로 전체를 읽음 처리하지 않는다. 해당 상세를 확인하면 관련 레드닷도 해제한다.
- 확인은 장착·돌파·보고 실행과 별개다. 돌파 가능 문구는 조건이 유지되는 동안 남는다.
- 이미 읽은 소식은 재접속·세계 전환·메뉴 열기로 다시 생성하지 않는다. 항목별 고유 ID와 읽음 상태를 저장한다.
- 소식에서 연결한 기능을 현재 지역에서 쓸 수 없으면 이유와 거점 안내를 보여준다. 숨은 기연 정답은 소식에 공개하지 않는다.
- 알림은 색상만으로 구분하지 않고 새 소식 수와 접근성 이름을 제공한다. 키보드로 확인·이동·닫기가 가능해야 한다.

## 전투 밀도와 성장 체감

초기 E급은 평타만 반복해 모든 공격을 버티는 상태가 아니라 예고를 보고 피해야 하는 상태로 만든다. 강제 패배·긴 무력 구간·반복 의뢰를 통한 필수 레벨업은 넣지 않는다. 성장 후에는 이전의 같은 적을 더 빠르고 안전하게 처리하고, 새 정예가 대응 기술을 요구하게 한다. 기존 적을 플레이어 레벨에 맞춰 자동 강화하지 않는다.

초기 전투 지역은 보스 포함 7명, 중반은 9명, 6장과 7장 현장은 6명을 첫 배치 목표로 한다. 좁은 구역에 모두 몰지 않고 경로상 2~3개 무리로 나눈다. 사거리 밖의 무리까지 한꺼번에 활성화하지 않는다. 무리당 동시에 근접 공격 예고를 시작하는 적은 최대 2명으로 제한하고, 원거리 공격은 별도 식별 가능한 예고를 둔다. 보스와 추가 적의 예고가 회피 불가능하게 겹치지 않아야 한다.

근접 압박, 느린 강타, 원거리 견제를 실제 동작으로 구분한다. 적 수 증가는 기존 그림의 역할에 맞는 적을 재배치하는 방식으로 시작한다. 단순 복제 때문에 보스가 여러 명 생기거나 처치 보상·클리어 판정이 중복되지 않아야 한다. 등장 좌표는 적의 전체 충돌 반경과 길 연결을 검증한다.

초기 현실 비교 전투는 기존 현실 균열 적과 동일한 기준 적을 사용한다. 무림 전승 전후에 적 능력치를 바꾸지 않고 다음 차이를 측정한다. 강제 피격 장면 없이 예고를 피하는 기본 전투로도 통과할 수 있어야 한다.

| 검증 | 통과 기준 |
| --- | --- |
| E급 기본 상태 | 무대응 평타 반복은 피해 위험이 있고 회피를 사용하면 첫 전투 완료 가능 |
| 첫 현실 대응 정착 후 | 동일 적·동일 공격 기회에 대응 기술을 사용하는 비교에서 처치 시간 또는 받은 피해 중 하나가 25% 이상 개선되고 다른 지표가 악화되지 않음 |
| 이전 지역 재방문 | 성장 후 일반 적은 눈에 띄게 빨리 처리되며 자동 레벨 보정 없음 |
| 후반 정예 | 체력만 늘어난 적이 아니라 받아내기·회피·억제 중 현재 계열의 대응이 유효함 |
| 전체 본편 | 반복 의뢰 없이 세 계열 모두 7장까지 진행 가능 |

이 비율은 재미를 증명하는 수치가 아니라 최초 조정의 검사 기준이다. 사람이 직접 플레이하며 피격 빈도·회복약 소비·전투 길이·적 밀도를 확인하고 최종 수치와 이유를 검수 기록에 남긴다. 데스크톱과 좁은 화면에서 예고 가독성과 프레임 비용을 함께 검사한다.

## 회복약과 현장 의뢰 정리

회복약은 기본 1키와 기존 화면 버튼으로 사용하고 최대 체력의 55%를 회복하며 재사용 대기는 1초, 가격은 25금화를 유지한다. 보유량·현재 회복량·사용 불가 사유를 버튼 상세에서 확인할 수 있게 한다. 체력 40% 이하이면서 약이 있을 때 첫 한 번만 비차단 사용 안내와 버튼 강조를 표시한다. 자동 사용이나 전투 중 강제 팝업은 추가하지 않는다. 움직임 감소 설정에서는 점멸 없이 정적으로 강조한다.

새 버전의 의뢰 버튼·의뢰판·수주·목표 우선순위·보상 경로를 제거하고 완료 후 대사에 남은 실전 의뢰 문구도 정리한다. 이전 버전의 의뢰는 보관판에서만 유지한다. 금화의 용도는 회복약 보급으로 남고 공격력 구매는 되살리지 않는다.

## 아트 검토와 제작 경계

기능 시제품은 기존 승인된 공개 프로토타입 자산과 Canvas 효과로 구현한다. 적 밀도 증가는 기존 적 재사용으로 시작하며 새로운 몬스터 종류를 요구하지 않는다. 새 UI 알림은 HTML/CSS로 구성한다. 미검수 이미지 후보를 자동 채택하지 않는다.

세계 차이를 최종 품질로 보여주기 위해서는 현실 충격 흡수·긴급 가속·균열 억제의 고유 동작과 이펙트, 무림과 다른 현실 스킬 아이콘이 추가 제작 후보가 된다. 기존 캐릭터 동작을 재생하면서 효과만 바꾼 경우 최종 보고에서 임시 표현임을 명시한다. 근접·강타·원거리 적의 구분이 기존 실루엣으로 충분한지도 실제 화면에서 판단한다.

최종 보고는 추가 아트를 필수, 권장, 현재 재사용 가능으로 나눠 설명한다. 새 이미지 제작은 별도 요청 없이는 진행하지 않는다. 아트가 없어 기술의 판정 범위를 읽을 수 없는 경우에는 불분명한 상태로 완료 처리하지 않고 코드 효과로 우선 보완하거나 제한을 보고한다.

## 검증과 배포 완료 기준

세계별 경험치와 능력치, 귀환 한 번 지급, 새 저장 반복 불러오기, 손상 데이터 거부, 구 저장 비변경, 세계별 장착, 보고 전후 대사, 읽음 동기화, UI 전투 차단, 저체력 안내를 회귀 테스트로 고정한다. 테스트 중 사용자의 실제 플레이 저장은 변경하지 않는다.

자동 검사는 기능 구현 전에 실패를 확인하고 구현 후 통과시킨다. 기존 회귀 테스트를 무조건 새 값으로 바꾸지 않고 구 규칙은 보관판 검사, 새 규칙은 개편판 검사로 구분한다. 세 계열과 양 세계, 4장 구조·5장 인증·6장 연계·7장 해결을 브라우저와 모델 양쪽에서 확인한다. 저장과 전투 경계는 최종 독립 코드 검토를 받는다.

모바일 390×844와 360×640, 가로 844×390, 데스크톱, 확대 글씨에서 메뉴·알림·전투 예고를 확인한다. 아트 첫 사용 로딩과 월드 전환 선로딩은 유지한다. 새 기술을 처음 쓸 때 판정만 진행하고 화면 동작이 보이지 않는 회귀가 없어야 한다.

배포 버전은 v0.12.0으로 묶는다. main 최신 원격 변경을 확인하고 통합 후 검사를 실행한다. 승인 범위만 명시적으로 커밋·푸시하고 GitHub Pages의 검사·배포·공개 커밋과 런타임 해시 일치까지 확인한다. 문서 작성이나 로컬 검사만으로 배포 완료라고 보고하지 않는다.
