# B안 일반 성장·개별 성취 개편 설계

기준: main a8d6214. AGENTS.md와 docs/planning/ 18개 문서 전수 읽음. 기존 Node 테스트 748개 통과. 최신 사용자 요청은 main 개발 및 검증 후 푸시·배포를 포함한다.

## 확정 계약

D-024 B / D-025 A / D-026 A 채택. 백련은 독립 첫 스승, 화산 전수자는 별도 역할명으로 배치한다. 무공 기본형은 1~9성, 무공별 예외 허용, 이십사수매화검법은 초식별 성취다. 현실 개별 성취와 투자는 무림과 별도다. 일반 성장만으로 본편/경지 진행, 기연은 더 강한 해법. 확정 투자는 환불하지 않는다.

## 구현 설계와 검증안

- 기존 전투·장 상태·8~10장 사건을 재사용한다. 별도 `ordinary-growth.js`는 양세계 일반 기술 성취와 화산 전수, `plan-b-story.js`는 새 사건 증거/보고/목표를 담당한다.
- 기본 검로는 1~9성. 검증안: 유효 수동 타격 4회마다 1성, 최대 9성. 기존 계열 숙련과 투자 값은 변환하지 않는다. 24수 중 1 매화노방(거리 검격), 2 매화접무(주변 검격)만 기존 moon/storm 동작을 활용해 검증한다. 이는 정설 효과가 아닌 게임 제안이다. 초식별 입문/활용/숙련 표기를 검증하며 나머지 22수는 미구현이다.
- 현실 기본 검격/집중 타격/연속 타격 및 소유 기연 스킬도 개별 성취를 표시한다. 기존 skillMastery 기록을 보존한다. 개별 성취의 추가 피해와 요구량은 검증 수치이며 양세계에 복사하지 않는다.
- 1장: 회복 확인→실제 타격/예고 회피 연습→별도 화산 전수자 소개→죽림 확보→전수 인정→현실 구조와 직접 보고. 완료한 기존 저장은 이 새 필수 연출에 한해 `legacy` 면제를 명시하고 새 행동 증거를 조작하지 않는다.
- 3장 심장 보스의 기연 필수 방어 제거. 일반 재수련/매듭/보스/구조 보고 경로를 추가한다. `fate.stage`는 구 저장 호환용 장 진행을 유지하고 기연 소유 `path/proven/inherited`는 비워 둔다. 명시적인 ordinaryRoute 저장 표시로 검증한다.
- 4장 약방 전달, 5장 연화 장부→서린 대조와 일반 전투, 6~7장 일반 공격/장치와 실제 제압 인정. 이미 죽인 적을 되살려 본편 증명시키지 않는다. 8~10장 기존 운송/공급/대피/감독관/결말을 유지한다.
- 기연 핵심→실전 증거→선택 후속 수련→복합 실전→선택 오의 수련. 늦게 획득해도 재접근 가능. 장 진행만으로 R/F 일괄 지급 금지. 기존 R/F는 보존한다.
- 저장은 additive versioned state, 기존 성장/투자/보상/완료 원장 보존, 낡은 데이터를 새 성수로 환산하지 않는다. a8d6214 실생성 저장 4종을 회귀 fixture로 보관한다.

## 미확정/후속

모든 수치·초식 효과·현실 성취 조건은 검증안. 화경 시련, 24수 나머지, 다른 문파 트리, 새로운 에너지/경제/서버 희소성/대량 아트는 이번 구현에 포함하지 않는다. 기존 echo/seal 소유는 보존한다.
