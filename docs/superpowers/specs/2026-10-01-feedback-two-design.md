# 쌍계 두 번째 피드백 통합 개선 명세

목표는 플레이어가 다음 행동과 목적지를 이해하고, 자신의 성장 상태를 알아보며, 두 세계를 오가는 주인공의 특별함을 경험하게 하는 것이다. 현재 기능 보완과 신규 이야기를 분리한다. 6장과 7장은 별도 스토리 승인 전 구현하지 않는다.

기준 배포는 main의 v0.10.3이며 커밋은 `87ebdd3628d733a1b018262cfc7f0fa45a5138c8`이다. 이 문서는 개발 승인 요청 범위를 구체화한 검토안이다. 특히 정산 수치와 대화 표시 규칙은 아래 제안을 검토한 뒤 구현한다.

## 작업 범위와 승인 경계

- main에서 직접 작업한다. 추가 브랜치나 worktree를 만들지 않는다.
- 사용자 소유의 미추적 이미지 후보, Unity 파일, 참고 자료를 건드리거나 배포하지 않는다.
- 일반 개선 범위는 아래 A부터 F까지다. 새 기연 획득 규칙, 새 심법, 새 경지 보상, 6장과 7장 사건은 G의 별도 승인 범위다.
- 기존 캐릭터, 세계관, 계열, 완료 기록은 유지한다. 다른 저장에 실제로 하지 않은 사건을 만들어 넣지 않는다.
- 자동 이동은 추가하지 않는다. 길 안내는 최종 목적과 다음 경유지를 보여 주며, 이동은 플레이어가 직접 한다.
- 대화 버튼의 별도 단축키 표시는 다시 추가하지 않는다. 키보드 선택과 확인 기능은 유지한다.
- 일반 개선 완료 후 전체 회귀 검사, 독립 코드 검토, main 최신 반영, 커밋과 푸시, Pages 배포 및 공개 파일 검증을 수행한다.

## A 입력과 길 안내

우측 목표창은 현재 pointer-events가 none이어서 클릭이 canvas에 도달한다. 이를 실제 버튼으로 바꾸고 표시 이름을 길 안내로 정한다. 목표창과 다른 모든 UI에서 누른 좌클릭과 우클릭이 전투 동작으로 전달되지 않아야 한다. 필드 위 좌클릭 공격과 우클릭 회피는 이번 범위에서 유지한다.

길 안내 창은 최종 목적, 완료 조건, 현재 경유지, 남은 경로, 추적 종류를 표시한다. 목적지 선택은 자동 이동이나 자동 상호작용을 수행하지 않는다. 알려진 통로와 목적지 표식을 강조하며, 탐험으로 아직 발견하지 않은 정답이나 숨은 기술 획득 조건은 공개하지 않는다.

하나의 ObjectiveModel이 HUD, 월드 표식, 화면 밖 화살표, 미니맵과 길 안내 창에 같은 목표를 제공한다. 최종 목적과 현재 이동 지점은 다른 필드로 보관한다. 본편은 기본 추적이며 선택 탐험과 반복 의뢰는 이름과 구분을 표시한다. 본편으로 복귀하면 선택 탐험 길잡이가 본편을 다시 덮어쓰지 않는다.

환서정 안내 상태는 다음과 같다.

| 상태 | 최종 목적 | 현재 행동 |
| --- | --- | --- |
| 제5장 이전 선택 방문 | 자유 탐험 또는 본편 복귀 | 물건 조사 또는 본편 추적으로 전환 |
| 제5장 해석 미발견 | 해석을 발견해 서린에게 보고 | 현재 조사 단계에 맞는 관찰 또는 실험 |
| 다른 계열 해석만 발견 | 사용 가능한 해석 준비 | 기록 보존 표시, 현재 계열 조사 또는 안전 거점 계열 선택 |
| 현재 계열 해석 발견 미장착 | 서린에게 조사 결과 보고 | 성장 화면에서 해당 해석 장착 |
| 현재 계열 해석 장착 | 현실 서린에게 보고 | 출구, 청운촌 경계석, 서린 순으로 경유지 갱신 |
| 관측소 개방 | 해석 효과 관측 | 장치 조사, 실제 효과 재현, 남은 적 처리, 보고 구분 |

계열이 없는 경우 계열부터 선택해야 함을 명시하고, 선택 가능한 계열이 없으면 본편의 계승 진행으로 안내한다. 해석 발견과 실제 장착을 같은 완료 상태로 취급하지 않는다. 이미 장착한 채 제5장을 시작한 저장도 불필요한 환서정 재방문을 요구하지 않는다.

## B 가독성과 목적지 표식

- 주요 목표는 행동과 대상 및 장소를 담은 한 문장으로 표시한다. 예시는 현실 기지의 서린에게 조사 결과 보고다.
- 대화 본문 기본 17px, 좁은 화면 최소 16px, 줄 간격 1.7을 사용한다. 목표 본문 최소 14px, 보조 정보 최소 12px로 시작해 실제 화면에서 검수한다.
- 색상만으로 본편, 선택 탐험, 완료 상태를 구분하지 않고 문구와 형태를 병행한다.
- 선택 목적지 다이아는 화면 기준 최소 18px로 그리며 어두운 외곽선과 바닥 링을 사용한다. 확대율에 따라 지나치게 작아지지 않아야 한다.
- 표식 이름과 거리를 읽을 수 있는 배경 위에 표시한다. 장식과 지형 뒤에 표식이 가려지지 않게 별도 최상단 월드 안내 단계에서 그린다.
- 1280x900, 390x844, 360x640, 844x390과 브라우저 글자 확대에서 목표, 대화, 보상이 겹치거나 화면 밖으로 잘리지 않아야 한다.

## C 화자별 대화와 보상 분리

캐릭터 이야기 대화는 구조화한 화자별 장면으로 표시한다. 이름과 초상화는 화자 메타데이터에서 가져오며, 본문에는 윤서 또는 백련 같은 화자 접두사를 넣지 않는다. 화면 한 장면에는 한 화자만 등장한다. 내레이션은 인물 대사와 다른 종류로 표시한다.

기존 긴 문장을 기계적으로 쪼개지 않는다. 인트로와 1장부터 5장의 진행 대화를 편집해 한 장면 1~3문장을 기준으로 구성하고, 중복 설명을 줄인다. 일반 메뉴와 시스템 창에는 대화 분할을 적용하지 않는다. 모든 키보드 입력, 재대화, 회상, 건너뛰기 경로를 보존한다.

중요한 규칙은 대사 넘김으로 게임 보상이 반복 지급되거나 중요한 수락이 자동 실행되지 않는 것이다. 게임 진행 변경은 기존 사건 발생 시점 또는 명시적인 수락에서 한 번만 수행한다. 중간 장면 버튼은 표시 이동만 한다. 전체 대화를 넘겨도 최종 결과와 다음 행동 요약에 도달한다. 인트로의 기존 건너뛰기와 회상 종료는 별도 의미를 유지한다.

퀘스트 상세에는 다음 영역을 구분한다.

1. 배경 설명
2. 수행 목표와 현재 수량
3. 보고 대상과 장소
4. 예정 보상
5. 수락, 나중에 또는 보상 수령

실제 지급 뒤에는 획득 보상과 다음 행동을 표시한다. 지급되지 않은 보상을 획득으로 표기하지 않는다. 본편은 실제 규칙에 존재하는 보상만 표시하며 추정 보상을 만들지 않는다. 완료 보고가 필요한 경우 적을 처치한 상태와 보상을 받은 상태를 구분한다.

## D 재화 정리와 기존 저장 보호

마정석의 신규 획득, 판매, 렌즈 제작, 관련 버튼과 안내를 제거한다. 관측 렌즈 없이도 진행이 가능해야 하며, 기본 기감 범위는 기존 렌즈 보유자의 탐험 편의가 줄지 않도록 모두 340으로 통일하는 안을 제안한다.

골드 보상 제안은 기존 총 재화 가치에서 출발한다. 일반 무림 적은 기존 16, 보스는 110을 유지한다. 기존에 마정석 1개 또는 3개를 주던 현실의 일반 적과 보스는 각각 총 46과 200골드로 바꾼다. 시험, 잔류 파형, 이미 보상받은 적은 추가 골드를 주지 않는다.

반복 의뢰는 총 140골드와 경험치 100을 유지하는 안이다. 적 4명 처치 시 각 16골드를 즉시 받고, 보고 시 76골드와 경험치 100을 받는다. 완료 전에 후퇴해도 이미 처치로 받은 골드는 유지되지만 보고 보상은 없다. 반복 처치 수익은 일반 사냥보다 높지 않게 검수한다. 의뢰 시작 전에 이 지급 구조를 명시한다.

골드 공격력 강화 구매는 제거한다. 신규 게임은 기존 레벨, 공통 수련, 숙련, 심법, 첫 경지로 성장한다. 신규 경지와 새 성장 보상은 스토리 승인 범위와 섞지 않는다. 강화 없이 본편 난이도를 검수하며 필요하면 보스별 수치를 조정하고 변경 근거를 기록한다.

기존 저장의 일회성 정산 제안은 다음과 같다.

- 보유 마정석 m개: 30m골드.
- 렌즈 보유: 제작에 쓴 마정석 2개 가치와 60골드를 합한 120골드.
- 기존 강화 n단계: 실제 누적 구매비용인 80n + 30n(n-1)골드 환급.
- 기존 강화 공격력 4n은 기존 성장 보정으로 보존한다. 구매나 재강화는 불가능하며 기존 저장 보호임을 명시한다. 새 이야기 수련을 했다는 기록으로 바꾸지 않는다.
- 골드 상한 999999를 넘는 환급액은 정산 잔액으로 보관하고, 보급소에서 잔여 한도만큼 받을 수 있게 한다. 상한 때문에 보상이 유실되지 않는다.
- 새 저장 버전은 9다. 이전 버전을 기존 검증기로 검증한 다음 한 번만 정산한다. 버전 9 재불러오기에는 재환급하지 않는다. 잘못된 값, 음수, NaN, 범위 초과를 거부한다.

## E 성장의 존재와 현재 상태 전달

새로운 내공 숫자 체계를 추가하지 않는다. 내공은 축적한 무공 기반이라는 설명 용어로 쓰고, 소비 자원은 기존 내력으로 통일한다. 플레이어에게 두 개의 같은 자원이 있는 것처럼 보이지 않게 한다.

성장 화면은 무공 습득, 계열 숙련, 무공 해석, 심법, 경지를 구분한다. 각 항목에 현재 효과, 성장 또는 변경 방법, 다음 변화를 표시한다. 전투 HUD에는 현재 심법과 경지를 간결하게 노출하고, 성장 화면으로 연결한다. 키 배지는 추가하지 않는다.

심법은 안전 거점에서 현재 방식과 다른 방식을 비교하고 선택한다. 집중 준비와 유수 추가 회복 상태는 짧은 비차단 표시로 확인할 수 있게 하며 매 타격마다 알림을 띄우지 않는다. 경지 조건은 충족 여부와 남은 조건을 구체적으로 표시한다. 첫 돌파를 무조건 초반으로 당기거나 강제 튜토리얼로 만들지 않는다.

성장 알림은 숫자 변화와 실제 운용 변화를 구분한다. 해석 변경은 예를 들어 몸이 귀환하는 대신 잔향이 공격한다는 차이를 보여 준다. 기존 레벨업 비차단 알림은 유지한다.

## F 기존 사건의 판정과 대사 정합성

먹향 재현검의 R은 실제 귀환이 아니므로 청운 귀환로의 잔영보 귀환 구조 판정으로 인정하지 않는다. 기본 귀환 운용이나 다른 구조법을 선택할 수 있게 안내하며 기존에 완료한 구조 기록은 소급 취소하지 않는다.

관측은 기감 조사, 실제 해석 효과, 보스 처리, 보고를 분리한다. 무공 버튼 누름만으로 실제 효과를 달성했다고 표시하지 않는다. 적이 없으면 보상 없는 잔류 파형으로 재현할 수 있게 유지한다.

백련의 계열별 확인, 연화의 첫 편지와 재대화, 제5장 승리와 보고를 구분한다. 이미 본 긴 설명은 재대화 때 현재 남은 행동으로 줄인다. 과거 문서의 마정석, 렌즈, 강화 안내는 현재판 설명에서 제거하되 역사 기록은 과거 버전임을 표시한다.

## G 별도 승인 범위

6장과 7장 스토리는 `2026-10-01-chapters-six-seven-story.md`에서 검토한다. 제목, 적, 새 장소, 새 심법과 경지 운용, 보스 해결, 결말과 헌터 승급은 그 문서 승인 전 게임에 추가하지 않는다. 이번 일반 개선 배포에서는 5장 이후 신규 장으로 이동하는 버튼이나 실제 사용 가능한 새 능력을 만들지 않는다.

기연의 행동 반복형 획득을 대체하는 새 규칙 역시 확정 전까지 기존 저장과 계열 획득 경로를 유지한다. 기존 방식의 삭제로 본편을 막지 않는다. 새 방식과 6장 돌파를 같은 사건으로 혼동하지 않는다.

## 완료 판정

새 게임, 제5장 전 선택 방문, 해석 미발견, 다른 계열만 발견, 미장착, 기장착, 관측 중, 보스 처치 후 미재현, 보고 가능, 과거 강화 저장을 각각 검수한다. HUD와 경유지 표식이 모순되지 않아야 한다. 대화 스킵과 저장 반복으로 보상이나 환급이 증가하지 않아야 한다.

독립 브라우저 세션만 테스트에 사용하고 사용자의 로컬 플레이 저장은 변경하지 않는다. 자동 테스트와 수동 시각 검수는 별개로 기록한다. 최종 배포는 GitHub 검사와 check-live.py의 커밋 및 모든 runtime byte 일치 결과까지 확인한 뒤 완료로 보고한다.
