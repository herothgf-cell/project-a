# v0.5 — 행동이 남긴 무공 / 고전 2D RPG 아트

사용자가 제공한 고전 RPG 스크린샷과 생성 컨셉을 방향으로 사용한다. 원작 게임의 타일·초상·캐릭터를 추출하지 않는다. 쌍계의 현실/무림과 기존 저장은 보존한다. 사용자는 기획·수정·main 게시를 위임했으며 이번 작업은 추가 제안이 아니라 실행이다.

## 1. 기연의 원인 이동
- NPC 완료 보고만으로 새 기연이 생기는 기본 경험을 바꾼다. 공통 기술은 보존한다.
- 제1장 공통 무공 습득 후 일반 전투에서도 발현한다. 임시 시험에서는 이 발현을 중복 적립하지 않는다.
- 파문: 적의 실제 공격 예고 마지막 0.32초에 기본 검격으로 맞받아친다. 같은 예고를 여러 번 때려도 1회이다.
- 잔향: 자신이 노려진 실제 공격 예고에서 회피로 이동한 후 1.8초 내에 그 공격자에게 반격한다. 이동 거리 40 이상이 필요하다.
- 봉합: 선택형 균열 오브젝트 가까이에서 E를 눌러 주변 적의 실제 예고를 억제한다. 평온한 상태의 상호작용만으로 얻지 않는다.
- 첫 유효 행동은 실제 전투 효과와 장소/상대/행동 기록을 만든다. 두 번째 유효 사건은 현장 각성 선택을 연다. 사부 방문 없이 Q/R/F가 활성화된다.
- 다른 길을 강제로 덮어쓰지 않는다. 현장에서는 보류 가능하고 도감에서 재확인한다. 수락은 플레이어의 선택이다.
- 한 사건의 보너스는 중복 적용하지 않는다. 유효 사건 수는 경과시간이나 기본 공격 총횟수로 증가하지 않는다.
- 첫 획득 장면은 임무 완료 모달이 아니라 현장 발현 컷인이다. 구체적 장소/상대를 근거로 보여준다.
- 기존 v0.4 경로와 증명된 재수련은 선택적 연습으로 남긴다. 기연을 현장에서 얻었으면 3장 사부 수락을 다시 요구하지 않는다.
- 기록 없는 이전 저장에 가짜 행적을 만들지 않는다. 예전 계열은 '이전 여정에서 계승'으로 표시한다.

## 2. 비주얼
- 실제 플레이 필드에 페인터리 잔디/불규칙 흙길/개별 돌/그림자/꽃/잎 디테일을 적용한다. 컨셉 이미지를 플레이 화면 위에 덮어 씌우지 않는다.
- 풀색 무림과 청회색 현실을 구별하되 기존 단색 도형 표현을 줄인다.
- 고전 RPG 비율의 인물/의복/무기를 다시 그린다. 움직임·공격 자세·Y 정렬과 충돌은 유지한다.
- 반투명 남청색 대화 패널, 밝은 장식선, 큰 초상, 정돈된 HUD. 모바일 조작 공간은 기존 안전 배치를 보존한다.
- 사용자가 제공한 생성 컨셉의 주인공 초상과 한 자세의 캐릭터만 게임용 작은 원본 에셋으로 재사용하고 출처를 문서화한다. 원작 스크린샷의 초상은 사용하지 않는다.
- 저효과/화면효과 줄이기에서 기능과 위험 예고는 그대로 유지한다.

## 3. 범위/검증
- 무한 개인 스토리/서버 유일 직업/PvP는 범위 밖. 세 계열을 다른 행동으로 발견하는 싱글플레이 경험이다.
- 저장 v4. v1~v3 불러오기와 획득된 무공·성장·3장 상태 보존.
- 전투 규칙 Node 검사, 기존 62개 회귀, 브라우저 세 화면 크기/현장각성/취소/기존 저장/필드 렌더 확인.
- 원격 main을 다시 확인한 후 fast-forward만 게시. 테스트를 통과한 코드만 Pages 배포.
