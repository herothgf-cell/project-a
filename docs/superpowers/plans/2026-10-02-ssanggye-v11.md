# 쌍계 v1.1 전체 개선 구현 계획

**Goal:** 승인한 전체 개선을 main의 실제 플레이 경로에 연결하고 기존 저장을 보호한다.
**Architecture:** 기존 Game과 단일 dialog를 유지하며 진입 판정, 실제 성장 사건, 음향 재생의 책임을 분리한다.
**Tech Stack:** JavaScript UMD, Node test, Playwright, Web Audio.
**Spec:** ../specs/2026-10-02-ssanggye-v11-design.md 및 ../../SSANGGYE_IMPROVEMENT_SPEC_v1.1.md.

## 공통 조건

사용자가 설계 검토 후 개발 진행을 요청했다. main 직접 작업, 기존 미추적 파일 보존, 푸시·배포 없음. 본편 1~7장과 보관판 유지. 새 필드는 기존 저장을 보존하며 이행. 반복 보상 금지. 실기기·사람 검수는 자동 테스트와 구분.

## 위험 집중 검증

- 오래된 저장/악성 필드/정산 직후 재접속: 원본 보존, 중복 없음.
- 조기 처치와 계열 변경: 6장 진행 가능, 수련 파밍 없음.
- 입구 밖/다른 세계/로딩 실패/키 유지: 이동 우회와 중복 없음.
- 음소거/AudioContext 거부/중단: 게임 계속, 과거 소리 재생 없음.
- 360px 및 확대: 팝업 버튼과 긴 텍스트 접근 가능.

## 실행 기록

- 기준 main 5898d75. 기존 추적 파일 변경 없음, 미추적 사용자 파일 다수 확인.
