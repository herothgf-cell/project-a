# 쌍계 v0.3 Implementation Plan

> Execution: superpowers:executing-plans. User delegated scope and continuous execution.

**Goal:** Deliver a usable two-world RPG with clear objectives, responsive combat, replaced visuals, and a second chapter.
**Architecture:** Retain vanilla JS/Canvas. Separate static world definitions, DOM-free simulation, drawing and UI; stable save adapter.
**Tech Stack:** JavaScript, HTML/CSS, Node built-in tests; Python Playwright for browser verification.
**Spec:** ../specs/2026-09-25-v03-design.md

## Global Constraints
- Preserve main history, deployment URL and dualworld.save.v1 key; no paid services.
- Do not ship partial multi-file changes: assemble verified tree and fast-forward once.
- No runtime dependencies, network images or test-only production hooks.

## Review Focus
- Old saves at every milestone, malformed storage and explicit new-game overwrite.
- Multi-pointer cancellation, dialog/focus transitions, landscape canvas sizing.
- Wrong-world objective, completed boss replay, seals before guards and retreat reset.
- Character cannot enter walls; all objectives reachable from spawns.
- Deployment must serve matching asset versions and exclude tests/server files.
