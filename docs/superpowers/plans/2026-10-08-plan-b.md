# B안 일반 성장 개편 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans, Native implementation. Steps use checkbox syntax.

**Goal:** 기연과 일반 성장을 분리하고 B안 사건을 실제 완주에 연결한다.
**Architecture:** WorldGame hooks + additive ordinary growth / story models. Existing chapter and save validation contracts retained.
**Tech Stack:** JavaScript UMD, Node test, Playwright.
**Spec:** docs/superpowers/specs/2026-10-08-plan-b-design.md

## Global Constraints

main 직접 작업. 기존 투자/완료 이력 보존. 일반 본편/경지에 기연 소유 요구 금지. 새 효과/수치는 검증안. 사용자 최종 지시대로 검증 후 main 푸시·배포.

## Review Focus

- 기연 없는 저장이 모든 하위 validator를 통과하고 재로드 뒤에도 진행되는지.
- 늦은 체득이 완료 장/보상/기존 기술을 되돌리거나 후속 기술을 무상 일괄 지급하는지.
- UI 밖 reset API와 잘못된 투자 입력에서 확정 투자가 줄어드는지.
- 허공/동료/가짜 적/시험으로 본편 실전 증거를 조작할 수 있는지.
- 기존 완료 저장을 재전투시키거나 NPC가 보고 전 타세계 정보를 아는지.
