# 첫 기연 성장 흐름 구현 계획
Goal: 1·2장 승리를 보존하며 3장 직전 통로 방어 실패 → 백련에게 경험 전달 → Q 체득 → 현실 재도전을 구현한다.
Architecture: 현재 WorldGame에 GrowthArc 규칙을 연결한다. 과거 버전 Game에는 적용하지 않는다. worldState.growthArc에 영구 진행을 보관하고 시도 시간은 임시 런타임으로 분리한다.
Tech Stack: 기존 DOM-free JavaScript 규칙, Node test, 브라우저 하네스.
Spec: 대화로 기술 묶음을 받는 대신 Q만 먼저 증명한다. R은 4장 구조 이후 백련에게 운용을 배우고, F는 7장 위기 실전 이후 열린다. 초기 선택을 추가하지 않는다. 기존 저장의 계승 기술은 보존한다.
Global Constraints: main 직접 작업; 원격 push/배포 없음; 기존 지역·저장·두 세계 성장은 유지; 몬스터 조정은 3·4장 신규 흐름에 한정한다.
Review Focus: Q-only 잔영 시험, 조기 각성 우회, 철수 중 저장 및 사망, 보상 반복, 재도전 Q 실효 요구, 기존 전장 HP 스냅샷 호환.

## Task 1: 진행·해금·저장
실패하는 테스트 작성 → 실행 → GrowthArc 및 save/world-game 연결 → 관련 테스트.
Interfaces: worldState.growthArc {version, phase, legacy, held, learnedR, learnedF, returnProven}; temporary growthArcRuntime.
Expected: 초반 무공 잠금과 명확한 다음 목표; 기존 저장은 legacy 처리; 잘못된 데이터 거부.

## Task 2: 기연·실전·밸런스
실패하는 전투 테스트 → Q-only 시험/재도전/구조/후속 해금 → 통로 압박과 초기 난이도 조정.
Expected: 공격 실효로 증명; 강제 철수는 금화·경험치 손실 없음; 새 전장 HP와 구 저장 전장 모두 복원.

## Task 3: UI·회귀 검증
전체 테스트, 문법 점검, 브라우저 흐름 및 최종 코드 리뷰. 테스트 안내를 문서에 기록한다.
Expected: 전체 기존 회귀 유지, 신규 흐름 실제 조작 가능. 원격 배포는 별도 요청 때 수행.

## 실행 기록
- Task 1: 5개 신규 테스트에서 잠금·철수·저장·검증 실패 확인 후 통과.
- Task 2: Q-only 시험 3계열, 실제 Q 재현, 스케일된 전장 저장, 치명타 철수 테스트 추가. 전장 복원 시 두 번 난이도가 적용되는 문제를 재현하고 중복 조정을 제거했다.
- Ruling: R은 4장 완료 보고 자체로 지급하지 않고 백련의 별도 Q→R 실습 적중으로 체득한다. 사용자 요청의 느린 성장을 따른다. 실습 도중 저장은 기존 시험 규칙대로 마을에서 재시작한다.
- Ruling: F는 7장 천흔 중심부의 위협 제압으로 체득한다. 기존 7장 완료 상태를 복원한 경우 완료 증거를 인정한다. R을 먼저 익힌 캐릭터에만 적용한다.
- Ruling: 신규 흐름의 3·4장 전장만 HP −15%, 심장 피해 −15%, 귀환로/부두 피해 −10%. 기존 저장은 legacy로 구 수치를 유지한다. 인간 플레이 테스트로 추가 조정할 수 있다.
- 초기 완전 계승 fixture는 구 저장 호환 상태로 명시했다. 실제 새 게임→6·7장 helper는 새 철수/Q-only/R실습 경로를 직접 실행하도록 갱신했다.
- Final review: 별도 리뷰어가 목표 안내 누락과 저장 상태 검증 부족을 지적했다. 두 문제 모두 실패 테스트 → 수정 → 통과로 검증했다. R 실습에 첫 Q 안내가 나오는 문제는 학습을 혼동시키므로 Important로 재평가하여 수정했다.
- Final: fixed 첫 현실 귀환에서 Q가 자동 장착되지 않던 흐름 — 신규 RED→GREEN 테스트로 검증.
- Final: fixed R/F 조기 해금 데이터와 잘못된 통로 방어 단계 — 이야기 증거 검증, 신규 RED→GREEN 테스트로 검증.
- Ruling: 기연 미계승 구 저장은 새 흐름을 적용하고 조사 중 저장은 조사부터 이어간다. 이미 계승한 구 저장만 legacy로 기술·전장 수치를 보존한다. 모든 구 저장을 legacy로 처리하면 기존 플레이어가 새 흐름을 테스트할 수 없기 때문이다.
- Ruling: F 영구 해금은 7장 전투 완료 단계(4 이상)가 확인되는 프레임으로 이동했다. 제압 직후 저장에서도 이야기 기록과 해금이 일치한다.
- 자동 검증: npm test 689/689, check/check:revision/check:world 통과. 브라우저 검증 결과는 테스트 안내 문서에 별도 기록한다.

- Task 3: complete — 실제 브라우저 신규 흐름과 기존 v12 UI 테스트 통과. R/F 잠금과 저장 복원 화면 확인. 최종 검토의 Important 항목 모두 RED→GREEN, 추가 보류 사항 없음.
