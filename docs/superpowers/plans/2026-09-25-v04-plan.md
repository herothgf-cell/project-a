# Ssanggye v0.4 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans in this session. User explicitly delegated planning, implementation and main publication.

**Goal:** Deliver three earned signature paths, their combat VFX and chapter-three payoff on the existing Pages site.
**Architecture:** Keep common Game rules, add DOM-free FateRules lifecycle hooks; separate FateArt drawing from gameplay; extend existing browser UI and pipeline.
**Tech Stack:** Plain JavaScript/Canvas/CSS, Node test runner, Python Playwright 1.57.0.
**Spec:** docs/superpowers/specs/2026-09-25-v04-design.md

## Global Constraints
Preserve chapters 1–2 and save key dualworld.save.v1. No runtime dependencies or credentials. No changes to repository visibility or history. All three paths get two actives and one ultimate. Main updates only after local tests, via normal non-force commit.

## Review Focus
- Trial death/retreat/load must not grant or duplicate proofs; no softlock on failed mechanic.
- Invalid path/save/prototype property names cannot invoke unintended actions.
- Effects and collision cannot disagree: no teleport through walls or damage outside stated area.
- Small/mobile viewport controls cannot overlap or retain stale touch input.
- Signature effect settings must not affect gameplay or hide boss warnings.
