# v0.5 Implementation Plan

> For agentic workers: use superpowers:executing-plans. User delegated design and main deployment.

**Goal:** Move signature awakening into lived combat and replace placeholder visuals with original classic RPG art.
**Architecture:** `legend.js` owns per-player memories and witnessed field events. `game.js` invokes explicit hooks; FateRules retains existing skills/trials with field-path integration. `classic-art.js` supplies cached terrain and sprite/portrait rendering before the read-only renderer is loaded; `classic.css` overlays visual styling. No network dependency at runtime.
**Tech Stack:** Existing JS/Canvas, Node tests, Python Playwright.
**Spec:** docs/superpowers/specs/2026-09-28-v05-design.md

## Global Constraints
Existing stages/skills and saved progression preserved; no original-game asset copying; no silent forced path; prototype/NaN/input validation; no auth tokens in site files; mobile 360x640/390x844/844x390.
