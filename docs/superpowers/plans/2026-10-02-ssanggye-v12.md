스토리가 최상위로 참조하는 통합 개선기획 v1.2는 이번 첨부에 없다. 사용자에게 기준을 질문한 뒤 최종 판단을 위임받았으며, 아래 최종 조정 기준으로 구현했다. 문서의 ‘현재 너무 쉬움’은 직전 실제 피드백인 ‘죽림이 어려움’보다 우선하지 않으므로 적 수치를 재상향하지 않는다.

## 구현 순서

1. **공통 UI와 독립 성장 화면**: 기존 성장/무공 모델의 계산과 저장은 유지한다. 성장 진입을 캐릭터 팝업의 복합 탭에서 분리하고 심법 선택→효과 상세→실행을 나눈다. 세계 적용 표시, 비교 전용 안내, 본문 18px/최소16px, 버튼48px, 모바일 단일 열과 뒤로 동작을 검증한다.
2. **기준 확정 후 심법 모델**: 고유 사건 원장·노드 수준·세계별 운용·미리보기/실제 계산 공통 함수. 재배분·귀환·비율 보존 및 이행 테스트.
3. **첫 성장**: 이류 실제 시련과 D 실제 평가/훈련을 서로 다른 사건으로 구현. 통합 입구를 재사용하고 기존 본편 접근권을 보존한다.
4. **중반 확장**: 4장 연화 확인, 5장 초대/진화 증명, 6장 무료 체득, 7장 지역망 폐쇄. 기존 저장의 소유권과 완료 기록을 인정한다.
5. **8~10장**: 운송망 추적·공급 차단/대피·감독관 대면/실제 보스/후일담. 성장 시험과 본편 필수조건 분리. 세 계열·무투자·늦은 승급으로 진행 가능.
6. **검증**: Node 전체 회귀, 브라우저 화면/입력/저장/전체 여정, 실전 비교. 사람의 사용성·실물 기기 검수는 자동 검사와 구분한다.

## 사용자 위임에 따른 최종 조정

사용자는 충돌 사항의 최종 판단을 위임하며 스토리 연계를 요구했다. 12P 사건 원장(기본기2/첫 이류3/4장2/5장3/6장1/7장1), UI의 F/C 노드와 누적 특화 포인트를 적용한다. 경지/훈련 수치는 UI의 낮은 초기값으로 시작한다. 첫 이류는 기연 기본 증명으로 도전하고 5장 진화를 요구하지 않는다. 실제 평가·훈련 없이 등급을 자동 부여하지 않는다. 현실 심법은 정상 귀환 시 스냅샷 교체, 무료6장 체득은 별도 보존한다. 상위 평가와 시련은 본편 접근을 막지 않는다.

파일 소유: passive-growth.js(심법), advancement.js(시련/평가), cycle-one.js(8~10장) 독립 모듈과 각 테스트를 위임했다. 주 작업자는 growth-screen.js·공통 UI·world-game/save/입구/전투/렌더 통합을 담당한다.

- 성장 전용 화면, 현재/다음 수치, 두 세계 비교, 순차 메뉴 개방, 포인트 획득 근거, 안전 거점 재배분, 저장 실패 시 변경 복구. 모바일 목록/상세, 고정 실행 영역, 100/125/150/200% 글자 설정, 캐릭터 성장 출처.
- 심법은 고유 사건 원장으로 중복 지급 방지. 첫 돌파/공식 등급은 실제 시련·평가 후 확인/서린 보고로 확정. 통합 입구에도 선택 성장 연결.

- 효과음과 음향 설정은 계속 제거. main에서 로컬 변경만 진행; 이번 변경은 커밋·푸시·배포하지 않았다.

## 검증 범위의 한계

자동 실전 검사는 입력/상태/피해/보상 연결을 확인한다. 사람의 체감 난도·재미나 실제 모바일 기기 사용성 검수를 대신하지 않는다. 신규 감독관은 동작과 정체성을 구분하는 코드 렌더를 사용하며 기존 회화풍 아트와 통일하는 최종 일러스트 제작은 별도 작업이다. 신규 지역은 기존 배경을 재사용한다.

최종 확인: Node 665/665 통과, 루트 실행 스크립트 70개 문법 검사 통과, 브라우저 7개 시나리오 통과. 코드 리뷰에서 발견한 보스 승리 직후 저장·공격 특화 소수 정산·대면 전 타격 문제는 재현 테스트와 함께 수정했다. 로컬 미리보기는 57459 포트에서 실행한다.

사용자 후속 요청으로 중요도별 글자색을 적용했다. 밝은 패널에서도 각 글자색 대비 4.5:1 이상, 전체 25개 브라우저 검사(실패 2건 수정 후 해당 검사 재통과), 665개 Node 테스트 통과. 커밋·푸시·배포를 명시적으로 요청받아 main 릴리스를 진행한다.
