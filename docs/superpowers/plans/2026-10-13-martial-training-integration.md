# 무공 수련 본편 통합 및 배포

> Execution: subagent-driven-development. 사용자가 UI 방향을 승인하고 개발·배포를 명시 요청했다. 재승인 없이 구현·검증·main 통합·Pages 배포까지 진행한다.

**Goal:** 기존 게임 안에서 월영참 구성·목인 적중 → 탐험으로 세 무공의 요소/조합법 발견·습득 → 세 창안과 현실 운용을 낮은 난도로 플레이한다.
**Architecture:** 독립 수련장으로 이동하지 않는다. 본편 WorldGame에 영구 학습 모델과 일시 전투 상태를 연결하고, 기존 dialog/UI에 ‘무공 수련’을 표시한다. 기존 저장과 기연·이야기 연계를 보존한다.
**Spec:** 이번 대화에서 승인한 무공 수련 시안과 무공 습득/창안 분리. 최초 기획은 docs/design/skillform/README.md. 시안의 미정 등급·획득 경로를 아래 구현안으로 구체화한다.

## Global Constraints
- main 직접 작업, 추가 브랜치/워크트리 금지. 사용자 파일·아트 검수 변경 보존.
- 제목 ‘무공 수련’. ‘무공 습득’ / ‘무공 창안’을 큰 탭으로 구분. 기존 무공 운용 기능은 접근 가능하게 보존.
- 무공 등급 기초/상승/절학, 해독·요소 보유·숙련은 분리. 월영참 기초, 세 Q 무공 상승. 절학은 도감의 잠긴 확장 안내만 제공하고 이번에 새 절학을 만들지 않는다.
- 형/기/운/의 각 하나의 결정적 조합법. 미보유 요소 거부. 미해독 해답을 결과 미리보기에서 누출하지 않는다. 소모 재료·확률 실패 없음.
- 월영참은 백련 안내, 구성, 기존 청운촌 목인 실효 적중 후 습득. 기존 습득자는 유지한다.
- 기연 무공은 무명 비경의 기존 세 흔적을 조사해 요소와 일부 단서를 받고 지도 실습으로 나머지 조합법을 알아낸다. 구성한 Q의 실제 흡수/회피/억제를 확인해 체득한다. 세 계열 모두 플레이로 얻을 수 있다.
- 창안: 파문세+월영참=반류일선, 잔영각+월영참=유영잔참, 쇄경진+월영참=이맥봉류. 두 체득 무공·연결 원리 하나, 준비 1회 소비, 창안끼리 중첩 금지. 추가 내력/원래 효과 포기 대가.
- UI는 기존 게임 전장으로 닫혀 돌아간다. 쉬운 수련 지원 기본 활성: 적 피해 완화, 긴 예고, 내력 회복. 성장 상태를 파괴하거나 기존 세이브의 수치를 변경하지 않는다.
- 시험 재시작/패배/재접속에서 무공 학습은 유지, 임시 준비/예약 검격은 초기화. 수련 표적 보상 없음.
- 배포 전 origin/main fetch·통합·병합 결과 검증, main push로 기존 Pages 워크플로 사용. 배포된 커밋·핵심 자산 확인.

## Review Focus
1. 옛 저장의 무공·진행이 사라지거나 첫 월영참 단계에서 막히지 않는다.
2. 조합 없이 기연을 즉시 받는 기존 진입점과 세 계열 전환이 새 습득 조건을 우회하지 않는다.
3. 일반 공격/연계가 같은 준비를 두 번 소비하지 않고 세계·지역 이동에서 임시 상태가 남지 않는다.
4. UI 저장 실패 롤백, 모바일/키보드, 메뉴 닫기와 새 스토리 이벤트를 확인한다.
5. 공개 빌드에서 본편 모듈이 빠지지 않고 독립 개발 실험 자료는 노출되지 않는다.
