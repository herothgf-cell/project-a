# v0.5 검증과 결정

## 기반
원격 main 48f6f70e24fd8c11f2d2ac5d35c1065f5e5bb157, tree 9d69ee8c5cb96d5074014038d5bbaaea12b82f85를 먼저 확인했다. 제공된 v0.4 ZIP을 추출해 계산한 git tree가 이 원격 tree와 일치한다. 원격의 다른 변경을 덮어쓰지 않도록 게시 직전 main을 재확인한다.

## 실제 변경
- 제1장 공통 기술 습득 뒤 일반 적의 실제 예고에 대한 맞받아치기, 위험 회피 후 반격, 선택형 균열 억제가 각각 발현의 원인이 된다.
- 첫 발현은 전투 효과와 실제 장소/상대/행동 기록을 남긴다. 두 번째 유효 사건에서 각성 수락/보류를 제공한다. 원치 않는 계열로 강제 전환하지 않는다.
- NPC를 방문하지 않아도 그 전장 안에서 첫 계열을 각성하고 Q/R/F를 쓸 수 있다. 기존 비경은 선택적 연습이며, 먼저 각성한 사람은 제3장에서 사부 수락을 다시 수행하지 않는다.
- v1/v2/v3 저장은 읽되 과거에 없던 행적을 만들지 않는다. 저장 version 4에서 실제 행적과 준비된 계열을 검증한다.
- 고전 RPG형 풀스크린 필드, 질감 지면, 큰 초상, 기와/수목과 원본 생성 컨셉의 주인공 페인팅 자세를 적용했다. 출처와 한계는 art-provenance-v05.md에 구분했다.

## 실행한 로컬 검증
- 기존 기준선: Node 62/62 통과.
- 새 규칙 15개가 의도한 이유로 실패하는 것을 확인하고 구현했다. 자체 검토로 추가한 자동 연타/기존 계열 재발현 2개도 실패 후 수정해 통과했다.
- 게시 자산 회귀는 원래 서버에서 새 파일을 못 찾는 실패를 확인한 뒤 현재 allowlist에서 모두 200 및 올바른 MIME으로 통과했다.
- 최종 구문 검사 성공, Node 80/80 통과.
- 기존 브라우저 검사 8묶음, 세 기연/제3장 검사 7묶음, 새 현장 발현/그래픽 검사 6묶음: 합계 21묶음 통과. 모델 위치/예고를 준비한 뒤 실제 DOM 버튼·키보드·터치 이벤트를 사용한다. 전 과정을 무보조로 플레이한 인증이나 자동 FPS 벤치마크는 아니다.
- 390×844, 360×640, 844×390에서 조작 영역 겹침과 모달 경계, 입력 취소, 기연 버튼을 확인했다. 데스크톱과 모바일 스크린샷을 직접 확인했다.

로컬 Chromium HTTP 탐색은 관리자 정책으로 차단되어 인라인 문서와 저장 shim으로 검사했다. 다른 호스트로 우회하지 않았다. GitHub Actions는 실제 HTTP/native localStorage에서 동일한 세 브라우저 검사를 모두 통과해야 Pages를 배포한다. 원격 통과 여부는 워크플로 결과를 별도로 확인한다.

## 발견 후 수정
- 발현 이펙트 생성 직후 타원의 반지름이 음수가 되던 오류를 수명 시작/중간/끝 조건으로 확인하고 최소 1로 제한했다.
- 대화창 native close 이벤트가 늦게 처리되며 이미 새로 눌린 이동키를 지우던 race를 실제 이벤트 시간순으로 재현했다. 모든 닫기/취소 경로에서 즉시 입력을 지우므로 중복된 비동기 close 리스너를 제거했다.
- 헤드리스 첫 그림 래스터화 지연 때문에 정해진 250/400ms 후 결과를 보는 검사 대신, 같은 이동량/실제 반격 성공 조건을 제한시간 2.5초 안에 기다린다. 성공 조건은 삭제하지 않았으며 이것을 성능 인증으로 설명하지 않는다.
- 새로운 캐시 그림은 첫 소개창 이전에 한 번 그려 둔다. 정적인 지형과 소품은 프레임마다 다시 만들지 않는다.
- 자동 길게 누르기의 타이밍을 직접 맞받아친 행적으로 취급하지 않는다. 빈 공간 이동, 조용한 틈 조사, 같은 예고 중복 공격으로 기연을 지급하지 않는다.

## 남은 제한
독립 리뷰어 도구가 없어 작성자가 자체 검토했다. 세 기연의 획득 원인은 개인 행동이지만 서버 유일 소유권/무한 생성 스토리/완전히 다른 사용자별 스킬 생성은 아니다. 원작 나르실리온과 동일한 아트 에셋이나 완성도라고 주장하지 않는다. 주인공의 완전한 8방향 애니메이션, 모든 NPC 페인팅, 실제 저사양 Android/iPhone Safari 장기 성능은 이번에 검증하지 않았다. 저장은 동일 브라우저 내 로컬이며 자동 계정 동기화가 없다.
