# v0.5 아트 출처와 실제 적용 범위

## 사용한 자료
사용자가 대화에 올린 여섯 장의 고전 RPG 스크린샷은 색감·카메라·비율·대화창을 논의하기 위한 참고 이미지다. 그 게임의 픽셀, 캐릭터, 초상, 타일, UI는 추출하거나 저장소에 복사하지 않았다.

게임에 사용한 래스터 초상과 필드 인물은 같은 대화에서 생성된 오리지널 컨셉 이미지 `바람이_머무는_판타지_rpg_전설.png` (1448×1086)의 주인공 부분이다. 상업 게임 스크린샷이 아니다. 주인공 초상 한 장과 필드 자세 한 장을 잘라 작게 변환했다. 원본 컨셉 전체를 배경에 붙인 것이 아니며, 게임 화면은 실제 이동·충돌·전투와 함께 렌더링된다.

## 파일
- `portrait-data.js`: WebP로 압축한 주인공 초상(224×252)과 투명 필드 자세(117×141)의 데이터 URI. 런타임에 외부 사이트로 이미지를 요청하지 않는다.
- `classic-art.js`: 직접 작성한 잔디/흙길/석재의 결정적 질감, 개별 기와, 나무 잎, 돌과 그림자. 인물/오브젝트는 기존 충돌 위치와 Y 정렬을 따른다. 사부·관리관 등의 초상은 자체 Canvas 도형으로 그린 것이다.
- `classic.css`: 남청색 반투명 대화창, 큰 초상, 밝은 테두리, 풀스크린 필드와 작은 지도. 원작 UI를 그대로 복제하지 않았다.

## 한계
컨셉 이미지와 픽셀 단위로 같은 완성도를 구현한 것이 아니다. 주인공은 한 자세의 페인팅을 기반으로 좌우 반전·보행 흔들림·공격 기울기를 적용한다. 8방향/전용 프레임마다 새로 그린 스프라이트 시트는 아니다. 다른 인물과 건물은 벡터 기반이고, 주인공보다 단순하다. 최종 상용 원화·애니메이션 교체는 별도 아트 제작이 필요하다.

스타일 참고는 고전 2D 판타지 RPG이지만 현실의 헌터 기지와 무림이라는 쌍계의 장소·인물 이름·성장 규칙은 유지했다.
