## 범위와 원인
현실 building이 무협 기와 렌더러로 들어가고 NPC도 동일한 로브를 쓰던 경로를 별도 현대 렌더러로 분리했다. 공격 궤적의 고정 월드 좌표와 캐릭터 이동이 분리되던 경로는 손과 무기 접점 기반으로 연결했다. 보행은 시간 반복 대신 실제 변위로 구동한다. 공격 판정은 기존 즉시 타격 시점을 유지하고 해당 시점부터 접촉/후속동작/회복을 표현한다. 지연 공격이나 판정 범위 변화로 밸런스를 바꾸지 않았다.

## 검사
- presentation.test.cjs: 새 기능 전 9개 실패를 확인한 뒤 구현. 세계 구분, 실제 이동/벽 충돌, 공격 접점/방향, 저장 호환, 안내의 실제 관찰 반영, 뉴스 고지/분류/무상 보상 방지.
- v08_browser.py: 이전 v0.7 소스에서 도움말 부재 실패를 확인. 현재 코드에서는 PC 및 390x844 / 360x640 / 844x390의 모든 기존 조작 버튼, 5개 소식 탭 고정 문구, H 안내 후 E 실제 이동/B 기감/E 조사/N 수첩, 해석 미지급, 효과 줄이기 후 자세 회복을 검사한다.
- 기존 여섯 브라우저 스위트와 전체 Node tests를 유지했다. main 배포 CI는 총 일곱 스위트를 실제 HTTP/브라우저 저장소에서 실행한 후에만 배포한다.
- 로컬에서는 이 환경의 HTTP 탐색 제한으로 인라인 문서/저장소 대체를 사용했다. 원격 Actions가 HTTP/native localStorage 검증을 담당하며 결과는 해당 실행 기록을 기준으로 확인한다.

## 리뷰에서 고친 부분
장식용 CSS 버튼 접두어가 접근성 이름을 바꾸어 정확한 버튼 찾기가 실패했다. 텍스트 접두어를 제거했다. 효과 줄이기의 장식용 t=0이 공격 회복 시간을 멈추지 않도록 동작에는 simulation playTime을 사용한다. 현대 상점 초상에 무림 초상이 남는 경로도 수정했다. 닫힌 뉴스 모달의 참조를 정리해 반복 열기 시 누적되지 않게 했다.

## 남은 범위
새 8방향 손그림 애니메이션 전체 및 모든 맵 원화 제작은 아님. 실제 저사양 Android/iPhone의 장기 발열·프레임·배터리 및 사람을 대상으로 한 탐험 이해도 검증은 별도다. 스크린샷은 실제 캔버스/DOM 렌더링이며 컨셉 이미지를 게임 화면처럼 합성하지 않는다. 시뮬레이션 뉴스는 실제 멀티플레이가 아니다.
