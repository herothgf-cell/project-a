- 첫 정착 추천 배분을 실제 미리보기 버튼으로 연결했다. 공격 4·체력 4를 제안하며 적용 전에는 소비하지 않는다.

- 정박 해석의 실제 억제 6초를 기술 설명에 표시한다. 지속 억제 카드에는 정박 사용 중 추가 시간 효과가 없음을 안내한다.
- 보관함에 기존 정착분, 새 결정 배분, 각인 구매·활성 상태를 구분해 표시한다. 상한 도달 시 보관과 다음 조건을 안내한다.
- 계승·각성의 UI 실행을 성장 저장 트랜잭션으로 연결했다. 저장 실패 시 상태와 공명 지급을 되돌리고 성공 창을 띄우지 않는다. 실패→재시도→재접속 브라우저 회귀를 추가했다.
- 공명과 첫 기연 브라우저 화면 증거 경로를 Windows/Linux 공통으로 변경했다. 모든 현재 런타임 캐시 URL과 버전 표시를 v0.12.5로 맞췄다.

검증: 단위 검사 722개, 3개 구문 검사 명령, 공명 배분·환불·실패 취소·완료·재접속, 이전 저장 가져오기, 계승 저장 실패, 세 계열 현실 정착, 첫 기연 진행, 키보드 대화, 성장 내비게이션, 독립 세계 성장, 성장 화면 및 개발 시작점 브라우저 검사 통과. 별도 검토에서 기존 공통 유료 노드 8종 × 심법 2종의 이전 전후 능력치·효과·기술 비용·환불을 비교했다.

## 별도 검토와 수정

별도 맥락의 검토자가 전체 구현을 검토했다. 치명적 발견은 없었고 다음 사항을 실제 재현 후 수정했다.

1. 봉인 F 억제가 Q 성공으로 집계돼 불러올 수 없는 저장을 생성: Q 행동만 대응 기록으로 인정. 실패 회귀 → 통과.
2. 잔영 먹향 R의 지연 적중이 연속 운용 도전에서 누락: 지연 큐에 원래 유료 행동을 연결해 1회 인정. 실패 회귀 → 통과.
3. 배분 후 포커스가 닫기로 이동해 다음 Enter에 초안을 잃음: 검토자는 Minor로 분류했으나 실제 키보드 작업 유실이므로 Important로 올려 수정. 실패 브라우저 검사 → 통과.
4. 작성자 추가 점검: 새 귀환 소식이 변화 없는 능력치로 표시되던 안내를 획득 결정 수와 공명 성장 화면으로 연결. 실패 회귀 → 통과.

남겨 둔 Minor 코드 발견은 없다. 수정 후 추가 검토자 호출 대신 재현 회귀와 전체 테스트로 확인했다.

## 구현 중 판단과 영향

판단은 발생 순서대로 남긴다.

1. 사용자가 지정한 기존 클라우드 체크아웃과 v0.2 브랜치 사용. 추가 worktree 없이 작업했으며, 별도 물리적 격리가 필요했다면 격리 재구성이 필요하다.
2. 클라우드 스킬의 실행 보조 파일을 로컬 명령으로 실행할 수 없어 동일 구조의 진행 원장을 직접 작성했다. 자동 원장 생성의 편의는 얻지 못한다.
3. 기존 런타임은 15% 기본 경감을 무림에만 적용한다. 이 동작을 유지하고 설명을 수정했다. 양쪽 경감을 의도한 기획이라면 현실 밸런스를 다시 검토해야 한다.
4. 전투와 이전 저장이 같은 코드를 공유하므로 Task 2/3을 함께 커밋했다. 개별 작업 단위 되돌리기는 덜 세밀하다.
5. 아이콘은 별도 SVG 파일 대신 인라인 SVG로 제공했다. 동일 벡터 표시이며 외부 아트 파이프라인에 넣으려면 파일 추출이 필요하다.
6. 도전·UI·시작점은 진입/저장/화면 연결을 공유하므로 테스트된 통합 단위로 커밋했다. 개별 기능 단위 되돌리기는 덜 세밀하다.
7. 사용자 지정 v0.2 브랜치를 유지한다. 원격 푸시·main 병합·배포를 실행하지 않았으므로 공개 주소에는 아직 반영되지 않는다.
8. 키보드 포커스 발견을 실제 초안 유실에 따라 Important로 다시 분류했다. 이 판단으로 수정·브라우저 회귀 범위가 추가됐다.

## 검토의 한계와 사용자 플레이 확인

- 재미·난도는 코드 검토만으로 확정하지 않았다. 프로토타입 수치로 구현했고 실제 플레이에서 성장 목표 선택과 재도전 동기를 확인해야 한다. 자동 검사 통과가 재미를 입증하지는 않는다.
- 도전 9개 등록·잠금·세 가지 성공 조건은 자동 검사했고 대표 도전의 메뉴 조작·완료·재접속을 브라우저로 확인했다. 9개 모두를 자연스러운 사람 입력으로 완주한 검증은 아니다. 각 지역의 체감 난도는 사용자 플레이 검토가 남는다.
- 기존 저장 이전은 실제 이전 런타임으로 생성한 고정 저장과 변형 회귀 사례를 확인했다. 모든 과거 저장 조합의 동등성을 전수 증명하지는 않았다. 원본을 유지하고 검증에 실패한 기록은 거부하므로 예외 기록은 원본을 가지고 분석할 수 있다.
