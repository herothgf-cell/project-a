## 구현

현실 던전 입구의 선택 체험으로 첫 전투 → 기존 계승 → 귀환·장착 → 같은 전투의 실제 대응 → 직접 보고 → 역할 선택 → 적용 전투가 연결된다. 본편 진입 조건은 그대로다. E1/E4 적 프로필은 동일하며 강타 예고 1.2초·후딜 0.8초, 파문 흡수 0.7초·강화 4초·후속기 쿨 5초다. 임무 보상은 0이며 입장 전 자원이 복구된다.

저장 버전 10·improvementVersion 2를 유지한다. 새 영구 묶음은 `worldState.returnProof.version=1`. 중간 저장은 본편 스냅샷과 검증된 증거를 보존하고 `returnProofSession`으로 재시작한다. 기세·쿨다운은 `encounter.returnProofResources`에 별도로 검증해 보존한다. Set/Map 런타임은 직렬화 투영 후 원래 참조로 되돌린다.

## 판단 기록과 남은 검증

- 기존 저장기가 초기화하던 입장 전 기세·쿨을 보존하기 위해 encounter 하위 자원 투영을 추가했다. 잘못되면 추가 마이그레이션 면이 생기므로 범위·형식 손상 테스트를 둔다.
- 표시된 회수 사각형의 모서리까지 확보·상호작용을 허용했다. 원형 거리보다 영역이 조금 넓지만 전후 임무는 동일하다.
- 사람 8명, H1~H5, 재미, 실제 신규 플레이의 20~30분 도달은 **미실행**이다. [사람 테스트 양식](return-proof-playtest.md)을 사용한다. P6 확장은 하지 않았다.

최종 통합(검토 전): `check`, `check:revision`, `check:world` 통과, **718/718 테스트 통과**. 신규 E1~E6 흐름과 별도 브라우저 안전성 검사(실제 DOM 준비 취소/게임 교체/중복/준비 실패, 보고 저장 quota 실패 후 보급·원본 보존) 통과. 기존 v12 UI/art, dev-starts, dialog-keyboard, navigation-followup, fantasy-ui 브라우저 통과.

## 독립 검토와 수정

`gpt-6-astra`의 별도 맥락 검토에서 Critical 0, Important 2, Minor 1이 보고됐다. 검토자는 전체 718개 테스트와 후기 6장 저장의 무보상 경계를 독립 확인했다.

- 연습 도움말 버튼이 HUD 갱신마다 교체되어 포커스를 잃음: 브라우저 실패 재현 후 텍스트 노드와 버튼을 분리해 같은 버튼을 유지했다.
- 준비 안내와 실제 대상 선택 불일치: 봉인은 가장 가까운 대상만, 파문 진화 반격은 실제 관통 사거리·통로를 같은 함수로 계산한다. 근거리 미억제/원거리 억제 혼합과 250 거리 진화 반격을 실패 테스트 후 수정했다.
- 연결된 기존 장착 화면의 실제 키가 레거시 포맷으로 다시 변환됨(E→G): 기본 키와 J 재지정 브라우저 재현 후 실제 키 텍스트를 직접 표시했다.

보류한 Minor: 선택 연습의 도움말 활성화는 로컬 관찰 로그에 포함되지 않는다. 사람 테스트 양식에서 도움 개입을 수동 기록한다. 제품 판정·보상에는 영향이 없다.

검토자가 판단을 유보한 사람 학습·재미·H1~H5·실제 소요 시간·실기기 모바일 사용성은 미실행 상태를 유지한다. 이 판단이 틀리면 자동 검사로 발견하지 못한 조작·재미 문제가 사람 테스트까지 남을 수 있다.

프로토타입 빌드(검토 전 `8086c29`): 544개 실행 자산, 새 모듈·CSS 포함, 개발 시작점 제외, Chromium `/preview/project-a/` 하위 경로 정상 로드. `artReady:false`는 저장소의 기존 미승인 아트 상태이며 이번 작업에서 출시 승인을 부여하지 않았다.

최종 수정 후: **720/720 테스트 통과**, `check:world` 통과, `npm run test:browser:return-proof`의 흐름·안전성·도움말 포커스 3종 통과. 기본 E 및 J 재지정 장착 안내도 브라우저에서 확인했다. 독립 검토의 Important 항목은 실패 재현→수정→전체 검사로 닫았으며 재검토 에이전트는 추가 실행하지 않았다.
