# 쌍계
## 성장·서사·전투·UI 통합 개선 기획서

**다른 세계에서 얻은 힘이, 현실의 삶과 역할을 바꾼다.**

문서 v1.1 · 2026년 10월 2일 · 개발 전 검토안

기존 분석 기준: `herothgf-cell/project-a` / v0.12.1 / `59ba7e2`

v1.1은 첨부 v1.0과 추가 요청을 반영한 문서 개정이다. 저장소·실제 화면·효과음을 이번에 새로 실행하거나 재검증한 것은 아니다.

이번 문서는 하나의 왕복 성장 경험을 완성하는 재설계안이다. v1.1에서는 심법 심화 명칭, 전투 효과음, 세계별 단일 던전 입구와 퀘스트 해금형 선택 UI를 성장·서사·전투·통합 화면에 연결한다.

> **이번 개편의 핵심**
> 지금의 전투는 너무 쉽다는 사용자 피드백에서 출발한다. 먼저 의미 있는 초기 위협을 만들고, 기연 획득 후에는 그 위협을 확실히 넘어선다. UI는 옛 RPG의 장식이 아니라 현재 행동·성장·보상을 명확히 읽는 도구로 바꾼다.

| 문서의 구분 | 적용 원칙 |
| --- | --- |
| 사용자 확정 방향 | 기존 성장·서사·난도·UI 개선 + 심법 심화 명칭 + 전투 효과음 + 세계별 던전 입구 통합 |
| 기존 분석의 현재 상태 | v1.0이 검토한 기준 커밋의 코드·기록. v1.1에서 재실행한 결과가 아님 |
| 상세 제안 | 기존 수치·역할·화면안 및 추가 음향 규칙·목록 동작·저장 이행은 구현 전 설계 |
| 미검증 | 실제 재미, 사용성, 밸런스 목표 달성, 공개 배포본 일치 여부 |

**게임 코드 수정·커밋·푸시·배포는 이번 문서 작성 범위에 포함하지 않는다.**

# 01. 의사결정 요약

## 핵심 판단

세계별 레벨 분리와 귀환 정산은 유지한다. 다만 이를 개편의 최종 목표로 보지 않는다. 플레이어가 무림에서 얻은 힘으로 현실의 전투를 바꾸고, 이전과 다른 임무와 역할을 얻는 데까지 연결해야 한다.

| 축 | 유지할 것 | 이번에 바꿀 것 |
| --- | --- | --- |
| 무림 | 백련·청운촌·기존 세 계열·심법·첫 경지 | 대화 보상보다 관찰·시도·성공으로 깨닫는 과정 |
| 성장 | 현실/무림 레벨·숙련·장착 분리, 성취별 중복 방지 | 큰 기연에 기본 전투력 상승과 새 행동을 함께 제공 |
| 현실 | 기존 지역·서린·도겸·현장 인증 설정 | 지원자에서 핵심 수행자로 역할 변화, 실제 임무 조건과 보급 변화 |
| 전투 | 예고·수동 회피·계열 차이·기존 지역 자동 강화 금지 | 쉬운 초기 기준 교정, 정예 압박, 성장 후 압도 구간 |
| UI | 키 설정·저장 보호·UI 입력 차단 | 정보 구조·타이포·공통 부품·반응형을 통합 재설계 |
| 명칭·음향 | 심법·경지 구분, 계열과 세계의 정체성 | 심법 심화로 정리, 타격·위험·성공 효과음 개선 |
| 진입 | 현실↔무림 경계석, 기존 지역·사건 | 각 세계 던전 입구 1개 + 퀘스트 해금형 선택 창 |

## 선택한 접근

색상과 폰트만 고치는 부분 개편은 정보의 중복과 숨은 성장 기능을 해결하기 어렵다. 전면적인 새 게임 제작은 기존 1~7장과 저장 자산을 불필요하게 버린다. **기존 콘텐츠를 재구성하고 공통 UI 틀을 교체하는 통합 개편**을 채택한다.

## 범위의 경계

본편의 단발성 역할 목표·보상을 보강한다. 반복 의뢰판·강제 노가다·공격력 구매는 되살리지 않는다. 새 대형 지역·직업·주거 경영·화폐·AI 동료·멀티플레이·가상 채팅은 제외한다. 공식 승급은 후속 범위다. v1.1에는 전투 효과음과 진입 UI를 포함하며 새 BGM·전면 성우 녹음·자유 순간이동은 추가하지 않는다.

## 완료의 정의

플레이어가 “무엇을 깨달았는지 → 현실에서 무엇이 강해졌는지 → 그래서 무엇을 맡게 되었는지”를 설명하고, 화면에서 다음 행동을 도움 없이 찾는다. 기능 테스트 통과만으로 재미 검증을 완료 처리하지 않는다.

## 세 가지 상태 표기

**기존 분석의 현재 확인:** v1.0이 기준 파일에서 읽은 규칙을 보존한다. v1.1의 새 코드 확인이나 사용자의 실제 플레이 평가와 구분한다.

**제안:** 이번 문서가 채택한 설계 방향이다. 구현돼 있다는 뜻이 아니다.

**검증 목표:** 측정할 가설 또는 임시 조정 범위다. 확정된 밸런스나 통계적 보증이 아니다.

## 문서와 구현의 버전 관계

문서 v1.1은 개선안 자체의 버전이다. 게임 버전을 임의로 v0.13 등으로 확정하지 않는다. 실제 작업 착수 시 기준 커밋 이후 변경분을 비교하고 적용 버전을 정한다. 과거 v0.10.1 기준 플레이 기획서를 최신 성장 규칙으로 혼용하지 않는다.

## 참고 자료를 사용하는 방법

첨부 「로그인 무림 상세 정리」에서는 ‘무림 성장 → 현실의 높은 난도 콘텐츠·보상·사회적 변화’와 인연에 따른 재방문 구조만 참고한다. 작품의 인물·사건을 복제하지 않으며, 첨부 자료의 서버 최초·가상 채팅 제안은 이번 범위에 도입하지 않는다. 첨부 자료의 작품 세부 사실을 독립적으로 검증한 문서는 아니다. [R01]

**우선순위:** 이번 사용자 추가 요청 → 본 문서의 승인된 상세안 → 최신 실제 구현 → 과거 공략서 → 참고 작품 정리. 26~31장의 신규 규칙은 관련 본문에도 반영하며, 기존 게임의 동작 사실로 취급하지 않는다.

# 04. 핵심 플레이 구조

## 한 번의 왕복에 필요한 여섯 단계

| 단계 | 플레이어의 행동 | 반드시 남는 결과 |
| --- | --- | --- |
| 1. 현실의 한계 | 예고를 피하며 초기 정예와 현장을 통과한다. | 현재는 조심해야 한다는 기준 기억 |
| 2. 무림의 인연 | 백련의 가르침과 현장 단서를 연결한다. | 왜 이 수련과 발견을 하는지 이해 |
| 3. 행동과 깨달음 | 관찰한 원리를 시도하고 실제 효과에 성공한다. | 행동으로 얻은 기연, 성공 기록 |
| 4. 무림에서의 증명 | 기존 위협을 새 힘으로 넘어선다. | 무림에서도 강해졌다는 즉각적 보상 |
| 5. 현실에서의 역전 | 이전 기준 적·현장을 더 안전하고 빠르게 처리한다. | 같은 힘의 현실 대응, 기본 전투력 차이 |
| 6. 역할과 다음 선택 | 성과를 보고하고 후속 현장의 역할을 맡는다. | 새 목표·보급·접근권·관계 반응 |

## 압도감과 무협다움의 병행

모든 성장을 ‘현상을 푸는 새로운 정답’으로 만들지 않는다. 큰 기연에는 힘으로 기존 위협을 넘어서는 장면이 먼저 있어야 한다. 그 뒤 운용과 판단으로 새로운 현상을 해결한다. 사부는 능력을 클릭으로 지급하는 사람이 아니라, 윤서가 겪은 감각을 이해하도록 돕는 인물로 둔다.

## 현실과 무림의 비중

초기 검증에서는 무림 → 현실의 성장 보상을 먼저 완성한다. 반대 방향은 현실의 실전 경험과 관측, 인물과의 약속이 무림에서 다음 시도와 통로를 여는 방식으로 연결한다. 능력치를 양쪽에 무한 복사하는 순환 보상은 만들지 않는다.

## 반복 방지

왕복 때마다 목표·전장 상태·가능한 행동 중 하나가 바뀌어야 한다. 이미 한 보고를 전달하기 위한 이동만 남으면 대사를 합치거나 다음 필수 이동에 포함한다. 실패는 현재 단계 재도전이며, 완료한 구조·관찰·기연 획득을 되돌리지 않는다.

# 05. 기연·경지·전승의 보상 설계

## 성장 개념을 섞지 않는다

| 개념 | 의미 | 대표 보상 |
| --- | --- | --- |
| 레벨 | 해당 세계의 누적 실전 성장 | 기본 체력·자원·공격력 |
| 숙련 | 기술을 효과적으로 다룬 경험 | 기술 효율·피해 보정 |
| 기연 | 관찰·선택·인연으로 발견한 특별한 원리 | 새 행동, 현실 대응 기술 |
| 심법 | 가진 힘을 운용하는 방식 | 회복형/집중형 전투 흐름 |
| 경지 | 누적 경험과 깨달음으로 넘는 한계 | 체질 변화와 뚜렷한 성장 구간 |
| 심법 심화 | 기존 심법을 더 깊이 체득한 단계. 별도 성장축 아님 | 연계 강화: 자원 효율·재생 억제·후속 효과 |

## 큰 기연의 ‘세 겹 보상’

첫 핵심 기연에는 ① 기본 전투력의 분명한 상승, ② 계열 고유 대응 기술, ③ 현실에서의 역할 증명 기회를 함께 둔다. 처음 사용하는 사람도 ①을 느끼고, 숙련될수록 ②의 이득이 커진다. ③은 기술 획득과 자동으로 지급하지 않고 실제 현장 성과를 확인한 뒤 열린다.

**초기 조정 목표:** 같은 현실 레벨·기준 적·입력에서 큰 기연 전승 후 기본 공격 성능 +20~30%, 생존 여유 +15~25%를 실험한다. 기술 활용까지 포함한 같은 전장의 공략 시간은 30~45% 단축을 가설로 삼는다. 현재 달성 수치가 아니며, 먼저 재조정한 초기 전장을 기준으로 한다.

## 누적 폭주와 강제 수집 방지

첫 기연의 공통 신체 성장은 여정당 한 번만 지급한다. 두 번째·세 번째 계열은 선택 폭을 넓히되 같은 큰 보너스를 다시 지급하지 않는다. 모든 계열을 모아야 정상 난도가 되는 설계를 금지한다. 기연 보상과 첫 경지 보상은 각각 별도 성취 ID로 관리한다.

현재 세계 능력치는 ‘세계 기본 성장 + 정착한 성취의 합’으로 출처를 표시한다. 동일 성취의 새 보상값이 기존 기록보다 커진 경우 차액만 한 번 정산하고, 기존 획득을 임의로 초기화하지 않는다. 세부 수치는 실측 후 데이터로 확정한다.

## 같은 사건을 서로 다르게 해결한다

현실 역할 목표는 세 계열 모두 완료할 수 있어야 한다. 특정 계열이 정답인 자물쇠를 만들지 않는다. 파문은 강타를 반격해 위협 시간을 줄이고, 잔영은 공격 위치를 바꾸며, 봉인은 위협의 실행을 끊는다. 공통 완료 조건은 ‘안전한 통로 확보’이고 기술 사용 횟수는 숨은 필수 카운터가 아니다.

## ‘사용 전/후’ 연출 원칙

파문은 받아낸 순간과 반격의 충격을, 잔영은 실제 이동 경로와 도착점을, 봉인은 억제 중인 한 대상과 남은 시간을 읽게 한다. 무림 동작의 자세·음향 모티프는 현실에도 남기되, 현실 효과의 범위를 무림의 광역 효과처럼 오해시키지 않는다. 27장의 계열별 효과음도 실제 방어·이동·억제 성공과 맞춰 재생한다.

## 해석의 위치

이번 1차 개편은 계열 대표 경험부터 완성한다. 모든 해석마다 별도 현실 기술을 추가하지 않는다. 기존 해석의 발견·장착·현실 재현 설명은 유지하고, 대표 해석 하나가 현실 대응의 차이로 확장되는 실험은 핵심 검증 이후의 선택 범위다.

| --- | --- | --- | --- |

마지막 역할을 ‘다음 업데이트에서 의미가 생길 보상’으로만 남기지 않는다. 예를 들어 7장 최종 준비에서 ‘대피 통로 우선/정예 차단 우선’ 중 하나를 선택하고, 등장 위치·엄호 구간·선행 목표 중 실제 한 항목이 달라지게 한다. 새 AI 전투 동료는 필요하지 않다.

## 전투력·자격·등급 표시

**실제 전투력:** 체력·공격력·기술과 최근 현장 성과로 설명한다. 임의의 통합 전투력 숫자를 새로 만들지 않는다.

**현장 자격:** 특정 조사나 지역에 참여할 권한이다. ‘C급 현장 인증 · 공명 관측소’처럼 대상 범위를 표시한다.

**공식 헌터 등급:** 등록된 평가 결과다. 현재 E급을 대사 한 번으로 C급으로 바꾸지 않는다. 공식 승급은 별도 평가 사건이 구현됐을 때만 변경한다.

## 생활 변화의 최소 범위

기지의 현장 기록, 기존 인물의 역할별 대사, 본편 역할 보상, 1회 보급 지원으로 성과를 표현한다. 보급은 회복약의 획득·소비와 함께 검수한다. 수입이 늘었다는 대사만 쓰거나 쓸 곳 없는 새 화폐를 만들지 않는다. 주거·길드 경영은 이번 범위가 아니다.

## 제안 대사

대화 건너뛰기, 보고 전 다른 지역 이동, 계열 변경, 과성장으로 적 조기 처치, 실패와 재접속, 5장 이후 늦은 연화 재회, 이전 저장으로 6장 진입을 각각 확인한다. 보고는 마지막 명시적 행동에서 한 번 실행한다. 같은 화면을 열었다는 이유로 사실 확인·보고·장착을 동시에 처리하지 않는다.

## 무림의 관계를 보상으로만 쓰지 않는다

백련은 윤서가 이미 해낸 행동을 인정하고 다음 관점을 제공한다. 연화는 구조 후 자신의 일상을 회복하며 윤서의 행동을 기억한다. 현실의 인정이 늘어도 무림에 남은 사람과 약속이 사라지지 않는다. ‘무림은 보상 창고’라는 인상을 피한다.

## 통합 사건 기록

임무 완료, 대사, 소식, 현실 역할, 귀환 결과와 던전 해금은 같은 사건 정의를 참조한다. 목록을 열었다는 이유로 사건·보고·자격을 완료하지 않는다. 화면마다 다른 조건으로 ‘잠김’과 ‘입장 가능’을 동시에 표시하지 않는다. 새 입구는 이동 편의이며 세계 간 NPC 통신 장치가 아니다.

# 11. 전투 난이도: 쉬운 기준부터 교정

## 이번 개편의 난이도 원칙

현재 쉬운 전투에 성장 보너스만 추가하지 않는다. 초기 정예와 무리 전투에 먼저 의미 있는 위험을 만든다. 이후 같은 적은 플레이어의 성장으로 쉬워지고, 다음 지역의 새 정예가 새로운 판단을 요구한다. 기존 적을 레벨에 맞춰 자동 강화하지 않는다.

| 전투 대상 | 성장 전 초기 목표 | 첫 큰 성장 후 동일 대상 | 새로운 상위 위협 |
| --- | --- | --- | --- |
| 일반 적 1명 | 3~5초, 타이밍 무시 시 피격 가능 | 약 1~2초, 확실한 정리 구간 | 단순 체력 증가보다 역할 조합 |
| 3~4명 무리 | 25~45초, 대상·위치 판단 필요 | 약 15~28초, 공략 여유 증가 | 사격+강타로 우선순위 요구 |
| 정예 | 15~25초, 기회와 위험이 분명 | 패턴 1~2회 안에 처리 가능 | 20~35초, 계열의 강점 활용 |
| 첫 보스 | 60~100초, 의미 있는 패턴 경험 | 이전보다 짧고 안전한 재대면 | 70~110초, 새로운 대응 판단 |

**모든 시간은 전투 개시부터의 임시 조정 범위다. 이동·대화는 제외하며, 계열·숙련도별 실측 전에는 확정값이 아니다.** 플레이어를 일부러 맞게 하거나 실패율을 채우기 위해 조정하지 않는다.

## 입력별 차이

기본 공격 유지로 초기 교육 전투는 통과할 수 있어도 대표 정예·보스까지 안정적으로 돌파하지는 못하게 한다. 이동·회피를 사용하는 플레이어는 생존할 수 있고, 기연 대응에 성공하면 공략이 뚜렷하게 유리해져야 한다. 실수 한 번의 즉사는 초반 표준 난도에서 배제한다.

## 최종 적용값을 기준으로 한다

현재 Director는 지역 정의 뒤에 적 수치를 다시 결정한다. 개선 시 지역별 체력·피해·속도·예고·보상·역할을 단일 최종 표에서 산출한다. 지역 설정과 실제 생성 결과가 다르면 테스트에서 드러나게 한다. ‘표의 보스 1,150’만 보고 실제 난도를 판단하지 않는다. [S06](https://github.com/herothgf-cell/project-a/blob/59ba7e23e892ed9612868261c5404436f7a6938d/encounter-director.js)

## 공정한 압박

근접 동시 예고 상한은 유지하되, 여러 무리가 섞일 때도 전체 위험이 감당 가능한지 확인한다. 사격은 단순히 무제한으로 겹치지 않게 개시 간격을 검수한다. 초기 큰 공격은 약 1.0~1.3초의 읽기 시간을 시작값으로 사용하고, 후반도 반응 시간을 일괄 급감시키지 않는다. 효과음은 같은 예고·명중 사건에 맞추며, 소리 없이도 시각 신호로 대응할 수 있어야 한다.

## 자원과 회복약

자원 재생·회복약·무적 시간·넉백·공격 중단이 쉬운 난도의 원인이 될 수 있으므로 각각 측정한다. 먼저 무기력한 적 AI와 수치 덮어쓰기를 확인한 뒤 플레이어를 약화한다. 회복약을 통해 생존할 수 있어도 반복 구매가 본편 진행의 필수 노가다가 되어서는 안 된다.

보급 지원은 사건당 한 번이며 재입장·불러오기로 다시 받지 않는다. 역할 보상의 금화와 약을 추가하면 기존 지역 수입·기지 회복·소비량을 함께 비교한다. 가격과 수량을 따로 바꾸어 효과를 혼동하지 않는다.

## 성장 구간의 리듬

‘현재 도전 → 큰 성취 → 이전 위협 압도 → 새 도전’을 한 묶음으로 검증한다. 성장 직후의 짧은 압도 구간은 실패한 밸런스가 아니라 의도된 보상이다. 단, 본편 전체가 같은 쉬운 정리 전투로 끝나는 것은 허용하지 않는다.

## 자동 검사와 사람 플레이의 역할

자동 검사는 규칙·중복 보상·최종 수치·저장·소프트락을 검증한다. 사람 테스트는 읽기·학습·긴장·압도감·다시 하고 싶은 이유를 검증한다. 자동 조작만으로 세 계열의 재미가 같다고 판정하지 않는다.

## 기록 단위

커밋, 데이터 버전, 지역, 계열, 현실/무림 레벨, 숙련, 정착 성취, 난도 보조, 입력 정책, 초기 적 상태를 저장한다. 시간·피해·회복약·사망·주요 대응 성공을 기록하고 테스트 전후 성장 지급을 차단한다. 음향 켜짐/꺼짐·개별 음량·청취 기기를 함께 기록해 효과음 변경을 수치 변화로 혼동하지 않는다. 사용자 동의 없는 서버 전송이나 개인정보 수집은 없다.

## 초기 사람 테스트

처음 보는 사람 5명과 기존 플레이 경험자 2명 정도의 소규모 탐색 테스트를 제안한다. 5명 중 4명이 성장 원인과 다음 행동을 설명하는 것을 초기 사용성 관문으로 삼되, 이 수치를 모집단의 성공률로 일반화하지 않는다. ‘너무 쉬움/억울함/읽기 어려움’은 구간과 입력 상태를 함께 기록한다.

## 통합은 ‘모든 것을 한 화면에 넣기’가 아니다

캐릭터 개요는 현재 세계의 상태만 먼저 보여 준다. 다른 세계는 ‘비교 보기’로 연다. 무공은 장착과 효과, 성장은 심법과 경지처럼 행동이 다른 정보를 나눈다. 무공 트리와 상세 수치를 개요에 전부 나열하지 않는다.

## 빠른 진입은 유지하되 실행 지점은 하나

초상화 → 캐릭터 개요. ‘돌파 가능’ 알림 → 캐릭터 성장의 해당 카드. 귀환 소식 → 해당 성취 결과. 임무 목적지 → 같은 길 안내. 여러 진입 경로가 있더라도 장착·돌파·보고의 실제 처리와 상태는 하나만 사용한다.

## 기존 키와의 호환

방향키 이동, QWER/ASDF 전투 체계, G 상호작용, 기본 1키 회복약과 사용자 키 변경을 유지한다. 키의 구체적 표시는 실제 설정에서 읽는다. 상태·수첩 등의 기존 바로가기는 새로운 정식 화면으로 연결하고, 예전 창을 별도로 띄우지 않는다.

## 화면 이동 규칙

상위 메뉴 → 탭 → 상세의 최대 3단계. 보유 무공 장착·심법 변경·돌파는 관련 첫 탭에서 바로 실행한다. 던전 선택은 통합 입구의 상황별 팝업이며 다섯 번째 상시 메뉴가 아니다. 임무 화면은 위치 안내·입장 조건 조회만 제공한다. 상세에서 돌아오면 선택·스크롤을 보존한다.

| 좌상단 | 초상화, 현재 세계, Lv, 체력·자원 | 초상화만 캐릭터 진입. 공식 등급·모든 성장 수치 상시 노출 금지 |
| 상단 중앙 | 보스/중요 적의 이름·체력·핵심 상태 | 보스전 때만 표시, 공격 예고 영역을 가리지 않음 |
| 우상단 | 현재 임무 1개와 다음 행동, 작은 지도 | 긴 설명은 접고 ‘길 안내’로 확장 |
| 화면 중앙 | 전장·공격 예고·상호작용 대상 | 장식 패널과 알림을 배제, 판단에 필요한 공간 우선 |
| 하단 | 공격·회피·기술·약의 현재 조작 | 비용·재사용·사용 불가 이유 구분 |
| 모서리 | 캐릭터·임무·기록·설정 | 단정한 공통 메뉴, 전투와 입력 분리 |

## HUD에서 덜어낼 것

브랜드 문구, 긴 장 제목, 세계관 슬로건, 상시 저장 문장, 중복 공명 카드처럼 전투 판단과 무관한 정보는 시작 화면·기록으로 옮긴다. 보스 예고와 목표 마커 위에 피해 숫자나 획득 알림이 겹치지 않게 우선순위를 정한다.

## 길 안내의 의미를 고정

‘길 안내’는 목적지·현재 경유지·완료 조건을 보여 주며 자동 이동이 아니다. 지도에는 현재 위치와 목적지를 모양·라벨로 구분한다. 숨은 기연의 정답 위치는 본편 표식으로 노출하지 않는다. 다음 세계로 가야 한다면 경계석 → 그 세계의 통합 던전 입구 → 선택할 목적지를 함께 표시한다. 같은 세계라면 통합 입구만 경유한다. 현재 목표가 NPC 대화·보고면 던전으로 유도하지 않는다. 지도는 세계 이동/던전 선택의 아이콘과 라벨을 구분한다.

## 반응형 기준

1280×720, 1920×1080에서 전장 중심을 우선 확보한다. 폭 1024px 미만에서는 상시 측면 설명 패널을 접는다. 360×640·390×844 세로 화면에서는 지도와 긴 임무 설명을 임무 화면으로 이동하고, 844×390 가로에서도 같은 기능에 접근 가능하게 한다. 화면 전체를 축소해 맞추지 않는다.

# 17. 캐릭터 개요·성장·무공

## 캐릭터 개요의 첫 화면

| 구역 | 내용 |
| --- | --- |
| 머리말 | 윤서 / 현재 세계 / 현재 세계 Lv / 다른 세계 비교 |
| 상태 | 체력·자원·공격력과 출처 펼치기 |
| 현실 정보 | 공식 E급 / 특정 현장 자격 / 현재 역할을 분리 |
| 무림 정보 | 현재 경지 / 심법 / 장착 무공을 먼저 표시 |
| 최근 변화 | 가장 최근의 정착 성취 1개와 원인 |
| 주요 이동 | 무공 장착 / 성장 확인 |

다른 세계 비교는 기록 조회다. 그 세계로 이동하거나 장착을 바꾸는 버튼처럼 보이면 안 된다. 현재 세계와 비교 세계의 강조 정도를 분명히 다르게 한다.

## 성장 탭

첫 화면에는 ‘현재 심법/현실 운용’과 ‘경지 돌파’ 두 카드를 둔다. 심법 심화는 첫 카드 안의 단계이고, 효과 이름은 ‘연계 강화’다. 새 카드·게이지·전용 전투 버튼을 늘리지 않는다. 돌파 상태·조건·다음 행동·실행 버튼은 펼치기 없이 보인다. 숫자만 `8/8`로 나열하지 않고 ‘무림 실전 숙련 충족’처럼 뜻을 적는다. 비활성 상태도 숨기지 않고 거점·세계·미충족 조건을 설명한다.

## 무공 탭

현재 장착 계열을 최상단에 두고 계열 선택과 세부 기술을 분리한다. 기술 상세는 ‘무엇을 하는가 → 언제 유리한가 → 현재 키/비용/재사용 → 수치 상세’ 순서다. 발견 전 해석의 이름·정답은 감춘다. 모바일에서는 큰 트리를 억지로 축소하지 않고 같은 관계를 세로 단계 목록으로 제공한다.

## 제안 문구

‘계승하기’는 첫 획득에만, ‘장착하기’는 보유 기술 교체에만 사용한다. ‘현재 장착 중’과 ‘변경 불가 · 거점에서 가능’을 구분한다. ‘현실 대응 정착’ 아래에는 ‘무림에서 익힌 원리가 현실에서 작동함을 확인했습니다’처럼 뜻을 한 번 설명한다.

# 18. 임무·대화·상호작용

## 임무 정보의 고정 순서

| 순서 | 표기 예시 | 목적 |
| --- | --- | --- |
| 목표 | 귀환 부두의 대피 통로 확보 | 왜 하는지 이해 |
| 다음 행동 | 부두 동쪽의 강타 정예 저지 | 지금 무엇을 하는지 이해 |
| 완료 조건 | 위협 제거 후 대피 완료 확인 | 단순 처치와 사건 완료 구분 |
| 경로 | 헌터 기지 → 던전 입구 → 귀환 부두 선택 | 현재 경유지와 최종 목적 구분 |
| 결과 | 역할 기록·1회 보급 지원 | 실제 바뀌는 것 예고 |

예시는 제안이며, 현재 본편의 고정 대사나 확정 보상값이 아니다.

## 대화 화면

화자·본문·행동 버튼을 서로 다른 영역에 배치한다. 한 번에 한 화자의 짧은 발화를 먼저 보여 주고 자동 넘김은 기본에서 끈다. 전체 대화 이력은 별도 펼치기로 읽는다. 대사 안에 버튼 키·스탯 계산·퀘스트 카운터를 섞지 않는다.

본문은 데스크톱 18px, 좁은 화면 16~18px부터 검수하고 1.6~1.75 줄간격을 사용한다. 길면 글씨를 줄이지 말고 페이지나 세로 스크롤로 나눈다. 마지막 ‘보고하기/훈련 시작/돌아가기’가 어떤 상태를 바꾸는지 명확히 한다.

## 입력과 표식

UI 위 클릭·우클릭·터치는 공격/회피로 전달하지 않는다. 대화 닫기 직후 같은 누름을 전장 행동으로 재사용하지 않는다. G/Enter 선택과 Esc 닫기를 지원하되 기존 사용자 키 설정을 우선한다. 대화 버튼마다 불필요한 단축키 장식을 다시 붙이지 않는다.

상호작용 대상에는 가까울 때 현재 키 또는 ‘상호작용’ 버튼을 표시한다. 클릭 가능한 UI와 단순 목표 표식은 모양과 커서 반응을 구분한다. 마커만 작은 다이아로 남기지 않고 출입구/인물/목표의 라벨을 함께 제공한다. 던전 입구에서 상호작용하면 선택 창만 열리며 목록 클릭·Enter 유지로 즉시 입장하지 않는다. 선택 후 별도의 ‘입장하기’를 한 번 실행한다(30장).

# 19. 귀환 결과·현실 역할·기록

## 귀환 결과는 원인과 변화가 먼저

| 화면 순서 | 보여줄 정보 |
| --- | --- |
| 1. 성취 | ‘파문검의 원리를 체득했습니다’ 등 실제 획득 원인 |
| 2. 신체 변화 | 현재 현실 능력치의 이전 → 이후, 보정 출처 |
| 3. 기술 변화 | 발현 가능 / 장착 / 실제 성공으로 정착을 구분 |
| 4. 다음 행동 | ‘무공에서 장착하기’ 또는 ‘본편 현장에서 활용하기’ |

현실 역할은 실전 성과 이후의 별도 결과다. 기연을 얻은 것만으로 공식 등급·현장 자격·보급 권한을 동시에 지급하지 않는다. 수치가 바뀌지 않는 해석 발견은 `공격력 +0` 목록 대신 새로운 원리와 사용할 곳을 표시한다.

## 알림의 우선순위

전투 중 큰 결과창을 강제로 열지 않는다. 주요 성취는 3~5초의 비차단 요약과 영구 기록으로 남기며, 안전한 거점에서는 첫 큰 변화의 결과를 확인할 수 있게 안내한다. 같은 왕복에 새 성취가 없으면 결과창·새 소식·붉은 점을 만들지 않는다. 최초 결과 연출의 재생과 보상 지급을 분리한다. 던전 해금도 고유 사건으로 한 번만 알리고, 전투 중 선택 창을 강제로 열지 않는다.

## 기록 화면의 역할

‘소식’은 읽지 않은 변화, ‘행적’은 완료 사건과 역할의 시간 순 기록, ‘관찰’은 직접 확인한 단서다. 세 화면을 같은 내용의 복제 목록으로 만들지 않는다. 소식에서 상세를 읽으면 관련 메뉴 배지도 함께 갱신한다. 목록을 열었다는 이유로 전체 읽음 처리하지 않는다.

## 장 종료의 현실 변화 카드

‘실전 성과 → 받은 인정 → 이번에 열린 행동’ 세 줄로 요약한다. 예: 통로를 지켰음 → 초동 대응 역할 부여 → 다음 본편 현장의 진입 경로 선택. 역할이 열렸는데 실제 버튼·목표가 없으면 미완료로 판정한다.

# 20. 가독성·모바일·접근성 기준

| 항목 | 프로젝트의 설계 목표 | 검증 방법 |
| --- | --- | --- |
| 일반 본문 | 16~18 CSS px, 핵심 안내는 16px 미만 금지 | 주요 화면의 계산된 스타일 확인 |
| 보조 정보 | 14px 이상, 중요 상태를 보조 크기로 숨기지 않음 | 상태·비활성·저장 오류 샘플 |
| 제목 | 22~28px, 과도한 자간·짧은 세로 줄바꿈 금지 | 긴 한글 제목과 좁은 화면 |
| 명암 대비 | 일반 글자 4.5:1 이상, 권장 조합은 더 여유 있게 | 실제 배경·상태별 측정 [W01](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) |
| 버튼 크기 | 일반 조작 영역 44×44px 이상, 전투 터치 56~64px 권장 | 실제 입력 영역과 간격 확인 [W02](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum) |
| 확대 | 게임 내 100/125/150%, 브라우저 200%도 정보·기능 보존 | 대화·목록·확인 버튼 리플로 [W03](https://www.w3.org/WAI/WCAG21/Understanding/resize-text) |
| 비색상 정보 | 세계·위험·선택·새 소식을 글자/모양으로도 구분 | 회색조·색각 조건 점검 |

44px는 프로젝트가 채택하는 목표이며 WCAG AA의 일반 최소값이라고 표현하지 않는다. WCAG 2.2의 2.5.8은 예외 조건을 둔 24×24px 최소 기준이고, 2.5.5의 강화 기준은 44×44px다. 이 문서는 WCAG 전체 적합성을 인증하지 않는다. [W02](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)

## 모바일 전투 배치

세로 화면은 왼쪽 이동 영역과 오른쪽 3열 이내 행동 묶음을 분리한다. 손가락 영역을 계산해 버튼을 겹치지 않게 배치하고, 길게 누르기 설명으로 전투 입력을 지연시키지 않는다. 설명은 무공 화면 또는 거점 도움말 모드에서 읽는다. 화면 회전을 강제하지 않고 두 방향을 검수한다.

## 텍스트와 효과

중요 안내는 DOM 텍스트로 제공하고 캔버스 확대에 의존하지 않는다. 한국어 단어를 무조건 글자 단위로 쪼개지 않되 긴 식별자는 줄바꿈 가능하게 한다. 흔들림·번쩍임·큰 성장 연출은 감소 옵션을 제공하고, 감소 상태에서도 공격 예고와 성공 여부를 읽을 수 있게 한다.

## 통합 부품의 상태 계약

| 부품 | 필수 상태 | 공통 규칙 |

| 버튼 | 기본/선택/호버/포커스/비활성/처리 중 | 클릭·키보드·터치 결과 동일, 한 번만 실행 |

| 상태 카드 | 잠김/가능/진행/완료 | 색과 문구를 함께 사용, 잠긴 이유 표시 |

## 누락하지 않을 화면

시작·이어하기·새 여정 확인·보관판 안내, 세계 이동 로딩·아트 로드 실패·재시도, 저장 성공·실패·가져오기 오류, 전투 실패·재도전, 설정·키 변경·충돌 안내, 모바일 회전·확대, 빈 기록·잠긴 기술, 장 완료 화면, 던전 선택·잠김·이동 실패, 음량·효과음 미리듣기도 같은 규칙으로 이관한다. HUD만 새로 꾸미고 시스템 창은 옛 디자인으로 남기지 않는다.

## 입력과 일시정지 정책 제안

대화·캐릭터·임무 상세·설정·던전 선택 등 집중해서 읽는 패널은 시뮬레이션을 일시정지한다. 전투 음향의 반복·예약도 함께 중단하고, 재개 때 지난 소리를 몰아 재생하지 않는다. 단, 전투 중 변경 금지는 유지해 일시정지로 장착 제한을 우회하지 못하게 한다. 닫기 후 누르고 있던 키·마우스 상태를 비우고 새 입력부터 전투를 재개한다. 백그라운드 전환 후에도 입력이 고착되지 않아야 한다.

## 공통화 순서

## 개발 전달용 핵심 지시

기준 커밋 이후 변경을 먼저 비교한다. 현재 분리 성장과 저장 보호는 유지한다. 새로운 반복 의뢰·화폐·강화·AI 동료를 만들지 않는다. 최종 적용 적 수치를 기준으로 난도를 재조정하고, 첫 기연의 성장 전후를 같은 조건에서 검증한다. UI는 네 최상위 목적과 캐릭터 3탭으로 통합하되 기존 입력 설정과 실제 행동 제한을 유지한다.

6장 대화만으로 체득시키지 말고 실제 효과 성공을 기록한다. 과성장·계열 변경·이전 저장에서도 진행이 막히지 않아야 한다. 현실 역할은 대사뿐 아니라 기존 본편의 실제 행동이나 보급으로 연결한다. 공식 등급은 별도 평가 없이 변경하지 않는다. 심법 심화는 기존 심법 내부의 단계로 넣고, 연계 강화 효과와 구분한다. 세계 이동 경계석은 유지하며 던전 진입만 세계별 1개로 묶는다. 퀘스트 해금 판정은 목록·길 안내·실제 입장에서 공유한다. 전투음은 입력이 아니라 확정된 시전·예고·명중 사건에 연결한다.

## 기능과 표현의 경계

기본 공격과 기연 대응을 유효하게 연결하면 기존 회복형/집중형 규칙의 추가 효과를 얻는다. 첫 명칭 이행은 기존 효과·자원·연계 시간·보조 옵션을 바꾸지 않는다. 전투 수치 조정은 11~13장의 별도 실험으로 처리한다. 심법 선택을 바꾸어도 이미 체득한 단계를 잃거나 재획득하지 않는다.

**화면 문구 제안:** ‘심법 심화 — 두 세계의 경험으로 익힌 힘을 더 능숙하게 다룹니다.’ / ‘연계 강화 — 유효한 공격과 기연 대응을 이어 추가 효과를 얻습니다.’ 상세에서는 현재 운용에 실제 적용되는 효과만 보여 준다.

## 전면 적용과 저장 호환

HUD·성장·기술·임무·소식·도움말·6~7장 대사·접근성 이름·튜토리얼을 같은 용어표에서 읽는다. 일반 대사 속 자연스러운 ‘호흡’까지 기계적으로 치환하지 않는다. 게임명 ‘쌍계’와 기존 부제도 이번 명칭 변경으로 바꾸지 않는다.

기존 내부 키(예: `dualBreath`)는 표시명 변경만으로 삭제·일괄 개명하지 않는다. 이미 획득한 상태·소식 읽음·보상 원장을 유지하고, 새 획득 연출이나 보상을 중복 지급하지 않는다. 새로운 체득 과정은 새 여정에 적용하며 기존 기록은 ‘이전 버전 획득 보존’으로 구분한다.

# 27. 전투 효과음: 타격과 판단을 함께 강화

## 목표와 범위

기본 공격·무공·현실 대응·적 공격·피격·방어·회피·반격·억제·처치·심법 심화의 전투 효과음을 개선한다. 단순 음량 증가가 아니라 **휘두름과 명중, 위험과 성공, 가벼운 타격과 결정타를 구분**한다. 새 BGM·전면 성우·환경음 전면 교체는 제외한다. 아래는 기존 사운드의 진단 결과가 아닌 신규 제작·통합 명세다. [U02]

| 사건 | 청각 표현 방향 | 재생 조건 |
| --- | --- | --- |
| 기본 공격·헛침 | 짧은 칼바람, 적중 시만 재질감 추가 | 시전 성립 / 실제 명중을 각각 구분 |
| 강타·원거리 예고 | 준비음과 발사음이 서로 구분됨 | 실제 예고 시작 / 실제 발사 사건 |
| 피격·막힘 | 신체 충격, 단단한 충돌을 구분 | 적용된 피격 또는 방어 결과 |
| 회피 | 짧은 이동음, 실제 회피 성공은 별도 짧은 신호 | 이동 성공 / 유효 위협 회피 |
| 파문검·현실 흡수 | 짧은 울림 → 응축 → 반격의 묵직한 타격 | 받아내기·흡수·충격 소비가 실제 성립 |
| 잔영보·현실 가속 | 가벼운 보법, 이동과 도착을 분리 | 실제 이동과 추격 적중, 가짜 복귀음 금지 |
| 경계봉인·현실 억제 | 절제된 공명, 억제 성공의 짧은 끊김 | 실제 억제·중단, 단일 대상 범위 존중 |
| 결정타·처치·연계 강화 | 낮은 빈도의 명확한 종결·성공 신호 | 실제 처치 / 연계 효과 발동. 중복 제한 |

## 두 세계는 같은 원리, 다른 질감

무림은 검·옷깃·보법·내공의 절제된 울림을, 현실은 짧고 단단한 충격·가속·국소 억제의 질감을 사용한다. 같은 계열의 핵심 음색 모티프는 남겨 현실에서도 무림의 힘을 알아보게 한다. 현실 가속에 과거 위치 귀환음, 단일 억제에 거대한 광역 폭발음을 붙이지 않는다.

## 성장 후의 차이

성장 전후의 차이를 음량으로 속이지 않는다. 강한 반격·자세 붕괴·결정타가 실제로 발생했을 때만 밀도 있는 타격층을 더한다. 기본 연타는 짧게, 성공의 여운은 드물게 사용한다. 음악적 획득 팡파르는 전투 기술마다 반복하지 않으며 심법 심화 최초 체득도 실제 획득 사건에 한 번만 연결한다.

# 28. 음향 통합·피로도·검증 기준

## 사건에 연결하고, 겹침은 제한한다

입력 버튼이 아니라 확정된 시전·예고·명중·방어·회피·사망 사건에 연결한다. 재사용 대기·자원 부족·일시정지 중에는 공격음이 나지 않는다. 연타와 다중 타격은 ‘시전 ID + 타격 순번 + 대상 + 결과’로 중복을 구분하고, 여러 적 적중음은 묶거나 제한하되 실제 피해 판정은 바꾸지 않는다.

| 항목 | 초기 설계값·규칙 | 확인할 점 |
| --- | --- | --- |
| 중요도 | 적의 위험 예고 → 피격/방어 → 주요 기술 → 반복 타격·UI | 필요한 신호가 연타에 묻히지 않음 |
| 동시 재생 | 총 24개, 그 안에서 중요 신호 4개 우선 확보 | 프로젝트 시작값. 실기기 결과로 조정 |
| 반복 변주 | 기본 타격 3~5종, 같은 샘플 연속 방지 | 장시간 반복 시 피로·기계적 반복 감소 |
| 성공 피드백 | 같은 종류 연속 알림은 약 0.3초 안에 묶기 | 위험 예고는 묶어서 누락하지 않음 |
| 시점 | 실제 판정과 같은 시뮬레이션 사건에서 요청 | 예약 효과 취소·후속 타격과 싱크 일치 |

## 설정·기기·자산

설정 → 소리에서 전체·배경음·전투 효과음·UI 효과음을 구분한다. 기본 켜짐 여부보다 기존 사용자의 음소거·음량을 우선 보존한다. ‘예고 / 타격 / 반격’ 미리듣기는 설정 안에서만 짧게 재생하고 전투 사건이나 보상을 만들지 않는다.

음원 재생이 허용되지 않은 상태·로드 실패·무음에서도 게임은 진행돼야 한다. 최초 사용자 조작 후 재생을 준비하고 실패 안내는 과도하게 반복하지 않는다. 중요 예고는 소리뿐 아니라 시각으로도 제공하며 방향 정보가 필요하면 위치 표시를 병행한다. 원본·제작자·사용 근거·편집본·루프 여부를 자산 목록에 기록한다. 출처 불명 음원은 넣지 않는다.

## 추가 출시 관문

**A-01** 헛침/명중/흡수/회피/억제/사망의 소리가 실제 결과와 일치. **A-02** 보스·다수 적·연타에서 중요 예고 보존, 겹침·왜곡·끊김 없음. **A-03** 무음·저음량·일시정지·전환·재접속에 오류 없음. **A-04** 데스크톱·실물 휴대폰·이어폰·내장 스피커에서 10분 이상 반복 청취. 수치와 청취 결과는 별도 기록하고, 실제 기기 검수 전 완료로 보지 않는다.

# 29. 세계별 단일 던전 입구와 순차 해금

## 유지할 포털과 합칠 포털

**현실↔무림을 잇는 경계석은 지금처럼 유지한다.** 그 기능·왕복 규칙·귀환 정산을 던전 선택과 합치지 않는다. 현실 거점에는 현실 던전용 입구 1개, 무림 거점에는 무림 던전용 입구 1개만 둔다. 해금된 던전이 늘어도 거점의 포털 오브젝트·아이콘·충돌체 수는 늘지 않는다. [U02]

| 구분 | 현실 거점 | 무림 거점 |
| --- | --- | --- |
| 세계 이동 | 기존 경계석 → 무림 거점 | 기존 경계석 → 현실 거점 |
| 던전 진입 | 던전 입구 1개 → ‘현실 던전 선택’ | 던전 입구 1개 → ‘무림 탐험지 선택’ |
| 선택 범위 | 현재 세계의 해금된 전투·현장 지역 | 현재 세계의 해금된 전투·탐험 지역 |
| 귀환 | 해당 세계의 지정 안전 귀환점 | 해당 세계의 지정 안전 귀환점 |

일반 NPC·상점·수련 상호작용, 던전 내부의 출구·다리·봉인 등 사건 장치는 제거 대상이 아니다. 선택 창은 플레이어용 이동 목록이며 새로운 세계 간 통신·순간이동 장치라는 설정을 만들지 않는다. 목록을 누른 것만으로 다른 세계로 건너가지 않는다.

## 퀘스트 진행이 해금의 원인

| 구간 예시 | 해금 조건의 설계 원칙 | 보존할 제약 |
| --- | --- | --- |
| 초기 전장 | 해당 세계 도착 + 본편의 첫 진입 허용 사건 | 인트로·기본기·첫 보고 건너뛰기 금지 |
| 중반·구조 현장 | 선행 본편 완료 또는 명시된 수락·보고 | 단순 레벨·공식 등급만으로 자동 해금 금지 |

# 30. 던전 선택 팝업과 길 안내

## 입구에서 선택하고 확인한 뒤 입장

통합 입구 접근 → 현재 상호작용 키 → 선택 팝업 → 목록에서 목적지 선택 → 상세 확인 → **입장하기** 순서다. 행 클릭은 선택만 하며 더블클릭·키 유지도 즉시 입장으로 해석하지 않는다. 팝업은 공통 UI의 단일 계층을 사용하고 배경 이동·공격·회피를 차단한다.

| 영역 | 표시 내용 | 사용 규칙 |
| --- | --- | --- |
| 상단 | 현재 세계, 선택 창 제목, 닫기 | 다른 세계로 바꾸는 탭은 제공하지 않음 |
| 목록 | 발견한 이름·상태·현재 임무 표시 | 현재 임무 → 새 해금 → 나머지 진행순 정렬 |
| 상세 | 목적·위협 특징·입장 조건·현재 진행·보상 정책 | 긴 설명은 펼치기. 이미 받은 보상 재지급 암시 금지 |
| 잠긴 항목 | 잠김 + 다음에 할 비스포일러 행동 | 이유는 읽을 수 있고 입장만 비활성 |
| 하단 | 선택 지역 이름·입장하기·닫기 | 대상 선택 전 비활성. 로딩 중 재입력 차단 |

**상태를 분리한다:** 잠김 / 새 해금 / 진행 중 / 목표 완료·보고 필요 / 공략 완료·재방문 가능 / 현재 진입 불가. 공략 완료가 자동으로 재방문 가능을 뜻하지 않으며, 원래 허용된 지역만 재방문한다. 새 던전이 열려도 자동 입장·강제 팝업은 없다.

## 길 안내는 실제 경유지를 가리킨다

같은 세계: ‘통합 입구 → 귀환 부두 선택’처럼 안내한다. 다른 세계: ‘경계석 → 상대 세계 거점 → 통합 입구 → 대상 선택’으로 잇는다. 팝업에서 현재 임무의 대상은 우선 표시하되 사용자가 다른 곳을 선택할 수 있다. 필수 단계·준비가 남으면 이유를 제시하고 입장은 제한한다. NPC에게 보고할 차례라면 NPC를 우선한다.

임무·지도에서 상세를 미리 보더라도 입구 밖에서는 ‘입구 위치 보기’만 가능하다. 허브 밖·전투 중 원격 출발, 목록을 통한 세계 전환, 새 자동 이동은 추가하지 않는다.

## 좁은 화면과 입력

데스크톱은 목록+상세, 모바일은 목록→같은 팝업 안의 상세→뒤로를 사용한다. 닫기·입장 버튼은 확대/안전 영역에서도 접근 가능하게 두고 글씨를 축소하지 않는다. 선택 상태·스크롤은 돌아올 때 보존한다. 열 때 현재 임무를 강조하되 입장 버튼을 자동 실행하지 않으며 닫기 후 새 입력부터 이동을 받는다.

# 31. 진입 데이터·저장·추가 검증

## 조건의 단일 기준

지역 목록은 ‘기존 지역 ID / 세계 / 거점 입구 / 표시·해금 조건 / 입장 전제 / 재방문 규칙 / 안전 귀환점’을 참조한다. 퀘스트 해금·지역 완료·보고·일시적 입장 가능 여부를 분리한다. 영구 해금은 기록하되 현재 진입 가능 여부는 목록을 열 때와 입장 직전에 다시 평가한다. UI 잠김과 실제 입장이 같은 판정 결과를 사용한다.

선택은 상태 변경이 아니다. 입장 확인 시 세계·입구 접근·해금·선행 사건을 다시 검사하고 중복 요청을 막는다. 로딩·아트 준비가 성공한 뒤 지역 이동을 확정한다. 실패하면 기존 위치와 기록을 유지하고 같은 팝업에서 재시도한다. 입장만으로 보고·장 완료·경험치·보급을 지급하지 않는다.

## 저장 이행과 되돌아오기

기존 던전의 지역 ID·클리어·구조·보고·해금 기록을 유지한다. 던전 안에서 저장한 기록은 유효하면 그 진행으로 이어지며 모두 거점으로 보내지 않는다. 오래된 포털 좌표·목표 핀은 ‘통합 입구 + 목적지 ID’로 이관한다. 복원 위치가 유효하지 않을 때만 원래 세계의 안전 지점으로 보정하고 이유를 알린다. 사건·성장·보상은 초기화하지 않는다.

재방문은 기존 난도·보상 정책을 그대로 따르며 선택 창을 열었다고 적을 자동 강화하거나 1회 보상을 다시 주지 않는다. 목록의 마지막 선택은 편의 설정이며 해금 근거로 쓰지 않는다. 보관판에는 신규 입구·명칭·사운드 정책을 섞지 않는다.
