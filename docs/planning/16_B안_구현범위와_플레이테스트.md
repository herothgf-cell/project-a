## 확정과 검증안을 구분

**사용자 확정:** D-024 B, D-025 A, D-026 A, 기본 1~9성과 무공별 예외, 24수 초식별 성취, 현실 개별 성취/세계별 투자, 일반 본편·경지, 강한 기연, 영구 투자.

**이번 구현 검증안:** 기본기 유효 수동 타격 4회마다 1성(최대 32회/9성), 성마다 해당 기술 피해 +2%. 매화노방/매화접무는 기존 moon/storm 동작을 재사용하며 0/8/16회 입문/활용/숙련(+0/2/4%)이다. 이 효과·선행은 무협 원전의 정설이 아니다. 현실 기본기는 독립 기록이다. 기존 비전 개별 기록은 최대 30을 그대로 보존하고 4/8/12/15/19/23/27/30에서 2~9성, 해당 기술의 직접 피해를 성마다 +1%(최대 8%)로 검증한다. 비공격 행동의 별도 방어/기동 성취 효과는 후속이다. 임시 시험·비교·가짜 적·허공·자동 연타는 새 개별 성취를 지급하지 않는다. 동일 적/기술은 최대 3회 기록한다.

후속 비전 수련은 핵심 실제 대응 1회 → 선택 R 실습 → R의 실제 명중 1회 → 선택 F 실습을 검증한다. 기존 숙련·R/F 체득 이력은 감소시키지 않으며 기존 계열 숙련을 새 개별 기록으로 환산하지 않는다.

## 플레이 순서

1. 새 게임 → 인트로 완료/건너뛰기 → 청운촌 백련 → **화산 전수자**. 무공/스킬에서 기본 검로와 매화노방 확인.
2. **기본기 실습** 또는 죽림에서 검격을 맞히고 붉은 예고 안에서 회피. 죽림 두목을 제압한 뒤 화산 전수자 → 백련. 승리 후 동작이 부족하면 실습만 보충.
3. 현실 서린 → 균열 위협 제압 → **도겸 · 고립 작업자 귀환** → 서린 보고. 초동 대응 역할 확인.
4. 기존 2장 폐사·항만 → 통로 방어·철수 → 서린 → 백련 → **화산 전수자** 일반 재수련. 비경을 건너뛰고 서린 → 경계의 심장: 호위/두 매듭/보스 → 보고.
5. 청운 약방 → 귀환로 위협/권양기 → 서린/현실 부두 → 보고 → 청운촌 연화 → 서린에게 장부 전달 → 관측소 일반 제압/보고.
6. 6장 장치 점검 → 백련 → 현장 위협 제압 → **도겸 · 공급 연결 차단** → 서린. 7장은 준비 선택 후 각 현장 제압과 **공동 대응 상황 확인**, 현실 결과를 백련에게 보고.
7. 8~10장은 목표 안내에 따라 운송·공급·대피·감독관·양쪽 후일담 완료. 기연 소유가 없어도 진행되는지 확인. 첫 경지는 무림 검술 숙련 8/두 세계 실전/3장 보고 후 별도 시련.
8. 이후 선택적으로 비경에서 파문 시험→영구 체득. 실제 전장에서 핵심 대응→청운촌 **선택 비전 수련**에서 핵심+후속 적중. 다시 실제 전장에서 R 적중→선택 수련에서 핵심+R+F 적중.
9. 장마다 저장/재접속. 양세계 성취가 따로 오르는지, 완료 장과 보상이 유지되는지, 투자 초기화가 없는지 확인. 실제 키는 현재 입력 설정/스킬 버튼을 따른다(기본 핵심 E, 후속 R, 오의 F).
