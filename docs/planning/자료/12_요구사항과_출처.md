## 근거와 한계

현재 구현 근거는 main `f5a5a3b`, package v0.15.0, murim 장면/진행/성장/편성/알림 모델과 기존 저장·공명 코드다. 과거 테스트 결과는 당시 DOC-18 기록이며 이번 게임 재실행 증거가 아니다.

원본 FigJam 카드, 사용자 대화, Word·TXT 자료와 외부 무공 자료의 과거 접근 상태는 보관 추적 문서에 남긴다. 저장소에 없는 Word·ZIP을 새로 업로드했다고 쓰거나 가짜 다운로드 링크를 만들지 않는다. 이번에는 외부 참고 페이지와 MindMap을 재조사·동기화하지 않았다.

최신 목표와 현재 코드가 다르면 [로드맵](../개발방향/10_개발로드맵과_검증기준.md)에 차이를 남긴다. 문서 분류로 보류 항목을 새 확정 사항으로 바꾸지 않는다.
