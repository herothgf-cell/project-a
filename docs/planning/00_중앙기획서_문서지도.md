## 1. 게임의 중심 약속

> [사용자 방향] 노력으로 성장하는 기본 RPG 위에서, 일부만 얻는 강한 기연으로 나만의 주인공 서사를 만든다.

특별함을 모든 유저에게 똑같이 배분하거나 외형 차이로만 축소하지 않는다. 고유 능력·무공·칭호·아이템·성장 가속은 실제 격차를 만든다. 동시에 기연이 없는 유저도 전투·수련·기본 무공·장비·평가로 성장하고 본편을 진행할 수 있어야 한다. 이 분리는 **D-007에서 승인**됐다.

이 중앙 문서는 상세 기획을 대체하는 짧은 요약본이 아니다. 콘텐츠별 기준 문서를 찾고, 결정 상태와 충돌을 관리하는 시작점이다. 상세 규칙은 아래 담당 문서에서 갱신한다.

## 3. 링크와 경로

온라인에서는 [GitHub 기획 폴더](https://github.com/herothgf-cell/project-a/tree/main/docs/planning)를 시작점으로 사용한다. 상세 링크는 같은 폴더의 실제 `.md` 파일을 가리킨다. 로컬에서는 `docs/planning/` 전체를 받은 뒤 중앙 문서를 연다. 중앙 파일만 다운로드하거나 Word v1.0만 열면 상세 파일이 없거나 Markdown 연결 프로그램이 없어 열리지 않을 수 있다.

파일 이름과 문서 ID는 유지하고 최신 내용은 같은 파일에서 갱신한다. GitHub의 파일 History에서 이전 내용을 확인한다. 버전마다 복사 폴더를 계속 만드는 방식은 사용하지 않는다. Word는 필요할 때 현재 Markdown에서 내보내는 열람본이며, 기존 Word v1.0은 과거 기록이다.

## 5. 이번에 합의된 핵심

**세계와 서비스.** 양세계 왕복을 중심에 둔다. 회귀·전생은 현재 기본안에서 제외하되 인물과 사건은 유기적으로 재검토한다(D-001). 현재는 싱글 재미 검증, 장기는 MMO 지향이다(D-002). PvE·협동을 우선 검증하고 PvP 규칙은 나중에 정한다(D-004). 이 결정은 당장 네트워크를 개발하라는 뜻이 아니다.

**기연과 일반 성장.** 기연 없는 유저도 일반 수련으로 본편·경지를 진행한다(D-007). 특별한 기연은 실제로 더 강한 힘과 독자 해법을 준다. 화면의 퀘스트 표기는 현재 **[유일] 한 종류**로 통합한다(D-005). 실제 서버 독점 범위는 후속 미정이며 [유일] 배지로 서버 유일 구현을 주장하지 않는다.

**첫 검증 범위.** 화산 일반 계열 1개+기연 1개를 우선한다(D-014). 첫 기연은 파문 중심으로 설계해 본다(D-006). 파문의 완성 사건·수치·최종 보상 형태는 검증안이다. 후속 기연 후보는 DOC-13에 두되 전부 동시에 구현하지 않는다.

**세계 정체성.** 현실은 현대 생활권+헌터+마법·성력/마력·유물+악마·괴물, 과한 SF는 제거한다(D-008). 새 아트 대량 제작은 보류한다. 무림은 실명 문파를 사용하고(D-009), 주 문파 1개+제한적 외부 전수+기연 비전을 허용한다(D-013). 백련 소속과 개별 무공의 실제 선행 계보는 별도 검토다.

**영구 성장.** 스킬 초기화 금지, 스탯도 확정 후 초기화 금지로 성장 정책을 재설계한다(D-016). 현행의 ‘스킬 초기화 가능’을 목표 규칙으로 유지하지 않는다. 무공 성취도·투자/수련 공식·기존 저장 변환은 구현 테스트 후 확정한다(D-012).

**에너지와 상한.** 마기·성력은 초기 운용을 분리하고 혼합·공존은 별도 기연으로 연다(D-011). 기연 전 잠재 보유 범위와 데이터 표현은 남아 있다. 화경/S는 설정 상한이고 10장 완료에 최고 등급을 강제하지 않는다(D-015).

## 6. D-007을 구체적으로 이해하기

같은 위험 현장에 두 명이 도전한다고 가정한다.

| 항목 | 일반 성장 플레이어 | 파문 기연 플레이어 |
|---|---|---|
| 성장 | 기본 검법·심법·수련·장비 | 동일한 기본 성장에 희귀 파문 추가 |
| 압력 대응 | 회피·엄폐·타이밍 공격·일반 안정화 장치 | 충격을 받아 반격/흡수막으로 전환 |
| 결과 | 더 긴 전투로도 본편 해결 가능 | 빠른 제압·다른 해법·추가 성과 가능 |
| 경지 | 일반 수련과 실전 증명으로 돌파 가능 | 기연 운용도 실전 증명의 한 방법 |
| 받지 않는 것 | 파문이나 같은 성능의 보상을 자동 지급하지 않음 | 일반 유저와 같아지도록 강함을 자동 삭제하지 않음 |

핵심은 **‘기연이 있으면 유리하다’는 유지하고, ‘기연이 없으면 기본 성장 자체가 불가능하다’는 제거**하는 것이다. 기연 전용 수련·숨은 분기·고유 보상은 남아도 된다. 본편·기본 경지·일반 RPG가 그 소유권에 묶이지 않으면 된다.
