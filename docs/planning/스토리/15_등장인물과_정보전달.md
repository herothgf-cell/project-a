## 신규 여정의 인물

| 인물 | 실제 역할과 등장 시점 | 아는 정보·미정 경계 |
|---|---|---|
| 윤서 | 현실 E급 헌터. 백련 구조, 화산행 길 확보, 무림 성장·첫 귀환의 주체 | 직접 겪은 사건을 세계 사이에 전달. 혈통·전생·회귀 미채택 |
| 백련 | 천흔·마교 활동 조사 중 부상. 삼재검법 응급 전수, 화산 치료 뒤 정식 제자 제안·매화 제1초식 전수·후속 초식 수련 안내 | 조사한 위험과 직접 본 윤서의 행동을 앎. 화산 직위·개인 과거·추적자 소속 미확정 |
| 서린 | 현실 출발 임무 지시와 첫 귀환 재회 | 무림 사건은 윤서가 전달하기 전 모름. 초반 반복 보고 NPC로 배치하지 않음 |
| 남궁의 여행자 | 신규 화산행 등장 제외 | 개인 이름·항렬·본편 동료 가입 미정 |
| 무당의 여행자 | 계곡 돌파 뒤 화산으로 가는 길만 안내, 전수 없음 | 무당 전체 계보 전수 또는 정식 가입으로 확대하지 않음 |
| 아미의 여행자 | 신규 화산행 등장 제외 | 문파 전수와 주 소속을 구분 |
| 화산의 의원 | 백련 치료 장면 속 역할 | 별도 상시 NPC·의술 시스템·개인 서사 미구현 |
| 추적자·길목 우두머리 | 초반 위기와 화산행 전투 | 명칭만으로 전원 마교/흑조회 소속이라고 단정하지 않음 |
| 천흔 수문장 | 첫 귀환을 가로막는 최종 위협 | 정체·개인 전기·세계 전체의 최종 악역 여부 미정 |

인물은 필요한 사건 장면에서 만난다. 성장·입장 메뉴만 여는 NPC를 추가하지 않는다. 백련이 모든 전투를 대신하는 동행 AI는 없으며 동행은 대사와 사건으로 표현한다. 현 문파 여행자는 공통 초상 표현을 재사용하므로 독립 초상 제작 완료로 보고하지 않는다.

## 대사·관계의 계약

지식 출처는 직접 목격·대면 전달·기록 확인으로 구분한다. 추정은 추정으로 말한다. 다른 세계의 사실을 보고받기 전에 확정적으로 말하지 않는다. 사건으로 생긴 신뢰를 임의의 호감도 수치·연애·영구 충성으로 바꾸지 않는다.

제자 거절을 잘못된 선택으로 취급하거나 귀환 약속을 취소하지 않는다. 기연이 없는 윤서의 일반 성장을 무가치하게 평가하지 않는다. 완료된 사건을 회상하거나 재접속해도 학습권·보상을 중복 지급하지 않는다.

기능 NPC를 없앤다는 것은 등장인물을 없애는 뜻이 아니다. 사건에서 위험·해결·배움·다음 목적지 중 무엇을 바꾸는지가 역할의 기준이다.

## 이전 인물과 후속 설정

신규 후속 후보는 [DOC-25](25_첫귀환이후_왕복과_레이드_검토안.md)에 정리했다. 서린은 귀환 직후 안전을 확인하고 윤서의 보고 뒤에만 무림 경험을 안다. 지하역의 관측 정보로 임무를 설명하되 아직 보지 않은 보스 패턴을 전부 알고 말하지 않는다. 반복 공략마다 같은 보고를 강제하지 않는다. 백련의 개인 사제 관계는 유지하고 문파 운영으로 확대하지 않는다.

연화, 도겸, 흑조 감독관, 청운 약방·현실 보급 담당, 별도 화산 전수자, 모의 여정 발언자는 이전 캠페인 기록에 보존한다. 이들의 3~10장 역할을 신규 1~2장에 자동 삽입하지 않는다. 기존 저장의 인물과 진행은 삭제하지 않는다.
