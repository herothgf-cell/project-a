# 25. 첫 귀환 이후 — 왕복·레이드·평가 진행

## 1. 연결 범위

현재 신규 게임이 첫 귀환에서 끝난다는 구현 사실은 유지한다. 이 문서는 그 뒤를 새로 설계한 후보이며 보관된 3~10장 사건을 자동 복원하지 않는다. 백련의 직위·윤서의 전생·추적자 정체·마기/성력 혼합을 새로 확정하지 않는다.

사용자 확인(D-042): 짧은 안정화 사건 후 비전투 거점 사이에서 왕복을 개방한다. 첫 레이드 완료를 왕복의 필수 조건으로 하지 않는다. 따라서 첫 현실 기술을 배우기 위한 무림 숙련이 부족해도 레이드 전 선택 수련이 가능하고, 일반 스킬로 바로 레이드에 가는 선택도 남는다.

인물은 본 것과 보고받은 것을 구분한다. 서린은 윤서가 이야기하기 전 백련·화산·매화검법을 알지 못한다. 시스템 용어·정확한 비용은 대사가 아니라 별도 성장/임무 안내로 전달한다.

## 2. 전체 진행표

| 단계 | 상황과 플레이어 행동 | 시스템 결과 | 선택/필수 |
|---|---|---|---|
| C1 귀환 확인 | 서린과 재회, 부상 상태와 실종 중 경험을 짧게 전달 | 일반 현실 기술/현실 스탯 확인, 무림 성취 정산 | 최초 1회 이야기 |
| C2 경계석 안정화 | 외곽 안전을 확인하고 경계석의 지속 반응을 관찰 | 비전투 거점 왕복 개방, 출발/도착 상태 안내 | 최초 1회, 추가 보스 요구 없음 |
| C3 준비 선택 | 현실 기본 기술 확인, 연결 학습 또는 무림 수련 선택 | 2슬롯 편성, 획득 조건/재화 확인 | 성장·학습·무림 방문은 선택 |
| C4 집수정 임무 | 잔류 신호가 집수정으로 확산한다는 보고를 듣고 출발 | 대표 레이드 입장, 첫 목적 안내 | 다음 본편 목표 |
| C5 정찰·보스 | 전장의 지지체와 소환체를 관찰하고 갑각수 토벌 | 공략 보상·기술 숙련·재도전 기록 | 일반 경로 완주 가능 |
| C6 정산·평가 | 확보한 기록으로 위험 완화를 확인, 자신의 변화 확인 | 반복 토벌·성장·평가 안내 | 보고는 최초 1회, 반복마다 NPC 왕복 불필요 |
| C7 이후 선택 | 현실 반복/변이, 무림 수련/토벌, 새 학습 중 목표 선택 | 플레이어가 다음 성장 경로 결정 | 특정 세계 방문을 매 회차 강제하지 않음 |

## 3. 왕복 규칙

- D-047: 최초 개인 제자 제안을 거절했어도 첫 귀환·안정화 후 백련을 찾아 다시 수락할 수 있다. 기존 거절 사건과 귀환 기록을 지우지 않고 새로운 전수 사건으로 이어진다. 기존 수락자는 중복 학습·보상을 받지 않는다. 재방문 동선과 대사는 검토안이며 문파 가입·평판·의무를 추가하지 않는다.

- 연결 지점은 현실 지하역 외곽 통제 구역과 무림 천흔 외곽 안전 지점이다. 화산 치료실과 직접 연결되는 새 포탈을 임의로 만들지 않는다.
- D-052: 첫 귀환 후 천흔과 화산 사이의 이미 확보한 길은 안전 이동으로 생략한다. 재전투는 선택 토벌로 분리하며 수련·재전수를 위해 같은 길의 전투를 강제하지 않는다. 미확보 지역을 건너뛰는 규칙이나 진행 중 전투에서 탈출하는 기능은 아니다. 세계 이동 지점은 그대로 유지한다.
- 출발/도착 양쪽이 안전할 때만 전환한다. 진행 중 레이드·시련·수련은 완료하거나 철수한 뒤 이동한다.
- 왕복은 무료인 후보이며 에너지/입장권 소비를 새로 만들지 않는다. 재료를 세계 간 환전하지 않는다.
- 다른 세계에서 확보한 성취와 개별 투자는 남는다. 왕복 자체는 보상 사건이 아니므로 같은 성취를 반복 정산하지 않는다.
- 활동 중인 임무와 전투 자원을 가지고 왕복하며 무료 회복하는 경로는 허용하지 않는다. 거점의 일반 회복과 새 회차 시작은 별도이며 이전 보스전은 이어지지 않는다.
- 안정화는 윤서의 기존 연결 반응이 재현 가능하다는 관찰이다. 모든 사람이 이동 가능하다거나 세상의 균열이 영구 안정됐다는 결론은 내리지 않는다.
- 천흔 접근이 처음 어려웠던 이유는 위험과 수문장이다. 수문장 제압 후 통로를 확보했고, 귀환 후 안전한 재현을 확인했다는 인과관계를 설명한다.
- 현실/무림 시간 배율과 접속하지 않은 동안의 사건 진행은 이번에 확정하지 않는다. 성장 메뉴를 보느라 필수 사건이 실패하는 실시간 압박은 넣지 않는다.

## 4. 핵심 장면 초안

### C1 — 먼저 살아 돌아온 것을 확인

서린은 경계석 옆으로 넘어온 윤서를 붙잡는다. 회수 장비는 흙에 젖어 있고, 팔의 붕대는 출발 때 없던 것이다. 윤서는 검을 내려놓고 숨을 고른다.

서린: “신호가 끊긴 뒤로 안쪽을 계속 확인했어. 혼자 움직일 수 있겠어?”

윤서: “걸을 수 있어. 돌에 손을 댔더니 다른 곳으로 넘어갔어. 다친 사람을 데려다주고, 돌아오는 길을 찾았어.”

서린: “다른 곳이라는 건 나중에 차근차근 듣자. 먼저 상처부터 보자.”

안전이 확보된 뒤 윤서가 백련과 무공을 짧게 설명한다. 이후 성장 화면에서 실제로 달성한 성취와 정산 재료만 표시한다. 매화 미습득 플레이어에게 매화 기술을 사용한 대사를 재생하지 않는다.

### C2 — 돌아가는 길이 남았는지 확인

장비를 정리하던 윤서가 멈춘다. 경계석의 금이 귀환 직전과 같은 간격으로 희미하게 밝아진다. 서린은 통제선을 뒤로 물리고 주변에 움직이는 위협이 없는지 확인한다.

윤서: “넘어오기 직전에도 저렇게 반응했어. 반대편 길을 막던 것은 치웠고.”

서린: “이번에는 무작정 들어가지 마. 여기서 반응이 이어지는지부터 확인하자.”

짧은 확인 행동으로 출발 지점과 반대편 안전 지점이 연결되어 있음을 관찰한다. 모든 세계의 비밀을 설명하지 않고 이번 통로만 왕복할 수 있다는 사실을 알린다. 확인을 위한 의무 토벌이나 장시간 재료 수집은 추가하지 않는다.

### C3 — 기술과 준비를 선택

현실 훈련 구역에서 윤서는 기존 집중 타격과 연속 타격을 확인한다. 매화 성취가 있는 경우 연결 가능한 검격을 성장 화면에서 확인할 수 있다.

서린: “전에 쓰던 동작도 먼저 확인해. 몸이 괜찮다고 해서 낯선 힘까지 바로 익숙해지는 건 아니니까.”

윤서: “익숙한 것부터 준비할게. 넘어가서 더 배워올 수도 있고.”

연결 기술의 시연은 학습 전 체험으로 명시하며 실전 소유·영구 숙련을 주지 않는다. 실제 기술 습득은 각인과 결정을 소비하는 별도 확인이다. 플레이어는 기본 기술로 출발하거나 무림의 공개 수련 조건을 먼저 수행할 수 있다.

### C4 — 레이드에 들어갈 이유

서린이 지하역 도면을 펼친다. 외곽 회수 구역은 조용해졌지만 배수 구역의 신호가 커지고 있다. 역무 통로 쪽은 통제되어 있고, 집수정에서 올라오는 소리 때문에 작업을 재개할 수 없다.

서린: “외곽은 확보했는데 아래쪽에서 다시 움직임이 잡혀. 우선 통로를 확인하고, 핵이 있으면 억제해야 해.”

윤서: “장비 회수 때는 안 들어갔던 곳이네. 돌아올 길부터 확인하면서 갈게.”

도면에는 통로·집수정·퇴로만 표시한다. 아직 직접 보지 않은 보스 패턴을 서린이 모두 알고 설명하지 않는다. 실제 정찰에서 지지체와 적의 집결을 보여주고 보스전에서 활용하게 한다.

### C6 — 이겼지만 반복 목표가 남음

핵의 빛이 약해지고 지하역의 진동이 멎는다. 윤서는 현장 기록을 전송한다. 서린은 외곽 장비의 수치가 내려간 것을 확인한다.

서린: “위로 번지던 신호는 줄었어. 다만 잔류 반응이 남아 있어. 핵이 다시 모이는지는 계속 확인해야 해.”

윤서: “다음에는 움직임을 알 테니 더 준비해서 들어갈 수 있겠어.”

새 기술을 쓴 경우에는 관찰된 변화만 한 줄 덧붙인다. 일반 기술만 썼다면 준비와 대응을 인정한다. 기연/매화 미획득을 실패한 선택처럼 평가하지 않는다. 반복 공략에서는 이 전체 대사를 다시 요구하지 않고 달라진 임무 조건만 전달한다.

## 5. 목표와 화면 정보

| 시점 | 플레이어가 이해해야 할 것 | 보여줄 정보 |
|---|---|---|
| 귀환 | 왜 안전 확인부터 하는가 | 부상·귀환 위치·서린의 관찰 |
| 안정화 | 언제 어디서 다시 오갈 수 있는가 | 안전 거점 두 곳, 진행 중 전투 전환 불가 |
| 학습 | 배운 무공이 현실에 무엇을 여는가 | 자격/비용/잔량/사용 예시를 별도 표시 |
| 레이드 입장 | 왜 들어가고 무엇을 끝내야 하는가 | 집수정 확산 억제, 일반 기술 공략 가능 |
| 보스 패턴 | 무엇을 보고 어떻게 대응하는가 | 모양/동작/소리 전조, 실제 핵 노출 |
| 정산 | 무엇이 늘고 무엇을 선택할 수 있는가 | 최초/반복 보상, 숙련, 강화·수련 목표 |

현재 지도 위치를 유지하며 대사와 이미지를 함께 보여주는 기존 방향을 유지한다. 설명을 늘리더라도 한 화면에 모든 세계관과 성장 수치를 몰아넣지 않는다. 인물의 행동→대사→플레이 결과로 이어지고 기능 설명은 메뉴에 남긴다.

## 6. 전투력·헌터 등급·랭킹 — 예상과 공식 기록 분리

실제 유저 랭킹이 아닌 세계관 속 헌터 명부를 먼저 기획한다. 가짜 접속자 수나 실시간 유저 경쟁처럼 표현하지 않는다. 공식 E급과 무림 경지는 별개이며 첫 레이드 완료로 자동 D급·새 경지를 지급하지 않는다.

사용자 확정(D-045): 예상 전투력은 성장·편성 변경 즉시 표시하고, 공식 전투력과 순위는 협회 재측정 완료 때 갱신한다. 실제 게임에는 미구현이다.

| 표시 | 갱신 시점 | 의미 |
|---|---|---|
| 현재 예상 전투력 | 현실 능력·숙련·강화·편성 변경 즉시 | 지금 준비한 상태의 평가 예상치 |
| 공식 전투력·순위 | 협회 재측정 완료 | 마지막 공식 평가에 등록된 기록 |
| 마지막 측정 정보 | 공식 기록과 함께 갱신 | 측정 시점·당시 편성·평가 기준 버전 |

세부 운영은 다음 검토안으로 둔다. 현재 예상과 공식 기록을 나란히 보여주고, 상태가 달라지면 ‘재측정 전’ 표시를 붙인다. 변경된 편성을 과거 공식 기록의 근거처럼 표시하지 않는다. 재측정은 당시 능력·편성·평가 기준을 함께 저장하며, 같은 조건에서 반복해도 점수가 누적되거나 성장 보상이 발생하지 않는다. 공식 기록은 최고점 보관이 아닌 최근 측정 결과로 갱신하는 안이며 최고 기록이 필요하면 별도 표시한다. 같은 버전의 명부를 기준으로 순위를 비교하고 평가 기준 변경 시 과거 점수와 새 점수를 직접 혼합하지 않는다. 재측정 비용·소요 시간·동점 처리·명부 변동 규칙은 추가 검토 대상으로 남긴다.

공통 산정 후보는 현재 현실 능력과 편성 2슬롯을 대상으로 한다. 미편성 기술·미소비 재료·무림 원시 스탯은 더하지 않는다. 임시 전투 버프와 일회성 회복도 제외한다. 평가 프로필은 다음 세 항목을 나란히 제공한다.

- 공격: 고정된 표준 단일 대상과 소수 대상에서의 기대 피해. 치명타 확률 등의 평균값을 사용해 평가 운을 줄인다.
- 생존: 최대 생명과 해당 편성으로 실제 쓸 수 있는 방어/회피 능력. 무제한 회피 성공을 가정하지 않는다.
- 지속: 정해진 전투 시간 동안 마력 소비/회복을 고려한 유지 능력. 같은 자원 절약 효과를 피해와 별도로 이중 가산하지 않는다.

총 전투력은 동일 버전의 표준 평가 기준으로 합산하는 후보이며 정확한 가중치는 아직 정하지 않는다. 레이드 클리어 시간·피격·최고 난이도 기록은 별도 공략 기록으로 표시한다. 랭킹 수치가 특정 레이드 공략 능력을 보장하지 않으며 첫 레이드의 강제 입장 문턱도 아니다.

## 7. 다음 작업과 의존성

이번에 레이드, 일반/매화 연결 활용, 완료 숙련, 반복 보상, 왕복과 첫 귀환 장면, 랭킹의 역할을 함께 작성했다. 각각을 별도 대화가 끝날 때까지 방치하지 않고 서로 참조한다.

남은 검토는 새 콘텐츠를 무조건 늘리는 작업이 아니다. (1) 패턴/스킬 역할과 투입량을 사용자가 검토, (2) 대표 공략 시간을 기준으로 수치 조정, (3) 기존 저장 이행은 실제 개발 전에 별도 설계, (4) 두 번째 무공 추가 시 각인 공급과 선택 의미 재검토다. 실제 플레이 검증 없이 재미·균형·공정성이 입증됐다고 쓰지 않는다.
