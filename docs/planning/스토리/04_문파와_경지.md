## 현재 전수 구조

백련이 삼재검법 기초를 응급 전수한다. 공통 기초 후 검술·보법·내공에 자유 분산 투자한다. 화산 도착·치료 후 백련이 정식 제자를 제안하고, 수락 시 이십사수매화검법과 제1초식 매화노방을 배운다. 거절해도 귀환할 수 있다. 별도 화산 전수자 소개·인정은 신규 여정의 조건이 아니다(D-028).

정식 제자 선택과 성장 분기 투자는 별개다(D-029). 문파 여행자에게 배웠다고 자동 가입·탈문하지 않는다. 장기 소속 원칙은 주 문파 1개+제한적 외부 전수+기연 비전(D-013)이며 탈문·재입문·비전 상실의 세부 규칙은 미정이다.

## 문파별 현재 범위

| 문파 | 현재 신규 여정 | 후속 심상·검토 범위 |
|---|---|---|
| 화산 | 치료 목적지, 백련의 제자 제안·매화 제1초식 | 나머지 초식·정식 직위·계보 |
| 남궁 | 2번째 길목 뒤 여행자, 검술의 거리 읽기 수련 기회 | 큰 검세·공간 압박 후보 |
| 무당 | 4번째 길목 뒤 여행자, 내공 운기 수련 기회 | 흘림·원형 전환·타이밍 후보 |
| 아미 | 6번째 길목 뒤 여행자, 보법 거리 조절 기회 | 정밀 검·보법·경혈 후보, 치유 전용으로 고정하지 않음 |
| 소림 | 현재 신규 사건·트리 없음 | 권·장·봉·방어 후 대응 후보 |
| 마교 | 백련이 조사하던 활동으로 언급 | 소속·마기·대가·사회 반응의 구체 관계 미정 |

실명 문파 채택은 특정 작품의 인물·계보·효과 전체 채택이 아니다. 삼재검법·매화 초식의 게임 효과를 원전 정설로 쓰지 않는다. [무공 참고자료](../자료/14_무공명과_참고자료.md)를 함께 본다.

## 경지와 성취 구분

세계관 경지 방향은 삼류 → 이류 → 일류 → 절정 → 초절정 → 화경이다. 코드의 기존 경지 체계는 초절정까지이며 화경 전용 시련은 후속이다. 신규 1~2장의 성장 안내에는 경지 돌파·헌터 승급을 한꺼번에 노출하지 않는다.

무공 개별 성취의 기본형은 1~9성이지만 고유 구조를 허용한다. 매화검법은 초식별 성취다. 초식 번호·무공 성취·인물 경지·현실 공식 등급은 다른 값이다. 기본 경지에 기연이나 24초식 전체 습득을 요구하지 않는다.

기존 투자를 문파 이동이나 기연 획득으로 환불하지 않는다. 백련의 화산 내 직위·혈연·배신 과거, 여행자의 이름·항렬은 이번 최신화로 확정하지 않는다.
