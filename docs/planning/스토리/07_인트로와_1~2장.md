## 목표와 진행 계약

현실로 돌아가기 위해 부상한 백련을 돕고 화산에서 치료받게 한 뒤 천흔으로 향한다. 이동·공격·회피를 익히고 스탯·스킬 성장을 선택한다. 이야기 장면은 이미지·화자·대사로 전달하며, 장면 뒤 준비 화면에서 성장 확인 또는 다음 던전 진입을 선택한다.

현실 출발 인트로는 유지한다. 첫 귀환은 **2장 수문장 제압 이후**다. 대사 건너뛰기는 전투 완료나 제자 자동 수락이 아니다. 완료 전장·최초 보상·대화 페이지·제자 선택을 별도로 저장한다.

## 인트로와 튜토리얼

튜토리얼은 현재 3웨이브 2/2/3명 검증안이다. 정밀 회피 타이밍·투자·기연을 완료 조건으로 요구하지 않는다. 적을 먼저 전멸시켰을 때 남은 조작 안내 또는 추가 실습을 통해 진행할 수 있어야 한다.

## 1장 — 화산행 10개 던전

던전 목록에서 장을 고르는 대신, 완료 후 아래 사건을 보고 다음 지역으로 이어간다. 번호는 던전 순서이며 별도 장 번호가 아니다. 이름·대사·배치 세부는 현재 구현된 검증안이다.

| 순서·지역 ID | 던전 | 완료 뒤 사건·배움 |
|---|---|---|
| 1 `murimRoad1` | 추적자의 죽림 | 추적을 떨치고 초소로 향함, 성장 재료 확인 |
| 2 `murimRoad2` | 갈림길 초소 | 수레에 막힌 길을 피해 잔도로 우회 |
| 3 `murimRoad3` | 무너진 잔도 | 백련의 느려진 걸음, 계곡으로 우회 |
| 4 `murimRoad4` | 물안개 계곡 | 무당 여행자의 길 안내 1회, 전수 없이 역참으로 이동 |
| 5 `murimRoad5` | 버려진 역참 | 적을 돌파해 산길 진입로 확보 |
| 6 `murimRoad6` | 산사의 돌계단 | 돌계단 끝에서 협곡의 매복 확인 |
| 7 `murimRoad7` | 매복의 협곡 | 백련의 붕대에 다시 피가 배고 윤서가 앞장섬 |
| 8 `murimRoad8` | 운무 숲길 | 추적을 끊고 화산 능선 확인 |
| 9 `murimRoad9` | 화산 외곽 관문 | 부상자 구조 신호, 마지막 접근로 확보 필요 |
| 10 `murimRoad10` | 화산 산문 | 의원의 치료 장면으로 연결 |

화산행의 타 문파 만남은 무당 여행자의 길 안내 1회다. 만남은 무공 전수·스킬 해금과 연결하지 않는다. 검술·보법·내공은 삼재검법의 공통 성장으로 유지하며 타 문파 고유 트리는 잠금이다. 귀환길에는 별도 문파 만남을 추가하지 않는다.

## 2장 — 치료·선택·천흔 귀환

| 순서·현재 ID | 사건·조건 | 결과 |
|---|---|---|
| `murim-treatment` | 10개 길목 완료 후 화산에서 치료 | 백련 회복, 제자 제안으로 연결 |
| `murim-disciple` | 명시적으로 수락 또는 거절 | 수락: 매화노방 체득 / 거절: 미획득. 둘 다 귀환길 열림 |
| `murim-disciple-accept/decline` | 선택 결과 장면 | 수락: 매화검법 전용 트리 해금, 제1초식 직접 배치 후 후속 초식 수련. 거절: 매화 미습득 상태로 귀환길 진행 |
| `murimReturn1` | 천흔 옛길 적 제압 | 선택 기연과 본래 길 안내 |
| `murimChance` (선택) | 천흔의 메아리 실전 | 천흔 호흡과 최초 재료 보상. 건너뛰어도 본편 진행 |
| `murimReturn2` | 검은 진영 제압 | 수문장 앞 장면 |
| `murimReturn3` | 천흔 수문장 제압 | 첫 현실 귀환 장면 |
| `murim-first-return` | 경계석으로 현실에 돌아와 서린과 재회 | 무림 성장 보존·현실 연계 확인, 이번 신규 여정 종료 |

현재 선택 기연 진입은 귀환길 1 완료 후, 귀환길 2 완료 전이며 건너뛰기를 확정하면 닫힌다. 이것은 현 구현의 체험 배치이며 향후 파문 획득·재발견 정책을 확정한 것이 아니다. D-026은 **이미 얻은 비전의 후속 수련**을 다루므로 이를 기연 자동 지급이나 모든 획득 기회의 영구 개방으로 확대하지 않는다.

## 실패·저장·회상

전장 완료 후 전방 출구에서 다음 장면으로 간다. 현재 위치·배경을 유지하고 그 자리에서 성장·편성 후 다음 맵으로 간다. 출구 최초 완료 시 기존의 생명·기력 회복을 현장에서 제공하며 재료 보상은 중복 지급하지 않는다. 미완료 철수·사망은 준비 상태로 돌아오며 기존 투자·완료·보상은 보존한다. 다음 미완료 던전을 재도전할 수 있다. 회상은 진행·보상을 변경하지 않는다. 이미지나 다음 지역 자산 준비 실패는 재시도를 제공하며 취소 뒤 늦은 응답으로 이동하지 않는다.

v0.14 진행 저장은 완료 기록에 맞는 다음 사건으로 연결한다. 이미 한 튜토리얼·제자 선택·보상을 되돌리지 않는다. 구 캠페인 저장은 원래 경로를 보존하고 강제 편입하지 않는다.
