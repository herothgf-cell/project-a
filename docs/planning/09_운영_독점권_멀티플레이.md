# 09. 운영·독점권·멀티플레이

문서 ID: DOC-09 | 기획 버전: **1.1** | 갱신일: **2026-10-08**

[중앙 문서](00_중앙기획서_문서지도.md) · [결정대장](11_결정대장_확답이필요한질문.md)

## 1. 현재와 장기의 분리

원본 C-05·C-12, K-07·K-10 및 서버 관련 검토를 담당한다.

> [확정 D-002] 현재는 싱글 재미 검증, 장기는 MMO 지향.
> [단계 방침 확정 D-004] PvE·협동 중심으로 검증하고 PvP 정책은 나중에 정한다.
> [후속 보류 D-018~020] 미접속·시즌, 서버 통합, 가상 채팅·소문은 현재 고려할 단계가 아니라는 사용자 답변을 반영한다.

이 문서의 장기 항목은 잊지 않기 위한 기록이지 현재 구현의 필수 체크리스트가 아니다. 서버 소유권·시즌 회수 규칙을 먼저 확정해야 첫 파문 기연을 만들 수 있다는 순서를 사용하지 않는다.

## 2. 의도된 격차와 운영 가설

[사용자 방향] 특정 능력·칭호·아이템의 소유를 극도로 제한하고 실제 성능 격차를 허용한다. 이를 전면적인 동일 성능이나 외형 차이로만 바꾸지 않는다. 모든 플레이어에게 같은 기연이나 같은 위력의 보상을 자동 지급하지 않는다.

‘운영으로 문제를 해결할 수 있다’는 방향은 검토 가설로 유지한다. 다만 운영 결정을 실제로 실행하려면 획득 이력·소유권·재지급·오류 복구를 검증할 수 있어야 한다. 시스템 검증과 운영 판단은 서로 대체하는 관계가 아니다.

| 시스템이 검증할 사실 — 후속 서비스 | 운영이 결정할 정책 — 후속 서비스 |
|---|---|
| 누가 어떤 조건으로 언제 획득했는가 | 몇 명에게 어느 기간 소유를 허용할까 |
| 중복 발급·복제·저장 오류가 있는가 | 잘못 지급됐을 때 어떻게 고지·복구할까 |
| 실제 소유와 발견자 이력이 무엇인가 | 거래·휴면·서버 통합을 어떻게 처리할까 |

현재는 실제 공유 서버가 없어 이런 기능이 구현됐다고 주장하지 않는다. 문서만 갱신하는 작업에 서버 레지스트리나 인증 시스템을 추가하지 않는다.

## 3. 플레이 단계별 검증

**현재 싱글:** 일반 화산 성장과 파문 기연의 차이, 발견감, 현실의 변화, 초기화 없는 선택의 이해를 검증한다. 기연을 경험하기 쉬운 시연 저장은 서비스 확률과 구분한다.

**필요할 때 협동:** 기연 소유자와 일반 성장 캐릭터가 서로 어떤 역할을 하는지 본다. 동료가 할 일이 없어지는지, 기연의 강함이 실제로 느껴지는지, 일반 기여가 남는지를 확인한다. 이 단계의 네트워크 구현 시점은 별도다.

**장기 MMO:** 여러 플레이어의 양세계 접근, 개인/공유 사건, 경제, 유일 소유권을 연결한다. 실제 서비스 규모와 비용·부하·운영 범위를 그때 확인한다.

## 4. [유일] 표기와 실제 소유 범위

> [수정 확정 D-005] 현재 플레이 UI의 특별 퀘스트 분류는 **[유일] 한 종류**로 통합한다.

개인 전용, 계정 한정, 서버 N인, 서버 1인, 전 서버 1인, 서버 최초 기록은 장기적으로 서로 다른 의미를 가질 수 있다. 그러나 이 분류들을 현재 화면에 여러 배지로 모두 노출하는 구안은 사용하지 않는다.

**D-003은 미답변이다.** [유일] 표기가 실제 서버 1인 소유나 영구 기간을 자동 결정하지 않는다. 또한 ‘현재 [유일] 퀘스트 1종’은 분류 통합이고, 최초 콘텐츠를 화산+기연 1개로 제한한 것은 D-014의 별도 결정이다.

싱글 시연 안내에서 범위를 설명하며 실제 서버가 없는데 ‘전 서버 최초 1명 획득’이나 가짜 접속자 수를 사실처럼 표시하지 않는다. 매 전투 화면마다 긴 운영 문구를 띄울 필요는 없다.

## 5. 기연 없는 플레이어의 동기

[확정 D-007] 일반 수련·기술·장비·평가로 기본 성장과 본편이 가능해야 한다. 희귀 소유권을 기본 활동의 입장권으로 쓰지 않는다. 이후 다른 기연을 탐색할 기회는 존재할 수 있지만 모든 유저에게 획득을 보장하지는 않는다.

일반 유저의 목표는 자기 문파의 완성, 전투 숙련, 장비 선택, 현장 역할, 협력·관계 등이 될 수 있다. 기연 소유자의 강함을 없애지 않으면서도 ‘나는 더 할 수 있는 일이 없다’는 상태가 되는지 검증한다.

기연 미획득 자체와 잘못된 안내·버그·불가능한 기본 진행을 구분한다. 기본 루프 실패를 의도된 불공정성이라고 정당화하지 않는다.

## 6. PvP 정책

첫 검증은 PvE·협동 중심이다. PK·경쟁 랭킹·기연 수치 정규화·PvP 전용 보정·전면 무보정 가운데 어느 것도 지금 자동 채택하지 않는다. PvP를 영원히 만들지 않겠다는 결정도 아니다. [D-004]

PvE에서 기연이 강한 경험을 만들었다는 결과가 곧 PvP에서 모든 격차를 그대로 적용해도 된다는 결론은 아니다. 반대로 PvP 우려 때문에 현재 PvE 기연을 동일 성능으로 만들지도 않는다. 두 검증 시점을 분리한다.

## 7. 거래·상실은 보상 종류를 보고 결정

> [보상 확인 후 결정 D-017] 사용자는 실제 유일 보상이 무엇인지 먼저 확인한 뒤 답하기로 했다.

[DOC-13](13_기연배치와_보상후보.md)에 파문 무공의 체득권, 기존 검법의 숨은 진화, 성장 심법, 혼합 체질/심법, 실물 유물의 차이를 정리한다. 비급 원본을 팔 수 있는지와 이미 체득한 무공을 거래할 수 있는지는 같은 질문이 아니다.

현 단계에 거래 기능을 구현하지 않는 것과 장기 정책으로 모든 기연을 영구 귀속하는 것은 다르다. 거래·상속·약탈·파괴·영구 회수는 아직 미정이다. 단일 규칙을 임의 확정하지 않는다.

[확정 D-016] 새 기연을 얻거나 문파를 옮겨 기존 기술·스탯을 초기화하고 환급하는 행위는 허용하지 않는다. 유물 매매 규칙은 이 초기화 금지와 별도 사안이다.

## 8. 후속 보류 대장

| 결정 | 기록해 둘 범위 | 현재 처리 |
|---|---|---|
| D-018 | 미접속·탈퇴·시즌·소유 기간 | 사용자 지정 후속 보류. 자동 회수/리셋 정책 미확정 |
| D-019 | 서버 통합 시 유일 복수 소유·격차 개입 | 사용자 지정 후속 보류. 회수·보상·수치 수정 미확정 |
| D-020 | NPC 소문·모의 채팅·세계 공지 | 사용자 지정 후속 보류. 별도 시스템 구현 없음 |
| D-003 | 실제 독점 범위와 인원·기간 | 미답변. 공유 서버 실증 전 검토로 분리 |

D-018~020을 ‘사용자 답변 미입력’으로 계속 표시하거나 현재 작업의 필수 질문으로 다시 나열하지 않는다. 사용자는 지금 다루지 않겠다는 범위 결정을 했다.

일반 스토리의 NPC 대사는 유지할 수 있지만 이를 가상 채팅/소문 기능 승인으로 해석하지 않는다. 플레이어처럼 보이는 가짜 접속자 메시지를 현재 특별함 연출의 필수 수단으로 추가하지 않는다.

## 9. 실제 공유 서버 단계에서의 검증 메모

이 절은 후속 참고다. 서버가 권위 있는 소유를 검증하고, 획득 이벤트 ID·중복 요청·동시 획득·중단 복구·감사 로그를 설계해야 한다. 로컬 저장 파일만으로 실제 서버 독점을 보장한다고 주장할 수 없다.

동시 청구와 임시 예약·최종 획득, 아이템 현재 소유와 최초 발견 이력, 오류 복구와 플레이어 재분배는 별개다. 서비스 형태를 확정할 때 다시 상세화한다. 이번 작업에서 이 기능을 구현·배포하지 않는다.

## 10. 현재 검증에서 기록할 지표

일반 경로의 실제 완주 가능성, 파문 획득의 발견감, 획득 직후 행동 변화, 상대적인 클리어 효율, 역할·관계 변화, 영구 투자 이해도를 기록한다. 특정 비율로 모든 빌드를 같게 만들겠다는 목표를 선결하지 않는다.

실제 유저 수·서비스 확률·서버 격차 데이터가 없는 상태에서 운영 문제가 해결됐다고 결론 내리지 않는다. 기연 체험이 재미있는지와 장기 MMO에서 건강하게 운영되는지는 서로 다른 검증 결과다.
