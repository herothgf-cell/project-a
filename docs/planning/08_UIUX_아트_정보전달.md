## 1. 목표와 최신 변경

원본 R-02·R-03, G-02, V-07~V-09를 이어받는다. 플레이어가 현재 목표, 성장 이유, 다음 행동, 확정할 선택을 이해하게 한다. ‘더 많은 텍스트’보다 필요한 장소에서 필요한 정보가 보이는 구조를 우선한다.

> [확정 D-005] 현재 특별 퀘스트의 분류·배지는 **[유일]** 하나다.
> [수정 확정 D-016] 스킬 초기화 금지, 스탯도 확정 후 초기화 금지. 확정 전 미리보기와 취소는 영구 재분배와 구분한다.
> [확정 D-008] 현실의 과한 SF 표현 제거. 새 아트의 대량 제작은 보류한다.

현재 v0.12.9의 목적별 화면·실제 스킬 트리·스탯 출처 UI는 활용 가능한 기반이다(SRC-G02/G05). 전체 UI가 없다는 전제로 중복 화면을 만들지 않되, 영구 성장과 세계 구분을 기준으로 개선한다.

## 2. 목적별 메뉴

| 메뉴 | 주요 질문 | 노출 정보 |
|---|---|---|
| 캐릭터 | 지금 얼마나 강하고 무엇에 투자할까? | 세계별 능력치, 현재/예상, 잔량, 출처 |
| 무공·스킬 | 무엇을 배웠고 다음 기술은 무엇인가? | 계열·실제 선행선·성취·효과·장착 |
| 심법·패시브 | 힘을 어떻게 운용할까? | 패시브 효과·선행·영구 투자·이야기 체득 |
| 경지 돌파 | 다음 경지에 무엇이 필요한가? | 일반 수련·실전 증명·시련·확정 |
| 헌터 승급 | 공식 등급은 어떻게 바뀌는가? | 평가 조건·결과 보고·현재 공식 등급 |
| 지역 입구 | 어디로 가고 무엇을 할까? | 한 입구의 대상 지역·임무 선택 |

경지와 공식 등급은 전투력이나 무공 대성과 다른 항목이다. 선택한 세계를 조회한다고 실제 전환·보상 정산·장착 변경이 발생하지 않게 한다.

## 3. 스탯과 스킬의 영구 확정

기본 흐름은 **현재 수치 → 투자 초안 → 예상 변화 → 비용과 영구성 확인 → 확정**이다. 잔량과 실행 버튼이 화면 하단에서 사라지지 않도록 배치한다. 출처 ⓘ에서 획득 사건과 사용처를 확인한다.

확정 전 +/−와 초안 취소는 실제 투자 감소가 아니다. 확정 후 환불·재분배·초기화 버튼은 제공하지 않는다. 스킬·심법도 같은 영구 정책을 따른다. 원본 기획의 ‘스탯은 영구, 스킬은 초기화 가능’ 문구와 초기화 동선은 새 목표에서 삭제한다.

[제안] 확정 직전 안내 예시: **“이 투자는 확정 후 되돌릴 수 없습니다. 공격 +2, 사용 포인트 1.”** 영구성만 경고하고 실제 효과를 숨기지 않는다. 기초 단계에서부터 사용자가 이해할 수 있는 범위의 선택을 제시한다.

연습이나 미리보기는 정식 저장을 바꾸지 않는 상태로 구현한다. 새 기연·문파 이동 때 ‘초기화하고 다시 배워야 한다’는 안내를 내보내지 않는다. 이미 배운 기술의 슬롯 변경은 재분배와 다르며 장착 제약은 별도로 정의한다.

## 4. 트리·성취도·전수의 화면

선행선에는 실제 잠금 조건만 연결한다. 장식상 연결해 놓고 조건이 없는 선을 쓰지 않는다. 선택 노드에는 현재 효과, 다음 효과, 필요한 성취/전수, 비용, 영구 확정 버튼을 표시한다.

성취 UI는 무공별 정의를 따른다(D-021). 초식형은 전수·습득한 초식과 다음 학습 조건을, 단계형은 해당 무공의 고유 단계를 표시한다. 기본 1~9성을 표시하되 초식형 등 예외에 같은 게이지를 강제하지 않는다. 정확한 비용·실전 조건은 D-012 테스트 후 결정할 값이다. 본 문서의 예시를 데이터 확정값으로 사용하지 않는다.

모바일에서는 전체 문파 트리를 아주 작게 축소하기보다 현재 계열과 인접 가지, 선택 상세를 함께 볼 수 있게 한다. 이중 스크롤에 갇히거나 선택할 때마다 강화 버튼이 보이지 않는 문제가 없는지 확인한다. 이야기로 이미 체득한 패시브를 포인트 구매 버튼으로 다시 판매하지 않는다.

## 5. [유일] 퀘스트와 발견감

[수정 확정 D-005] 화면 분류를 [유일]로 통합한다. [개인 전용]/[서버 유일]/[서버 최초]를 동시에 노출하는 구안을 현재 UI에 사용하지 않는다.

| 시점 | 표시 제안 |
|---|---|
| 발견 전 | 현장의 이상 징후, 환경 반응. 유일 보상 정답 경로 없음 |
| 발견 직후 | **[유일] 메아리 없는 바위**와 알아낸 단서 |
| 도전 중 | 현재 실제로 시도할 행동과 철수/재시도 정보 |
| 체득 순간 | 새로 가능해진 행동 하나를 짧게 전달 |
| 이후 | 획득 이력·수련과 실제 효과를 상세 화면에서 확인 |

위 세부 노출 시점은 유지 제안이자 테스트 항목이다. 사용자가 확정한 것은 현재 분류 통합이다. [유일] 배지가 실제 서버 1인 소유 구현을 증명하지 않으므로 싱글 시연 안내에서 범위를 설명하고, 허위 접속자 수·전 서버 획득 공지를 넣지 않는다.

발견 이후 다음 행동을 모르게 방치하는 것이 기연 설계는 아니다. 정답 위치를 미리 공개하지 않는 것과 이미 찾은 도전의 규칙을 설명하는 것을 구분한다.

## 6. 순차 해금과 알림

기본 이동·공격·회피 → 일반 수련 → 첫 기연 보유자의 Q → 현실에서의 변화 → 후속 수련 R → 심법 심화 → 위기 실전 뒤 F의 리듬을 검증한다. 일반 경로는 자기 계열의 성장 안내를 받으며 기연 보유를 강제하는 잠금 메시지를 보지 않는다. [D-007]

레벨업, 신규 기술, 경지, 헌터 승급, 귀환 정산을 하나의 팝업에 몰아넣지 않는다. 전투 중에는 짧은 변화만 알리고 세부 선택은 안전한 상황에서 하게 한다. 읽은 알림과 이미 체득한 기술을 계속 ‘새 소식’으로 반복 표시하지 않는다.

현재 숨긴 관찰 수첩·해석 장착 메뉴를 새로운 설계를 소개한다는 이유로 복원하지 않는다. 필요한 실전 안내와 사건 기록은 해당 목적 화면에서 제공한다. 코드 비교 근거는 SRC-G02다.

## 7. 세계별 성장 비교

무림의 레벨·내력·경지와 현실의 레벨·자원·공식 등급을 분리해 보여준다. 귀환 결과는 ‘같은 캐릭터의 공격력이 합쳐졌다’보다 **원인 성취 → 받은 현실 성장 → 새 기술/현장 역할**이 보이게 한다.

마기·성력 모델은 D-010 미정이므로 영구 스탯 입력란·별도 게이지·속성칸을 모두 한꺼번에 확정하지 않는다. 미개방 계열은 숨기거나 최소 정보만 표시한다. 혼합 기연 전후의 표현은 D-011-A의 소유 의미를 확인한 뒤 정한다.

조회는 읽기 전용이다. 비교 화면을 열고 닫았다고 세계 전환, 공명 결정 지급, 스킬 투자·장착이 발생하지 않도록 한다.

## 8. 아트·모션·음향 방향

| 항목 | 현실 | 무림 |
|---|---|---|
| 공간 | 현대 거리·기지·지하역·항만과 마법적 침식 | 촌락·사찰·산길·문파 수련터 |
| 복장·도구 | 작업복·헌터 장비·유물·부적 | 문파 복식·검·봉·비급 |
| 기술 | 마력막·룬·주문·결계 | 호흡·검로·보법·호신기 |
| 적 | 마수·괴물·악마·계약자 | 무인·산적·진법 위협·마기 운용자 |
| 소리 | 주문·보호막·현장 소음 | 검풍·발디딤·내공·전통 공간의 울림 |

이는 세부 음원·색상·모델의 확정 제작 목록이 아니다. 나르실리온풍 같은 이전 아트 선호는 후보 검토에 참고하되 과한 SF를 남기는 근거로 사용하지 않는다.

[확정 D-008] 대량 아트 제작은 보류한다. 먼저 한 지역·한 몬스터·파문의 양세계 효과 같은 소수 비교안으로 정체성을 확인한다. 기존 아트 자산을 삭제하거나 새 모델을 일괄 구매·생성하는 작업을 이번 문서 갱신에 포함하지 않는다.

## 9. 입력·길 안내·대화

목표 클릭은 길 안내/진행 정보로 처리하고 배경 공격으로 전달되지 않는다. 여러 포털이 겹치는 대신 한 입구에서 진입 대상을 선택하는 구조를 유지·점검한다. 실제 상호작용 키와 화면 안내가 다르지 않게 한다.

대화는 화자·본문·선택·실행을 구분하고 버튼의 실행/선택/비활성 상태를 명확히 한다. 같은 키를 누른 채 유지한다고 대화 수락이나 영구 투자가 중복 실행되지 않게 한다. UI를 닫거나 문서·세계를 조회하는 것만으로 퀘스트가 진행되지 않는다.

‘청운촌 귀환→환서정 이동→청운촌 귀환’처럼 실제 다음 조건 없이 왕복 안내가 순환하지 않게 한다. 완료된 구조 목표를 계속 표시하거나 멀리 있는 다른 목표를 현재 상호작용보다 우선 표시하지 않는다.

## 10. 기획 검토의 마커

기획 문서와 지도에는 `[확정]`, `[방향 합의]`, `[부분 확정]`, `[검증 후 결정]`, `[질문]`, `[후속 보류]`, `[제안]`, `[현재 코드]`를 사용한다. 색만으로 상태를 전달하지 않고 문구와 결정 ID를 함께 둔다.

[확정]을 구현 완료 아이콘으로 쓰지 않는다. D-018~020은 미응답 독촉 대상이 아니라 사용자 지정 후속 보류다. 마인드맵의 옛 ‘모두 미확정’ 노드는 최신 GitHub 결정대장보다 우선하지 않는다.

## 11. 검수 기준

360×640, 390×844, 데스크톱과 200% 글자 확대에서 목표·확정 버튼·잔량·선행 조건을 읽고 조작할 수 있는지 확인한다. 컨트롤 간 겹침, 과한 가로 스크롤, 이중 스크롤, 대화 중 전투 입력 전파를 점검한다.

초안 취소는 상태를 바꾸지 않고, 영구 확정은 한 번만 적용되며, 확정 후 초기화 요청은 실제 데이터에서 거부되는지 확인한다. [유일] 배지 없이도 기연 체감이 있는지, 기연 없는 플레이어도 올바른 다음 목표를 받는지, 세계별 기술을 구별하는지 확인한다. 이 문서는 테스트 정의이며 실행·통과 보고가 아니다.

## 10. B안 스토리와 인물 안내 [제안]

현재 목표, 해당 인물의 위치, 필요한 증거/미보고 상태를 구분한다. 연화가 구조 전후 두 곳에 동시에 보이지 않게 하고, 이미 완료한 장의 NPC는 회상과 새 수련을 구분한다. 보고 전에는 NPC가 상대 세계의 단서를 확정적으로 말하지 않는다. 실제 표시 키는 액션 ID의 현재 바인딩에서 가져온다. 신규 화산 전수자와 초식별 화면은 기획안이며 구현된 UI가 아니다.
