# 01. 컨셉과 게임 구조

## 1. 소유 범위와 중심 약속

원본 C-01~C-12를 이어받는다. 게임 경험, 일반/특별 성장의 공존, 양세계의 필요성, 서비스 단계가 이 문서의 범위다. 획득 절차는 DOC-02, 공유 소유권은 DOC-09가 담당한다.

> [사용자 방향] 노력하면 성장하는 RPG를 기반으로, 일부 플레이어가 우연한 기회로 특별한 능력·칭호·아이템·빠른 성장을 얻는 먼치킨 경험을 만든다. 모든 유저에게 같은 특별 보상을 보장하지 않는다.

**기본 성장의 약속.** 기연 없이도 전투·수련·기본 무공·일반 장비·평가로 실제 성장하고 본편·경지를 진행할 수 있다. 단순히 입장 버튼만 열리는 것이 아니라 실제로 이길 수 있는 경로가 필요하다. [확정 D-007]

**특별함의 약속.** 기연은 소유권·전투 성능·성장 속도·세력 관계·접근 가능한 선택지에서 실질적 차이를 만든다. 강한 격차를 외형 차이로만 바꾸지 않는다. 모두에게 같은 보상을 주고 실제 공유 서버 유일이라고 주장하지 않는다.

**발견의 약속.** 플레이어가 먼저 이상한 현상과 자기 행동의 관계를 알아차린다. 퀘스트는 발견 이후 도전의 기록·안내다. 발견 전부터 정답 좌표와 유일 보상을 함께 공개하는 메뉴가 아니다. 발견 이후에는 다음 행동을 이해할 수 있게 한다.

**삶의 변화에 대한 약속.** 현실에서 회수 보조가 위험 현장을 맡게 되고, 무림에서 보호받던 객인이 문파·동료에게 영향을 준다. 숫자와 함께 NPC의 요청·역할·대우·현장 배치가 변해야 한다. 반응은 실제 행동·관측·보고가 근거다.

## 2. 두 성장 경로

| 구분 | 일반 성장 | 기연 성장 |
|---|---|---|
| 접근 | 규칙을 알고 노력할 수 있음 | 기회 자체를 모든 유저에게 보장하지 않음 |
| 과정 | 전투·수련 → 기본 계열 → 숙련 → 평가 | 징후 → 발견 → 자격 → 도전 → 체득 |
| 보상 | 레벨·스탯·일반 무공·장비·등급 | 고유 무공·체질·성장 가속·유물·칭호 |
| 실패 | 학습하고 다시 도전 | 기회 상실이나 다른 분기로 이어질 수도 있음 |
| 기본 진행 | 일반 경로만으로 가능해야 함 | 특별한 해법과 더 큰 성과를 얻을 수 있음 |

[확정 D-007] 필수 전투를 일반 경로로도 해결할 수 있게 하되 기연 소유자에게 더 강한 출력·빠른 대응·독자 분기·추가 성과를 허용한다. 두 경로의 효율을 같게 만들지 않는다. 기본 경지에 희귀 소유를 요구하는 조건은 변경 대상이다.

예를 들어 화산 검법을 수련한 일반 플레이어는 보스의 예고를 피하고 틈에 공격한다. 파문을 얻은 플레이어는 충격을 받아 반격에 실어 훨씬 유리하게 싸운다. 일반 유저에게 똑같은 반격을 보상으로 지급하지 않는다. 반대로 파문이 없다는 이유만으로 모든 공격이 무효가 되게 만들지도 않는다.

기연 소유자만 들어가는 비전 수련이나 숨은 이야기는 존재할 수 있다. 이것은 일반 유저가 반드시 밟아야 하는 본편·기본 경지와 구분한다.

## 3. 스토리 장치의 별도 평가

| 방식 | 주는 재미 | 추가 설계 부담 |
|---|---|---|
| 회귀 | 미래 지식으로 기회를 선점 | 시간선·역사 변화·정보 우위의 정합성 |
| 전생·환생 | 숨겨진 재능과 과거 정체성 | 이전 인격·기억·가족 관계의 중심 서사 |
| 양세계 왕복 | 한 세계의 수련이 다른 삶을 변화 | 세계별 성장·정보·시간·소유 경계 |
| 모두 결합 | 장르 장치를 넓게 활용 | 첫 설명 과밀과 특별함의 원인 혼란 |

> [방향 합의 D-001] 양세계 왕복을 중심에 두고 주인공 회귀·전생은 현재 기본안에서 제외한다. 사건·인물·기연은 유기적으로 짜 보면서 다시 검토한다.

‘양세계 유지’는 현재 인트로와 모든 챕터 대사를 확정한 것이 아니다. 컨셉을 흐리는 사건은 과감하게 바꿀 수 있다. 후속 회귀/전생 소재도 자동 채택하지 않는다.

## 4. 양세계 구조를 유지할 조건

무림은 전수·수련·경지·문파 관계가 중심이다. 현실은 현대 생활권의 헌터 역할·스킬·마법·성력/마력·유물·사회적 평가가 중심이다. 배경 색과 기술 이름만 바뀌면 목표를 충족하지 않는다. [D-008]

무림 성취는 현실의 별도 성장 자원과 독립 기술의 원리로 연결한다. 동일 공격력을 그대로 복사하는 메시지를 핵심 보상으로 삼지 않는다. 현실 경험은 무림에서 새 관찰·전술·전수 접근을 열 수 있으나 현행의 역방향 성장 재화 미제공 원칙을 당장 뒤집는 제안은 아니다. 같은 재화를 왕복 정산해 무한히 늘리지 않는다. 구현 근거는 DOC-12 SRC-G02, 상세 목표는 DOC-06을 따른다.

## 5. 싱글 → MMO의 단계

> [확정 D-002] 현재는 싱글 재미 검증. 장기적으로 MMO를 지향한다.

**현재 검증:** 윤서의 개인 서사에서 발견·성장·양세계 연결·현실 역할 변화가 재미있는지 확인한다. 서버 유일 정책을 먼저 완성해야 초반 이야기를 만들 수 있다는 순서를 택하지 않는다.

**협동 검증:** 필요할 때 기연 소유자와 일반 성장 캐릭터의 역할·기여·강함을 비교한다. D-004의 PvE·협동 우선은 이번에 네트워크 시스템을 구현하라는 승인이 아니다.

**장기 MMO:** 여러 플레이어가 두 세계에 접근하는 이유, 개인 이야기와 공유 세계의 사건, 실제 한정 소유권은 별도 설계한다. ‘NPC 사회에서는 극소수인 경계 적합자’ 같은 설정은 후보일 뿐 현재 확정이 아니다.

개인 서사의 ‘주인공만 왕복 가능’과 MMO의 여러 플레이어를 아무 설명 없이 동시에 확정하지 않는다. 이 문제는 없애지 않고 전환 시점의 결정 항목으로 보존한다. 현재 윤서 중심 이야기를 만드는 데 방해가 되지 않도록 범위를 나눈다.

## 6. 프로토타입 검증과 실제 희소성

시연에서 기연을 자주 경험하게 해도 되지만 그것을 실제 서비스 획득 확률로 보고하지 않는다. 기연 체험용 조건을 갖춘 저장, 기연이 없는 일반 경로 저장, 단서가 있어도 놓칠 수 있는 저장을 구분한다.

[확정 D-005] 화면 배지는 현재 **[유일]** 하나로 통합한다. 테스트 설명에 싱글 검증임을 명확히 하고 ‘전 서버 1명’ 같은 검증하지 않은 문구는 덧붙이지 않는다. 여러 배지를 노출하지 않는 결정과 실제 데이터의 소유 범위가 미정이라는 사실은 함께 유지할 수 있다.

검증 질문은 보상 이름을 보지 않고도 발견한 행동을 설명하는지, 기술이 실제로 강해졌는지, 기연을 놓쳐도 다음 수련 목표가 남는지다. 단순 퀘스트 완료율과 따로 관찰한다.

## 7. 최초 제작 범위

[확정 D-014] 화산 일반 계열 1개와 기연 1개를 우선한다. [방향 합의 D-006] 기연은 파문 중심으로 시도한다. 두 계열의 확정된 수치·트리·사건은 아니며 상세 성장 방식은 D-012 테스트 대상이다.

다른 문파와 후속 기연은 설정·인물·후보로 남겨 장기 그림을 확인한다. 후보가 문서에 있다는 이유로 동시에 구현하지 않는다. 대량 아트·새 서버·PvP·경제 전체·시즌은 현 단계에 자동 추가하지 않는다.

## 8. 영구 선택과 재미

[수정 확정 D-016] 스킬과 스탯은 확정 후 초기화하지 않는다. 이는 성장 공식까지 확정됐다는 뜻이 아니라 선택을 되돌려 다시 찍는 기능을 금지하는 정책이다. 잘못된 첫 선택 때문에 초반 콘텐츠를 완전히 막는 설계가 되지 않도록, 기본 유효성·미리보기·연습과 공개 선행 조건을 함께 설계한다.

특별한 기연은 기존 수련을 초기화해서 갈아타게 만드는 것보다, 쌓아 온 기술을 새로운 해법으로 확장하는 방향을 우선 제안한다. 모든 빌드의 위력을 같게 만들 필요는 없지만 기본 진행 가능성은 검증해야 한다.

## 9. 자동 채택하지 않는 것

기연 격차의 전면 제거, 비소유자에게 동등 보상 즉시 배분, PvP 정규화, 시즌 회수, 전 서버 유일, 미접속 회수는 자동 채택하지 않는다. 운영 중심 해결이라는 가설은 남기되 획득 검증·기록·복구 같은 시스템 기능과 운영 결정을 구분한다. D-018~020은 사용자 지정 후속 보류다.

## 10. 검수와 연결

‘기연 없이도 성장하는가 / 실제로 다른 힘을 얻는가 / 획득을 발견으로 기억하는가 / 현실의 역할이 달라지는가 / 영구 선택을 이해하고 확정하는가’를 각각 확인한다. 이 약속을 바꾸는 변경은 DOC-11에 기록한다.
