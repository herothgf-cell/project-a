# 04. 무림 세계 — 문파와 경지


> **v1.3 확정 정정 (2026-10-08):** D-024 B(독립 첫 스승 백련 + 별도 화산 전수자), D-025 A(기본 검로 + 소수 초식 우선), D-026 A(선행 체득·실전 증거로 늦은 후속 수련)를 채택한다. 무공 성취 기본형은 **1~9성**이며 무공 고유 구조를 허용한다. 이십사수매화검법은 초식별 성취다. 현실 스킬도 개별 성취를 가지며 양세계 성취·투자는 별도로 보존한다. 확정 스탯·무공·스킬 투자는 초기화하지 않는다. 새 수치·초식 효과·성취 조건은 **검증안**이다.

## 1. 무림 정체성

원본 M-01~M-12의 담당 문서다. 문파·세가·사제·전수·내공·경지가 플레이와 사건을 만든다. 검을 쓰는 판타지 마을에 무협 명칭만 붙이는 구조에서 벗어난다.

> [부분 확정 D-009] 소림·무당파·화산파·아미파·남궁세가 등 익숙한 실명 문파를 사용한다. 세부 무공명·선행 계보·초식과 백련의 소속까지 확정된 것은 아니다.

실제 역사·무술, 여러 작품에서 쓰이는 장르 관습, 특정 작품의 고유 설정, 이번 게임의 창작 규칙을 구분한다. 문파 이름이 익숙하다는 이유로 특정 작품의 인물·계보·효과를 보편 정설로 단정하지 않는다. 사용자가 제공한 24초식은 DOC-14에 참고 목록으로 보존하며 게임 채택 범위·효과와 분리한다. 이번에 제공받은 참고 링크의 접근 결과와 추가 자료는 DOC-14에 기록한다.

## 2. 청운촌과 첫 스승

[제안] 청운촌은 객인·행상·문파 외문 인물이 만나는 경계 지역이다. 백련은 윤서가 처음 의지하고 수련을 배우는 인물이며, 문파 세계로 들어가는 연결점으로 삼는다. 모든 무공과 희귀 기연을 지급하는 만능 상점 NPC로 두지 않는다.

**백련은 독립적인 첫 스승이다(D-024 B 확정).** 화산 무공 전수는 별도 인물인 화산 전수자가 맡는다. 개인 이름·항렬·구체 과거는 아직 확정하지 않는다.

## 3. 문파별 플레이의 차이

아래 표는 **게임 설계 후보**다. 대표 용어를 특정 작품과 무관한 보편 정설로 인증하는 표가 아니다.

| 문파·세가 | 철학·플레이 제안 | 참고할 명칭·심상 | 반드시 다르게 만들 부분 |
|---|---|---|---|
| 소림 | 견고한 기본기, 버티기, 권·장·봉 | 나한, 금강, 역근의 심상 | 자세·방어 후 대응·내공 운용 |
| 무당파 | 원을 그리며 흘리고 전환 | 태극, 양의, 유연한 검로 | 적의 힘과 타이밍을 이용하는 대응 |
| 화산파 | 정확한 검로와 분화·연계 | 매화, 자하, 검술의 성취 | 기초에서 복합 검법으로 확장되는 과정 |
| 아미파 | 정밀한 검·보법·경혈 운용 | 균형, 절제, 빠른 전환 | 치유 전용으로 제한하지 않는 정밀 전투 |
| 남궁세가 | 넓은 검세·압박·기세 | 창궁무애검법·제왕검형은 검토 후보 | 큰 동작의 위험과 강력한 공간 지배 |
| 마교 | 고출력·대가·특수 운용 | 마기, 비전, 금기 | 힘의 사용 조건과 소속·사회 반응 |

각 문파는 공격력 색만 다른 트리가 아니라 수련 과제, 전수 조건, 전투 리듬, 인간관계에서 차이를 만든다. 화산의 화려한 효과나 무당의 원형 동작을 기능 없이 장식으로만 쓰지 않는다.

## 4. 최초 범위와 계보

> [확정 D-014] 처음 검증할 실제 성장 계열은 **화산 1개+기연 1개**다. 다른 문파는 설정·등장·관계의 후보로 유지한다.

화산 계열의 목표는 ‘기초 검법을 익히고 실제로 수련하여 24수 매화검법에 이른다’는 사용자의 의도다. 아래 연결은 그 의도를 검증하기 위한 창작 구조다.

```text
기초 검로
  └ 화산의 기본 검법
       ├ 보법·거리 수련
       └ 분화·연속 검로
            └ 전수 자격과 실전 증명
                 └ 24수 매화검법
                      └ 초식별 전수·습득·운용·연계 (세부 조건은 검증)
```

‘기초 검로/분화 검로’는 문서의 기능명이며 실제 작품 속 선행 무공의 정식 이름이라고 주장하지 않는다. 정확한 무공명·선행 성수·필요 경지·전수 사건은 DOC-14 조사와 D-012 테스트 뒤 정한다.

24수는 24개의 액티브 버튼을 한꺼번에 지급한다는 뜻이 아니다. 하나의 검법 안에서 초식 변화·연계·타격 패턴을 어떻게 표현할지 검증한다. 기존 단일 무공도 유지하며, 모든 기술을 긴 트리에 억지로 넣지 않는다.

## 5. 소속과 전수 규칙

> [확정 D-013] 주 문파 1개+제한적인 외부 전수+기연 비전.

소속, 전수권, 실제 습득, 성취도, 현재 장착을 별도 상태로 본다. 타문파 무공을 배웠다는 이유만으로 자동으로 두 문파의 정식 구성원이 되지 않는다. 구해 준 인물의 답례, 제한된 합동 수련, 문파가 아닌 개인 비전, 비급 해석 등이 외부 전수의 후보가 된다.

외부 학습 제한은 소속의 의미를 만들기 위한 장치다. 단순히 모든 스킬을 자유 구매하는 구조와 구분하되, 희귀 기연이 기존 문파의 의미를 지워 버리지 않게 한다.

[미정] 탈문·파문·재입문·비전 누설·기술 상실의 세부 규칙은 아직 결정하지 않았다. 사용자에게 승인받지 않은 영구 삭제를 기본값으로 삼지 않는다.

[확정 D-016] 문파를 바꾸거나 새 기연을 얻었다고 기존 기술을 초기화하고 투자 재화를 돌려주지 않는다. 이미 배운 기술의 사용 제한과 습득 이력 삭제/환불은 다른 사안이다. 문파 이동을 금지된 초기화의 우회 기능으로 만들지 않는다.

## 6. 마교·마기·도덕성을 분리

마기 보유, 마교 소속, 악행, 균열을 조작하는 흑조회 협력은 서로 다른 상태다. 마기를 얻었다고 자동으로 악인이 되거나 모든 문파에 적대하지 않는다. 힘의 폭주·수련 위험·사회적 오해는 사건 후보로 설계하되 일괄 도덕 점수로 단정하지 않는다.

[부분 확정 D-011] 마기와 성력은 초기 운용을 분리하고 혼합·공존은 별도 기연으로 가능하게 한다. 혼합 기연 이전에 두 힘을 잠재적으로 보유만 해도 되는지는 D-011-A 확인 항목이다. 자동 정화·자동 삭제·합산은 하지 않는다.

마기 특성은 공격력 항목 하나인지, 내력 운용을 바꾸는 자원인지, 체질·친화인지 D-010에서 아직 결정하지 않았다. 이 미정을 이유로 첫 화산+파문 검증에 여러 에너지 게이지를 먼저 구현하지 않는다.

## 7. 경지 체계

[사용자 방향] 1차 세계관 상한은 **화경**이다. 이번 게임의 경지 순서는 다음을 기준으로 정리한다.

| 경지 | 게임에서 표현할 성장 방향 제안 |
|---|---|
| 삼류 | 기본 자세·체력·무기 운용을 익힘 |
| 이류 | 기본 무공을 안정적으로 운용하고 실제 위협에 대응 |
| 일류 | 주력 계열의 내공·초식·전술을 결합 |
| 절정 | 자기 전투 방식의 강점과 약점을 통제 |
| 초절정 | 복합 위협 속에서도 고도화된 원리를 운용 |
| 화경 | 축적한 무공과 깨달음의 질적 전환을 후속 콘텐츠로 표현 |

이 표는 모든 무협 작품의 공통 공식 분류가 아니다. 세부 의미·전투 수치·돌파 장면은 게임 설계다. 무공 하나의 ‘대성’, 인물 전체의 ‘화경’, 현실 협회의 ‘S등급’은 서로 다른 축이며 자동 1:1 대응하지 않는다.

현재 `advancement.js`에는 삼류~초절정 5단계가 있고 화경은 없다(DOC-12 SRC-G04). 화경을 넣을 때 이름만 추가하지 않고 조건·시련·효과·저장·UI를 함께 설계한다.

> [확정 D-015] 화경/S는 설정 상한이며 10장 본편 완료에 최고 등급을 강제하지 않는다. 정확한 10장 권장 경지와 최고 도달 시점은 테스트 뒤 정한다.

## 8. 일반 돌파와 기연의 관계

[확정 D-007] 일반 수련·실전 대응으로 기본 경지를 돌파할 수 있어야 한다. 현재 첫 이류 조건의 ‘기연 계승·증명’은 새 목표와 다른 구현 지점이다. 단순히 문구만 바꾸지 않고 실제 조건을 일반 수련 증명으로 대체/확장해야 한다.

기연을 가진 무인은 고유한 실전으로 더 강하게 증명하거나 빠르게 성장할 수 있다. 그러나 기본 경지에 오르기 위해 모든 유저가 같은 파문을 획득하도록 만들지 않는다. 비전의 다음 단계에는 해당 비전 소유를 요구해도 되며, 이것을 일반 경지 조건과 혼동하지 않는다.

## 9. 데이터·수련·검수

문파 ID, 주 소속, 전수권 이벤트, 기술 습득, 개별 성취, 실제 수련 증거, 경지 평가를 분리한다. 세력 관계가 바뀌어도 기존 기록이 임의 환산·초기화되지 않게 한다. 정확한 저장 구조는 개발 시 현행 코드와 맞추며 이 문서는 새 필드가 이미 구현됐다는 명세가 아니다.

검수는 화산 일반 경로만으로 성장 가능한지, 이름만 바뀐 기존 기연 트리에 불과하지 않은지, 무공 대성과 경지가 구분되는지, 외부 전수와 소속이 혼동되지 않는지, 혼합 기연이 초기화 기능이 되지 않는지 확인한다.

## 10. 화산 전수와 인물의 분담 [확정 D-024 · B]

백련은 독립 첫 스승으로, 별도 화산 전수자가 화산 계열 전수를 맡는 것으로 확정했다. 장점은 기초 생존·판단과 문파 전수권을 구분하는 것, 비용은 신규 인물 1명과 소개 장면이다. 백련에게 전수권을 함께 부여하는 대안도 DOC-11에 남긴다. 상세는 [DOC-15](15_NPC_등장인물_관계와_장별행동.md).

D-021에 따라 24수는 초식별 성취를 기록한다. 번호는 성수가 아니며 24초식 완성을 10장 입장 조건으로 삼지 않는다. 정확한 전수권·선행·완성 판정은 미정이다.
