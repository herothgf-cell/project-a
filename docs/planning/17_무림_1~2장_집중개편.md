# 17. 무림 1~2장 집중 개편 — v0.14.0

[중앙 문서](00_중앙기획서_문서지도.md) · [결정대장](11_결정대장_확답이필요한질문.md)

## 이번 사용자 확정

- 다른 요소를 제외하고 무림 스탯·스킬 성장과 인트로~2장만 먼저 개편한다.
- 현실에서 무림으로 떨어진 윤서가 부상한 백련을 돕는다. 마교 활동과 천흔을 조사하던 백련을 뒤쫓은 정체불명의 대상 때문에 위기를 맞고, 응급처치로도 약해진 백련이 **삼재검법**의 기초를 급히 전한다. 사용자의 ‘삼재겁법’ 표기는 삼재검법으로 해석했다.
- 이동·공격·회피, 성장과 스탯/스킬 UI를 익힌다. 위험한 천흔 대신 백련 치료를 위해 화산으로 향한다. **10개 무림 던전**을 순차 돌파하며 문파 인물과 만나고 성장 재료를 얻는다.
- **공통 기초 → 검술·보법·내공 자유 분산 투자**. 문파 제자 선택은 별도다(사용자 답변 확정).
- 화산에서 치료 후 백련의 정식 제자 제안을 수락하면 이십사수매화검법과 제1초식, 거절하면 미획득. 어느 쪽도 귀환을 막지 않는다.
- 2장은 성장·선택 기연 기회를 거쳐 천흔의 적대 무리와 보스를 제압하고 첫 현실 귀환. 무림 성취와 현실 성장은 기존 양세계 원칙으로 연결한다.
- 확정 투자 환불/초기화 금지와 기존 성장·완료 이력 보존을 유지한다.

이 범위의 백련 전수와 첫 귀환 시점은 이전 DOC-07/15/D-024의 초반 구성보다 우선한다. 백련의 화산 내 직위·개인 과거는 추가 확정하지 않는다. 3~10장과 현실 트리의 예전 설계는 보관하며 이번 새 여정에는 연결하지 않는다.

## 구현한 플레이 흐름

| 구간 | 실제 행동과 완료 |
|---|---|
| 인트로 | 낯선 하늘→응급 전수→화산행 결심. 건너뛰어도 실전 튜토리얼은 진행 |
| 추적자 습격 | 실제 이동, 기본 검격 명중, 회피 사용, 추적자 제압→출구. 예고 회피 타이밍 성공은 본편의 잠금 조건이 아님 |
| 화산행 1~10 | 추적자의 죽림 / 갈림길 초소 / 무너진 잔도 / 물안개 계곡 / 버려진 역참 / 산사의 돌계단 / 매복의 협곡 / 운무 숲길 / 화산 외곽 관문 / 화산 산문 |
| 만남 | 2번 길목 후 남궁의 여행자(검술), 4번 후 무당의 여행자(내공), 6번 후 아미의 여행자(보법). 야영지에서 대화하면 마지막 분기 노드의 수련 기회 해금 |
| 화산 도착 | 백련과 대화해 치료. 다시 대화해 제자 수락/거절. 선택은 이번 여정에서 확정 |
| 귀환길 | 천흔 옛길→검은 진영→천흔 수문장. 첫 길목 이후 별도 ‘천흔의 메아리’는 선택 기연 실전 |
| 첫 현실 귀환 | 수문장 제압 후 야영지의 천흔으로 이동. 서린에게 돌아온 몸과 공명 재료를 확인하고 이번 범위 종료 |

각 던전은 별도 지역 ID·완료·보상·배치와 사건을 가진다. 지형·캐릭터 아트 및 전투 동작은 기존 자산을 재사용한다. 대량 신규 아트, 화산 전용 건축 장면, 백련 동행 AI는 구현하지 않았다. 백련의 동행은 대사·사건과 야영지 표현이다.

## 성장과 UI — 아래 수치는 검증안

- 단련석: 최초 3개, 화산행 최초 확보마다 2개, 귀환길마다 3개, 선택 기연 4개. 1개로 공격 +2 / 최대 생명 +10 / 최대 기력 +5 중 배분. 레벨 기본 성장도 유지.
- 수련첩: 최초 2개, 화산행/귀환길마다 1개, 선택 기연 2개. 노드당 1개를 확정 투자. 같은 완료를 재보고/재접속/재공략해도 중복 지급하지 않는다.
- 검술: 검로 다듬기(기본 검격 +5%/단계)→횡검 체득→남궁의 거리 읽기(횡검 +8%/단계).
- 보법: 가벼운 발(회피 재사용 −0.1초/단계)→안정된 중심(생명 +8/단계)→아미의 거리 조절(회피 무적 +0.03초/단계).
- 내공: 고른 호흡(기력 +6/단계)→기력 아끼기(횡검/매화노방 비용 −1/단계)→무당의 운기(기력 회복 +0.3/초/단계).
- 횡검은 1단계, 다른 노드는 3단계 투자 상한. 이는 **투자량**이며 무공 성취의 공통 3단계라는 뜻이 아니다. 삼재검법 기술의 성취는 1~9성, 매화 제1초식은 입문/활용/숙련으로 검증한다.
- 제자 수락 시 제1초식 매화노방: 기존 주변 검격 동작 재사용. 나머지 23초식은 미구현.
- 선택 기연 ‘천흔 호흡’: 무림 공격 +4/기력 +10의 초기 검증용 보너스. 이름·배치·효과는 미확정이다. 기존 파문 전체 수련/후속 기술 개편은 이번 범위가 아니다.
- UI는 세 열의 선행 연결·투자량·잠김 이유·현재/다음 효과, 단련석/수련첩 보유량, 스탯 배분 전후를 표시한다. 모바일에서도 세 분기를 비교하고 선택 기술 상세로 이동한다. 이번 흐름에서는 현실 트리/경지/헌터 승급을 노출하지 않는다.

## 저장과 기존 반복 안내

신규 게임은 `worldState.murimJourney`와 `murimGrowth`로 분리한다. **기존 저장을 새 10개 던전 경로로 강제 편입하지 않는다.** 기존 저장의 성장·투자·완료를 유지해 이어할 수 있다. 새 구성은 타이틀의 ‘새로운 여정’으로 시작하며 기존 저장은 새 게임 확인 후 브라우저 백업에도 보관한다. 중요한 기록은 설정의 저장 다운로드로 별도 보관할 수 있다.

기존 안내 반복 원인은 화산 소개 후에도 목표 대상이 `huashan`에 고정된 것이었다. 소개 후에는 던전 입구, 죽림 승리 후 동작이 부족하면 기본기 실습, 동작을 갖추면 전수 인정, 인정 후에는 백련을 가리키도록 수정했다. 저장 파일 없이 사용자의 개별 기록 상태까지 확인했다고 주장하지 않는다.

지역 안 저장은 남은 적 체력/위치와 보상을 복원한다. 사망/철수 시 야영지로 돌아오며 투자·완료·재료는 남는다. 스탯/스킬 저장 실패 시 변경을 취소한다. 임의 저장 조작의 단계/선행/보상 초과는 거부한다.

## 첫 테스트 순서

1. 새 게임→인트로→이동/기본 공격/회피→추적자 제압→출구.
2. 야영지 ‘캐릭터’에서 단련석 배분 전후, ‘무공/스킬’에서 3개 트리와 선행 조건 확인. 투자는 선택이며 미투자도 진행 가능.
3. ‘화산으로 가는 길 · 여정 선택’에서 1번부터 순서대로 입장. 적을 제압하고 출구로 귀환. 2/4/6번 후 문파 여행자와 대화.
4. 10번 완료→백련 치료→제자 제안 수락 또는 거절. 수락 시에만 매화노방이 열리는지 확인.
5. 귀환길 1~3, 선택적으로 천흔의 메아리→천흔 수문장 제압→야영지 천흔→첫 현실 귀환.
6. 중간 재접속/철수/재방문으로 확정 투자와 보유 재료·완료 이력 유지, 최초 보상 중복 여부 확인.

자동 완주 검사는 실제 공격·피해·상호작용을 사용하되 위치와 재사용 시간을 통제한다. 사람의 난이도, 조작감과 각 던전의 체류시간을 대신 검증하지 않는다.
