## v1.1 — 2026-10-08 · 사용자 결정 반영과 GitHub 문서 허브

### 보관·탐색 방식

`herothgf-cell/project-a`의 `docs/planning/`을 Markdown 기획 원본 폴더로 사용한다. README 시작 페이지, 중앙 문서, 콘텐츠 상세 문서, 결정대장, 출처·요구 추적을 상대 링크로 연결한다. 중앙 파일만 따로 열 때 생기는 상대경로 문제를 안내하고 온라인 고정 시작 주소를 제공한다.

문서 버전별 복제 폴더 대신 같은 파일의 Git 변경 이력으로 관리한다. 기존 Word v1.0은 과거 열람본이며 자동 갱신되지 않는다. MindMap AI도 자동 동기화되지 않으므로 오래된 노드보다 최신 Markdown 결정대장이 우선한다.

D-003 실제 서버 독점 범위는 미답변이며 현재 싱글 검증의 선행조건에서 제외한다. D-010 마기·성력의 데이터 의미는 질문으로 남겼다. D-011-A는 혼합 기연 전 잠재 보유의 의미를 확인할 하위 질문이다.

DOC-13 ‘기연 배치·보상 후보’를 추가했다. 첫 파문을 체득형 비전으로 검토하고, 기존 계열의 숨은 진화·성장 가속·혼합 심법·유물·잔영·봉인의 후속 후보를 구분했다. 후보 목록은 동시 개발 승인 목록이 아니다.

DOC-14 ‘문파·무공 레퍼런스 검토’를 추가했다. 사용자 제공 나무위키 두 페이지의 본문 접근 실패를 기록하고, UNESCO 태극권 자료와 교육기관 자체 수련 소개의 활용 범위를 구분했다. 검증하지 못한 화산·아미·남궁 등의 세부 계보를 정설로 채우지 않았다.

원본 C/K/R/M/G/V 72개 카드의 ID·의도·담당을 유지하고, 대체된 구제안은 최신 결정으로 표시했다. 결정대장만 갱신한 것이 아니라 관련 상세 문서의 초기화·퀘스트 표기·필수 기연 조건·현재/후속 범위를 함께 수정했다.
