## v1.1 — 2026-10-08 · 사용자 결정 반영과 GitHub 문서 허브

### 보관·탐색 방식

`herothgf-cell/project-a`의 `docs/planning/`을 Markdown 기획 원본 폴더로 사용한다. README 시작 페이지, 중앙 문서, 콘텐츠 상세 문서, 결정대장, 출처·요구 추적을 상대 링크로 연결한다. 중앙 파일만 따로 열 때 생기는 상대경로 문제를 안내하고 온라인 고정 시작 주소를 제공한다.

문서 버전별 복제 폴더 대신 같은 파일의 Git 변경 이력으로 관리한다. 기존 Word v1.0은 과거 열람본이며 자동 갱신되지 않는다. MindMap AI도 자동 동기화되지 않으므로 오래된 노드보다 최신 Markdown 결정대장이 우선한다.

중앙1+상세12의 Markdown 문서, 중앙·결정대장 Word 열람본, MindMap AI 지도를 생성해 전달한 버전이다. 최초에는 결정 질문 20개를 미확정으로 두었고, 구현 비교는 project-a91c6262의 일부 코드·자료였다.
