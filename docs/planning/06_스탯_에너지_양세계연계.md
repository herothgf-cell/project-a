# 06. 스탯·에너지·양세계 연계

문서 ID: DOC-06 | 기획 버전: **1.1** | 갱신일: **2026-10-08**

[중앙 문서](00_중앙기획서_문서지도.md) · [결정대장](11_결정대장_확답이필요한질문.md)

## 1. 목표와 최신 결정

원본 G-01~G-04, G-12, R-06·R-11, M-07을 담당한다. 세계별 성장과 생활 변화는 연결하되 캐릭터 하나의 숫자를 복사한 느낌은 줄인다.

> [수정 확정 D-016] 성장 정책을 전면 재설계한다. 스킬 초기화 금지, 스탯도 확정 후 초기화 금지.

> [검증 후 결정 D-012] 성취도·투자·수련 공식과 이전 저장의 대응표는 구현 테스트 후 확정한다.

v0.12.9의 ‘영구 스탯·스킬 초기화 허용’은 구현 비교의 과거 기준이다. 새 목표에서 스킬 초기화 허용을 유지하지 않는다. 원본의 ‘스탯 방식 자체는 나쁘지 않다’는 피드백이 새 영구 성장 정책을 막는 근거가 되지 않도록 한다.

## 2. 서로 다른 데이터 의미

| 구분 | 의미 | 예시 |
|---|---|---|
| 영구 능력치 | 확정한 신체·전투 성장 | 체력·공격·내력 최대치 등의 투자 |
| 전투 자원 | 기술을 쓰며 소모·회복 | 내력·마력·성력 후보 |
| 친화·자격 | 특정 힘을 다룰 수 있는 조건 | 마기 적합·성력 개방 |
| 기술 속성 | 공격·보호 효과의 성격 | 화염·성력·마기 |
| 소속·관계 | 사회적 위치와 전수 권한 | 화산·마교·길드 |

마교에 영향을 받은 마기 스탯, 현실의 성력 능력치는 이 구분 위에서 구체화한다. 마기를 얻으면 마교에 자동 가입하거나 악인이 된다는 규칙은 아니다. 성력 기술 하나가 모든 성력 관련 수치를 동시에 개방하는 것도 자동 규칙이 아니다.

## 3. D-010 — 남아 있는 선택

**A 별도 에너지 모델:** 성력 사용 자격을 얻으면 성력 자원·최대치·효율이 열린다. 마력과 다른 기술을 사용하며, 미개방 계열은 화면에서 숨긴다.

**B 영구 배분 스탯 모델:** 공격·체력처럼 마기·성력에도 포인트를 투자한다. D-016에 따라 확정 후 감소·환불·재분배할 수 없다.

**C 속성 모델:** 별도 게이지·배분 항목 없이 기술에 속성과 사용 자격만 붙인다.

[질문 D-010] 사용자 답변이 아직 없다. A를 검증 출발점으로 제안하되 확정하지 않는다. 첫 화산+파문 검증에 마기·성력까지 전부 구현할 필요는 없다. 복수 에너지의 정식 데이터 필드는 모델을 결정한 뒤 만든다.

## 4. 세계별 성장 경계

현실·무림의 레벨, 경험치, 무공/스킬 숙련, 장착, 경지/등급을 별도 기록한다. 한 세계의 세부 수련이 다른 세계의 동일 숙련 숫자를 자동으로 덮어쓰지 않는다. 동일 플레이어의 이야기·성취 관계는 연결하되 원본 성장과 반영 결과를 구분한다.

현재 공명 결정·무공 각인의 독립 성장과 출처 관리 방향은 DOC-12 SRC-G02에 근거가 있다. 새 정책은 이 기반을 참고하지만 포인트 종류·환산식·영구 선택 UI까지 그대로 유지한다고 확정한 것은 아니다.

| 무림의 성과 | 현실의 변화 제안 | 자동으로 같아지지 않는 것 |
|---|---|---|
| 기본 수련·신체 성장 | 현실 성장 자원과 능력 잠재 | 같은 레벨·공격력 숫자 |
| 무공 원리 체득 | 현실 독립 스킬의 사용 자격 | 같은 이름·이펙트·자원 |
| 실전 경험 | 현장 해법·역할·신뢰 | 공식 헌터 등급 |
| 문파·인물 관계 | 보고와 새로운 정보 | 상대 세계 NPC의 전지적 지식 |

## 5. 무림 → 현실 정산

성취 발생 → 귀환 시 아직 반영하지 않은 성취 확인 → 현실 반영 내역 생성 → 사용처와 변화 안내 → 사용자가 영구 투자 확정의 순서로 제안한다. 실제 성취 ID와 반영 기록을 저장해 왕복만으로 같은 보상이 반복되지 않게 한다.

공명 결정은 현실 능력 성장에, 무공 각인은 현실 독립 스킬에 연결하는 현재 방향을 우선 참조한다. 실제 투자·성취 방식을 재설계할 때 새 재화를 무조건 더 추가하지 않는다. 출처는 ⓘ로 조회하고 ‘어디에서 얻어 무엇에 쓰는가’를 같은 화면에서 이해하게 한다.

첫 대응 스킬을 자동 장착하는 것은 빈 슬롯을 안내하는 편의로만 검토한다. 이미 장착한 기술을 사용자 의사와 무관하게 덮어쓰지 않는다. 획득, 투자, 장착, 사용 증명은 서로 다른 이벤트다.

## 6. 현실 → 무림 연결

현재 README의 현실→무림 성장 재화 미제공 방향을 비교 기준으로 남긴다(SRC-G02). 바로 반대쪽 성장 재화를 추가해 왕복 환전 구조를 만들지 않는다.

[제안] 현실의 구조 경험·정보·현장 관찰이 무림의 새 전술, 인물과의 대화, 장치 이해, 전수 접근을 열 수 있다. 현대 장비를 무제한 운반하거나 마력을 그대로 내력에 합산하는 규칙은 미확정이다. 같은 원리를 여러 이름으로 정산해 무한히 성장시키지 않는다.

정보를 얻었다고 백련이 자동으로 아는 것이 아니다. 전달과 실제 반응 상태를 구분하며 DOC-03/07의 정보 규칙을 따른다.

## 7. 마기·성력의 분리와 혼합

> [부분 확정 D-011] 초기 운용은 분리한다. 별도 기연을 통해 혼합·공존이 가능해진다.

초기에는 마기와 성력을 한 기술에 자동 합산하지 않는다. 혼합 기연은 두 힘을 함께 운용하는 새로운 원리·기술·체질을 열어 주는 사건으로 제안한다. 단순한 메뉴의 ‘합치기’ 버튼으로 기존 투자를 환급하거나 삭제하지 않는다.

**D-011-A의 남은 질문:** 혼합 기연 전에도 두 힘을 ‘잠재적으로 보유’하고 하나씩만 사용할 수 있는가? 아니면 두 힘을 동시에 보유하는 것부터 혼합 기연이 필요한가? 사용자의 ‘공존 가능’이라는 답을 기존의 보유 공존 권장안 전체 승인으로 넓히지 않는다.

답변 전에는 자동 삭제·정화·영구 합산을 넣지 않는다. 실제로 두 힘을 획득하는 콘텐츠는 이 해석을 확인한 뒤 확정한다. 데이터 초기값은 다른 힘을 얻었으니 기존 능력을 지우는 값이 아니라 미개방·미정 상태를 안전하게 보존하는 방향이다.

| 요소 | 무림·현실에서 검토할 역할 | 현재 상태 |
|---|---|---|
| 내력 | 일반 무공·심법 운용 | 기존 세계 기반 참조 |
| 마기 | 높은 출력·대가·특수 운용 | 세부 모델 D-010 미정 |
| 마력 | 현실 마법·흡수막·룬 | 현실 정체성 확정, 수치 모델 미정 |
| 성력 | 보호·정화·치유·결계 | 현실 정체성 확정, 수치 모델 미정 |
| 혼합 원리 | 분리된 두 힘의 복합 운용 | 별도 기연 방향 합의, 후속 후보 |

## 8. 영구 투자 UX

**현재 수치 → 초안 투자 → 투자 후 예상 → 영구 확정**을 한 흐름으로 보여준다. 현재 잔량, 소비량, 획득 출처, 변경된 능력치, 다음 성장이 명확해야 한다.

확정 전 초안은 +/−와 취소로 조정할 수 있다. 실제 확정 이후에는 스탯과 스킬 모두 감소·환불·재분배 기능을 제공하지 않는다. 버튼을 숨기는 것뿐 아니라 게임 상태 변경 경로에서도 감소 요청을 거부해야 한다. 이 내용은 후속 구현 요구이며 현재 코드가 수정됐다는 뜻이 아니다.

새 스킬·기연·문파 이동·세계 전환을 초기화 기회로 만들지 않는다. 이미 보유한 기술의 장착 변경은 투자 재분배와 구분한다. 구체 장착 제약은 별도 기획이며 임의로 모두 금지하지 않는다.

잘못된 이해를 줄이기 위한 연습·미리보기는 정식 저장을 바꾸지 않는 별도 상태에서 처리한다. 개발 실험용 초기화와 플레이어 재분배를 분리한다. 영구 선택 고지는 확정 직전 보이되 같은 안내로 화면 전체를 채우지 않는다.

## 9. 이전 저장과 예외

기존 투자를 임의로 줄이거나 현재 강화 레벨을 정해지지 않은 비율로 1~9성에 환산하지 않는다. D-012 확정 후 현재 저장과 목표 모델의 대응표를 작성한다. 백업·버전 식별·1회 이행·재실행 안전성이 필요하다.

데이터 오류 복구는 영구 선택을 유저가 마음대로 되돌리는 기능과 다르다. 오류 복구를 명분으로 기본 환불 UI를 남기지 않고, 초기화 금지를 명분으로 손상된 저장을 방치하지도 않는다. 정식 수정 범위는 실제 문제와 이행안에 따라 따로 승인받는다.

보상 직전·직후 저장, 반복 귀환, 메뉴 조회, 중복 클릭에서 투자·성취·정산이 한 번만 적용되어야 한다. 기존 HP/자원 비율과 월드 상태를 보존할지는 효과 변경 유형별로 검증한다.

## 10. 검수와 연결

세계별 경험치·숙련 독립, 귀환 정산 중복 방지, 조회만으로 상태 변경 없음, 초안 취소 불변, 확정 후 스탯·스킬 감소 거부, 혼합 전 자동 삭제/합산 없음, 혼합 기연이 초기화 우회가 아님, 잘못된 저장이 현 진행을 덮어쓰지 않음을 확인한다.

D-010/D-011-A의 답이 필요한 복수 에너지 검증은 후속으로 표시하고 최초 화산+파문 검증의 공통 선행조건으로 만들지 않는다.
