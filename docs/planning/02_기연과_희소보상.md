# 02. 기연과 희소 보상


> **v1.3 확정 정정 (2026-10-08):** D-024 B(독립 첫 스승 백련 + 별도 화산 전수자), D-025 A(기본 검로 + 소수 초식 우선), D-026 A(선행 체득·실전 증거로 늦은 후속 수련)를 채택한다. 무공 성취 기본형은 **1~9성**이며 무공 고유 구조를 허용한다. 이십사수매화검법은 초식별 성취다. 현실 스킬도 개별 성취를 가지며 양세계 성취·투자는 별도로 보존한다. 확정 스탯·무공·스킬 투자는 초기화하지 않는다. 새 수치·초식 효과·성취 조건은 **검증안**이다.

## 1. 정의와 확정 범위

원본 K-01~K-12, C-03~C-06, G-10을 상세화한다. 기연은 낮은 확률의 아이템만이 아니라, 남들이 지나친 조건과 나의 행동이 만나 특별한 성장 경로가 열리는 사건이다. 실제 희소성·보상의 강함·발견의 감정은 서로 다른 축이다.

> [사용자 방향] 고유 능력·무공·칭호·아이템·성장 가속은 실제 격차를 만들 수 있다. 기연 획득을 모든 유저에게 보장하지 않는다.

[확정 D-007] 기연은 기본 본편·경지의 필수 소유 조건이 아니다. [확정 D-005] 현재 퀘스트 배지는 **[유일] 한 종류**다. [방향 합의 D-006] 첫 기연은 파문 중심으로 설계·검증한다. 구체 사건과 성능은 제안이다.

## 2. 상태 흐름

| 단계 | 경험 | 기록·안내 |
|---|---|---|
| 잠재 | 아직 존재를 모름 | 전용 퀘스트·정답 좌표 미표시 |
| 징후 | 소리·물결·흔적·NPC 반응이 이상함 | 지나쳤다고 즉시 실패 처리하지 않음 |
| 발견 | 관찰·상호작용으로 변화를 일으킴 | 발견 이벤트 기록, 보상 확정은 아님 |
| 자격 | 왜 나에게 반응했는지 추론 | 조건과 소유권 예약을 혼동하지 않음 |
| 도전 | 힘을 다루고 위험에 대응 | 실제 성공 조건·철수·재시도 안내 |
| 체득 | 이전에 못 하던 행동에 성공 | 핵심 기술·소유권·보상 1회 확정 |
| 명명 | 나에게 열린 길의 의미를 이해 | [유일] 분류와 기술 이름을 보여줌 |
| 수련·변화 | 강함을 다듬고 현실에서 써 봄 | 후속 수련·역할 변화·NPC 반응 |

[제안] 첫 기술은 유효한 행동에 성공한 순간 체득한다. 백련의 후속 대화는 보상 수락이 아니라 기술의 이름·위험·수련법을 해석하는 장면이다. 현행 v0.12.4 안내의 ‘시험 성공 뒤 백련에게 수락’과는 개편 대상이 다르다. 근거는 DOC-12 SRC-G03.

## 3. 우연의 설계

장소·사건 시점·플레이 기록·NPC 인연·보유 원리 또는 체질을 조합한다. 난수는 만남이나 징후의 일부에 쓸 수 있으나, 이미 성립한 희귀 도전을 설명 없는 확률 실패로 반복시키는 것을 기본으로 삼지 않는다.

‘패배 10번’ 같은 실패 횟수 파밍 대신, 위협의 원리를 관찰했는지·사람을 도왔는지·다른 대응을 선택했는지 같은 의미 있는 행위를 조건으로 제안한다. 고성장으로 적을 먼저 잡아도 필요한 환경 흔적을 확인할 수 있게 해, 강함이 진행 교착의 원인이 되지 않도록 한다.

기연을 못 얻는 것은 허용하지만 이유를 알 수 없는 저장 유실·UI 오류·잘못된 목표 안내를 희소성으로 포장하지 않는다. 의도적 기회 상실과 버그로 인한 진행 실패를 구분한다.

## 4. 강한 보상과 어려움

강한 보상에 필요한 어려움은 반복 시간만이 아니다. 발견 희소성, 원리 이해, 조작 도전, 위험 감수, 다른 선택의 포기, 이후 수련의 부담으로 나눌 수 있다. 수치와 획득 인원은 현재 미확정이다.

| 유형 | 획득 부담 후보 | 습득 이후 |
|---|---|---|
| 희귀 단일 기술 | 관찰·짧은 실전 증명 | 독립 수련과 높은 즉시 체감 |
| 고유 계열 비전 | 사건·인연·복합 자격 | 전용 후속 기술·전수 관계 |
| 특수 심법·체질 | 희귀 적합성·장기 사건 | 성장 방식·상성·운용 확장 |
| 유일 실물 유물 | 발견·수호자·해석 | 사용·보유·충전·거래 정책 |
| 실제 서버 유일 | 공유 사건·소유권 검증 | 후속 서비스 운영 대상 |

[사용자 방향] 강함은 실제로 존재해야 한다. 모든 콘텐츠의 효율을 같게 만드는 해법으로 고유성을 지우지 않는다. 그렇다고 현재 검증 없이 전역 경험치 배수·PvP 성능 상한을 확정하지도 않는다. D-003/D-004의 서비스 정책은 후속이다.

## 5. 기연 무공의 세 위치

**독립 비전:** 일반 문파 전체를 대체하지 않는 고유 원리와 후속 수련을 제공한다. 첫 파문은 이 위치를 우선 검증한다.

**기존 계열의 숨은 진화:** 일반 매화검법의 성취를 바탕으로 다른 분기·연계·출력을 연다. 일반 검법을 삭제하거나 초기화해 갈아타는 기능이 아니다.

**특수 심법·체질:** 특정 계열의 수련 효율, 에너지 운용, 혼합 가능성을 바꾼다. 마기·성력 혼합은 이 범주의 후속 후보다.

| 기존 비전 후보 | 무림의 변화 | 현실 재해석 후보 |
|---|---|---|
| 파문 | 충격을 받아 반격에 싣기 | 마력 흡수막·응축 충격 방출 |
| 잔영 | 발을 딛는 타이밍·추격 | 마법적 도약·표식 추적 |
| 봉인 | 흐름의 맥을 짚어 발동 차단 | 룬 결계·주문 억제 |

이름과 효과는 개편안이다. 현실 표현을 초고도 SF 장치로 설명하지 않는다. 잔영·봉인을 삭제한 결정은 없지만 현재 첫 검증은 파문에 집중한다. [D-006/D-008/D-014]

## 6. 다섯 보상 유형의 계약

**능력·체질:** 불가능했던 행동이나 새로운 수련 효율을 연다. 영구 소유와 현재 활성 상태를 구분한다. 새 체질이 기존 투자를 자동 환급하거나 삭제하지 않는다.

**무공·스킬:** 고유 기술 또는 숨은 가지의 습득권을 연다. 첫 체득부터 강한 차이를 허용하되 그 비전의 후속 수련까지 즉시 완성할 필요는 없다(D-021). 스킬 투자·성취 초기화는 금지한다. 확정된 획득·수련 이력을 다음에 새 기연이 나왔다고 되돌리지 않는다. [D-016]

**칭호:** 발견 이력, 현재 소유, 장착 효과를 구분한다. 최초 칭호와 유물 현재 소유자가 같은지, 슬롯·중첩은 검토 대상이다. 초기 검증에 여러 전역 배수를 동시에 추가하지 않는다.

**아이템:** 물리적으로 보유하는 유물은 습득한 무공과 다르다. 독점 범위·거래·충전·상실을 각각 결정한다. 이번에 거래·파괴·약탈·영구 회수를 기본 정책으로 승인하지 않았다. [D-017]

**성장 가속:** 노력한 만큼 더 빨리 성장하는 특별함을 허용한다. 어떤 수련에 적용되는지와 정산 원인을 기록하고, 반복 귀환으로 같은 보너스를 재발급하지 않는다.

## 7. [유일] 퀘스트 표기 — 현재 규칙

> [수정 확정 D-005] 현재 플레이어가 보는 분류는 **[유일]** 하나로 통합한다.

표시 예시: **[유일] 메아리 없는 바위**. 상세에는 발견한 징후, 다음 도전 행동, 실제로 체득한 효과를 표시한다. ‘개인 전용/서버 유일/서버 최초/서버 한정’ 4~5종 배지를 현재 UI에 함께 넣지 않는다.

[유지 제안] 발견 전에는 현장의 징후만 보이고 발견한 뒤 퀘스트를 등록한다. 사용자가 확정한 것은 표기 통합이며 구체 노출 시점은 테스트로 조정할 수 있다. 친절한 후속 안내와 스스로 발견했다는 감정은 양립하도록 설계한다.

이 분류 통합은 실제 서버 N·독점 기간의 확정이 아니다. 테스트 안내에는 ‘싱글 재미 검증, 기연 조건은 시연 설정’임을 밝힌다. 실제 공유 검증이 없는 ‘전 서버 1명 획득 완료’ 문구를 만들지 않는다. 화면마다 긴 운영 설명을 반복할 필요도 없다.

## 8. 일반 성장과 기연 분리 — 승인된 구조

기존 첫 이류 조건에는 기연 계승·증명이 포함된다(DOC-12 SRC-G04). 이 소유 조건은 새 목표와 다르다.

> [확정 D-007] 공통 필수는 ‘기본 수련과 유효한 위협 대응의 증명’이다. 희귀 기연 보유는 여러 해법 중 하나이며 공통 입장 열쇠가 아니다.

일반 플레이어는 화산 기본기·회피·장치 등으로, 기연 플레이어는 파문의 높은 출력·반격·보호로 같은 위험을 해결한다. 일반 경로에 보상형 가짜 파문을 지급하지 않는다. 기연 경로의 강함을 평준화하지 않는다.

본편과 경지의 분리만으로 충분하지 않다. 후속 장의 보고, 수련 목표, 보스 약점, UI 잠금 이유가 다시 ‘기연 필수’를 숨겨 만들지 않는지 검수한다. 기연 전용 후속 수련은 소유자만 접근해도 된다.

## 9. 첫 기연 사례 — 메아리 없는 바위

[제안·가칭 / 상세는 DOC-13] 현실의 귀환 통로 압력에 밀려 철수한 윤서가 무림에서 백련을 돕다가 계곡의 이상한 울림을 발견한다. 백련은 비급 위치를 알려주는 대신 돌아오는 힘을 억지로 밀어내지 말라는 원리를 설명한다.

플레이어는 자세·위치·타이밍을 바꾸어 물결과 바위의 반응을 확인한다. 메뉴에서 파문/잔영/봉인을 골라 일괄 수령하는 장면이 아니다. 첫 반응은 임시 체험이고 유효한 위협을 받아 되돌리는 성공이 체득 증거가 되는 안을 제안한다. 요구 횟수는 확정 수치가 아니다.

Q에 해당하는 핵심 행동 하나만 체득한다. R은 뒤의 연계 수련, F는 충분한 실전 이후이며 각각 별개의 신규 기연으로 세지 않는다. 정상 귀환 후 현실의 마력 흡수막/반격으로 이전 압력에 대응하고 서린이 현장 역할의 변화를 확인한다.

기연 조건이 없는 저장은 일반 수련·장치 경로로 진행한다. 첫 실패 자체가 누구에게나 파문을 예약해 주는 조건은 아니다. 데모에서 파문 체험률을 높인 것은 콘텐츠 노출 설정이다.

## 10. 이후 배치와 보상 확인

DOC-13은 파문 외에도 매화 변형, 성장 심법, 마기·성력 혼합, 실물 유물, 잔영·봉인 후보를 비교한다. 이는 장기 공백을 확인하기 위한 배치안이다. D-014의 최초 기연 1개를 넘어 전부 개발하기로 확정하지 않는다.

D-017을 답하기 전에 무엇이 ‘거래 대상’인지 보여준다. 체득한 무공, 비급 원본, 발견자 칭호, 소모성 영약, 실물 유물은 서로 다른 대상을 뜻한다. 보상 종류 확정 없이 거래 허용/금지를 통일하지 않는다.

## 11. 저장·예외·검수

발견·자격·임시 체험·실제 소유를 구분해 저장한다. 보상 직전 저장, 재접속, 재대화로 기술·포인트·공지·칭호가 중복되지 않도록 사건 ID를 사용한다. 초기화 금지를 지키기 위해 기연 재선택을 환불 수단으로 쓰지 않는다.

실제 서버 동시 획득·예약·네트워크 중단은 공유 서버 단계의 문제로 남긴다. 지금 로컬 저장이 그것을 보장한다고 주장하지 않는다.

검수 질문은 ‘배지 없이도 특별한가 / 발견한 행동을 설명하는가 / 획득 직후 강한가 / 기연 없이도 성장하는가 / 다음 수련이 보이는가 / [유일] 표기가 실제 테스트 범위를 오해시키지 않는가’다.
