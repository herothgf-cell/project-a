# 10. 개발 로드맵과 검증 기준

갱신: 2026-10-12 (KST) · 구현 대조: `main f5a5a3b` / 게임 `v0.15.0`

[기획 시작](../README.md)

## 현재 기준선

최신 원격 main을 2026-10-12 확인했으며 게임 기준은 `f5a5a3b` / v0.15.0이다. 장면 연결·편성·알림은 이미 구현돼 있다. 이를 ‘개발 전’으로 다시 분류하거나 중복 구현하지 않는다. 이번 작업은 문서 최신화·이동·링크 검증이며 게임 코드·저장·아트·워크플로는 변경하지 않는다.

## 다음 검토 순서 — 개발 제안

| 우선순위 | 확인할 것 | 완료 판단 |
|---|---|---|
| 1 | 초반 전투 학습과 성장 체감 | 이동·공격·회피를 실제로 이해하고 투자 전후 차이를 설명. 적 수 증가만으로 판단하지 않음 |
| 2 | 장면→전투 호흡·문파 만남 | 화산행 이유·다음 행동을 이해하고 반복 메뉴·불필요한 보고로 느끼지 않음 |
| 3 | 영구 투자·편성·레드닷 | 미투자 가능, 미습득 HUD 비노출, 쿨다운 유지, 읽음 해제·저장 |
| 4 | 현재 기연과 파문 목표의 차이 | 천흔 호흡의 보너스 체험과 파문 발견/독자 해법을 구분해 후속 범위 결정 |
| 5 | 첫 귀환 이후 | 현실 성장 사용처·역할 변화·새 3장 연결을 별도 설계 |
| 후속 | 화경·문파 확대·복수 에너지·공유 서버 | 필요한 결정과 검증이 갖춰질 때 범위화 |

새 수치·효과·초식·대사를 최종 확정으로 쓰지 않는다. 슬롯 2개·튜토리얼 7명 등 현재 값은 변경 가능한 검증안이다. 과거 자동 입력에서 튜토리얼이 빠르게 끝난 기록은 후속 검토의 단서이지 사람의 재미 평가가 아니다.

## 저장·실패 계약

기존 투자·성취·제자 선택·완료·최초 보상 원장은 보존한다. 구 캠페인을 신규 10개 길목으로 강제 전환하지 않는다. v0.14 중간 상태는 이미 완료한 내용에 맞춰 다음 사건으로 이행하고 보상을 다시 지급하지 않는다.

저장 실패는 장면·선택·편성·투자·읽음 변경을 원복한다. 취소·다른 저장 로드 후 늦은 이미지/지역 준비 응답은 무시한다. 재배치로 쿨다운이 초기화되지 않아야 한다. 완주 확인에는 수락/거절×기연 획득/미획득 및 미투자 진행을 포함한다.

## 검증 구분

모델 검사: 선행·상태·중복·투자 보존. 브라우저 검사: 실제 화면·입력·비동기 실패·모바일. 사람의 플레이: 조작감·전투량·장면 길이·성장 이해. 배포: 실제 워크플로와 공개판 상태. 이 네 결과를 서로 대신하지 않는다.

이번 문서 작업은 링크·분류·원문 보존·요구 추적·결정 충돌을 검사한다. 게임 전체 검사를 실행하지 않았으므로 과거 801/50/7 결과를 이번 실행 결과로 재사용하지 않는다.

main에서 작업하며 푸시·배포는 해당 작업의 사용자 요청과 [AGENTS.md](../../../AGENTS.md)를 따른다. 옛 계획의 완료 체크나 과거 출시 승인을 새 작업의 실행 지시로 사용하지 않는다.
