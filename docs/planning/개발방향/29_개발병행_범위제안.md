# 29. 개발 병행 — 양세계 첫 성장 순환 범위

작성: 2026-10-12 · 상태: D-059 개발·main 푸시·배포 승인 반영

[수련·토벌](../시스템/28_정식수련과_무림반복토벌_기획안.md) · [스킬·레이드 비교](../시스템/27_스킬역할_레이드조건_성장속도_비교안.md) · [현재 구현](18_현재구현과_제한.md)

## 사용자 선택과 완료 목표

D-058: 무림 수련/토벌만의 작은 개발 묶음 대신 현실R1·레이드까지 포함하는 범위로 재설계한다. 최초 작성 당시에는 구현하지 않는 범위 제안이었다. 이후 D-059에서 실행 계획부터 구현·검증·main 푸시·배포까지 승인했다. 실행은 [DOC-30](30_양세계성장_실행계획.md), 실제 범위와 검증 결과는 [DOC-31](31_양세계성장_구현과검증.md)을 따른다.

완료 목표는 **첫 귀환→안정화/왕복→무림 수련·토벌→매화 성취→현실R1 유료 학습→일반 기술과 혼합 편성→첫 레이드 성공→보상으로 다음 성장 선택**을 일반 화면에서 한 바퀴 플레이하는 것이다. 각 기능이 테스트 화면에서만 동작하는 상태는 완료로 세지 않는다.

## 포함 범위 제안

| 영역 | 이번 범위 제안 | 검증 이유 |
|---|---|---|
| 성장·저장 | 완료 단위 숙련, 회차/구간 기록, 중복 정산 방지, 기존 투자·보상 보존 | 양세계 콘텐츠가 같은 완료 계약 사용 |
| 매화 | 기존1~3초식 유지, 후속 초식 첫 완료 학습 자격, 노방 활용과R1 자격 | 기존 기능을 보존하며 연결1종 검증 |
| 무림 수련 | 노방 정식 수련1종·기초 삼재 성취 확보 경로 | R1 자격/첫 각인 공급에 막힘 방지 |
| 무림 토벌 | 분산 적/강한 적 두 구성 | 무림 재료와 여러 기술 성장 비교 |
| 사건·왕복 | 안정화, 비전투 거점 왕복, 확보한 길 안전 이동, 백련 재수락 | 조기/늦은 매화 선택 모두 정상 순환 |
| 현실 스킬 | G1/G2·R1, 공용2슬롯, G2 연속 적중 보강 | 일반 경로와 혼합 경로 비교 |
| 현실 수련 | R1 집중 수련1종 | 무림 기술을 현실 적용으로 익힘 |
| 현실 레이드 | 갑각수 기본 공략, 첫 완료 후 두 반복 조건 | D-054의 반복 선택까지 검증 |
| 성장 결과 | 최초/반복 보상, 기술별 숙련, G1/G2/R1 강화·다음 목표 | 첫 성공 뒤 성장 선택 확인 |

세부 최소 콘텐츠 선정은 범위 제안이다. R2/R3 학습·나머지 정식 수련·공식 랭킹·추가 기연·장비·문파 운영은 후속으로 남긴다. 기존 매화 제2/3초식을 삭제하거나 배우지 못하게 막지 않는다. R2/R3 미구현은 트리에 구분하고 학습 비용을 소비하게 하지 않는다. 첫 레이드는R3 없이도 일반기술과R1으로 완주·반복 가능해야 한다.

## 내부 작업 순서 — 완료 목표는 전체 순환

1. 기록과 이행: 활동 시작/구간 완료/실패/최종 정산 상태, 새 완료 기록과 기존 명중·투자·보상 대조표 설계.
2. 무림 반복: 거점 접근, 노방 과제, 토벌 두 구성, 매화 학습 자격·재료 연결.
3. 두 세계 연결: 안정화·왕복·재수락·최초 정산·R1 유료 학습 연결. 테스트 전용 이동만으로 대체하지 않음.
4. 현실 적용: G1/G2/R1·편성·R1 수련·기본 보스·재도전·두 조건·강화 연결.
5. 전체 검증: 조기/늦은 수락·일반 공략·재료 선소비·실패·재접속 비교.

부분 작업을 완성품으로 보고하지 않는다. 한 단계의 기록 규칙이 다음 콘텐츠에서도 맞는지 확인하며 최종 검증은 양세계 순환 전체에 적용한다.

## 상세 구현 계획 전에 닫을 항목

- 현재 `ordinary-growth.js`는 명중 기반 단계 계산, `murim-growth.js`는 별도 매화 조건을 갖는다. 기존 명중을 임의로 완료 횟수로 나누지 않는다. 보유 효과/투자 보존과 새 완료 기록의 관계를 저장 유형별로 결정해야 한다.
- `boundary-resonance.js`의 기존 최초 보상과 새 기초/매화 정산을 출처별로 대조한다. 같은 성취를 다시 지급하거나 사용한 재화를 되돌리지 않는다.
- 삼재1~9성은 매화0/3/8과 별개다. 단계별 완료 요구를 임의 복제하지 않고 첫 각인 성취와 삼재 단계의 적용 범위를 정한다.
- 기본 공격·보스HP·지지체HP·피해·마력·체크포인트 복원값을 함께 조정한다. DOC-27/28의 시간은 초기 목표이며 성능 보장이 아니다.
- 기존 저장에 새 규칙을 적용할지, 버전별 경로를 보존하고 새 여정부터 적용할지는 이행안을 제시해 확인해야 한다. 코드 편의를 이유로 초기화하지 않는다.

## 완료 판단

- 기존 첫 귀환 이전 흐름·투자·제자 거절 경로가 깨지지 않음.
- 노방을 늦게 배워도 수련/토벌로R1 자격·비용 확보 가능. 최초 성취는1회만 정산.
- 수련은 지정1종, 토벌·레이드는 유효 사용 기술별 숙련. 중간 교체·재도전 기록 일치.
- R1 없이 G1/G2로 기본/두 조건 공략 가능. G1/R1은 다른 공략 행동을 제공.
- 실패·철수·재접속·저장 실패에서 미완료 보상이나 중복 소비/지급 없음.
- 키보드·모바일에서 전조·조준·편성·남은 조건·보상 이해 가능.
- 자동 검사와 실제 플레이 시간을 구분. 반복의 지루함은 사람의 플레이로 확인.

후속 실행 계획과 구현 검증을 DOC-30/31에 기록했다. 기존 1~2장 보존·안정화 시 완료 기반 전환은 D-060으로 확인했다.
