# 09. 운영 방향과 후속 검토

갱신: 2026-10-12 (KST) · 구현 대조: `main f5a5a3b` / 게임 `v0.15.0`

[기획 시작](../README.md)

## 서비스 단계

현재 싱글 PvE 재미 검증 → 필요 시 협동 → 장기 MMO 순서다(D-002/004). 네트워크 구현, 공유 경제, 실제 서버 유일 소유권은 현재 신규 1~2장 개발의 선행조건이 아니다.

기연의 실제 강함과 희소성은 목표로 유지한다. 운영으로 대응하겠다는 가설과 이를 검증할 소유권·복제 방지·복구 시스템은 다르다. 로컬 저장만으로 서버 독점을 보장했다고 쓰지 않는다. 가짜 접속자 수·획득 공지를 실제 서비스 정보로 표시하지 않는다.

## 미정·보류 대장

| 결정 | 남은 내용 | 다시 검토할 시점 |
|---|---|---|
| D-003 | 실제 유일/N인/전 서버 범위와 기간 | 공유 서버 검증 전 |
| D-010 | 마기·성력의 자원/영구 스탯/속성 모델 | 해당 콘텐츠 개발 전 |
| D-011-A | 혼합 기연 전 동시 잠재 보유 가능 여부 | 복수 에너지 획득 설계 전 |
| D-012 | 성취·투자 공식·요구량·기존 기록 대응 | 플레이 검증 후 |
| D-013 | 탈문·재입문·전수 제한의 세부 사건 | 문파 소속 확장 시 |
| D-014/015 | 최소 장비 분량·성장 속도·권장 경지 | 후속 범위와 밸런스 검토 시 |
| D-017 | 보상 유형별 거래·상속·약탈·파괴·상실 | 실제 보상안을 먼저 제시한 뒤 |
| D-018 | 휴면·탈퇴·시즌·회수 | 사용자 지정 후속 보류 |
| D-019 | 서버 통합·격차 개입 | 사용자 지정 후속 보류 |
| D-020 | 가상 채팅·소문 | 사용자 지정 후속 보류 |

D-018~020은 답변 누락이 아니다. 지금 다루지 않겠다는 결정이며 이번 문서 정리의 필수 질문으로 다시 올리지 않는다. PvP/PK/랭킹/정규화 정책도 후속이다. 영구 투자 초기화 금지는 위 미정 항목과 별개로 확정돼 있다.

## 첫 귀환 이후

레이드와 연결되는 성장·첫 귀환 이후 사건의 초안은 [DOC-23](../시스템/23_현실_지하역_레이드와_스킬_검토안.md)~[DOC-25](../스토리/25_첫귀환이후_왕복과_레이드_검토안.md)에 작성했다. 세계관 속 헌터 순위 표시는 현재 기획 대상이지만 실제 유저 랭킹·공유 경제·정규화·시즌은 여전히 후속이다. 공명 결정의 반복 레이드 공급은 D-041로 목표 확인했고 현재 게임에는 미적용이다.

현실 성장의 사용처와 전투·역할 변화, 파문의 본격 수련, 3장 이후 사건 연결, 다른 문파 트리, 화경 시련, 장비·경제 확대는 별도 작업 범위다. 이전 후반 사건은 보관 자료에서 검토할 수 있으나 신규 첫 귀환 시점과 충돌하지 않도록 다시 설계해야 한다.

백련의 직위·개인 과거·여행자 이름·초식 출처를 임의 확정하지 않는다. 대규모 아트·음향·호감도·동행 AI를 문서 분류에 포함했다는 이유로 개발 승인된 것으로 취급하지 않는다.
