## 적용 범위

사용자가 실행 계획 이후 개발·main 푸시·Pages 배포를 승인했다(D-059). 기존 1~2장을 유지하고 첫 귀환 뒤 안정화부터 새 완료 규칙을 적용한다(D-060). 문파 운영·R2/R3·공식 랭킹·장비는 후속이다.

| 구간 | 실제 구현 |
|---|---|
| 안정화 | 서린의 좌표 측정 설명 → 안정화 버튼 → 현실/무림 비전투 거점 왕복 |
| 늦은 전수 | 확보한 길은 이동 생략. 백련 재수락을 별도 기록하며 과거 거절 장면 보존 |
| 무림 | 삼재 기초·노방 정식 수련, 분산/강적 토벌. 토벌 완료 수련첩 1·무림 XP 40 |
| 매화 | 앞 초식 사용 완료 1회 + 수련첩 2로 다음 초식. 3/8회 성취, 기존 피해 단계 하한 유지 |
| 연결 | 노방 완료 3회 후 R1 마력 개화를 각인 1·결정 2로 학습. 무료 지급 아님 |
| 현실 | G1/G2/R1 공용 2슬롯. G2는 같은 적에 두 번째 타격까지 적중 시 추가 피해. R1은 지정된 가까운 위치에 0.8초 뒤 범위 피해 |
| 레이드 | 정찰 → 안전 편성 지점 → 갑각수 → 최종 정산. 기본 첫 성공 후 집결 억제/핵 공략 동시 개방 |
| 보스 | 내려찍기/휩쓸기/돌진 전조. 65% 이하 지지체 2개·소환체, 모두 파괴 시 6초 노출. 30% 이하 돌진/내려찍기 교대 |
| 성장 | 반복 결정 2·현실 XP 80, 최초 추가 2·40. 사용 기술별 +1. G1/G2/R1 완료 3/8회 후 결정 2/3으로 강화 |

수련은 기본 표적에 지정 기술 2회 유효 사용 후 적용 전투로 진행한다. 지정 기술만 숙련 +1이며 반복 재화·XP는 없다. 적용 전투에서 다른 기술만 사용했으면 표적을 남겨 지정 기술을 보완할 수 있다. 과제 완료까지 최소 시간을 강제로 기다리게 하지 않는다.

## 저장·재료 계약

- `worldState.dualProgression.version = 1`을 기존 v10 저장 안에 추가한다. 기존 저장 슬롯과 백업 계약은 유지한다.
- 기존 명중·투자·학습을 삭제하거나 완료 횟수로 환산하지 않는다. 이미 얻은 성취 효과는 하한으로 보존한다. 안정화 뒤 삼재 기본형은 완료 4회마다 다음 성, 매화는 3/8회를 이번 비교값으로 적용한다.
- 현재 구간 실패·재접속은 현재 사용 기록과 전투를 초기화한다. 완료 구간의 기술 기록은 보존한다. 재접속은 해당 구간의 안전 준비에서 재개한다.
- 회차당 기술 +1, 중간 교체 이전 기술도 인정. 최종 정산 후 회차를 닫아 다시 지급하지 않는다. 철수는 미정산 기록을 버린다.
- 회복은 새 활동에서 구간당 2회이며 기존 보유 회복약을 소비하지 않는다. 재도전 시 체력·자원·회복 2회를 복원한다.
- 기초 삼재 완료 3회의 각인은 이전 `practice:training` 지급 여부와 대조한다. 과거에 받았다면 다시 지급하지 않는다. 결정 2는 새 완료 성취분이다.
- 접무 완료 3회는 각인 1·결정 2, 토염 완료 3회는 각인 1·결정 3을 추가 확보한다. 이후 새 연결을 추가할 때도 비용 확보 성취를 함께 설계한다.
- 정식 학습·강화·편성·정산은 기존 저장 거래를 사용한다. 저장 실패 시 변경을 취소한다.

## 검증 근거

최종 로컬 검사: 자동 테스트 826/826, 3개 JS 구문 검사 묶음, 기획 문서 링크 389개 통과. 신규 브라우저·기존 첫 귀환·기존 매화 연속 진행 검사 통과. 준비 중 창 닫기는 이동을 취소한다.

- 신규 자동 검사: 완료 원장, 저장 이행, 늦은 수락, 실제 수련→유료 R1, 초식 학습, 레이드 조건/보상, 교체·실패·재접속, 손상 저장 거부.
- 별도 코드 리뷰에서 수련 진행 막힘, 무림 회복의 현실 유출, 불가능한 숙련 저장 허용을 발견했다. 세 문제 모두 실패 재현 테스트 후 수정했고 재리뷰에서 추가 차단 문제 없음.
- 브라우저: 메뉴로 왕복·재수락·수련·유료 R1·공용 편성·레이드 첫 성공, 저장 실패 거래 취소, 재접속, 데스크톱/390px 화면. 기존 무림 첫 귀환 브라우저도 통과.
- G1/G2 자동 플레이는 능력치/자원/위치 보정 없이 이동·공격·회피·회복 입력으로 기본/집결/핵 조건을 모두 완료했다. 같은 캐릭터의 연속 실행에서 약 142/100/109초, 재도전 0회였다. 후속 조건에는 앞선 경험치 성장이 반영된다.
- 이 자동 시간은 사람의 초회 플레이 시간이나 두 조건의 동일 난이도를 증명하지 않는다. 8~12분 레이드·4~6분 토벌·2~3분 수련은 계속 목표 후보이며 실제 이용 관찰이 필요하다.

## 현재 한계와 다음 우선순위

1. 사람의 일반/혼합 편성 플레이 기록으로 소요 시간·자원 부담·반복 피로 비교. 빠른 반복을 억지 대기로 늘리지 않는다.
2. R1의 현재 조준은 전방 가까운 적의 시전 순간 위치(없으면 전방 지점)다. 독립 지점 선택·발동 전 조준 확인 UI는 후속 화면 검토이며 적을 발동 후 추적하지 않는다.
3. 새 전투는 기존 무림/현실 아트와 전조 표시를 재사용한다. 전용 지하역 배경·보스 아트는 새로 제작하지 않았다.
4. 이번 매화 투자 선택은 기존 공통 트리와 초식 추가 학습, 현실 기술 강화다. DOC-22의 N/J/T 전용 강화 6노드는 아직 후보이며 구현하지 않았다.
5. 수련별 추가 배치 A/B·무피격/시간 선택 기록·R2/R3 수련·공식 랭킹은 후속이다.

배포 완료 판정은 이 문서 작성 시점의 로컬 테스트와 별개다. 승인된 main 푸시 SHA에 대응하는 Pages 성공과 배포 후 바이트 검증을 확인한다.
