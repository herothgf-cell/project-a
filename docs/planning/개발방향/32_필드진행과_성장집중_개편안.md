# 32. 필드 진행과 성장 집중 개편안

2026-10-12 · 사용자 피드백 반영 초안 · 결정 질문 답변 전 · 미구현

## 목적과 확인한 문제

스킬·스탯 성장, 현실 레이드, 이를 잇는 이야기와 필드 행동에 집중한다. 무림 반복 토벌을 우선 숨긴다. 기존 저장의 학습·투자·보유 재료는 보존한다. 이번 MMO 지향은 NPC와 지역을 오가며 진행하는 방식에 반영하며 멀티플레이 서버 구현을 의미하지 않는다.

- DOC-08은 성장·입장 선택을 위해 NPC를 방문하지 않는 것으로 규정했다. 이번 필드 중심 요청과 충돌하므로 변경이 필요하다.
- `dual-activities.js`는 활성화 후 모든 상호작용을 활동 창으로 보내고, 지역 포인트도 활동 확인 출구 하나로 대체한다. 원래 NPC·이동 포인트가 사라지는 직접 원인이다.
- `dual-activities-ui.js`는 안정화, 왕복, 전수, 수련, 토벌, 레이드, 성장까지 같은 창에서 처리한다. 서린과 백련은 현장 인물보다 버튼 설명처럼 등장한다.
- `murim-journey-ui.js`의 공용 저장 함수는 이야기 진행에도 투자 경고를 설정한다. 투자 경고는 실제 비용 확정 영역에만 있어야 한다.
- 무당 여행자는 길만 안내하고 퇴장한다. 현재 내용만으로는 소속과 등장 의미가 부족하다.
- 반복 수련·토벌을 전부 감추면 노방 완료 3회와 이후 초식 학습, 추가 각인 공급 경로가 막힌다. UI만 숨기면 안 된다.

## 제안하는 진행

첫 귀환 → 현장의 서린과 대화 → 경계석 확인 행동 → 현실 균열 임무 안내 → 입구로 이동 → 정찰·보스 → 현장 완료 → 성장 확인.

무림 방문은 새 무공을 배우려는 선택 목표로 둔다. 현실 레이드마다 무림을 다녀오거나 안정화 이야기를 반복하지 않는다. 이미 완료한 귀환·안정화 장면은 재방문 시 재생하지 않는다. 임무 기록에서 회상할 수 있다.

성장 메뉴는 스탯·기술 투자와 편성에 사용하고, NPC 대화와 세계 이동을 대체하지 않는다. 임무 목록은 목표를 추적하고 위치를 알려주며 임의 위치에서 곧바로 입장시키지 않는다. NPC·출구 상호작용은 거리와 현재 임무 상태를 검사한다.

## 화면의 역할

| 화면 | 역할 |
|---|---|
| 필드 HUD | 현재 목표 하나, 대상 이름·방향·거리, 상호작용, 장착 기술과 자원 |
| NPC 대화 | 필드 배경을 유지한 하단 대화, 화자·짧은 대사·필요한 선택. 거래 안내와 이야기 연출을 혼합하지 않음 |
| 이야기 컷신 | 첫 전이·구조·첫 귀환 등 사건 전환. 이미지·상황 묘사·등장인물 행동을 보여주며 진행 메뉴는 넣지 않음 |
| 성장 | 별도 넓은 화면. 현재 능력치, 선택 기술 트리, 선택 상세·비용·전후 차이, 편성으로 구성 |
| 결과 | 획득 재료·경험치·실제 사용 기술 숙련과 다음 해금까지 남은 양. 이야기 자동 재생 없음 |

기존 경계공명 시안의 무림/현실 색 구분, 기술 연결선, 전후 수치 비교를 참고한다. 시안의 오래된 기술명·선행·재화 규칙을 복원하지 않는다. 작은 범용 창에 성장·이야기·임무를 모두 쌓는 방식을 해소한다.

## 확인 중인 결정

1. 무림 토벌 외 별도 반복 수련·레이드 변이도 숨기고 기본 현실 레이드를 유지할지.
2. 숨긴 반복 수련을 대체할 백련의 일회성 전수 퀘스트를 제공할지, 반복 정식 수련을 유지할지. 전수 퀘스트를 선택하면 기존 완료 기반 연습을 수행해 자격을 얻으며 R1 유료 학습은 유지한다. 각인 중복 지급 금지와 기존 수령자 추가 공급 검증이 필요하다.
3. 무당 여행자를 화산 구조 연락원으로 변경할지, 무당 인물의 목적·후속 사건을 보강할지.

위 답변으로 습득 가능한 초식과 재화 경로를 먼저 확정한 뒤 난이도·성장 속도를 측정한다. 완료 횟수 3/8, 재료 가격, 영구 투자 조건을 임의로 완화하지 않는다.

## 구현 순서와 검증 기준

1. 공용 투자 경고 제거, 대화/컷신 표현 구분. 진행·건너뛰기·회상·저장 실패에서 선택과 보상이 중복되지 않는지 검사.
2. 첫 귀환 후 NPC·경계석·균열 입구 포인트와 거리 기반 상호작용 복구. 메뉴를 열지 않고 목표 추적→이동→대화→입장이 가능한지 실제 브라우저 입력으로 확인.
3. 확정된 전수 및 현실 성장 경로 연결. 반복 콘텐츠 숨김 후에도 신규/기존/제자 거절 저장 모두 학습·각인 공급이 막히지 않는지 검사. 숨긴 활동 진행 중인 기존 저장은 재개 또는 안전 철수 가능해야 함.
4. 기존 시안을 참고한 성장 화면과 필드 HUD 개편. 데스크톱·390px·키보드·터치에서 정보와 선택 영역을 확인.
5. 같은 시작 저장으로 일반 편성과 매화 혼합 편성을 각각 비교. 이동·대화·전투·메뉴 시간, 첫 학습까지 반복 횟수, 피격·회복·사망·재도전, 보상과 다음 강화 시점을 기록. 순간이동·능력치 보정 테스트는 기능 검사로만 분리.
6. 관측된 막힘과 불필요한 클릭·반복 설명을 우선 수정. 보스 체력·공격·보상 조정은 측정 근거를 남긴다. 자동 플레이 시간으로 사람의 재미를 입증했다고 표현하지 않는다.
7. 기존 저장·스토리·성장 회귀 검사 후 최신 원격 main 통합, 합친 결과 재검증, main 푸시, Pages 성공·공개 파일 검증.

맵 전체 재제작은 다음 단계다. 이번에는 이야기와 성장 진행에 필요한 NPC 위치·이동 연결을 먼저 다듬는다.
