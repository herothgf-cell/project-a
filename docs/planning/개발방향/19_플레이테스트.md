# 19. 신규 여정 플레이 테스트

갱신: 2026-10-12 (KST) · 구현 대조: `main f5a5a3b` / 게임 `v0.15.0`

[기획 시작](../README.md)

## 실행 준비

저장소 루트에서 Node.js 20 이상으로 `npm start` 또는 `node server.cjs`를 실행한다. npm이 없어도 Node가 있으면 후자로 실행할 수 있다. 브라우저에서 서버가 출력하는 주소를 연다. 중요한 기존 저장은 먼저 내보낸다.

**새 흐름은 새로운 여정으로 확인한다.** 구 캠페인 저장의 이어하기는 이전 이력 보존 경로다. 옛 ‘2장 보고 후부터’나 기연 계승 개발 프리셋을 새 1~2장의 시작점으로 사용하지 않는다. 실제 키는 현재 입력 설정과 HUD를 따른다.

## 기본 흐름

1. 현실 지하역 출발 → 경계석 반응 → 무림 도착·백련 구조를 읽는다. 이미지와 화자를 확인한다.
2. 삼재검법 응급 전수 뒤 3웨이브에서 이동·기본 공격·회피를 사용한다. 적 선처치 후 남은 조작을 보완할 수 있는지 확인한다.
3. 출구 → 화산행 결심 → 준비. 캐릭터/무공·스킬의 레드닷을 확인하고 화면을 읽는다. 재료를 남겨도 알림이 사라져야 한다.
4. 스탯 초안 취소와 영구 확정을 구분한다. 검술·보법·내공에 자유 투자한다. 횡검을 배웠다면 단축키 설정에서 배치한다.
5. 미습득·미장착 기술이 HUD에 없고 이전 키로도 발동하지 않는지 확인한다. 배치·교환·해제 후 실제 기술·키·쿨다운이 일치해야 한다.
6. 장면 → 준비 → 다음 던전으로 화산행 10개 길목을 진행한다. 2/4/6 이후 남궁/무당/아미 만남이 수련 기회를 열되 특정 투자를 통행 조건으로 요구하지 않아야 한다.
7. 산문 완료 → 백련 치료 → 제자 수락 또는 거절. 수락 시 매화 제1초식을 배우고 직접 배치한다. 거절해도 귀환길이 열린다.
8. 천흔 옛길 뒤 선택 기연에 도전하거나 건너뛴다. 검은 진영 → 천흔 수문장 → 첫 현실 귀환·서린 재회로 끝난다.

## 사람의 플레이 관찰

적 수가 늘었는지만 보지 않고 공격 예고를 읽을 시간과 기술을 시험할 기회가 있었는지 본다. 화산행 목적·문파 만남·투자 효과·편성 방법을 플레이어가 설명할 수 있는지 묻는다. 장면의 길이와 반복 이미지가 전투 흐름을 방해하는지도 기록한다. 성공률·완주 시간의 임의 합격선을 이 문서에서 확정하지 않는다.

모델: `tests/murim-scenes.test.cjs`, `tests/murim-loadout.test.cjs`, `tests/murim-notices.test.cjs`와 기존 여정 검사. 화면: `tests/murim-scenes.browser.cjs`, `npm run test:browser:murim`. 전체: `npm test`, `npm run check`, `npm run check:revision`, `npm run check:world` 및 저장소 워크플로의 브라우저 검사.

이 문서는 **테스트 절차**다. 실행·통과 보고는 별도이며 과거 통과 수를 새 검증의 증거로 쓰지 않는다.
