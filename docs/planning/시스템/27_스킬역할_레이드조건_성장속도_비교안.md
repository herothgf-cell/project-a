## 1. 비교 범위와 결론

일반 기술은 현재 보이는 빈틈에 대응하고, 매화 연결은 적의 다음 위치·큰 공격 기회를 예측하는 역할로 비교한다. 일반=약한 시작 기술, 연결=무조건 교체할 상위 기술로 만들지 않는다. 매화는 일반 전수 무공이며 희귀 기연의 성능 우대 원칙과 동일하게 취급하지 않는다.

사용자가 확정한 2슬롯·완료 숙련·유료 연결·두 임무 조건·교체 사용 인정·체크포인트 보존은 유지한다. D-053~055로 G2 연속 적중 보강, 첫 기본 공략 후 두 조건 동시 개방·동일 반복 보상·최초 추가 보상 전체 1회, 단일 기술 집중 수련을 확인했다. 이하 배율·동작 시간·과제 시간·적 수치는 설계 비교값이며 시뮬레이션 결과가 아니다. 어느 편성의 실제 클리어가 몇 분 빠르다고 단정하지 않는다.

## 2. 스킬별 역할과 비교 수치

A는 현재 현실 공격력이다. 강화·성취·방어가 없는 단일 대상 기준이며, 피해/마력은 기본 공격과 행동 시간을 포함하지 않은 제한된 지표다. G2는 D-053에 따라 연속 적중 보상을 보강한다. 기존 1.1A×2를 비교 기준으로 남기고 새 1.0A+1.8A는 검토 수치로 둔다.

| 기술 | 역할 | 비교 후보 | 지불하는 대가 | 피해/마력 |
|---|---|---|---|---:|
| G1 집중 타격 | 움직이는 표적·짧은 빈틈을 놓치지 않음 | 1.8A / 마력14 / 재사용3초 | 단일 대상, 큰 창의 순간 피해는 낮음 | 0.129A |
| G2 연속 타격 | 중간 길이의 빈틈에 두 타격 완성 | 1.0A+1.8A / 마력20 / 재사용5초 | 2타까지 머물러야 함. 1타 후 회피하면 1.0A만 남고 비용 환불 없음 | 완성0.140A / 중단0.050A |
| R1 마력 개화 | 집결할 위치를 예측해 여러 표적 처리 | 0.8초 뒤 대상별2.4A / 마력18 / 재사용8초 | 지정 위치 고정, 빗나가도 소모 | 1명0.133A / 3명0.400A |
| R3 응축 검격 | 예측한 큰 빈틈에 집중 | 준비0.6초 후3.8A / 마력26 / 재사용10초 | 높은 1회 비용, 준비 중 취소하면 피해 없이 소모 | 0.146A |
| R2 회피 연계 | 실제 회피를 다음 연결의 자원 이득으로 전환 | 다음 R1/R3 비용20% 절감, 4초 기본 지속 | 실제 위협 회피·기간 내 소비 필요, 1충전 | 기본 R1 비용14.4 / R3 비용20.8 |

G2는 기존 총2.2A에서2.8A로 약27% 높이는 비교안이다. R3의 총3.8A와 비교하면 한 번의 큰 기회는 R3가 강하고, 기회가 자주 오면 G2의 짧은 재사용이 장점이다. R3가 G2보다 준비 시간이 짧으므로 ‘G2가 항상 더 안전하다’고 설명하지 않는다. G2의 장점은 자주 사용할 수 있다는 점과 준비 중 완전 손실 대신 첫 타격이 남는 점이다.

**동작 비교 후보:** G1은 입력 후0.15초 적중·0.35초 행동 종료, G2는0.15/0.85초 적중·1.0초 종료, R1은0.25초 시전 뒤 이동 가능·0.8초 폭발, R3는0.6초 적중·0.8초 종료. 재사용은 발동 확정부터 계산한다. G2는 2타 자동 추적을 보장하지 않고, 표적이 범위를 벗어나면 빗나간다. 적 공격·사거리·입력 지연까지 검증하기 전 반응성의 우열을 확정하지 않는다.

### 같은 공격 창에서 한 기술만 비교

창 시작 시 재사용 완료·마력 충분·제자리 표적·추가 기본 공격 없음·다음 공격 전 행동 종료 기준이다. 다른 기술을 섞은 실제 연계 피해가 아니다.

| 안전한 창 | G1 | G2 후보 | R1 | R3 |
|---|---:|---:|---:|---:|
| 0.5초 | 1회1.8A | 1타1.0A 후 취소 | 먼저 설치하고 이탈 가능하나 적이 남아야 2.4A | 안전하게 완성 불가 |
| 2초 | 1회1.8A | 1회2.8A | 1회2.4A | 1회3.8A |
| 6초 | 0/3초 발동, 합3.6A | 0/5초 발동, 합5.6A | 1회2.4A | 1회3.8A |

마력3/초 회복에서 쿨다운마다 쓴 이론 소비는 G1=4.67/초, G2=4/초, R1=2.25/초, R3=2.6/초다. G1+G2를 계속 쓰는 편성이 오래 유지된다는 뜻은 아니다. 기본 검격으로 시간을 메우고 좋은 창에만 기술을 쓰게 한다. R1+R3도 합4.85/초로 기본 회복을 넘는다. R2는 자원 부담을 줄이지만 회피 성공과 소비 기회를 모두 만족해야 하므로 항상20% 절감으로 계산하지 않는다.

## 3. 두 레이드 조건의 실제 차이

이름은 각각 **A 집결 억제**, **B 핵 공략** 후보. 기본 첫 공략은 기존 교육 흐름이고 두 조건은 이후 반복 선택이다. D-054에 따라 첫 기본 공략 후 둘 다 개방하고 반복 보상·숙련은 동일하다. 최초 추가 보상은 레이드 전체 1회이며 조건별 재지급은 없다. 보상 수량은 검토값이다.

| 항목 | A 집결 억제 | B 핵 공략 |
|---|---|---|
| 중심 판단 | 주변 위험을 먼저 줄일지, 지지체부터 끊을지 | 현재 짧은 창을 쓸지, 다음 돌진/노출을 기다릴지 |
| 소환체 | 최대3, 지지체 한쪽 주변의 예고된 집결점으로 이동 | 최대1, 측면 견제. 집단 처리 필요성 감소 |
| 지지체 | 서로 떨어진2개. 하나 주변에 집결점 배치 | 떨어진2개. 돌진 회복 때 가까운 것부터 처리 |
| 외피 중 패턴 주기 | 내려찍기→집결 이동/1초 정지 예고→휩쓸기→돌진 | 내려찍기→돌진→휩쓸기→돌진 |
| 압박 조절 | 소환체 집결 공격과 보스 공격 판정을 겹치지 않는 순서로 배치 | 소환체 수를 줄이는 대신 보스의 돌진 대응을 더 자주 판단 |
| 지지체 파괴 뒤 | 핵6초 노출, 잔여 소환체 첫2초 공격 정지 | 핵6초 노출, 집중 공격 기회 |
| 일반 경로 | G1으로 소환체 수를 줄이고 G2로 지지체 마무리 | G1은 짧은 창, G2는 돌진 회복과 핵 노출 |
| 매화 활용 | R1으로 소환체+지지체 동시 피해 | R3로 돌진 뒤 집중 피해, R2 할인 소비 |
| 실패 회복 | 최대 수 제한과 기본 공격으로 개별 정리 | 돌진을 놓쳐도 다음 창 대기, 즉사/전멸 타이머 없음 |

공통: 보스 HP 단계100~65/65~30/30 이하, 외피 감소40%, 핵 노출 추가피해25%, 지지체 재생성은 노출 종료 뒤 기본 공격 패턴2회 완료 이후다. 집결 연출은 이2회에 포함하지 않는다. 소환체 처치를 입장·완료 필수 조건으로 추가하지 않는다. 강한 플레이어가 기믹을 건너뛰는 것도 허용한다.

**패턴 순서 보완:** 3단계의 돌진→2초 회복 보장→내려찍기 전조→내려찍기 순서로 제안한다. ‘연속 패턴’이라는 이유로 이미 안내한 공격 창을 빼앗지 않는다. R2는 돌진 자체를 실제 회피한 직후 그 회복 창에 R3로 소비하는 예시를 쓴다. 벽에 막혀 닿지 않을 돌진은 R2 충전을 주지 않는다.

### 표적 처리 비교용 기준

A₀는 첫 레이드의 기준 공격력이며 플레이어 성장에 따라 적 체력을 자동 재조정하는 값이 아니다. 지지체 HP2.8A₀, 소환체 HP1.6A₀를 우선 비교 후보로 둔다. 기본 검격1.0A₀·1초 주기는 장부 비교 가정이며 실제 기본 공격을 변경한 것이 아니다.

- 기준 G1은 소환체1마리를 한 번에 처리한다. G2는 같은 소환체에2타가 필요하므로 잡몹에서 자동 우위가 아니다.
- 기준 G2 완성/R3는 지지체1개를 한 번에 처리할 수 있다. G1은 기본 검격1회와 조합한다.
- R1은 집결한 소환체를 정리하고 지지체에2.4A₀를 남긴다. 지지체는 기본 공격으로 마무리한다. 두 지지체를 R1 하나로 동시에 맞히지 못하는 배치는 유지한다.
- 보스 HP와 전체 이동 시간은 아직 검토가 필요하다. 표적 처리 수치는 공략 역할을 비교할 뿐 8~12분 완주를 증명하지 않는다. 외피 직공 대비 지지체 처리 시간이 이득인지 별도 확인한다.

## 4. 6개 편성과 공략 선택

| 편성 | A 집결 억제 | B 핵 공략 | 성장/실패의 특징 |
|---|---|---|---|
| G1+G2 | 소환체G1→지지체G2→핵에 연속 공격 | 짧은 창G1→돌진G2→핵에 재사용 | 무림 연결 준비 없이 시작. 자원 연타 주의 |
| G1+R1 | 집결점R1→반대 지지체G1+기본 | 짧은 창G1, 고정 표적에R1 | R1 빗나가도 즉시 공격 수단 유지 |
| G2+R1 | R1 집결 처리→G2 지지체→핵 | 돌진/노출G2, 지지체R1+기본 | 집결과 연속 공격 대응, 짧은 창은 기본 검격 |
| G1+R3 | 소환체G1→지지체/핵R3 | 짧은 창G1→큰 창R3 | B에 역할이 명확. A는 여러 적을 한 번씩 처리 |
| G2+R3 | 소환체는 기본 검격, 지지체에 기술 분배 | 돌진마다 G2/R3 준비 상태 보고 선택 | 단일 피해 목적이 겹치고 마력 부담 큼. 편성 금지 대신 약점 공개 |
| R1+R3 | 집결R1→지지체/핵R3 | 짧은 창은 기본, 핵에R1/R3 | 예측 실패 시 긴 재사용 공백. R2 없다고 막히지 않음 |

R2는 보유하고 실제 조건을 만족할 때에만 이득을 더한다. A에서 R1 편성이, B에서 R3 편성이 좋아질 가능성은 있지만 실제 완주 시간은 입력·배치·기본 공격·성장에 따라 달라진다. 모든 조건에서 연결2개만 최선이면 일반 기술/패턴을 다시 조정한다.

**중간 편성 예시:** 정찰G1/R1→보스G2/R3는 실제 효과를 낸4기술 모두 최종 성공 시 +1 가능하다(D-050). 보스에 실패하면 정찰G1/R1은 보존하되 실패 시도G2/R3는 지운다(D-051). 숙련을 위해 모두 한 번씩 누르고 교체하는 절차를 임무 목표로 요구하지 않는다. 고정2개로 도는 경로도 함께 비교한다.

## 5. 성장 속도 — 재료와 숙련을 함께 계산

공통 가정: 레이드 성공1회8~12분, 첫 회 결정4/XP120, 이후 결정2/XP80, 실제 사용 기술별+1, 활용3/숙련8. 두 조건에서 같은 보상을 받는 비교안이다. 실패·거점 이동·대화 시간은 제외한다. XP로 오르는 레벨 수는 별도 필요 경험치가 없어 계산하지 않는다. 숙련3/8·가격2/3은 현재 후보를 사용한다.

| 목표 | 귀환 직후 남은 것 | 비용 후보 | 집중 수련2~3분 가정 시 |
|---|---|---|---|
| R1부터 활용 | 노방 완료1회 | 기초 각인1+결정2 소비 | 2~3분 추가 |
| R2 추가 | 접무 완료1회 | 접무 최초 정산 각인1+결정2 소비 | 2~3분 추가 |
| R3 추가 | 토염 완료2회 | 토염 최초 정산 각인1+결정3 소비 | 4~6분 추가 |
| R1/R2/R3 모두 | 위4개 과제 | 총 각인3+결정7 | 8~12분 추가, 이동/대화 제외 |

R3는 R2 학습을 선행으로 요구하지 않는다. 늦은 제자 수락자는 위 사례보다 준비가 더 필요하다. 노방0에서 단일 기술 과제만 쓴다면 노방3·접무3·토염3=9과제(18~27분)와 학습 수련첩4가 필요하다. 순서는 노방1→접무 학습→접무1→토염 학습 이후 자유다. 기초 삼재 성취는 별도이며 미달이면 해당 과제를 추가한다. 수련첩이 없으면 무림 토벌로 확보해야 하므로18~27분을 총 소요시간으로 안내하지 않는다.

### 정식 수련을 섞는 비교안

D-055에 따라 정식 수련은 지정 기술1종의 짧은 집중 과제로 제공하고 완료+1·재화/XP 없음으로 구분한다. 목표2~3분과 과제 내용은 검토값이다. 액티브는 목표에 유효 사용하고 과제를 완료해야 하며 타이머만 기다려 종료하지 않는다. G1은 이동 표적 대응, G2는 안전 창에서2타 완성, R1은 집결 예고 위치 지정, R3는 예고된 정지 창 공격을 연습한다. R2는 충분한 전조의 회피→할인 소비로 과제를 구분한다. 지정 외 기술의 동반 숙련은 지급하지 않으며 레이드 D-050의 실제 사용 전체 인정과 구분한다.

| 목표 | 레이드 중심 | 수련 혼합 | 차이 |
|---|---|---|---|
| 액티브1개 강화2까지 | 레이드8회:64~96분, 결정18−5=13, XP680 | 레이드2회+해당 수련6회:28~42분, 결정6−5=1, XP200 | 혼합은 특정 기술을 빨리 완성, 남는 자원·다른 기술 숙련 적음 |
| 액티브2개 강화2까지 | 레이드8회:64~96분, 결정18−10=8, XP680 | 레이드4회+각 기술 수련4회(총8):48~72분, 결정10−10=0, XP360 | 혼합은 두 기술만 집중, 레이드는 추가 자원 축적 |

수련만으로 숙련8을 채워도 강화 결정을 얻지는 못한다. 반대로 재료만 많아도 미사용 기술의 숙련을 살 수 없다. 무림 정산 잔액·다른 투자·실패가 있으면 표는 달라진다. 특정 기술을 연습하고 싶은 플레이어에게 수련 효율이 더 좋은 것은 의도한 선택이며, 레이드를 무조건 숙련 최적지로 만들 필요는 없다.

### 늦게 R1을 선택한 경우

일반G1/G2로3회 성공 후 R1을 학습하면 R1의 숙련은0이다. 이후 매회 R1을 쓰면 총6번째 레이드에서R1 활용3, 총11번째에서숙련8이다. 첫 레이드부터 계산하면88~132분이지만 앞의3회가 사라진 것은 아니다. 일반 성장과 보상은 그대로 남는다. R1 수련을 섞으면 추가8회 레이드 강제를 피할 수 있다.

재료 예시: 기초 정산 결정2를 쓰지 않고 시작→레이드3회 결정8→G1/G2 강화1에4 사용→잔액6→R1 학습2 소비→잔액4. 이후R1 과제8회(16~24분)만 완료하면 숙련8은 되지만 강화 총비용5에서1이 부족하다. 레이드1회를 더 섞고 수련을7회로 줄이면 추가22~33분에 R1 숙련8·강화2까지 가능(결정4+2−5=1). 기초 각인1과 노방 활용을 이미 확보한 경우에만 성립한다.

## 6. 확인 기준과 남은 설계

- 두 조건의 보상은 같은데 소요시간이 크게 다르면 빠른 조건만 파밍하게 된다. 먼저 이동·적 배치·회복 창을 조정하고 조건별 필수 일일 보상으로 이동을 강제하지 않는다.
- 체크포인트 복원은 보스 재도전 시작 상태를 명시해야 한다. 비교안은 HP/MP 전부·임무 회복2회로 복원하되, 새 회차 보상/숙련을 지급하지 않는 방식이다. 실제 값은 미확정이다.
- 실제 이동·모션·보스 HP·적 피해가 없으므로 공략 속도 우열은 미검증이다. 일반/혼합/연결 각 편성에서 최소한 A/B 한 번씩 동일 기준으로 비교해야 한다.
- 지지체를 처리하는 전략이 외피 직공보다 유리한지, G2 두 타격 보상이 유지되는지, R1 집결 예측이 모바일에서도 가능한지 우선 검증한다.
- 수련이 기술을 배우는 목적보다 타이머 대기로 느껴지면 과제 구성을 줄인다. 무림과 현실의 같은 기술을 동일 표적 과제로 반복하지 않도록 무림은 초식 운용, 현실은 레이드 상황 적용으로 구성한다.

이번 비교는 신규 기술 버튼·기연·문파 시스템을 추가하지 않는다. 기존 선택지4개와 연결 패시브1개의 역할을 검토하며, 새 일반 기술은 이 비교로도 선택 폭이 부족할 때 별도 확인한다.
