## 1. 확인된 정책과 계산 범위

- D-039: 첫 현실 연결 기술부터 기존 연결 재화로 학습. 성취는 자격이고 무료 기술 지급이 아니다.
- D-041: 공명 결정은 무림 성취 정산 외에 현실 레이드에서도 획득. 무공 각인은 무림 성취 전용.
- D-042: 첫 귀환 뒤 안정화 사건 후 안전 거점에서 양세계 왕복. 전투 도중 전환 불가.
- D-038/044: 매화와 현실 개별 숙련은 실제 사용한 전투·정식 수련 완료 기준.
- 기존 영구 투자·환불 금지, 세계별 성장 분리, 현실→무림 재료 환전 없음은 유지.

아래 공급량·가격·경험치·상한은 신규 여정 비교용 후보이며 사용자 확인으로 수치까지 확정된 것은 아니다. 기존 게임에 이 보상을 지급한 것으로 설명하지 않는다. 본 예산표는 새로운 회차와 출처를 기준으로 계산하며, 기존 카탈로그 보상과 중복 지급하지 않도록 이행 시 출처 대조가 필요하다.

## 2. 재화 역할

| 자원 | 목표 공급 | 용도 | 경계 |
|---|---|---|---|
| 단련석 | 기존 무림 최초 진행 보상 유지 | 무림 공통 스탯 | 반복 토벌의 무제한 지급은 이번에 추가하지 않음 |
| 수련첩 | 기존 최초 보상 + 새 무림 반복 토벌 | 공통/무공 고유 학습·강화 | 현실에서 지급·환전하지 않음 |
| 무공 각인 | 무림 일반/개별 무공 성취의 최초 정산 | 현실 연결 기술/노드 학습 | 레이드 반복 드롭·원화 구매·영구 자격으로 변경하지 않음 |
| 공명 결정 | 무림 성취 최초 정산 + 현실 레이드 | 현실 일반 강화·연결 학습/강화 | 수련첩 환전 없음, 투자 상한 별도 |
| 경험치 | 활동한 세계의 전투 완료 | 해당 세계 레벨 | 양세계 동시 경험치 복사 없음 |

일반 현실 기술 G1/G2 기본 습득에는 각인을 요구하지 않는다. 일반 기술의 강화를 위해 무림 특별 무공을 배워야 하는 조건도 없다. 연결 성취와 최초 정산은 일회성이며 회상·반복 수련·세계 왕복으로 같은 자원을 재발급하지 않는다.

## 3. 무림 최초 성취 정산 후보

**D-049:** 각인을 소비하는 연결 노드를 추가할 때 추가 학습 비용을 확보할 수 있는 공개된 무림 성취도 함께 설계한다. 보상은 공용 각인이며 투자 순서는 자유롭다. 같은 성취의 재지급·무한 반복 각인 파밍·투자 환불은 추가하지 않는다. 공급 성취가 해당 미습득 현실 연결을 필수로 요구해 순환 잠금을 만들지 않아야 한다. 아래 매화 예산은 현재 3종만의 예시이며 다른 연결을 추가할 때 공급·소비 전체를 다시 대조한다.

| 출처 키(기획용) | 조건 | 각인 | 결정 | 의도 |
|---|---|---:|---:|---|
| basic-practice-first | 삼재 기초 기술을 유효 사용한 무림 전투/정식 수련 누적 3회 | 1 | 2 | 기연·매화 없이 확보하는 첫 연결 재료 |
| plum-step-practice | 매화접무 활용 단계 최초 달성 | 1 | 2 | 접무 연결 노드의 학습 예산 |
| plum-focus-practice | 매화토염 활용 단계 최초 달성 | 1 | 3 | 토염 연결 노드의 학습 예산 |

노방 활용은 R1 자격을 열지만 별도 각인/결정을 다시 주지 않는 안이다. 노방의 최초 비용은 기초 수련 보상에서 충당할 수 있다. 사용자는 그 결정을 일반 강화에 먼저 써도 되며, 부족한 결정은 일반 레이드로 다시 확보할 수 있다.

이 3종의 표상 합계는 각인 3·결정 7이다. 기존 기본기 정산과 같은 행동을 이중 보상하지 않는다. 현재 코드에는 위 키와 새 매화 완료 집계가 없으며, 이행 설계 전 옛 `practice:training` 등과의 실제 매핑을 확정하지 않는다. 기존 저장의 보상 잔량·투자·출처는 보존한다.

무림에서 조건을 달성하면 정산 대기 상태로 기록하고 현실 거점 도착 시 한 번 확인한다. 필요한 재료와 획득처는 양쪽 성장 화면에서 볼 수 있다. 매화 거절자는 첫 각인을 보유해 다른 연결에 사용할 수 있으며 자동 매화 보상으로 바뀌지 않는다.

## 4. 반복 활동 보상 후보

[DOC-28](28_정식수련과_무림반복토벌_기획안.md)에 과제·토벌·재도전과 매화 연결 사례를 상세화했다. D-056/057로 기본 과제 완료와 무림 토벌의 두 구성 선택을 확인했다. 토벌4~6분·수련2~3분은 비교 목표다. 수련 자체에는 반복 재료/XP가 없지만 수련으로 달성한 기존 최초 성취의 일회성 각인·결정 정산은 가능하다.

**D-054/055 반영:** 첫 기본 공략 후 두 조건을 함께 개방하며 반복 보상·숙련은 동일하다. 최초 추가 보상은 레이드 전체 1회만 지급한다. 기존 변이 3결정/100경험치·기본 3회 해금 후보는 대체했다. 정식 수련은 지정 기술1종의 짧은 집중 과제로 완료 숙련+1·재화/경험치 없음이며 목표2~3분은 검토값이다.

| 활동 | 매 완료 보상 | 최초 추가 | 숙련 | 제한/완료 단위 |
|---|---|---|---|---|
| 무림 정식 수련 | 재료 없음 | 없음 | 지정·유효 사용 초식 +1 | 한 번의 공개된 수련 과제 완료. 미리보기와 구분 |
| 무림 반복 토벌 | 수련첩 1, 무림 경험치 40 | 없음 | 유효 사용한 무림 기술마다 +1 | 한 회차 완료. 기존 길목 최초 지급과 분리 |
| 현실 정식 수련 | 재료 없음 | 없음 | 지정·유효 사용 기술 1종 +1 | 기초 조작/연결 연습, 연결 재료 파밍 불가 |
| 기본 지하역 레이드 | 공명 결정 2, 현실 경험치 80 | 최초 공략만 결정 +2, 경험치 +40 | 유효 사용 현실 기술마다 +1 | 정찰부터 핵 확인까지 한 회차. 보스 재도전은 동일 회차 |
| 두 조건 반복 레이드 | 공명 결정 2, 현실 경험치 80(수량 후보) | 없음: 레이드 전체 최초 보상과 중복 지급 안 함 | 유효 사용 기술마다 +1 | 첫 기본 공략 후 두 조건 동시 개방(D-054) |

기본 첫 성공의 총 보상은 결정 4·경험치 120이며 반복 기본은 결정 2·경험치 80이다. 각인은 어느 레이드 보상에도 없다. 첫 보상에 반복 보상을 포함했는지 UI에 명시한다. 반복 토벌과 정식 수련은 왕복 안정화 이후 개방하는 안이며 응급 호송 중 필수 반복을 요구하지 않는다.

재접속·보상 재표시·체크포인트 복구는 새 회차가 아니다. 새 입장해 목표를 다시 완료한 경우만 반복 보상을 받는다. 실패/철수는 완료 재료·경험치·숙련을 주지 않으며 이전 영구 성장은 잃지 않는다. D-051에 따라 같은 회차의 보스 재도전에서는 체크포인트 이전 완료 구간의 유효 사용 기록을 보존하고, 실패한 보스 시도의 기록만 지운다. 체력·마력·회복 횟수는 체크포인트에 정한 상태로 복원한다. 복원 수치는 별도 검토 대상이며 매번 누적 지급하지 않는다. 철수로 회차를 종료하면 미정산 임시 기록을 폐기한다.

수련은 선택 숙련에 집중하고 토벌은 재료와 숙련을 함께 얻는다. 수련의 1회 길이와 토벌 효율은 플레이 검토 대상이며, 수련이 너무 빨라 실제 전투가 손해가 되거나 반대로 의미 없을 정도로 느려지면 조정한다.

## 5. 현실 학습·강화 가격 후보

| 대상 | 조건 | 가격 | 영구 효과 후보 |
|---|---|---|---|
| G1/G2 기본 | 윤서의 기존 기본 능력, 귀환 후 재안내 | 연결 재화 없음 | 일반 기술 사용 가능 |
| G1 강화 1 / 2 | G1 활용 3회 / 숙련 8회 + 강화 1 | 결정 2 / 3 | G1 피해 각각 +5%, 해당 기술에만 적용 |
| G2 강화 1 / 2 | G2 활용 3회 / 숙련 8회 + 강화 1 | 결정 2 / 3 | G2 피해 각각 +5%, 두 타격에 동일 적용 |
| R1 학습 | 노방 활용 + 현실 귀환 | 각인 1 + 결정 2 | 마력 개화 기본 |
| R1 강화 1 / 2 | R1 활용 3회 / 숙련 8회 + 강화 1 | 결정 2 / 3 | R1 피해 +5% / R1 마력 비용 −2, 최저 1 |
| R2 학습 | R1 습득 + 접무 활용 | 각인 1 + 결정 2 | 실제 회피 후 연결 기술 비용 할인 |
| R3 학습 | R1 습득 + 토염 활용 | 각인 1 + 결정 3 | 응축 검격 기본 |
| R3 강화 1 / 2 | R3 활용 3회 / 숙련 8회 + 강화 1 | 결정 2 / 3 | R3 피해 +5% / R3 마력 비용 −2, 최저 1 |

R2는 이번 안에서 추가 유료 강화 없이 기본 효과로 비교한다. 수집한 무공 전체로 일반 공격력이 자동 합산되지 않는다. 표 밖 장기 강화는 아직 개방하지 않는다. G1/G2/R1/R3의 단계별 자체 성취 보너스는 별도 피해 +0/2/4% 비교안이며, 유료 강화와 구분해 전후 값을 보여준다. R2의 독립 성취는 입문/활용/숙련을 기록하되 직접 피해 보너스를 주지 않고, 후보 효과는 할인 유효 시간 4/4.5/5초다. 할인율은 모두 20%로 고정한다. 할인 계산은 고정 소모 감소 후 R2 20%를 적용하고 최종 비용 최저 1로 제한하는 안이다.

현실 학습 3종 전체 비용은 각인 3·결정 7이다. 일반/연결 액티브 4종을 모두 2단계 강화하면 결정 20이 추가된다. 기본 학습과 강화는 상호 배타적이지 않고 투자의 순서와 편성에서 선택한다. 장기 반복 공급이 있더라도 현재 구간의 강화·공통 투자 상한을 넘겨 무제한 스탯을 올리지 않는다.

기존 일반 공명 투자 상한을 이 문서로 해제하거나 레벨 상한을 바꾸지 않는다. 상한까지 투자한 뒤 남는 결정은 보유할 수 있지만 무한 파밍을 요구하는 장비/가챠 소비처를 덧붙이지 않는다.

## 6. 예산과 막힘 검토

[DOC-27](27_스킬역할_레이드조건_성장속도_비교안.md)은 일반/혼합/연결 편성의 성장 속도, 무림 준비 시간, 집중 수련과 레이드의 비용·시간을 비교한다. 시간은 후보값을 이용한 장부 계산이며 실제 공략 시간·레벨 상승량을 측정한 것이 아니다.

| 경우 | 시작·행동 | 계산 | 결과 |
|---|---|---|---|
| 매화 없이 첫 레이드 | 기본 기술 보유, 연결 소비 없음 | 첫 성공 결정 +4 | 무림 특수 성취 없이 일반 강화 예산 확보 |
| 첫 연결 즉시 학습 | 기초 정산 각인 1·결정 2, 노방 활용 | R1 비용 각인 1·결정 2 | 잔량 0/0, R1 사용 가능. 기술 자체는 무료 아님 |
| 결정을 먼저 사용함 | 각인 1·결정 0, R1 미학습 | 일반 기본 레이드 반복 결정 +2 | R1 없이 재료를 얻어 R1 학습, 순환 잠금 없음 |
| 세 연결 노드 목표 | 기초+접무+토염 최초 정산 | 공급 각인 3·결정 7 = 학습 비용 3/7 | 기연 없이 전체 학습 재료 확보 가능 |
| 다른 강화에 결정 소비 | 학습 자격·각인은 보유 | 기본/두 조건 반복 1회 결정 2 | 추가 레이드로 비용 복구 가능, 투자 환불 불필요 |
| 매화 학습 재료 소진 | 접무/토염 선행 성취, 수련첩 0 | 무림 반복 토벌 2회 ×1 | 다음 초식 비용 2 확보 |

세 연결을 살 자원은 마련되지만 모든 강화와 동시에 무료로 받는 구조는 아니다. 다른 계열의 각인 소비 기회까지 모두 충족하는 예산은 이번 표가 증명하지 않는다. 다른 무공을 추가할 때 일반 성취 공급과 영구 투자 선택을 함께 다시 검토한다.

**회차 예시(기본만 반복):** 기초 정산→R1 학습으로 결정 0에서 시작. 기본 3회 보상 4+2+2=8, R1 활용 조건 달성 후 강화 1 비용 2를 내면 6. 기본 총 8회 보상 4+7×2=18, 강화 1·2 합계 5를 내면 13. 이 예시는 그 외 소비·공통 투자·추가 정산이 없을 때의 장부 계산이며 실제 성장 속도/재미 검증이 아니다.

## 7. 현실 숙련·수련 세부

- 액티브는 성공 회차 안에서 유효한 적/목표에 실제 효과를 낸 발동이 있어야 +1. 편성만으로 지급하지 않는다.
- D-050: 사용 당시 편성되어 유효 사용한 기술은 안전 지점에서 교체한 뒤에도 최종 성공 시 숙련 대상으로 인정한다. 기술당 회차 최대 +1이며 반복 사용·재편성·체크포인트 복구로 추가되지 않는다. 종료 시 편성된 2개로 대상을 제한하지 않는다.
- R2는 실제 할인된 R1/R3 사용이 최소 1회 있는 성공 회차에 기록한다. R2 충전만 하거나 허공 회피는 무효. R1/R3 자체의 유효 사용 판정과 구분한다.
- 단계 후보는 입문 0, 활용 누적 3, 숙련 누적 8. 무림과 진행도를 공유하지 않는다. 완료 단위 방식은 확인됐지만 이 숫자는 검증안이다.
- 기본·변이 레이드 모두 회차당 +1. 높은 난이도는 재료/공략 성취로 보상하고 숙련을 강제로 몰아주지 않는 안이다.
- 최대 숙련 초식을 편성했다고 다른 미사용 초식에 대신 지급하지 않는다. 기본 검격의 별도 성취와 선택 초식의 기록은 구분한다.
- 실패한 보스 시도만의 임시 기록은 이월하지 않는다. 같은 회차의 완료 구간 기록은 D-051에 따라 보존하되 최종 성공 전에는 숙련으로 확정하지 않는다. 이미 성공해 확정된 숙련은 실패로 줄지 않는다.

**판정 예시:** 정찰에서 G1/R1 유효 사용→안전 지점에서 G2/R3로 교체→보스 시도에서 R3 사용 후 실패→재도전 성공 시 G2만 유효 사용했다면, 최종 숙련은 G1/R1/G2 각각 +1이다. 실패한 보스에서만 사용한 R3는 +0이다. 성공한 재도전에서도 R3를 유효 사용하면 R3도 +1이다. 각 기술은 여러 구간에서 사용해도 합계 +1을 넘지 않는다.

## 8. 과도한 반복과 경제 검증 기준

첫 연결을 얻기 위해 연결 기술이 필수인 콘텐츠를 요구하지 않는다. 일반 경로의 반복 재료 공급을 마련하고, 무림 성취에만 각인 자격과 공급을 두어 두 세계의 역할을 유지한다.

검토할 위험: (1) 쉬운 전투 한 번에 기술을 눌러 숙련만 챙기는 행동, (2) 반복 수련이 스토리보다 길어지는 상황, (3) 결정이 너무 풍부해 투자 순서가 무의미해짐, (4) 각인 부족으로 다른 무공 선택이 영구적으로 막힘, (5) 변이가 시간 대비 기본보다 불리함. 가격/지급량/수련 길이를 수정하고, 재료 수집을 늘리는 것만으로 해결하지 않는다.

이 문서는 새 경제의 목표안이다. 게임 코드·저장 이행·수치 밸런스는 구현하지 않았으며, 최초 보상의 실제 이행 대응과 플레이 시간 검증은 개발 전 별도 확인한다.
