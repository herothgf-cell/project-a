# 23. 현실 레이드 — 지하역 집수정 균열

## 1. 목적·확정과 제안의 구분

현실의 핵심 경험은 준비한 스킬로 균열을 반복 공략하고 성장하는 것이다. 대표 레이드 1종 안에서 일반 기술의 즉시 대응과 매화 연결 기술의 예측 공격을 비교한다. 일반 기술만으로 정상 공략 가능하며 연결 기술·기연·정밀 회피를 입장 조건으로 요구하지 않는다. 현재 싱글 PvE이며 파티 역할·매칭·실제 유저 랭킹을 선행조건으로 두지 않는다.

사용자 확인: 공명 결정은 레이드에서도 공급, 무공 각인은 무림 성취 전용(D-041). 첫 귀환 후 짧은 안정화 사건을 거쳐 비전투 거점 왕복(D-042). 일반·연결 기술 공용 액티브 2슬롯(D-043). 현실 개별 숙련도 전투·정식 수련 완료 기준(D-044). 첫 연결 기술도 재화를 소비해 학습한다(D-039).

아래 명칭·수치·패턴·보상량·대사는 수정/폐기 가능한 제안이다. 사용자 답변이 보스 수치나 전체 강화안의 승인까지 뜻하지 않는다. 기존 현실 코드·구 캠페인·저장에는 적용하지 않았다. 별도 SF 장치, 문파 운영, 신규 장비 경제를 추가하지 않는다.

## 2. 콘텐츠 개요

| 항목 | 제안 |
|---|---|
| 이름 | 지하역 집수정 균열 — 균열 갑각수 토벌 |
| 이야기 목적 | 귀환한 지하역의 잔류 균열이 배수 구역으로 번지는 것을 억제 |
| 기본 진행 | 입구 정찰 → 집수정 접근 전투 → 안전 준비 지점 → 보스 → 핵 확인·정산 |
| 플레이 기준 | 1인, 일반 기술 2개로 완주 가능한 난이도 |
| 최초 입장 | 첫 귀환·상태 확인·왕복 안정화 사건 완료. 매화/R1/랭킹 수치 제한 없음 |
| 반복 입장 | 최초 공략 후 잔류핵 재응집 토벌. 같은 보스 형상은 재응집체이며 첫 이야기 재실행 아님 |
| 실패 | 해당 회차 보스·전투 상태 초기화. 기존 투자·숙련·보상 유지, 재도전 가능 |
| 회차 길이 목표 | 정찰 포함 8~12분, 재도전은 학습에 따라 단축. 측정 결과가 아닌 목표 |
| 반복 목표 | 성장 재료 확보, 선택 기술 숙련, 안정된 공략, 변이 조건 도전 |

본 임무는 ‘영구 봉쇄 완료’라고 말하지 않는다. 당장의 확산과 핵을 억제하되 잔류 균열은 남아 반복 토벌이 필요하다는 정보를 첫 정산 때 전달한다.

## 3. 일반·연결 기술과 편성

역할·6개 편성·두 임무 조건의 상세 비교는 [DOC-27](27_스킬역할_레이드조건_성장속도_비교안.md)에 정리했다. D-053으로 G2 연속 적중 보강 방향을 확인했으며 아래 새 배율과 동작 시간은 검토 수치다. 실제 전투 검증 결과가 아니다.

기본 검격·기본 회피는 별도 유지한다. 액티브는 일반 G1/G2와 학습한 R1/R3 중 2개를 고른다. 같은 기술 중복 배치 불가. 안전 준비 지점과 거점에서만 교체하며 보스전 중에는 바꿀 수 없다. R2는 학습한 연결 패시브로 슬롯을 차지하지 않으며 편성한 R1/R3에만 작용한다.

| 기술 | 획득·선행 | 효과·수치 후보 | 좋은 상황 | 약점 |
|---|---|---|---|---|
| G1 집중 타격 | 윤서의 기본 현실 기술, 첫 귀환 확인에서 사용법 재안내. 연결 재화 불필요 | 즉시 단일 타격 1.8A, 마력 14, 재사용 3초 | 작은 틈, 이동 중인 적, 핵 지지체 처리 | 광역 처리 없음 |
| G2 연속 타격 | 기본 현실 기술, G1과 함께 보유. 무림 가입/기연 조건 없음 | 단일 대상 1.0A+1.8A 두 타격(새 비교안), 마력 20, 재사용 5초 | 보스의 충분한 빈틈, 연속 적중 보상 | 두 번째 타격 전에 이동하면 남은 타격 취소, 이미 사용한 마력 환불 없음 |
| R1 마력 개화 | 노방 활용 + 현실 귀환 + 학습 재화 | 가까운 지점에 0.8초 뒤 2.4A 광역 검격, 마력 18, 재사용 8초 | 소환체 집결점에 미리 배치, 고정된 핵 지지체 | 빠른 적이 범위를 벗어나면 빗나감 |
| R2 회피 연계 | R1 습득 + 접무 활용 + 학습 재화 | 실제 위협 회피 후 기본 4초 내 다음 R1/R3 마력 비용 20% 감소, 최저 비용 1. 성취별 유효 시간은 DOC-24 참조 | 회피 다음 공격을 계획해 긴 전투의 소모 완화 | 허공 회피 불인정, 1회만 적용, 비중첩, 만료 시 소멸 |
| R3 응축 검격 | R1 습득 + 토염 활용 + 학습 재화 | 0.6초 준비 후 좁은 전방 3.8A, 마력 26, 재사용 10초 | 돌진 후 회복·핵 노출의 예측 가능한 시간 | 이동하는 적에 취약, 준비 중 회피하면 발동 취소·소모/쿨다운 유지 |

A는 현재 현실 공격력이다. G1/G2는 기존 일반 기술 명칭·기본 배율을 참고한 새 레이드 기준안이며 신규 연결과의 최종 균형은 검증하지 않았다. 명중 중복·이동 취소·준비 시간은 새 목표 규칙이다. R1은 시전 순간 표시한 위치에 남고 적을 자동 추적하지 않는다. 방향 입력/타깃 조준과 터치 모두 같은 표적 표시를 보고 확정하도록 한다. 위치 지정 UI 자체는 후속 화면 검토 대상이다.

**자원 기준안:** 시작 마력 80, 자연 회복 초당 3, 기본 검격과 회피는 마력 미소모. 쉬지 않고 G1/G2를 재사용하면 소모가 회복을 웃돌도록 비교한다. 마력이 없어도 모든 필수 목표를 기본 공격으로 처리할 수 있다. 회피에는 별도 재사용 시간이 있어 무제한 무적이 아니다. 전투 중 자원 부족을 메뉴나 기술 교체로 초기화하지 않는다.

**회피 연계 판정:** 본인을 겨냥한 공격이 확정된 뒤 그 공격의 판정 시점에 회피로 피해를 피한 경우. 같은 공격 ID당 한 번만 충전하며 저장은 최대 1개. 충전 중 추가 회피는 시간 갱신/중첩을 하지 않는 안이다. 벽 충돌처럼 애초에 본인에게 닿지 않은 공격은 대상이 아니다. 기술을 확정 사용하면 할인과 충전을 소비하며 취소·빗나감으로 돌려주지 않는다.

| 2슬롯 조합 | 공략 성격 | 보장해야 할 것 |
|---|---|---|
| G1 + G2 | 즉시 대응과 안정적인 단일 피해 | 기본·변이 모두 정상 완주 가능 |
| G1 + R1 | 핵/단일 대응과 소환체 선제 처리 | R1 실패 때 G1/기본 공격으로 회복 가능 |
| G2 + R1 | 소환체 처리 후 긴 빈틈에 연속 공격 | 공격 욕심과 회피의 판단 |
| G1 + R3 | 짧은 틈과 큰 틈을 구분해 공격 | 고급 기술이 없어도 G1의 가치 유지 |
| R1 + R3 | 예측 공격에 집중 | 즉시 공격 공백을 기본 검격으로 메울 수 있음 |

R2 미획득 조합도 완주 가능하다. R2가 없는 일반 경로에 자동 동등 보상을 주지는 않지만, 장기 공략이 불가능할 정도로 마력 회복을 제한하지 않는다.

## 4. 보스 전장과 기본 규칙

집수정의 중앙 넓은 공간과 외곽 이동로를 사용한다. 두 핵 지지체 위치는 서로 가까운 한 원 안에 모두 들어가지 않도록 분리한다. 플레이어가 어떤 지지체를 먼저 처리할지 선택할 수 있고, 하나의 R1로 둘을 동시에 끝내는 구조는 피한다. 벽과 장식물이 전조를 가리지 않아야 한다.

보스는 완전 무적이 아니다. 강화 외피 중 피해 40% 감소, 일반 상태 정상 피해, 핵 노출 중 받는 피해 25% 증가를 비교한다. 지지체 기믹을 놓쳐도 반복 기회가 오며 전투가 영구 정지하지 않는다. 플레이어가 강해서 체력 경계를 넘기면 끝난 단계는 반복하지 않는다.

소환체는 최대 3개, 지지체는 2개다. 소환체가 남아 있으면 새 소환은 빈자리만 채운다. 적을 무한 누적시키거나 보스 체력을 재생시켜 실패를 무한 연장하지 않는다. 모든 지지체는 일반/기본 공격에도 피해를 받는다. 특정 계열 판정이나 전용 아이템은 요구하지 않는다.

## 5. 패턴 표 — 일반 경로와 매화 경로의 차이

| 패턴 | 전조와 판정 후보 | 기본 대응 | 일반 스킬 활용 | 연결 스킬 활용 | 실패 결과 |
|---|---|---|---|---|---|
| 전방 내려찍기 | 앞다리 들기·바닥 부채꼴 표시 1.2초. 판정 방향은 마지막 0.5초 전에 고정 | 옆으로 이동/회피, 뒤나 측면 진입 | G1로 짧은 회복 구간 공격 | 실제 회피 후 R2, 뒤에 R1 배치 가능 | 중간 피해·짧은 경직, 즉사 아님 |
| 횡방향 휩쓸기 | 상체 회전·가로 범위 표시 1.0초 | 범위 밖으로 물러나거나 회피 | G1은 짧게, G2는 다음 패턴을 보고 사용 | R1은 멀어져도 지연 공격, R2는 회피 시 충전 | 욕심낸 연속 공격 중단 |
| 표적 돌진 | 직선 경로 표시 1.4초, 마지막 0.6초에는 추적 종료 | 경로 옆으로 피함. 벽 유도 성공 여부와 무관하게 돌진 끝에 2초 회복 | G2를 넣거나 기본 검격 후 G1 | R3 준비 시간을 회복 구간에 맞춤 | 큰 피해·밀림, 연속 확정 피격 금지 |
| 핵 지지체 생성 | 2개 위치가 먼저 빛남. 외피 강화와 소환 시작 | 각 지지체를 공격해 파괴 | G1/G2로 한 개씩 정확히 처리 | R1으로 지지체 주변 소환체 동시 공격 | 처리 지연·외피 지속, 전멸 타이머 없음 |
| 소환체 집결 | 소환체가 표시된 집결점으로 이동 후 짧게 멈춤 | 이동을 이용해 모은 뒤 기본 공격/개별 처치 | 안정적으로 한 마리씩 제거 | R1의 지연 폭발을 집결에 맞춤 | 소환체의 견제 증가, 최대 수 제한 유지 |
| 핵 노출 | 지지체 2개 파괴 후 외피 열림·시각/음향 표시, 6초 | 공격 기회 활용. 이때 새 지지체/소환 없음 | G2의 연속 피해·G1 재사용 | R3 집중 타격, R1 예측 배치 | 기회만 놓침. 남은 소환체는 첫 2초 공격을 멈춤 |

전조는 색만으로 구분하지 않고 모양·동작·소리를 함께 사용한다. 전조 시간을 소모하는 필수 대사나 메뉴를 전투 중 띄우지 않는다.

## 6. 공략 단계와 순서

| 단계 | 조건 | 행동 구성 | 학습 목표 |
|---|---|---|---|
| 정찰 | 최초 진입 | 소수 적·고정된 지지체로 기본 조작과 표적을 먼저 확인 | 지지체는 기본 공격으로도 부술 수 있음 |
| 1단계 | 보스 HP 100~65% | 내려찍기 → 회복 → 휩쓸기 → 회복 → 돌진 → 회복 반복 | 일반 공격으로도 빈틈을 찾는 기본 |
| 2단계 | HP 65~30% | 현재 공격 종료 후 지지체 2개·소환. 기본 패턴과 병행. 둘 파괴 시 노출 6초 | 보스 공격과 주변 목표의 우선순위 |
| 3단계 | HP 30% 이하 | 남은 기믹 유지. 돌진 이후 1회 내려찍기를 잇되 별도 전조·회복을 제공 | 이미 배운 패턴의 조합에 대응 |
| 완료 | HP 0 | 적의 공격 판정 중단, 잔여 소환체 소멸, 핵 확인 후 정산 | 전투 종료와 보상 확인 |

지지체 재생성은 이전 노출이 끝난 뒤 기본 패턴 2회 완료 후에만 가능하다. HP 단계 전환으로 즉시 중복 생성하거나 핵 노출을 강제 취소하지 않는다. 진입 체력 경계를 한 번에 넘겼을 때도 동시에 두 단계의 패턴을 쌓지 않는다. 새 기믹은 2단계 한 번만 소개한다.

## 7. 공략 흐름 사례

**일반 G1+G2:** 기본 공격으로 거리를 확인 → 내려찍기 옆으로 이동 후 G1 → 돌진 회복에 G2 → 지지체가 나오면 보스 피해 욕심을 줄이고 하나씩 파괴 → 소환체는 최대 3마리 안에서 개별 정리 → 핵 노출에 G2/G1 → 반복. 전용 파훼 기술 없이 완주한다.

**G1+R1:** 소환체 집결점에 R1 선입력 → G1로 다른 지지체를 처리 → 노출 직전에 R1 위치를 보스 아래로 바꿈 → 기본 검격과 G1로 이어감. R1이 빗나가도 다음 재사용이나 일반 공격으로 해결한다.

**G1+R3(+R2 보유):** 내려찍기 실제 회피로 할인 준비 → 돌진의 고정된 회복 구간이나 노출에 R3 → 움직이는 보스에는 G1 → 마력이 부족하면 기본 검격으로 유지. R2의 충전이 없다고 R3가 잠기지 않는다.

연결 스킬 사용자는 목적에 맞는 이점을 얻지만, 보스 자체가 연결 스킬 전용 시연장이 되지 않도록 일반 경로를 함께 검토한다.

## 8. 반복·변이·실패

- 첫 공략 완료 후 기본 반복 토벌 개방. 횟수 제한·일일 입장권·피로도는 이번 안에 넣지 않는다.
- D-048: 반복 레이드는 입장 전에 공개된 ‘소환체 처리 중심 / 보스 빈틈 공략 중심’ 두 임무 조건 중 선택한다. 기존 집결 위치 변경만의 변이 후보를 대체한다. 두 조건 모두 일반 기술로 완료할 수 있어야 한다.
- D-054: 최초 기본 공략 뒤 두 조건을 함께 개방한다. 소환체 조건은 집결 예고와 주변 목표 처리, 빈틈 조건은 돌진 후 회복과 핵 노출 활용에 중점을 둔다. 최대 소환체 3·지지체 2·모든 표적 일반 공격 허용은 유지한다. 동시 패턴 밀도나 보스 체력을 단순히 늘리는 방식은 피한다. 구체 패턴 순서·수치는 검토안이다.
- D-054: 두 조건의 반복 보상·숙련은 동일하고 최초 추가 보상은 레이드 전체 첫 완료에만 지급한다. 반복 2결정/80경험치는 비교 수치다. 기존 변이 3결정/100경험치·기본 3회 후 해금 후보는 대체한다.
- 두 조건 모두 일반 2기술로 공략 가능해야 한다. 동일 반복 보상에서 시간 효율이 크게 달라지면 먼저 패턴·이동·배치를 검토한다.
- 사망·철수는 현재 회차 미완료. 완료 재료/숙련 미지급, 과거 기록/재화 차감 없음. 자동 부활 과금·영구 손실은 넣지 않는다.
- 첫 정찰 완료 체크포인트에서 보스 재도전 가능. 전체 임무 보상은 핵 처리 완료 때 1회. 보스 직행 재도전과 최초 보상 재발급을 혼동하지 않는다.
- D-050/051: 안전 지점에서 교체한 기술도 완료 구간에서의 유효 사용 기록을 보존한다. 보스 재도전은 실패한 보스 시도만 초기화하고 이전 완료 구간 기록은 유지한다. 체력·마력·회복 횟수는 체크포인트의 지정 상태로 복원하며 숙련·재화는 최종 성공 때만 지급한다. 수치와 기술별 판정 예시는 DOC-24를 따른다.
- 미완료 회차는 재접속 시 같은 회차의 정해진 체크포인트에서 전투를 다시 시작하는 안이다. 이미 정산된 회차는 보상 화면만 재표시하며 지급하지 않는다.
- 거점 이동으로 진행 중 레이드의 체력·마력을 회복한 뒤 이어 싸우지 않는다. 철수하면 해당 회차를 끝내고 새 회차로 재입장한다.
- 임무 시작 시 체력/마력과 임무 전용 회복 2회를 제공하는 후보. 회복은 최대 HP 30%, 재사용 8초. 전투당 드롭으로 추가되지 않고 회차 밖 재화로 바뀌지 않는다.

## 9. 성장·화면·검증

보상량과 학습 예산은 DOC-24 한 곳에서 관리한다. 보상 화면은 최초 보상/회차 보상/기술별 숙련/다음 목표를 분리한다. 아직 매화를 배우지 않았으면 일반 강화와 무림의 공개된 전수 조건을 안내하고 미습득 기술을 전투 버튼으로 만들지 않는다.

입장 화면: 목적·완료 조건·적 특징·보상·현재 2슬롯·권장 준비를 표시한다. 전투력은 권장 정보이고 첫 레이드의 수치 문턱이 아니다. 출구에서는 안전하게 성장·편성을 확인하고 원할 때 귀환한다. 전투 중 학습 팝업·원격 NPC 보고를 요구하지 않는다.

실패 시 학습 정보는 ‘어떤 전조에 맞았는가’와 ‘현재 대안’을 보여준다. 정답 기술을 사라는 안내로 바꾸지 않는다.
