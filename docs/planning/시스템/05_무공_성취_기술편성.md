# 05. 무공·성취·기술 편성

갱신: 2026-10-12 (KST) · 기준: `ed06c44` 이후 로컬 main 작업 · main 릴리스 대상 · 게임 버전 표기 `0.15.0`

[기획 시작](../README.md)

## 성장의 구분

**2026-10-12 목표 기획 갱신:** [매화검법 고유 트리·편성 검토안](22_매화검법_고유트리와_편성_검토안.md)을 함께 본다. 사용자 확인(D-038)에 따라 제1~3초식은 유효 사용한 전투·수련 **완료 단위**로 숙련을 쌓는 방향이며, 백련의 개인 제자 전수는 유지한다. 아래 명중 누적·1회 선행 등은 현재 구현 설명이다. 새 목표의 3/8회·강화 가지·비용은 검증안이고 기존 성취를 환산하거나 코드를 수정하지 않았다. 문파 운영 보류는 개인 사제 관계 삭제를 뜻하지 않는다.

| 축 | 의미 | 초기화 정책 |
|---|---|---|
| 습득·전수 | 사용할 기술과 학습 기회를 얻음 | 기존 습득 이력 보존 |
| 투자 | 재료를 확정 소비해 분기를 성장시킴 | 환불·감소·재분배 금지 |
| 성취 | 개별 기술의 실제 운용·수련 진전 | 기존 실전 기록 보존 |
| 편성 | 배운 기술을 입력 슬롯에 배치 | 안전한 준비 구간에서 교환·해제 가능 |
| 경지·소속 | 인물 전체의 수준·문파 관계 | 기술 성취와 별도 |

무공 성취 기본형은 **1~9성**이다. 무공별 초식·고유 특징에 맞는 다른 구조를 허용하며 동일 단계 수·대성 조건을 강제하지 않는다(D-021 정정). 이십사수매화검법은 초식별 성취다. 투자 상한 3은 ‘3성 무공’이라는 뜻이 아니다.

## 현재 무림 트리 — 효과·상한은 검증안

백련에게 삼재검법 기초를 배운 뒤 세 분기에 자유 분산한다. 아래 선행 노드는 1단계 이상 투자해야 다음 노드가 열린다. 투자당 수련첩 1개이며 문파 만남만으로 자동 투자하지 않는다.

| 분기 | 노드 순서 | 투자 상한·효과 |
|---|---|---|
| 검술 | 검로 다듬기 → 삼재·횡검 → 검끝의 거리 읽기 | 3: 기본 검격 +5%/단계 → 1: 횡검 습득 → 3: 횡검 +8%/단계 |
| 보법 | 가벼운 발 → 안정된 중심 → 발걸음의 거리 조절 | 3: 회피 재사용 −0.1초/단계 → 3: 생명 +8/단계 → 3: 회피 무적 +0.03초/단계 |
| 내공 | 고른 호흡 → 기력 아끼기 → 삼재 운기 | 3: 기력 +6/단계 → 3: 횡검/매화노방 비용 −1/단계 → 3: 기력 회복 +0.3/초/단계 |

마지막 노드도 공통 삼재검법 성장이다. 선행 노드와 수련첩만 요구하며 타 문파 만남을 요구하지 않는다. 남궁·무당·아미·소림 고유 트리는 별도로 잠금 표시한다. 현재 기술 비용·재사용(횡검 18/2.8초 등)은 원전 효과나 사용자 확정 밸런스가 아니다. 구현 원본은 [murim-growth.js](../../../murim-growth.js)다.

## 매화검법과 개별 성취

치료 후 제자 수락 시 제1초식 **매화노방**을 체득한다. 거절하면 미획득이며 귀환은 가능하다. 매화검법 전용 트리가 열리며 제2·3초식까지 수련할 수 있다. 제4~24초식은 미구현이다. 매화접무를 기본 두 번째 기술로 주던 구 캠페인과 구분한다.

현재 [ordinary-growth.js](../../../ordinary-growth.js)의 신규 여정 검증안:

- 삼재검격·횡검: 유효 기록 4마다 한 단계, 1~9성(기록 최대 32). 단계당 해당 기술 피해 +2%.
- 매화노방: 기록 0/8/16에서 입문/활용/숙련, 해당 기술 피해 +0/2/4%.
- 유효 수동 명중을 기록하며 동일 적/기술에 최대 3회. 허공·자동 연타·임시 시험·무효 대상은 새 실전 증거와 구분한다.
- 현실 기술도 독립 개별 성취 기록이 존재하지만 신규 현실 전투·트리 진행은 이번 범위에 연결하지 않았다.

새 성취 공식을 기존 숙련 숫자의 임의 환산이나 투자 환불로 적용하지 않는다. 실제 기술별 성취 조건과 최종 수치는 D-012 테스트 후 결정한다.

## 추가 초식 — D-036 검증 구현

| 초식 | 학습 조건 | 전투 효과 검증안 |
|---|---|---|
| 제1 매화노방 | 정식 제자 수락, 무료 | 기존 주변 검세 유지 |
| 제2 매화접무 | 매화노방 실전 기록 1 이상 + 수련첩 2 | 주변 거리 180, 공격 배율 2.6, 무적 0.25초, 기력 16, 재사용 3.6초 |
| 제3 매화토염 | 매화접무 실전 기록 1 이상 + 수련첩 2 | 전방 좁은 검로 거리 300, 공격 배율 4.4, 기력 24, 재사용 5초 |

제2·3초식은 각각 유효 수동 명중 기록 0/4/8에서 입문/활용/숙련, 피해 +0/2/4%다. 동일 적·기술은 3회까지 기록하며 허공·길게 누르기는 새 실전 기록을 주지 않는다. 기력 아끼기 투자의 비용 감소가 적용된다. 수치·효과·요구량은 최종 확정이 아닌 검증안이다. 초식별 습득·성취·쿨다운은 독립이며 배운 뒤 직접 두 슬롯 중 하나에 편성한다. 거절 경로와 기존 투자는 그대로 보존한다.

## 전투 단축키 편성

**현실 후속 목표(D-043/044):** [DOC-23](23_현실_지하역_레이드와_스킬_검토안.md)은 기본 공격·회피 외 일반/연결 공용 액티브 2슬롯을 사용한다. 현실 개별 숙련도 실제 사용한 전투·정식 수련 완료 기준이다. 패시브는 별도 액티브 버튼을 차지하지 않는다. 기존 현실 코드의 고정 액션/명중 집계를 변경했다는 뜻이 아니며, 세부 완료 판정과 수치는 [DOC-24](24_양세계_반복성장과_보상경제_검토안.md)의 검토안이다.

**미습득 비노출 대상은 전투 단축키다.** 투자 트리는 미습득 노드의 선행 조건·현재/다음 효과·비용을 계속 보여준다(D-031).

현재 선택 기술 슬롯은 2개 검증안이다. 기본 공격·회피는 별도 유지한다. 무공·스킬의 단축키 설정에서 습득 기술을 선택해 배치·교환·해제한다. 빈 슬롯 편집은 설정 화면에서 하며 HUD에는 배치한 기술만 나타난다. 새 습득이 기존 배치를 자동 덮어쓰지 않는다. 패시브는 장착 대상이 아니다.

키 설정과 기술 배치를 구분한다. 기본 선택 슬롯 키가 Q/W여도 그 키가 고정 무공명을 뜻하지 않는다. 키보드·터치·접근성 이름과 실제 발동은 같은 배치를 따라야 한다. 미습득/미장착 기술은 옛 키로도 발동하지 않는다.

기술의 비용·재사용 대기시간·성취는 기술에 속한다. 슬롯 교환·해제로 쿨다운을 초기화할 수 없다. 편성은 현재 전장의 적을 모두 제압한 안전 상태 또는 준비 구간에서만 가능하고 저장 실패 시 변경을 취소한다. 기존 v0.14 저장은 습득 기술을 기존 슬롯 대응으로 이관하며 신규 습득은 직접 배치한다. 근거: [murim-loadout.js](../../../murim-loadout.js).
