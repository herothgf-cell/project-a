# 05. 무공·성취·기술 편성

갱신: 2026-10-12 (KST) · 구현 대조: `main f5a5a3b` / 게임 `v0.15.0`

[기획 시작](../README.md)

## 성장의 구분

| 축 | 의미 | 초기화 정책 |
|---|---|---|
| 습득·전수 | 사용할 기술과 학습 기회를 얻음 | 기존 습득 이력 보존 |
| 투자 | 재료를 확정 소비해 분기를 성장시킴 | 환불·감소·재분배 금지 |
| 성취 | 개별 기술의 실제 운용·수련 진전 | 기존 실전 기록 보존 |
| 편성 | 배운 기술을 입력 슬롯에 배치 | 안전한 준비 구간에서 교환·해제 가능 |
| 경지·소속 | 인물 전체의 수준·문파 관계 | 기술 성취와 별도 |

무공 성취 기본형은 **1~9성**이다. 무공별 초식·고유 특징에 맞는 다른 구조를 허용하며 동일 단계 수·대성 조건을 강제하지 않는다(D-021 정정). 이십사수매화검법은 초식별 성취다. 투자 상한 3은 ‘3성 무공’이라는 뜻이 아니다.

## 현재 무림 트리 — 효과·상한은 검증안

백련에게 삼재검법 기초를 배운 뒤 세 분기에 자유 분산한다. 아래 선행 노드는 1단계 이상 투자해야 다음 노드가 열린다. 투자당 수련첩 1개이며 문파 만남만으로 자동 투자하지 않는다.

| 분기 | 노드 순서 | 투자 상한·효과 |
|---|---|---|
| 검술 | 검로 다듬기 → 삼재·횡검 → 남궁의 거리 읽기 | 3: 기본 검격 +5%/단계 → 1: 횡검 습득 → 3: 횡검 +8%/단계 |
| 보법 | 가벼운 발 → 안정된 중심 → 아미의 거리 조절 | 3: 회피 재사용 −0.1초/단계 → 3: 생명 +8/단계 → 3: 회피 무적 +0.03초/단계 |
| 내공 | 고른 호흡 → 기력 아끼기 → 무당의 운기 | 3: 기력 +6/단계 → 3: 횡검/매화노방 비용 −1/단계 → 3: 기력 회복 +0.3/초/단계 |

마지막 노드는 각각 길목 2/6/4 이후 해당 문파 여행자의 사건 완료가 필요하다. 현재 기술 비용·재사용(횡검 18/2.8초 등)은 원전 효과나 사용자 확정 밸런스가 아니다. 구현 원본은 [murim-growth.js](../../../murim-growth.js)다.

## 매화검법과 개별 성취

치료 후 제자 수락 시 제1초식 **매화노방**을 체득한다. 거절하면 미획득이며 귀환은 가능하다. 나머지 23초식은 신규 여정에서 미구현이다. 매화접무를 기본 두 번째 기술로 주던 구 캠페인과 구분한다.

현재 [ordinary-growth.js](../../../ordinary-growth.js)의 신규 여정 검증안:

- 삼재검격·횡검: 유효 기록 4마다 한 단계, 1~9성(기록 최대 32). 단계당 해당 기술 피해 +2%.
- 매화노방: 기록 0/8/16에서 입문/활용/숙련, 해당 기술 피해 +0/2/4%.
- 유효 수동 명중을 기록하며 동일 적/기술에 최대 3회. 허공·자동 연타·임시 시험·무효 대상은 새 실전 증거와 구분한다.
- 현실 기술도 독립 개별 성취 기록이 존재하지만 신규 현실 전투·트리 진행은 이번 범위에 연결하지 않았다.

새 성취 공식을 기존 숙련 숫자의 임의 환산이나 투자 환불로 적용하지 않는다. 실제 기술별 성취 조건과 최종 수치는 D-012 테스트 후 결정한다.

## 전투 단축키 편성

**미습득 비노출 대상은 전투 단축키다.** 투자 트리는 미습득 노드의 선행 조건·현재/다음 효과·비용을 계속 보여준다(D-031).

현재 선택 기술 슬롯은 2개 검증안이다. 기본 공격·회피는 별도 유지한다. 무공·스킬의 단축키 설정에서 습득 기술을 선택해 배치·교환·해제한다. 빈 슬롯 편집은 설정 화면에서 하며 HUD에는 배치한 기술만 나타난다. 새 습득이 기존 배치를 자동 덮어쓰지 않는다. 패시브는 장착 대상이 아니다.

키 설정과 기술 배치를 구분한다. 기본 선택 슬롯 키가 Q/W여도 그 키가 고정 무공명을 뜻하지 않는다. 키보드·터치·접근성 이름과 실제 발동은 같은 배치를 따라야 한다. 미습득/미장착 기술은 옛 키로도 발동하지 않는다.

기술의 비용·재사용 대기시간·성취는 기술에 속한다. 슬롯 교환·해제로 쿨다운을 초기화할 수 없다. 편성은 안전한 준비 구간에서만 가능하고 저장 실패 시 변경을 취소한다. 기존 v0.14 저장은 습득 기술을 기존 슬롯 대응으로 이관하며 신규 습득은 직접 배치한다. 근거: [murim-loadout.js](../../../murim-loadout.js).
