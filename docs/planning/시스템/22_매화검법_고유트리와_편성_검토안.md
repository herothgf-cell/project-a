# 22. 매화검법 고유 트리·편성·현실 연결 — 검토안

갱신: 2026-10-12 (KST) · 대조 기준: 원격/로컬 main `9681ec7` · 상태: 기획 검토, 구현 없음

## 1. 목적과 효력

플레이어가 “어떤 무공을 배우고 먼저 성장시킬까?”를 판단할 수 있도록 초식의 역할, 선행, 숙련, 투자, 편성과 현실 대응을 한곳에서 비교한다. 일반 무공은 공개된 조건과 반복 수련을 중심으로 성장하며, 매화검법을 파문·방벽 등 다른 무공의 성격으로 바꾸지 않는다. 특별한 발견·해석은 별도 독문 무공이나 잃어버린 무공의 계승에서 다룬다.

이 문서의 새로운 효과·수치·현실 기술명은 수정·폐기 가능한 제안이다. 문서 작성 요청을 모든 후보안의 채택이나 개발 승인으로 해석하지 않는다. DOC-05/06의 현재 동작, 기존 저장과 최초 보상 기록을 변경하지 않는다. 현행 규칙과 달라지는 목표는 2절의 사용자 확인 결과로만 확정한다.

## 3. 유지하는 기준

- 일반 경로와 제자 거절 경로 모두 첫 귀환 가능. 매화 완성·특별 기연은 귀환 조건이 아니다.
- 삼재검법의 기존 검술·보법·내공 공통 투자를 유지한다. 매화 트리로 강제 이전하거나 기존 효과를 제거하지 않는다.
- 매화는 초식별 성취이며 24성을 만들지 않는다. 일반 무공의 기본 1~9성과 구분한다.
- 확정 학습·투자는 영구적이다. 환불·초기화 없이 배운 초식을 자유롭게 편성한다.
- 기본 공격·회피와 별도로 선택 초식 2슬롯을 기준으로 검토한다. 패시브 장착 슬롯·주력 무공 강제 지정은 이번에 추가하지 않는다.
- 세계별 투자·성취 분리, 무림에서 현실로 연결, 현실 스킬의 개별 성취를 유지한다. 현실→무림 재료 환전은 추가하지 않는다.
- 기존 공명 결정·무공 각인의 잔량·정산 이력을 보존한다. 소비 재화를 영구 자격으로 바꾸는 앞선 아이디어는 채택하지 않은 후보이며 이번 문서로 적용하지 않는다.

## 4. 초식별 한눈에 보기

이 표는 새 목표 기획이다. 완료 기준 집계와 개인 제자 조건은 확인됐고, 횟수·비용·효과는 검증안이다. 현재 명중 기반 구현과의 차이는 6절에 별도 보존한다. 실제 전투 효과는 게임 창작이며 원전 정설이 아니다.

역할의 상대 기준: 노방은 기력 대비 반복 운용, 접무는 방어적 대응, 토염은 좁은 범위의 순간 피해가 장점이다. 접무가 노방보다 범위·피해·소모·재사용 모두 우월하거나, 토염이 광역 처리까지 가장 효율적이어서는 안 된다. 현재 수치가 이 목표를 충족한다고 판정한 것은 아니다.

접무의 짧은 회피는 현재 역할을 바탕으로 하며 새 순간이동·강제 이동을 의미하지 않는다. 셋 모두 기존 매화 계열의 공격 역할을 유지한다. 반격 방벽과 충격 흡수는 파문 비전 영역에 남긴다.

## 5. 트리의 연결과 투자

트리는 초식 학습 줄기와 각 초식의 고정 강화 가지로 구성한다. 강화를 선택한다고 기술 종류가 바뀌지 않는다. 초식 번호 1→2→3은 현재 연결을 보존한 것이며 24초식 전체의 일렬 학습을 뜻하지 않는다.

| 노드 | 선행 후보 | 수련첩 비용 후보 | 효과 후보·적용 범위 |
|---|---|---:|---|
| 매화노방 학습 | 치료 후 개인 제자 수락 | 0 | 제1초식 개방 |
| N1 내력 절약 | 노방 활용 단계 | 1 | 노방의 최종 기력 소모 10% 감소 |
| N2 검세 회수 | N1 + 노방 숙련 단계 | 1 | 노방 재사용 시간 10% 감소 |
| 매화접무 학습 | 노방 유효 사용 첫 완료 | 2 | 제2초식 개방; N1/N2는 필수 아님 |
| J1 중심 유지 | 접무 활용 단계 | 1 | 접무의 회피 구간 +0.05초 |
| J2 동작 정리 | J1 + 접무 숙련 단계 | 1 | 접무 재사용 시간 10% 감소 |
| 매화토염 학습 | 접무 유효 사용 첫 완료 | 2 | 제3초식 개방; J1/J2는 필수 아님 |
| T1 검세 집중 | 토염 활용 단계 | 1 | 토염 피해 +10% |
| T2 운기 안정 | T1 + 토염 숙련 단계 | 1 | 토염의 최종 기력 소모 10% 감소 |

모든 강화는 1회 투자 후보다. 3초식과 강화 6노드를 전부 배우는 비용은 수련첩 10개(학습 4 + 강화 6)다. 상호 배타적 선택이나 투자 환불은 없다. 유한 재료에서는 성장 순서를 고르고, 이후 추가 공급이 마련되면 모두 학습할 수 있다. 한 분기 선택으로 다른 분기를 영구 폐쇄하는 설계가 아니다.

새 강화는 해당 초식에만 적용되며 미편성 초식의 강화가 다른 기술이나 캐릭터 공격력에 더해지지 않는다. 삼재 공통 효과는 그대로 적용한 뒤 새 초식 전용 배율을 적용하는 후보로 비교한다. 예: 기존 공통 감소 후 소모의 90%, 최솟값 1; 확정 전에 실제 최종 값을 표시한다. 피해 +10%도 해당 초식에만 적용하며 세계 전체 공격력으로 환산하지 않는다.

비용과 효과 수치는 비교용이다. 특히 접무 회피 창 증가는 공통 회피 강화와 별도 행동에 적용하고, 반복 무적 운용이 되면 해당 강화는 축소하거나 폐기한다.

### 투자 선택 예시

노방을 배웠고 두 번째 강화 노드를 열 만큼 숙련했으며, 사용 가능한 수련첩이 2개라고 가정한다.

| 선택 | 소비 | 당장 얻는 것 | 나중으로 미루는 것 |
|---|---:|---|---|
| 노방 집중 | N1 + N2 = 2 | 사용 효율·재사용 개선 | 접무 학습 |
| 초식 확장 | 접무 학습 = 2 | 공격 중 대응 수단 추가 | 노방 강화 |
| 기초 유지·저축 | 공통 트리 투자 또는 보유 | 삼재 기반 강화 또는 다음 학습 준비 | 매화 추가 성장 |

현재 DOC-06의 수련첩은 기연 없이 총 15개지만, 매화 외 공통 트리와 경쟁한다. 따라서 15개 전부를 매화 전용 예산처럼 설명하지 않는다. 후속 DOC-24에 무림 반복 토벌로 수련첩을 추가 확보하는 수량 후보를 마련했다. 구현되거나 최종 수량이 확정된 것은 아니다.

## 6. 숙련 규칙 — 새 목표와 현재 구현의 차이

| 항목 | 현재 게임의 명중 기반 구현 | 새 목표: 완료 단위 숙련 |
|---|---|---|
| 기록 단위 | 유효 수동 명중, 동일 적·기술 최대 3회 | 해당 초식을 유효 사용한 전투·지정 수련 완료당 1회 |
| 단계 | 노방 0/8/16, 접무·토염 0/4/8 | 초식별 입문 0 / 활용 3 / 숙련 8(비교용) |
| 후속 초식 | 앞 초식 유효 명중 1회 + 수련첩 2 | 앞 초식 유효 사용 첫 완료(D-046) + 수련첩 2(비교용) |
| 반복 처리 | 현재 명중 기록 규칙 | 새로 시작해 정상 완료한 회차 인정; 동일 완료 재접속·보상 재확인은 중복 불인정 |
| 허공·실패 | 허공 등 제외 | 허공 제외, 실패 회차는 완료 숙련 미지급. 기존 확정 숙련은 유지 |
| 여러 기술 사용 | 기술별 독립 기록 | 실제 사용한 각 초식에 1회씩 가능, 마지막 타격 독점 없음 |

‘전투’는 개별 적이나 임의로 나눈 한 웨이브가 아니라 보상 화면에서 명시한 한 회차다. 정식 성장 수련과 영구 성취를 주지 않는 미리보기·체험장을 구분한다. 현재 시험 콘텐츠를 자동으로 숙련 파밍 장소로 바꾸지 않는다.

제1~3초식의 초기 유효 사용 후보는 유효한 적에게 실제 피해를 준 발동 1회 이상이다. 접무도 성장 조건에 정밀 회피를 강제하지 않는다. 지속 피해 틱·다수 적 명중·추가 타격은 횟수를 늘리지 않는다. 미습득 초식과 사용 당시 미편성인 초식에는 기록을 주지 않는다. 현실 레이드의 중간 편성 교체 뒤 인정은 D-050/DOC-24를 따른다. 적 처치 전에 해당 기술을 사용했다면 마지막 타격 여부와 무관하게 완료 시 1회를 인정한다. 단순 기술 버튼 누르기만 반복하는 문제가 관찰되면 사용 판정 또는 전투 구성을 재검토한다.

활용 3회와 숙련 8회는 누적 기준이다(3+8회가 아님). 단계의 직접 피해 보너스는 현재의 +0/2/4%를 비교 기준으로 유지하는 안이며 새 강화 T1과 별도로 표시한다. 다음 초식을 배우거나 해당 노드에 투자해도 이전 초식의 기록을 소비·초기화하지 않는다. 숙련 단계 뒤에는 다음 초식을 배우기 위한 추가 강제 반복을 요구하지 않는다.

D-046에 따라 후속 초식 학습 자격은 앞 초식 유효 사용 첫 완료로 연다. 3/8회는 성취·강화 기준 후보로 남고 현실 연결의 활용 조건도 유지한다. 따라서 귀환길 1에서 노방 사용 완료→접무 학습, 귀환길 2에서 접무 사용 완료→토염 학습이 가능하다(각 학습 재료 보유 시). 귀환을 막지 않고 D-042에 따라 첫 귀환 후 안정화·거점 왕복을 열어 DOC-24의 무림 수련/토벌을 선택할 수 있게 한다. 치료 직후 새 필수 수련 구간을 자동 삽입하지 않는다. 기존 명중 기록을 완료 횟수로 임의 환산하는 저장 이행은 승인하지 않는다.

## 7. 편성 규칙과 조합

- 기본 공격·기본 회피는 선택 슬롯을 차지하지 않는다. 선택 액티브 2개를 배치한다.
- 배운 삼재 횡검과 매화 초식의 혼합 편성을 허용한다. 같은 초식을 두 슬롯에 중복 배치할 수 없다.
- 현재 전장을 확보한 안전 상태나 준비 구간에서만 교환·해제한다. 전투 중 메뉴로 교체하지 않는다.
- 학습한 초식이 기존 슬롯을 자동으로 덮어쓰지 않는다. 미습득·미편성 기술은 전투 HUD에 표시하지 않는다.
- 비용·재사용 시간·숙련은 슬롯이 아닌 기술에 속한다. 교체·해제·재접속을 통해 남은 쿨다운을 지우지 않는다.
- 편성 변경은 숙련·투자의 삭제가 아니다. 새 패시브 슬롯이나 문파 소속 효과를 만들지 않는다.

| 편성 예시 | 강점 | 포기하는 것 |
|---|---|---|
| 노방 + 접무 | 주변 적 대응과 짧은 회피 | 좁은 취약 구간에 집중할 공격 |
| 노방 + 토염 | 지속적인 적 정리와 집중 공격 | 접무의 추가 회피 수단 |
| 접무 + 토염 | 위험 대응 후 보스 빈틈 공략 | 노방의 지속 전투 효율 |
| 삼재 횡검 + 매화 1종 | 기존 삼재 투자 활용 | 매화 초식 간 역할 조합 일부 |

어느 조합도 모든 전투에서 정답이 되어서는 안 된다. 기력·준비 동작·적 배치를 포함해 비교하며, 피해 배율만으로 우열을 정하지 않는다.

## 8. 현실 연결 — 효과와 경제를 구분

아래는 매화 계열의 고정 대응 후보다. 원리를 추리해 임의 기술을 창안하지 않는다. 실제 게임의 현재 연결 카탈로그에 포함되어 있다는 뜻이 아니다.

| 연결 | 무림 조건 후보 | 현실의 역할 후보 | 현실 내 성장 |
|---|---|---|---|
| R1 마력 개화 | 노방 활용 + 첫 현실 귀환 | 가까운 위치 지정 후 지연 광역 공격. 레이드 소환 적의 집결 시점에 배치 | 현실 개별 성취 + 정해진 강화 재료 |
| R2 회피 연계 | R1 습득 + 접무 활용 | 적의 실제 위험을 회피하면 다음 R1/R3의 마력 소모를 1회 감소. 비중첩, 시간 만료 | 별도 액티브 버튼 대신 연결 트리 노드 후보 |
| R3 응축 검격 | R1 습득 + 토염 활용 | 좁은 전방 집중 공격. 보스 취약 시간을 예측해 사용 | 해당 현실 기술의 독립 성취·강화 |

R2는 허공 회피로 충전을 만들지 않으며, 같은 위협으로 반복 충전하지 않는다. 무림 접무에 방벽·충격 저장을 역으로 추가하지 않는다. R1/R3는 별도 액티브이며 D-043에 따라 현실 일반 기술과 공용 2슬롯을 사용한다. R2는 학습한 연결 패시브로 별도 버튼을 차지하지 않는다. 세부 효과는 DOC-23에서 비교한다.

연결 조건에 N1~T2의 강화 구매를 요구하지 않는 안을 추천한다. 모든 강화를 산 뒤 현실에서도 다시 재료를 지불하는 이중 부담을 줄인다. 무림 투자 수치는 현실 피해 배율로 복사하지 않는다.

**연결 경제 — 사용자 확인:** 첫 R1부터 기존 연결 재화로 학습한다(D-039). 무림 조건 달성은 학습 자격만 열며 스킬을 자동 지급하지 않는다. 각인은 영구 자격 아이템으로 재정의하지 않는다. 무림 성취의 기존 정산과 새 매화 성취의 지급 대응은 전체 보상 설계에서 정한다.

| 노드 | 학습 비용 제안 | 학습 뒤 강화 제안 |
|---|---|---|
| R1 | 무공 각인 1 + 공명 결정 2 | R1 개별 성취와 공명 결정으로 정해진 강화 |
| R2 | 무공 각인 1 + 공명 결정 2 | 비중첩·1회 소모 원칙 안에서 효과 조정 |
| R3 | 무공 각인 1 + 공명 결정 3 | R3 개별 성취와 공명 결정으로 정해진 강화 |

숫자와 두 재화의 비용 조합은 새 노드의 비교용 제안이며 기존 카탈로그의 비용을 바꾸지 않는다. 모든 연결의 선행·비용·잔량·획득 경로를 무림/현실 양쪽에서 확인할 수 있어야 한다. 재료 부족은 학습 대기이며 자격 소멸이 아니다. 최초 학습은 1회만 소비한다. 연결 해금·회상·재접속으로 자격 보상과 학습을 중복 처리하지 않는다.

**새 공급 후보:** DOC-24에 기초 무림 성취로 각인 1·결정 2, 접무·토염 성취로 추가 학습 예산을 얻는 안을 마련했다. D-041에 따라 일반 레이드에서도 공명 결정을 획득하므로 R1 없이 부족한 결정을 보충할 수 있다. 각인은 여전히 무림 성취 전용이다. 표상 공급/비용은 비교했지만 플레이 검증·기존 저장의 정산 대조를 완료한 것은 아니다. 반복 무림 재료의 자동 환전은 금지한다.

## 9. 획득에서 레이드까지의 진행 예시

1. 현실 임무 → 무림 이동 → 백련 구조·삼재검법 기초 전수. 기존 화산행과 첫 귀환 시점 유지.
2. 치료 후 백련의 개인 제자 제안을 수락하면 노방 습득. 고유 트리와 현실 대응을 확인한다. 거절해도 귀환 가능하다. D-047에 따라 첫 귀환 후 안정화가 끝나면 백련을 찾아 다시 수락할 수 있다.
3. 노방 직접 편성 → 실전/허용된 수련 → 선행 성취 충족. 수련첩 2개를 접무 학습 또는 노방 강화에 사용할지 고른다.
4. 접무를 배웠다면 노방과 함께 편성하거나 삼재 기술을 유지한다. 접무 성취 후 토염의 학습 조건을 확인한다.
5. 수문장 제압 후 현실 귀환. 미완성 매화 트리와 기존 성취를 보존한다. 미달한 연결 조건은 ‘남은 조건’으로 표시한다.
6. R1의 무림 성취 조건과 각인·결정 잔량을 확인하고 학습 비용을 지불한 뒤 편성한다. 레이드의 적 집결을 예측해 사용한다.
7. 레이드에서 현실 개별 성취와 성장 보상을 얻는다. 무림 수치를 그대로 올리는 대신 현실의 강화에 투자한다.
8. 다음 무림 수련을 선택하면 접무·토염의 성취와 대응 노드를 목표로 한다. 매번 재료 납품을 위해 왕복하지 않는다.

호송 중 장시간 수련을 필수로 요구하지 않는다. 후속 목표는 첫 귀환 후 안정화·왕복을 열고 선택 수련을 제공하는 것이다. 현실 첫 레이드와 반복 수련은 아직 새 여정에 구현되지 않았다.

| 검토 대상 | 유지할 이유 | 수정 또는 폐기할 징후 |
|---|---|---|
| 노방·접무 분리 | 지속 전투와 회피 대응의 선택 | 접무가 항상 노방의 상위 호환 |
| 고정 강화 가지 | 초식 확장과 깊은 투자의 선택 | 후속 학습 전에 전부 구매하는 것이 사실상 필수 |
| 2슬롯 | 전투 목적에 따른 조합 | 조합 없이 항상 같은 2개만 사용하거나 지나친 교체 노동 |

| 현실 대응 | 무림 성취가 새로운 레이드 활용을 제공 | 이름만 바뀐 같은 기술, 동일 수련의 이중 반복 |
| 영구 투자 | 성장 기록과 선택의 의미 | 다른 무공을 키울 재료가 없어 진로 변경 불가능 |

## 11. 다음 상세 기획 순서

1. 확인한 Q-01~04를 바탕으로 초식 역할·새 강화·연결 비용 후보를 검토한다. 새 수치는 아직 채택하지 않았다.
2. 대표 현실 레이드 1종: DOC-23에 일반/연결 활용과 보스 공략 초안을 작성했다. 효과의 역할을 검토한다.
3. 보상·성장 속도: DOC-24에 회차·재료·학습 예산 초안을 작성했다. 실제 시간 대비 효율을 검토한다.
4. 첫 귀환·왕복·현실 능력 확인 장면: DOC-25에 초안을 작성했다. 상황 전달과 선택의 순서를 검토한다.
5. 전투력 평가·랭킹과 두 번째 일반 무공을 통해 선택이 유지되는지 검토한다.

이 문서 작성은 위 후속 콘텐츠의 구현·푸시·배포 승인이 아니다.

## 12. 제4~24초식 확장 원칙

- 사용자 제공 번호와 이름을 보존한다. 19/23의 같은 이름을 임의로 수정하지 않는다.
- 초식마다 독립 액티브·고정 연계·기존 기술 보강 중 역할을 먼저 결정한다. 24개 버튼 또는 일렬 순차 학습을 강제하지 않는다.
- 제1~3초식의 N/J/T 강화는 그대로 해당 초식에 남는다. 새 초식이 기존 초식을 없애거나 다른 무공으로 변형하지 않는다.
- 고급 초식의 선행은 고유 트리에서 명시한다. 모든 앞 초식 대성·모든 강화 구매를 일괄 요구하지 않는다.
- 고급 초식을 배워도 초기 초식의 효율·대응 역할이 남는지 확인한다. 그렇지 않으면 고급 기술 역할이나 비용을 수정한다.
- 현실 연결은 초식마다 새 버튼을 하나씩 만드는 방식으로 확대하지 않는다. 각 연결의 사용 목적과 학습 비용을 따로 검토한다.
- 확장 전에 추가 슬롯의 필요성, 투자 재료 공급, 주요 경지 조건을 사용자에게 확인한다. 이번 문서로 제4~24초식의 역할을 확정하지 않는다.
