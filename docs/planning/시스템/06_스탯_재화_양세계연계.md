# 06. 스탯·재화·양세계 연계

## 자원의 역할

| 자원 | 적용 세계·용도 | 현재 범위 |
|---|---|---|
| 단련석 | 무림 영구 스탯 배분 | 신규 1~2장 구현, 명칭·수량·효과는 검증안 |
| 수련첩 | 무림 공통 노드 투자·매화 후속 초식 학습 | 신규 1~2장 구현, 명칭·수량은 검증안 |
| 공명 결정 | 무림 성취를 매개로 현실 능력 성장 | 기존 독립 정산 원장 유지, 첫 귀환에서 잔량 확인 |
| 무공 각인 | 무림 성취를 매개로 현실 스킬 성장 | 기존 기반 유지, 신규 현실 트리 개편은 후속 |

단련석/수련첩은 무림에서의 직접 성장 재료이고, 공명 결정/무공 각인은 무림→현실 연결 매개다. 처음 검토했던 A/B/C/D 양방향 아이템안은 현재 설계가 아니다. 현실→무림 성장 재화를 새로 추가하지 않는다.

## 무림 공급·배분 — 현재 코드의 검증안

| 획득 | 단련석 | 수련첩 |
|---|---:|---:|
| 시작 기록 `start` | 3 | 2 |
| 화산행 각 길목 최초 완료, 총 10개 | 2씩 | 1씩 |
| 귀환길 각 전장 최초 완료, 총 3개 | 3씩 | 1씩 |
| 선택 기연 최초 완료 | 4 | 2 |

튜토리얼 처치마다 이 표의 재료를 반복 지급하지 않는다. 지급 원장 ID는 최초 완료와 연결하며 중복 대화·재접속·재시도로 재발급하지 않는다. 잔량은 총 지급에서 확정 투자를 빼서 계산한다. 선택 기연 제외 총 공급은 단련석 32/수련첩 15, 포함 시 36/17이다. 이는 현재 값의 합계이며 최종 경제 밸런스 확정이 아니다.

단련석 1개로 공격 +2 / 최대 생명 +10 / 최대 기력 +5 중 선택한다. 레벨에 따른 기본 성장도 별도로 유지한다. 각 배분 항목은 현재 코드에서 최대 100 검증 상한이다. 스킬의 생명·기력 보너스 및 천흔 호흡 보너스와 출처를 구별한다.

## 영구 투자

현재 수치 → 초안 +/− → 예상 결과·사용량 확인 → 영구 확정으로 진행한다. 초안 취소는 가능하지만 확정 이후 스탯·스킬 감소/초기화/환불은 금지한다. 새로운 기연·문파 이동·세계 전환을 환불 계기로 삼지 않는다.

현재 전장을 확보하면 배경·위치를 유지한 채 투자한다. 전투 중에는 확정할 수 없다. 매화 제2·3초식 학습은 각각 수련첩 2개를 영구 소비하며 기존 공통 투자와 같은 잔량에서 차감한다. 현재 구현은 능력 변화 전후 HP/기력 비율을 보존하며 저장 실패 시 상태를 되돌린다. 재료를 쓰지 않고 아끼는 것도 가능하다. 메뉴 조회·알림 읽음은 투자 확정이 아니다.

## 무림 → 현실 연계

무림 성취의 원천 ID와 현실 반영 기록을 분리하고 같은 성취를 반복 정산하지 않는다. 한 세계의 레벨·스탯·숙련 숫자를 다른 세계 기록에 그대로 덮어쓰지 않는다. 기존 공명 원장과 과거 직접 보너스는 이행 이력을 보존한다.

신규 여정의 첫 귀환에는 현실 성장 재료 잔량을 안내하지만 **모든 무림 던전 재료를 공명 결정으로 환전하는 규칙은 없다.** 기존 공명 카탈로그가 인정하는 성취를 사용한다. 신규 현실 전투·현실 투자 동선이 완성됐다는 뜻이 아니다. 실제 기준: [boundary-resonance.js](../../../boundary-resonance.js), [world-achievements.js](../../../world-achievements.js).

양세계가 연결된 성취와 각 세계의 독립 투자·기술 성취는 함께 보존한다. 현실 스킬 개별 성취는 D-027의 확정 원칙이고 상세 요구·효과는 검증안이다.

## 에너지·저장 경계

영구 능력치, 소모 자원, 속성, 친화/사용 자격, 문파 소속은 다른 개념이다. 내력·마력·마기·성력을 무조건 네 개 배분 항목이나 네 개 게이지로 만들지 않는다(D-010 미정). 초기 운용 분리, 별도 기연을 통한 혼합·공존은 방향 합의이며 기연 전 동시 잠재 보유는 미정이다(D-011-A).

기존 완료·투자·성취를 임의로 줄이거나 새 공식에 환산하지 않는다. 신규 여정 상태, 기존 캠페인, v0.14 이행은 [현재 구현·제한](../개발방향/18_현재구현과_제한.md)의 범위대로 구분한다.
