## 화면의 역할

| 화면 | 현재 신규 여정에서 제공할 정보 |
|---|---|
| 이야기 장면 | 이미지·화자·대사·다음/건너뛰기. 제자 선택은 명시적 별도 입력 |
| 준비 | 다음 목적지 하나, 성장 확인, 선택 기연 진입/건너뛰기, 재도전 |
| 캐릭터 | 단련석 잔량·배분 초안·현재/예상 수치·확정 비용 |
| 무공·스킬 | 세 분기·실제 선행선·학습 조건·효과·성취·수련첩 |
| 단축키 설정 | 습득 기술만 선택, 슬롯 배치/교환/해제 |
| 전투 HUD | 기본 공격·회피, 습득 후 배치한 선택 기술, 실제 키·비용·쿨다운 |

경지·헌터 승급·현실 트리·미습득 기연 키를 초반에 모두 노출하지 않는다. 성장 메뉴나 입장 선택을 위해 필드 NPC에게 왕복하지 않는다. 목표 클릭·대화·메뉴 조작이 배경 공격으로 전달되지 않아야 한다.

## 레드닷

최초 기능 안내, 새 재료 지급, 새 기술·문파 학습 기회의 미확인 여부를 안내한다. 해당 화면을 열어 정보를 확인하면 해제하고 읽음 기록을 저장한다. 미사용 재료가 남았다는 이유만으로 계속 켜 두지 않는다. 새 획득이 생기면 다시 표시한다. 전투 중에는 짧은 변화 안내를 우선한다. 구현: [murim-notices.js](../../../murim-notices.js).

## 트리와 전투 버튼의 차이

트리에는 배우지 않은 노드의 실제 선행·잠김 이유·다음 효과가 남는다. 영구 투자 전에 진로를 비교할 수 있어야 한다. 전투 HUD에는 미습득/미장착 선택 기술과 예고용 빈 슬롯을 표시하지 않는다. 패시브는 전투 버튼으로 만들지 않는다.

표시 이름·아이콘·입력·접근성 문구·기술 비용·쿨다운은 같은 배치 데이터를 사용한다. 슬롯 키 변경과 기술 장착을 분리한다. 고정 Q/R/F를 기연 성장 단계의 이름처럼 쓰지 않는다.

## 투자와 대화

초안 +/−와 취소는 허용하고 확정 후 재분배는 금지한다. 효과·비용·영구성을 실행 전에 보여준다. 저장 실패 시 변경을 취소하고 재시도할 수 있어야 한다. 대화 읽기·회상·건너뛰기로 보상이나 제자 선택을 중복 확정하지 않는다.

이미지·지역 준비 실패는 현재 장면/진행을 유지하며 재시도를 제공한다. 닫기·저장 교체 뒤 늦은 비동기 응답이 이동이나 다른 화면을 덮지 않아야 한다.

## 아트와 음향의 실제 범위

현실은 현대 생활권과 마법적 위협, 무림은 대숲·산길·검로·호흡을 우선한다. 장면 이미지는 기존 정지 이미지 자산을 재사용했다. 모든 던전·문파 인물의 전용 그림·초상·동작을 새로 만든 것은 아니다. 같은 이미지 반복과 여행자의 공통 초상은 후속 체감 검토 항목이다.

대량 신규 아트·동행 AI는 현재 범위에 넣지 않는다. 이전 합성 효과음 제작 문서는 연결 제거를 기록한 보관 자료이며, 새 음악/효과음 기능 구현 근거로 쓰지 않는다. [화면·출처](../자료/21_화면과_자산출처.md)에 실제 자료와 제작 이력을 연결한다.

## 확인 기준

데스크톱·360px 모바일에서 본문·선택·잔량·확정 버튼을 읽고 조작할 수 있어야 한다. 390×844 및 글자 확대는 검증 목록에 포함하되 이번 문서 작업에서 직접 확인했다고 쓰지 않는다. 탭 이동과 터치도 같은 기술만 실행한다.

공통 도움말·입력 설정·회상·가져오기 미리보기까지 옛 즉시 왕복·별도 전수자 필수 진행·옛 기술명이 새 여정에 섞이지 않는지 본다. 실제 테스트 순서는 [플레이 테스트](../개발방향/19_플레이테스트.md)를 따른다.
