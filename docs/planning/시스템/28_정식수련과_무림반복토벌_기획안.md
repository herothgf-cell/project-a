## 1. 확정 방향과 역할

- D-055: 정식 수련은 지정 기술1종의 짧은 과제, 완료 숙련+1, 반복 재화/경험치 없음. 목표2~3분은 검토값.
- D-056: 기본 과제 수행으로 완료한다. 무피격·정밀 회피·시간 기록은 보상 없는 선택 기록이다. 실제 회피가 기능인 R2만 넉넉한 전조에서 회피→할인 소비를 연습한다.
- D-057: 무림 토벌은 확보 지역에서 분산 적 정리/강한 적 빈틈 공략 두 구성을 공개 선택한다. 동일 보상이며 삼재만으로도 완료 가능. 4~6분·수련첩1·무림XP40은 검토값.

수련은 ‘다음 기술을 얻거나 부족한 숙련을 보완’, 토벌은 ‘편성을 써 보며 무림 재료 확보’, 현실 레이드는 ‘준비한 역할을 공략에 적용’하는 선택이다. 셋을 매번 순서대로 완료하도록 강제하지 않는다. 해당 세계의 수련과 반복 토벌은 첫 귀환·안정화 이후 거점에서 개방하는 기존 후보를 따른다. 호송 중 필수 수련을 추가하지 않는다.

## 2. 수련 공통 계약

| 단계 | 내용 | 완료/저장 규칙 |
|---|---|---|
| 선택 | 배운 기술1종·현재 숙련·남은 조건·과제·보상 표시 | 미습득 기술은 미리보기만 가능, 실전 숙련 없음 |
| 기본 연습 | 짧은 안내 뒤 핵심 행동을 서로 다른 배치에서2번 수행하는 후보 | 허공 입력 무효. 같은 발동의 다중 명중을2번으로 세지 않음 |
| 적용 연습 | 작은 전투에서 지정 기술 유효 사용과 공개된 목표 완료 | 모든 적 제압. 지정 기술 미사용이면 보완 표적을 제공해 재시작 강요 방지 |
| 결과 | 지정 기술 숙련+1, 다음 자격/강화 변화 표시 | 한 과제 회차에서1회만 확정. 선택 기록은 추가 숙련·재료 없음 |

2~3분은 처음 익힐 때의 목표이며 최소 대기시간이 아니다. 잘하는 플레이어가 빨리 끝내면 즉시 완료한다. 성공 횟수를 위해 일정 시간을 강제로 버티게 하지 않는다. 과제는 난이도 점수로 잠그지 않고, 같은 기술의 배치 A/B 중 선택하게 하는 후보다. 반복할 때 설명을 다시 읽지 않아도 목표는 화면에 남는다.

수련용 공간은 시작/구간 재시작 때 해당 세계 HP·자원을 회복시키는 후보이며 바깥 임무와 이어지지 않는다. 피격은 과제 전체 실패가 아니고, 사망하면 현재 구간만 재시작한다. 이미 완료한 기본 구간은 같은 회차에서 보존하되 영구 숙련은 최종 완료 때만 지급한다. 철수하면 미완료 과제 기록은 폐기하고 기존 성장은 유지한다. 재접속은 같은 회차의 구간 시작에서 재개하고 결과 재표시는 재지급하지 않는다.

수련에서 지정하지 않은 기술은 사용할 수 있어도 숙련을 받지 않는다. R2 수련 중 보조 R1/R3 사용도 동반 숙련을 주지 않는다. 수련 편성은 별도 임시 편성으로 준비하고 종료 시 기존 전투 편성을 복구하는 후보다. 미습득 기술을 빌려줘서 소유/성취를 늘리지 않는다.

**보상 예외의 구분:** 수련 자체의 반복 재료/XP는 없다. 다만 수련 완료로 기초/접무/토염의 기존 최초 성취를 달성하면 DOC-24의 각인·결정 정산 자격은 생긴다. 이는 같은 성취당1회이며 수련 반복 드롭이 아니다. 화면에서도 ‘수련 완료’와 ‘최초 성취 달성’을 분리한다.

## 3. 무림 정식 수련 과제

백련에게서 배운 내용을 스스로 연습하는 화산의 안전한 연무 공간 후보다. 문파 가입·출석·평판·사부 반복 보고를 요구하지 않는다. 처음 한 번만 맥락을 보여주고 이후 메뉴에서 바로 선택한다. 노방/접무/토염은 해당 초식을 실제 습득해야 한다.

| 기술·과제 | 기본 연습의 공개 조건 | 적용 연습 | 선택 기록과 현실 연결 |
|---|---|---|---|
| 삼재검격 — 거리 잡기 | 가까운 표적과 떨어진 표적에 접근해 각각 기본 검격 유효 명중 | 느린 적2명을 제압하며 기본 검격 사용 | 불필요한 피격/헛공격 줄이기. 기초3회 성취 후보의 유효 활동 |
| 삼재 횡검 — 검로 정리 | 서로 다른 배치의 표적에 횡검 유효 명중2회 | 흩어진 적3명 중 우선 표적을 골라 횡검 사용 후 제압 | 여러 적 동시 적중은 선택, 필수 아님 |
| 매화노방 — 주변 거리 유지 | 좌우에 바뀌어 놓인 근거리 표적을 노방으로 각각 공격 | 접근하는 느린 적3명을 제압하며 노방 사용 | 한 발동에 여러 적을 맞히는 기록. 현실R1의 집결 처리와 연결되지만 무림에는 지연 지정 공격을 추가하지 않음 |
| 매화접무 — 피한 뒤 검세 잇기 | 넓게 예고된 공격 범위를 이동/기본 회피로 벗어난 뒤 접무 유효 명중, 두 배치에서 수행 | 느린 공격자1명+견제자1명을 대응하며 제압 | 접무 자체의 무적 구간으로 피하는 것은 선택 기록. 정밀 회피를 학습 자격에 강제하지 않음 |
| 매화토염 — 빈틈에 검로 맞추기 | 앞쪽 표적의 멈춤 표시를 보고 토염 유효 명중2회 | 크게 공격한 뒤 멈추는 적1명과 약한 적1명 제압 | 일렬 다중 적중은 선택. 현실R3의 빈틈 활용과 이어지되 무림 효과를 마력 기술로 바꾸지 않음 |

배치 A/B는 좌우·접근 방향·우선 표적 위치를 바꾼다. 숨겨진 정답이나 새로운 추리 조건을 넣지 않는다. 표적은 횟수가 채워질 때까지 재등장하며 과도한 공격력으로 한 번에 제거해도 과제 진행이 막히지 않는다. ‘유효 명중2번’은 이 수련의 행동 과제일 뿐 전체 성장 집계를 명중 누적으로 되돌리는 규칙이 아니다. 영구 숙련은 끝까지 완료해야 +1이다.

삼재 1~9성의 완료 횟수별 보너스는 이번에 새로 확정하지 않는다. 삼재 완료 기록과 기초 정산 조건을 연결하되, 매화0/3/8을 삼재 전체에 복제하지 않는다. 실제 개발 전 삼재 단계 대응과 구 저장 처리표가 필요하다.

## 4. 현실 정식 수련 과제

현실 안전 구역의 표적·관측된 공격 동작을 활용한 연습 후보다. G1/G2는 귀환 후 사용 가능하고 R1/R2/R3는 유료 학습 뒤 개방한다. 레이드를 먼저 깨야만 R1 연습이 가능한 순환 조건은 없다. 첫 레이드 전에는 동작 연습으로 안내하고 아직 관측하지 않은 갑각수의 정체·전체 패턴을 미리 안다고 서술하지 않는다.

| 기술·과제 | 기본 연습 | 적용 연습 | 실제 레이드에서 쓸 판단 |
|---|---|---|---|
| G1 — 짧은 틈 잡기 | 이동 후 잠시 멈춘 표적을 G1으로2회 공격. 초심자용 멈춤 시간은 넉넉하게 | 단일 표적2개를 골라 제압 | 지금 보이는 작은 공격 기회 활용 |
| G2 — 두 타격 완성 | 충분히 긴 안전 표시 중 같은 표적에2타 적중을2회 완성 | 느린 공격 표적을 피하고2타 완성 후 제압 | 짧은 틈엔 욕심내지 않고 완성할 틈 선택 |
| R1 — 집결점 선점 | 표시된 위치로 이동하는 표적의 도착을 예상해 폭발 유효 명중2회 | 집결 표적2개와 고정 목표1개 처리 | A조건의 집결 처리. 다중 적중은 선택 기록이며 기본은 실제 피해 인정 |
| R3 — 준비 시간 확보 | 멈춤 예고를 보고 준비 동작을 끝내 유효 명중2회 | 큰 공격 뒤 쉬는 표적의 빈틈에R3 사용 후 제압 | B조건의 돌진 회복·핵 노출 활용 |
| R2 — 회피 뒤 자원 회수 | 실제 자신에게 닿을 공격을 회피→4초 내 보유R1/R3 할인 소비를2회 수행 | 같은 연결 행동을 작은 적용 구간에서1회 수행 | 회피만으로 끝내지 않고 할인 소비까지 연결 |

R2 과제는 피해가 낮고 전조가 긴 표적을 쓰되 실제 충전 판정을 우회하지 않는다. 회피 실패는 해당 시도만 다시 한다. 다른 기술의 숙련·입장을 R2 과제 성공에 묶지 않는다. G2는 두 번째 타격까지 살아남는 연습 표적을 써서 고성장 상태에서도 완성 행동을 평가한다. 학습용 표적의 피해 표현은 실제 적 HP 자동 상향과 구분한다.

## 5. 무림 반복 토벌 — 천흔 외곽 잔당 정리

첫 귀환 후 안정화와 안전 이동이 열린 뒤, 이미 확보한 천흔 옛길 인근에서 선택하는 임무다. 같은 수문장을 매번 부활시키거나 백련의 부상 장면을 되풀이하지 않는다. 남은 위협 때문에 옛길 주변을 정리한다는 맥락이며 세력 정체는 확정하지 않는다.

입장→짧은 전투 구간→안전 준비 지점→마무리 전투→정산, 목표4~6분 후보다. 안전 이동은 무료 이동 기능으로 남고 이 토벌을 통행료처럼 강요하지 않는다.

| 항목 | 분산 적 정리 | 강한 적 빈틈 공략 |
|---|---|---|
| 첫 구간 후보 | 근접2·견제1을 최대 동시3으로 처리 | 호위2를 제압하며 거리 확보 |
| 마무리 후보 | 좌우 진입 근접2·견제1, 위치를 입장 전 공개 | 느린 우두머리1·견제1 |
| 중심 행동 | 가까운 위협을 먼저 줄일지, 견제자를 먼저 끊을지 | 큰 공격 회피 후 빈틈을 쓰고 다음 공격 전 이탈 |
| 삼재 | 기본 검격으로 우선 표적, 횡검으로 주변 정리 | 기본 검격·횡검을 회복 구간에 사용 |
| 매화 | 노방의 주변 처리, 접무의 대응 후 공격 | 접무로 대응, 토염으로 빈틈 집중 |
| 실패 대안 | 적 수 제한, 떨어뜨려 하나씩 처리 가능 | 시간 제한·회복 무효·전용 파훼 없음 |

우두머리는 내려찍기/전방 돌진 두 행동과 각각의 회복 구간만 쓰는 후보다. 핵 지지체·소환체 집결·3단계 갑각수 패턴을 복사하지 않는다. 최초부터 준비 화면에 행동 특징을 공개한다. NPC 보호 체력·랜덤 경로·추적 도망·희귀 드롭·일일 입장권은 추가하지 않는다.

보상 후보는 두 구성 모두 수련첩1·무림XP40·유효 사용한 무림 기술마다 완료 숙련+1이다. 단련석·각인·공명 결정의 반복 드롭은 없다. 최초 성취 정산은 별개다. 처음부터 두 구성을 선택하며 같은 구성 반복을 금지하지 않는다. 한 번 완료한 구성의 추가 최초 보상을 별도로 만들지 않는다.

안전 준비 지점에서 교체 가능하며 앞 구간의 유효 사용은 최종 성공 시 인정한다. 보스 재도전과 같은 회차 원칙을 재사용하는 제안이다: 완료 구간 기록 보존·실패 구간만 초기화·최종 정산1회·철수 시 미정산 기록 폐기. HP/기력 전부 복원과 임무 회복1회(최대HP30%)는 비교 후보이며 회복 횟수를 재시도마다 쌓지 않는다. 구체 값은 플레이 검증 뒤 조정한다.

## 6. 매화 습득부터 현실 성장까지의 선택 흐름

### 조기 매화 수락·귀환길을 활용한 사례

1. 노방 습득→귀환길1 유효 사용 완료→접무 학습(수련첩2).
2. 귀환길2에서 노방/접무 사용→토염 학습(수련첩2).
3. 귀환길3에서 접무/토염 사용→첫 귀환. 기록은 노방2·접무2·토염1의 사례다.
4. 안정화 뒤 선택: 노방 수련1회로R1 자격을 채우거나, 토벌에서 노방/토염을 함께 사용해 재료도 얻는다.
5. 기초 정산 각인1·결정2로R1 학습→현실R1 수련 또는 일반 스킬과 혼합해 첫 레이드. 연습을 입장 조건으로 요구하지 않는다.
6. 현실에서 결정·숙련을 얻고, 토염의 남은 무림 성취를 원하는 때 보완해R3 학습. 레이드마다 왕복하지 않는다.

노방2·접무2·토염1에서 모든 활용3을 채우는 선택 비교(학습 수련첩4·기초 삼재 성취 확보 가정):

| 선택 | 활동 | 추가 활동 시간 | 추가 수련첩/XP | 결과 |
|---|---|---|---|---|
| 빠른 단일 보완 | 노방1·접무1·토염2 수련 | 8~12분 | 0/0 | 필요한3종 모두 활용3 |
| 재료와 함께 | 토벌 노방+토염1회, 접무+토염1회 | 8~12분 | 수련첩2·무림XP80 | 같은 활용 조건, 편성2개 유지로 가능 |
| R1만 먼저 | 노방 수련1회 | 2~3분 | 0/0 | R1부터 현실에서 활용, 나머지는 나중 |

시간은 실패·이동 제외 목표값이다. 위 사례는 여러 기술이 동시에 부족해 토벌 효율이 좋다. 한 기술만1회 부족하면 수련2~3분이 토벌4~6분보다 빠르다. 토벌이 모든 상황의 유일한 정답이 되지 않도록 대상 수와 실제 시간을 비교한다.

### 재료를 먼저 써 버렸거나 늦게 제자를 수락한 경우

수련첩0이라면 다음 초식 비용2를 위해 토벌2회가 필요하다(8~12분·XP80 후보). 그동안 배운 초식의 성취도 올라간다. 재료가 없는데 숙련 과제만 반복하라고 안내하지 않고 다음 초식 화면에 ‘재료 부족→토벌’을 보여준다. 환불은 하지 않는다.

늦은 수락·노방0·수련첩0 사례: 노방을 쓰며 토벌2회→접무 학습→노방/접무 토벌2회→토염 학습→접무/토염 토벌1회→토염 수련2회. 노방4·접무3·토염3, 수련첩 공급5−학습4=1, 무림XP200, 활동24~36분 후보. 기초 삼재 최초 성취가 미달이면 별도 보완한다. R1은3번째 토벌 뒤 노방 활용을 달성하면 먼저 배울 수 있으므로 전 과정을 끝내기 전 현실로 갈 수 있다.

이미 수련첩4가 있으면 단일 기술 수련9과제(18~27분) 또는 여러 기술을 쓰는 토벌을 섞을 수 있다. 빠른 길 하나를 강요하지 않고 남은 조건·실제 보유 재료를 기준으로 선택하게 한다.

현실 이후 시간·가격은 DOC-27 표를 유지한다. 액티브2종 강화2까지 레이드8회64~96분 또는 레이드4회+집중 수련8과제48~72분이라는 후보 계산이다. 무림 준비와 다른 투자 비용은 별도이며 레벨 상승량은 아직 계산하지 않는다.

## 7. 반복을 줄이는 화면·운영 원칙

- 입장 전 지정 기술·남은 완료 횟수·보상·과제를 한 화면에 표시. 종료 후 ‘같은 과제/다른 구성/성장 확인/거점’ 선택 제공.
- 새 초식 자격이나 활용 조건을 채웠다면 반복 버튼보다 학습/연결 선택을 함께 보여준다. 보상만 확인하려고 NPC를 다시 찾게 하지 않는다.
- 과제 시간 최단 기록은 비교 표시일 뿐 필수 보상 없음. 반복하면 보상이 깎이는 피로도나 특정 요일 우대 없음.
- 수련은 기술1종에 집중, 토벌은 배치·우선순위, 레이드는 임무별 편성 판단. 이름만 바꾼 동일 표적3회 구성을 양세계에 복제하지 않는다.
- 기본 완료는 쉽되 기술마다 핵심 행동은 실제로 수행. 긴 대기·숨은 정답·획득 확률로 수련 시간을 늘리지 않는다.

검증은 노방만 부족/수련첩만 부족/매화 거절/늦은 수락/전부 숙련/고성장 원킬 사례를 포함한다. 이번 문서는 수치 계산과 규칙 설계이며 실제 재미·공략 시간 통과 기록은 아니다.
