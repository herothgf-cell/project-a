# 05. 무공·스킬 — 트리와 성취도

문서 ID: DOC-05 | 기획 버전: **1.1** | 갱신일: **2026-10-08**

[중앙 문서](00_중앙기획서_문서지도.md) · [결정대장](11_결정대장_확답이필요한질문.md)

## 1. 설계 목표와 확정 경계

원본 G-05~G-10, M-06, K-05를 담당한다. 디아블로2식으로 선행 기술을 따라 한 계열을 깊게 파는 재미와, 무공 하나를 1성부터 대성까지 수련하는 재미를 함께 만든다. 특정 게임의 최신 수치·포인트·초기화 규칙을 그대로 복제한다는 뜻은 아니다.

> [검증 후 결정 D-012] 무공 성장의 구체 방식은 구현 테스트 후 확정한다. 선행 성수·포인트 비용·숙련 요구량·기존 강화 환산을 확정 수치로 쓰지 않는다.

> [수정 확정 D-016] 스킬 초기화 금지. 확정한 투자·습득·성취를 초기화하여 재분배하는 기능을 제공하지 않는다.

위 두 결정은 동시에 적용된다. 아직 정해지지 않은 것은 성장 공식이며, 초기화 허용 여부가 아니다. v1.0의 초기화 후 재투자·대성 이력 보존 논의는 현 목표에서 폐기한다.

## 2. 서로 다른 네 축

| 축 | 답하는 질문 | 예시 |
|---|---|---|
| 계열·선행 트리 | 무엇을 먼저 배워야 하는가? | 기초 검법 → 복합 검로 → 매화검법 |
| 개별 성취도 | 이 무공을 얼마나 익혔는가? | A무공 1성→…→9성→대성 |
| 심법·패시브 | 힘을 어떻게 운용하는가? | 내력 효율·기세·연계·안정성 |
| 경지 | 인물 전체가 어느 수준인가? | 이류·일류·절정·초절정·화경 |

무공 대성을 화경과 같게 취급하지 않는다. 하나의 무공을 완성한 인물이 다른 계열을 새로 배울 수 있다. 주력 무공을 깊게 파는 선택과 기초를 넓게 배우는 선택은 서로 다른 빌드다.

현재 v0.12.9에는 실제 선행 조건을 연결한 스킬·심법 트리가 이미 있다(DOC-12 SRC-G02·G05). ‘트리 미구현’이라고 적고 처음부터 중복 시스템을 만드는 것이 아니라, 기존의 강화·습득·수련 구조를 조사해 문파와 영구 성장에 맞게 재설계한다.

## 3. 테스트할 성장 방식

| 실험안 | 성장 방법 | 확인할 장점 | 주의할 문제 |
|---|---|---|---|
| A 포인트 중심 | 영구 포인트를 투자해 성취 상승 | 다음 목표·투자 선택이 명확 | 돈이나 숫자로만 무공을 배운 느낌 |
| B 수련 중심 | 유효한 사용·과제로 성취 상승 | 직접 체득한 감정 | 같은 행동 반복·무의미한 노가다 |
| C 복합 | 수련 증명+영구 투자/전수 조건 | 수련과 빌드 선택을 결합 | 같은 성장을 이중 비용으로 느낄 수 있음 |

세 안은 비교할 후보이며 모두 동시에 게임에 넣는 안이 아니다. 최초에는 화산 한 계열과 파문 한 기연을 대상으로 어떤 방식이 이해·몰입·성장 체감에 좋은지 본다. 테스트 데이터를 본 뒤 D-012의 구체 규칙을 확정한다.

실험 저장은 정식 진행과 분리한다. 개발용 실험 초기화가 플레이어용 재분배 기능이 되어서는 안 된다. 기존 실제 저장의 레벨을 임의 비율로 성수에 환산하지 않는다.

## 4. 1성~9성→대성의 표현 후보

아래는 ‘각 단계에 어떤 차이를 줄 것인가’의 설계 예시다. 모든 무공에 똑같이 적용할 확정 규칙이 아니다.

| 단계 | 성장 표현 예시 |
|---|---|
| 1성 | 핵심 동작과 효과가 성립한다 |
| 2성 | 소모·자세·사용 안정성이 개선된다 |
| 3성 | 실제 위협 대응이나 연계의 첫 증명을 한다 |
| 4성 | 거리·범위·타이밍 활용이 넓어진다 |
| 5성 | 주력 효과를 더 강하게 운용한다 |
| 6성 | 복합 실전·전수·깨달음 조건을 확인한다 |
| 7성 | 후속 초식과 연계가 정교해진다 |
| 8성 | 약점이나 사용 제약을 다루는 숙련이 생긴다 |
| 9성 | 해당 무공의 상위 운용을 안정화한다 |
| 대성 | 완성 증명과 고유한 완성 효과를 얻는다 |

3성·6성마다 반드시 퀘스트를 받게 한다는 확정은 아니다. 조건은 무공 성격에 맞춰 배치한다. 모든 성수 상승을 새 퀘스트 수락·보상 팝업으로 만들면 수련보다 행정 절차가 된다.

고유 기연은 1성에서도 강하고 다른 행동을 할 수 있어야 한다. 특별함을 9성까지 숨겨 두지 않는다. 반대로 기연을 얻는 즉시 1~9성의 수련을 전부 건너뛰게 만드는 것도 필수는 아니다.

## 5. 화산 계열의 시범 구조

[사용자 요청] 24수 매화검법 이전 단계부터 차근차근 발전한다. [확정 D-014] 최초 실제 검증 계열은 화산이다.

```text
입문 검술
 ├ 기초 검로 ─ 화산 기본 검법 ─ 분화·연속 검로 ─ 24수 매화검법
 └ 기초 보법 ─ 거리 조절 ───────────────────┘
                    전수 자격 + 실전 증명
```

이름은 기능 설명용 가칭이며 전통의 실제 계보라고 단정하지 않는다. 정확한 이름은 DOC-14에서 검토하고 선행 성수·필요 경지는 D-012 테스트로 정한다. 장비·일반 성장은 이 계열만 배워도 본편을 진행할 수 있는 토대여야 한다. [D-007]

24개의 초식을 24개 액티브 버튼으로 만들 필요는 없다. 하나의 검법 안의 연속 타격·방향·상황별 변화로 표현하는 안과 소수의 핵심 초식으로 나누는 안을 비교한다. 트리 화면에는 실제 선행 조건만 연결한다.

## 6. 네 종류의 무공

| 종류 | 습득과 성장 | 영구 기록 |
|---|---|---|
| 계열형 일반 무공 | 문파 전수와 선행 기술을 따라 성장 | 습득권·투자·개별 성취·실전 증거 |
| 단독 무공 | 짧은 전수 또는 별도 사건으로 습득 | 해당 기술의 성취, 다른 트리 강제 편입 없음 |
| 기연 비전 | 발견·특수 도전으로 고유 경로 개방 | 기연 사건 ID·소유·기술 체득·후속 수련 |
| 심법·패시브 | 내공 운용·수련·선행 심법으로 발전 | 확정 투자·운용 조건·이야기 체득 |

단일 검법도 필요하다. 모든 무공이 긴 선행 트리를 가진다면 우연히 배운 한 수의 매력이 사라진다. 기연도 독립 비전, 기존 계열의 숨은 진화, 특수 심법·체질로 나눠 비교한다.

[방향 합의 D-006] 첫 파문은 독립된 강한 원리의 체득을 우선 검증한다. 첫 행동 Q, 후속 R, 오의 F는 같은 비전의 발전이다. Q/R/F를 한 번에 주거나 서로 다른 세 기연으로 과장하지 않는다. 일반 화산 성장과 이어지더라도 희귀 소유권이 일반 트리의 공통 선행 조건이 되어서는 안 된다.

후속 ‘매화의 숨은 진화’는 일반 매화검법을 삭제해 다른 트리로 갈아타는 초기화가 아니다. 기존 성취를 토대로 추가 변형이 열리는 방향을 제안한다. 실제 후보는 DOC-13을 따른다.

## 7. 수련 증명과 반복 방지

유효한 적의 공격에 대응했는지, 실제 목표에 명중했는지, 해당 거리·자세·연계를 성공했는지 기록한다. 허공 사용, 무적 대상 반복 공격, 실패 횟수 파밍만으로 수련 조건을 채우지 않는다.

고성장으로 적을 빨리 제압해도 증명 기회를 잃지 않도록 잔류 위협·별도 연습을 둘 수 있다. 그러나 이미 이긴 전투를 강제로 다시 진행시키거나 스펙을 몰래 낮춰 학습을 강제하지 않는다. 이야기로 체득한 패시브를 포인트로 다시 사게 만드는 이중 지불도 피한다.

## 8. 초기화 없는 성장 UX

확정 전에는 현재 효과, 투자 후 효과, 필요한 비용, 열린 다음 가지, 영구 확정 여부를 한 화면에 보여준다. 초안의 +/− 및 취소는 허용하는 UX 제안이며, 실제 저장에 확정된 투자 감소·환불·재분배와는 구분한다.

체험이 필요하면 실제 보유·재화·성취를 변경하지 않는 연습 상태를 사용한다. 연습 종료 뒤 정식 캐릭터의 투자를 되돌리는 방식으로 구현하지 않는다. 영구 선택 안내는 실행 직전에 명확하게 표시하고, 매 클릭마다 여러 경고창을 반복하는 것은 피한다.

이미 습득한 기술의 슬롯 변경과 투자 초기화는 다르다. 장착 규칙은 별도 검토하되 ‘초기화 금지’를 모든 기술 교체 금지로 임의 확대하지 않는다. 새 문파·새 기연·양세계 왕복도 환불의 계기가 아니다.

[구현 차이] v0.12.9의 스킬 초기화 기능은 현재 코드의 사실일 뿐, 새 기획에서는 변경 대상이다. 기존 문서의 ‘초기화 후 재투자’ 절차와 관련 버튼을 목표 UI에서 제거한다.

## 9. 데이터·이전 저장·검수

제안 데이터는 `skillId`, `world`, `lineageId`, `sectId`, `acquisitionEventId`, `prerequisites`, `attainment`, `practiceEvidence`, `committedInvestment`, `opportunityId`다. 실제 파일·형식은 개발 시 현행 모델에 맞춘다. 투자 기록은 영구 성장의 감사 근거이지 환불 가능 잔액이 아니다.

D-012가 미확정이므로 기존 강화→성수 자동 환산은 보류한다. 이전 저장의 습득·성취·투자 사실을 보존하고, 실제 이행안이 승인되면 대응표·백업·중복 적용 방지를 함께 검증한다. 초기화 금지 정책을 이유로 예전 저장을 조용히 손상시키지 않는다.

검수 대상: 실제 선행선과 해금 일치, 트리 순환 없음, 일반 경로 완주, 개별 무공과 경지 구분, 영구 확정 후 감소/환불 요청 거부, 초안 취소 시 저장 불변, 연습 종료 시 재화 불변, 세계별 장착·숙련 분리, 이야기 체득의 재구매 방지. 현재 실행 결과가 아닌 후속 테스트 정의다.
