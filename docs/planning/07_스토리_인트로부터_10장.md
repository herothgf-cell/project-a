## 2. 전체 서사의 원인과 인물 역할

**개편의 중심:** 회수 보조 윤서가 무림의 일반 수련으로 작은 승리를 얻고, 한계를 경험한 뒤 더 배워 두 세계의 사람들을 지키는 사람이 된다. 파문은 일부 여정에 추가되는 강한 힘이다. 파문이 없는 여정도 이 서사를 완결한다.

흑조회는 통로와 물류를 통제하기 위해 일부 지역의 균열·천흔을 조작한다는 제안이다. 모든 게이트의 기원이나 세계 전체의 적으로 확대하지 않는다. 감독관의 잘못은 강한 능력의 소유가 아니라 통행권을 빌미로 사람을 위험에 몰아넣는 행위다.

백련은 구조받은 사람에서 첫 스승으로, 서린은 현장 관리관에서 윤서의 판단을 맡기는 책임자로 변한다. 연화는 구조 대상에서 물류 증거의 해석자로, 도겸은 초반 지원자에서 공동 작전의 현장 책임자로 발전한다. 화산 정식 전수자는 백련의 소속을 임의 확정하지 않고 일반 성장 경로를 구체화하는 신규 역할 제안이다.

## 3. 진행과 저장의 공통 계약

아래 `story.c01.*` 등은 **제안 상태명**이다. 현행 필드가 아니다. 실제 개발에서는 기존 `progress`, `fate.stage`, `chapter4`, `journey`, `laterStory`, `worldState.cycleOne` 등과 대응표를 승인받아 이행한다.

- **장 완료:** 필수 사건 증거와 필요한 보고가 충족될 때 1회 확정한다. 기연 소유·최고 경지·최고 헌터 등급은 공통 조건이 아니다.
- **분기:** `resolutionMethod`는 `ordinary` 또는 `ripple` 등 실제 해결을 기록한다. 캐릭터를 평생 한 분기로 잠그는 직업 선택이 아니다. 파문 보유자도 일반 해법을 쓸 수 있다.
- **NPC 정보:** `evidence.discovered`와 `reports.deliveredTo`를 분리한다. 동일 세계 관측·무전도 정보 출처가 될 수 있으나 상대 세계 자료는 윤서가 전달하기 전 알 수 없다.
- **재도전:** 전투 실패는 미완료 시도 상태만 되돌린다. 이미 체득한 일반 무공·초식·기연·확정 투자·완료 장·전달된 보고는 보존한다.
- **대화:** 페이지 넘김·회상·건너뛰기는 사건 증거가 아니다. 실제 행동 뒤 결과 확정 이벤트가 완료를 기록한다. 같은 대화가 보상을 재지급하지 않는다.
- **귀환:** 새 성취만 1회 정산한다. 초식 체득마다 현실 액티브 스킬을 하나씩 자동 생성하지 않는다.
- **조작 표기:** 본 문서의 핵심/연계/오의는 `signature1/2/ultimate` 역할이다. 과거 Q/R/F 표기는 입력 확정값이 아니다. 현행 기본 키는 E/R/F이며 설정을 바꿀 수 있으므로 UI에는 현재 바인딩을 표시한다.
- **파트 종료:** 보스 제압과 장 완료 보고를 구별한다. 보스 사망 후 미보고 상태에서 재접속해도 보고가 가능해야 한다.
- **장비·보급:** 기존 일반 전투·보급을 기준으로 하며 새 경제 시스템을 필수로 추가하지 않는다. 숫자·슬롯 확대는 D-014 별도 검토다.

**성장:** 공통 검술의 한 가지 유효한 변화와 일반 수련 이력을 준다. 24초식, 심법 트리, 경지, 헌터 승급을 함께 열지 않는다. 현행 월영참·천뢰격을 화산의 정식 선행 무공이라고 단정하지 않고 기능 가칭과 대응을 별도로 정한다.

**현실 결과:** 지원 참여자인 윤서가 '제한 구역의 동료 철수를 맡길 수 있는 사람'으로 기록된다. 공식 등급은 자동 승급하지 않는다.
**대사 제안:** 서린 “이번에는 네가 길을 열었네. 다음 출동에서도 그 구간을 맡아 줘.”
**완료 제안:** `c01.basicProof && c01.forestRouteSecured && c01.realityRescue && c01.resultReported`.
**예외:** 고성장으로 두목을 즉시 제압해도 승리를 인정한다. 놓친 기본기 연습은 보상 없는 별도 수련으로 보완하며 완료된 전투를 강제 재생하지 않는다.
**선택 콘텐츠:** 약방 물자 회수·화산 검객에게 검로 질문. 기연 획득 조건으로 자동 간주하지 않는다.
**검증 T-S01:** 기연 OFF 상태에서 C01-01~06 완료, 첫 역할 변화와 공식 등급 구분, 초반 UI 동시 해금 방지.

## 7. 2장 — 검은 인장의 길

**진입:** 1장 완료. D-024 B에 따라 독립 첫 스승 백련과 별도 화산 전수자를 만난다. 정식 문파 가입 계약·전수자의 개인 과거는 후속 설정이다.

| 사건 ID | 사건·행동 | 결과 |
|---|---|---|
| C02-01 | 백련에게 현실에서 확보한 검은 인장을 보여줌 | 백련이 자기 부상 현장의 표식과 닮았음을 말함 |
| C02-02 | 화산 전수자가 검로·보법을 실제 적용하는 과제를 제시 | 일반 계열의 다음 수련권. 이미 배운 동작을 다시 구매시키지 않음 |
| C02-03 | 월영 폐사 호위·봉인 이상 조사 | 감독관의 얼굴·손목 표식·운송 지시를 처음 목격 |
| C02-04 | 수문장 제압, 현장 인장·화물 표식을 확보 | 폐사 위협 해결, 무림 성취 보존 |
| C02-05 | 자료를 현실에 전달한 뒤 항만 위협과 흑조 집행관 처리 | 현장 승리와 반입 흔적 확보 |
| C02-06 | 철수 중 회수 통로에 별도 압력 발생, 동료 시간을 벌고 긴급 철수 | 해결한 항만 임무와 실패한 통로 방어를 구분 |

**보스·위협:** 월영 수문장은 세 인장과 연계되는 예고를 사용한다. 인장은 접근 가능한 환경 과제이며 특정 기연이 없어도 해제할 수 있다. 흑조 집행관은 감독관과 다른 현장 집행자다. 집행관을 쓰러뜨린 승리를 취소하지 않는다.

**강제 철수의 설득력:** 적 체력을 숨겨 무적으로 만드는 대신, 끊어진 통로의 압력이 적 처치와 별개임을 보여준다. 주 목표는 퇴로 유지·인원 철수다. 윤서가 강해도 인원은 더 안전하게 구하지만 현 장비로 통로 자체를 유지하지 못한다. 실패 횟수·사망 파밍 없음. 12초는 현행 구현 수치이며 개편 확정값이 아니다.

**일반 성장:** 화산 기본 검로와 보법 활용. 전수권과 주 문파 소속은 별도 상태다. 파문 자동 예약 없음.
**완료 제안:** `c02.templeSecured && c02.harborSecured && c02.evacuationConfirmed && c02.retreatReported`.
**NPC 정보:** 서린은 C02-05 전달 전 폐사 표식을 모르며, 백련은 항만 결과 전달 전 그곳의 승리를 모른다.
**예외:** 철수 직전 저장·적 선처치·체력 고갈 모두 동일한 철수 결과로 수렴하며 기존 보상은 중복 지급하지 않는다.
**검증 T-S02:** 항만 승리 보존, 과성장에서도 철수 인과 유지, 서린의 미전달 정보 선사용 방지.

## 8. 3장 — 다시 지킬 수 있는 길

**진입:** 통로 철수 보고. **공통 목표:** 일반 수련과 현장 준비로 재도전할 수 있게 한다. 파문은 추가 경로다.

| 사건 ID | 일반 필수 흐름 | 선택적 파문 흐름 |
|---|---|---|
| C03-01 | 백련에게 압력의 성질을 설명하고 검술·보법 재수련 | 설명만으로 기연 위치나 보상이 공개되지는 않음 |
| C03-02 | 화산 전수자의 거리·빈틈 대응 과제 | 별도 조건이 있는 여정에서 계곡의 이상 반응 발견 |
| C03-03 | 도겸과 엄폐·일반 안정화 수단·철수 위치 확인 | 메아리 없는 바위에서 실제 위협을 받아 되돌리는 첫 체득 |
| C03-04 | 호위·연결 매듭 제거 후 압력 예고를 피하며 근원 제압 | 파문 보유자는 흡수·반격으로 공격 기회를 더 크게 만듦 |
| C03-05 | 통로 안정과 인원 통과 확인 후 서린에게 결과 전달 | 실제 사용했다면 고유 대응 성과를 추가 기록 |

**보스:** 경계 포식자. 공통 해법은 전조 회피→매듭 차단→노출된 근원 공격이다. 일반 장치가 파문과 동일한 공격·흡수 능력을 주지는 않는다. 파문은 압력을 반격으로 바꾸는 우월한 선택을 제공한다.

**보상:** 공통은 통로 대응 실적·수련 진전·초동 대응 역할. 선택적 체득은 핵심 행동 1개이며 후속 연계·오의를 몰아 주지 않는다. 백련의 후속 대화는 이미 발생한 체득의 해석이다.
**완료 제안:** `c03.ordinaryReadiness && c03.passageStable && c03.peopleReturned && c03.reported`. `rippleOwned`는 공통 완료식에 없음.
**경지 연결:** 기본 수련과 유효한 대응 증거로 첫 경지에 도전할 수 있게 재설계하되 3장 완료 자체가 자동 이류 승급은 아니다.
**예외:** 파문을 놓쳐도 현장 목표·경지 안내가 정상 진행. 일반 완료 후 나중에 파문을 얻어도 장 보상 재지급 없음.
**검증 T-S03:** 미발견·발견만 함·체득 후 미사용·실제 사용 4상태 모두 완료 가능. 추가 성과만 달라짐.

## 11. 6장 — 끊어야 할 숨

**진입:** 회복 공급 단서 전달. **목적:** 되살아나는 위협 때문에 고립된 현장 인원을 빼내고 공급을 끊는다.

**오의:** 파문 핵심 체득, 후속 연계 체득, 유효 운용 증거를 갖춘 경우 오의 수련 계기를 제공한다. 7장 도달만으로 지급하지 않는다. 늦게 얻은 캐릭터는 후속 별도 수련으로 진행하며 장 완료를 막지 않는다.

**검증 T-S07:** 두 준비 선택×일반/파문, 미보고 진입, 연계 미체득 상태 완료, 오의 일괄 해금 방지.

| 사건 ID | 행동 | 결과 |
|---|---|---|
| C08-01 | 연화와 정상 운송 기록·압수 표식 대조 | 옛 운송길 위치 |
| C08-02 | 위험 장치 우선 또는 감시 위협 우선 차단 | 안전 구역/원거리 압박의 차이 |
| C08-03 | 운송 정예 제압·화물표 확보 | 현실 반입 일정을 특정할 근거 |
| C08-04 | 서린에게 직접 전달, 도겸의 후방 통제 아래 반입로 차단 | 감독관 본거지·회유 명령의 단서 |
| C08-05 | 현장 결과 보고 | 9장 준비 순서 해금 |

**성장:** 새 기연을 의무 지급하지 않는다. 쌓은 검술·초식·파문 운용이 같은 적에게 실제로 강해졌음을 느끼게 한다.
**완료 제안:** `c08.routeChoice && c08.roadSafe && c08.cargoEvidence && c08.evidenceDelivered && c08.dockBlocked && c08.reported`.
**예외:** 정예를 먼저 처치하면 선택에 대응하는 장치·현장 확인으로 마무리한다. 사라진 적을 선택 완료 때문에 다시 생성하지 않는다.
**검증 T-S08:** 선택 전 선처치, 자료 확보 후 미보고, 반복 대화 중복 증거 방지.

## 14. 9장 — 닫히는 퇴로

**진입:** 8장 완료·본거지 단서 전달. **목표:** 최종전을 위한 준비가 실제 보스 조건을 바꾸게 한다.

| 사건 ID | 사건·NPC | 보스전에 남는 결과 |
|---|---|---|
| C09-01 | 백련·화산 전수자에게 반입 계획과 공격 순서 전달 | 무림 후방 방어 배치 |
| C09-02 | 외곽 정예 제압·제단 공급 차단 | 외부 재충전 불가 |
| C09-03 | 현실에 결과 전달, 도겸이 대피로 통제 | 민간인과 보스 위협 분리 |
| C09-04 | 대피 경로 확보·반입 위협 제압 | 증원과 현실 도주로 차단 |
| C09-05 | 양쪽 결과를 각 책임자에게 확인 | 최종 진입 준비 완료 |

**대가:** 무엇부터 대응하느냐의 전투 부담을 주되 필수 민간인 희생을 강요하는 분기는 추가하지 않는다.
**완료 제안:** `c09.planDelivered && c09.externalSupplyCut && c09.civiliansEvacuated && c09.reinforcementsBlocked && c09.resultsDelivered`.
**잔여 충전:** 외부 공급 차단 전 모아 둔 유한 자원이 있음을 미리 관측한다. 현행 3회·6초·회복60·노출4초는 구현 참고값이며 새 밸런스로 확정하지 않는다.
**성장 상한:** 화경/S 또는 24초식 전부 체득을 입장 필수로 요구하지 않는다.
**검증 T-S09:** 대피·전투 순서 변경, 차단 기록 로드, 준비 UI와 실제 보스 효과 대응.

## 15. 10장 — 돌아갈 길의 주인

**진입:** 9장 완료. **현장:** 감독관 본거지 진입로→개방실. 현행 지역 자산을 우선 활용한다.

| 사건 ID | 단계 | 플레이·의미 |
|---|---|---|
| C10-01 | 진입로 정예 제압 | 과거 강했던 위협을 현재 성장으로 빠르게 돌파 |
| C10-02 | 감독관 대면 | 윤서의 통행을 보장하겠다는 회유. 사람의 길을 독점하는 목적 공개 |
| C10-03 | 전투 1단계 | 검격·위치 압박, 예고와 빈틈 공략 |
| C10-04 | 전투 2단계 | 유한한 내부 충전 사용. 노출된 매개를 끊거나 공격으로 압박 |
| C10-05 | 전투 3단계 | 외부 지원이 돌아오지 않는 상태의 직접 결전 |
| C10-06 | 무림 후일담 | 감독관 구속·시설 폐쇄·연화의 정상 운송 확인 |
| C10-07 | 현실 보고 | 윤서의 판단과 동료 기여를 기록, 변화한 현장 역할 확인 |

**공통 클리어:** 일반 빌드가 예고 회피·빈틈 공격·매개 차단으로 이길 수 있다. 파문은 높은 대응 출력·위협 무력화로 더 강한 승리를 만든다. 기연 미보유 피해 무효 없음.
**고성장:** 강하면 단계를 빠르게 넘어가도 된다. 강제 무적 대기로 시간을 맞추지 않는다. 생략된 전투 연출 때문에 후일담 조건이 누락되지 않아야 한다.
**최종 결과 제안:** 현행 구속 결말을 이어 쓰되 처형·영구 사망·가입 분기를 새로 확정하지 않는다. 감독관의 개인 이름·정확한 경지는 DOC-15의 미정 설정으로 남긴다.
**완료 제안:** `c10.approachSafe && c10.confronted && c10.bossDefeated && c10.murimEpilogue && c10.realityEpilogue`.
**보상:** 사이클 해결 기록·관계·현장 역할. 자동 최고 등급·새 기연·기존 투자 환급 없음.
**후속 여지:** 통로망 전체의 일부였다는 단서는 남길 수 있다. 감독관 즉시 부활·전부 시험이었다는 반전으로 이번 성취를 취소하지 않는다.
**검증 T-S10:** 단계 건너뛰기, 보스 후 미보고 저장, 후일담 역순 접근, 보상 재수령 방지.

## 16. 일반 성장과 파문 수련의 교차

| 사건 | 일반 성장 | 파문 보유 시 추가 | 공통 본편 조건에서 제외 |
|---|---|---|---|
| 1~2장 | 기본 검술·보법, 화산 전수 접점 | 아직 미보유여도 정상 | 기연 발견 |
| 3장 | 압력 회피·일반 현장 준비 | 핵심 대응 행동 체득 가능 | 파문 보유·핵심 스킬 사용 |
| 4~6장 | 구조·대상 선택·심법 운용 | 획득 후 실전과 별도 후속 연계 | 연계 수련 완료 |
| 7장 이후 | 복합 전장 대응·일반 상위 운용 | 연계 이후 오의 수련 계기 | 오의·기연 최고 완성 |
| 8~10장 | 축적한 빌드로 결전 | 높은 효율·고유한 대응 성과 | 최고 경지·최고 등급 |

성장 순서는 핵심 행동 체득→독립 실전 사용→후속 연계 실습→복합 위협 증명→오의 수련이다. 장 번호는 이 과정을 경험할 기회이고 자동 보상 버튼이 아니다. 구체 요구 횟수·수련 비용은 D-012, 늦은 획득 정책은 확정 D-026 A를 따른다.

이전 1장을 완료한 저장에 C01 신규 장면을 의무로 되돌려 요구하지 않는 방향을 제안한다. 신규 장면은 회상/선택 수련으로 접근시키고 이전 완료 이력을 보존한다. 신기획 증거를 과거에 실제 수행했다고 조작하지 않고 `legacyCompleted` 같은 별도 이행 근거를 검토한다. 필드명·이행 버전·상세 환산은 개발 전 승인 대상이다.

## 18. 기획 검수와 남은 결정

T-S01~10은 장별 대표 테스트이며 DOC-10의 공통 저장·일반 경로·입력 검증과 함께 사용한다. 기연 OFF 신규 저장, 기연 조기/늦은 획득, 고성장, 기존 완료 저장을 구별한다. 이번 문서는 실행·통과 결과가 아니다.

D-024~026 권장안 확정. 남은 것은 개인 과거·효과·요구량·상세 연출의 검증이다. 서버 유일·시즌 등 후속 운영 질문은 현재 문서 완성의 선행조건으로 다시 올리지 않는다.
