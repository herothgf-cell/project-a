## 읽는 순서와 상태

**2026-10-12 매화 상세 기획:** [DOC-22](시스템/22_매화검법_고유트리와_편성_검토안.md)에 제1~3초식의 역할·고유 강화·편성·현실 대응을 정리했다. 완료 단위 숙련, 개인 제자 관계 유지, 첫 현실 기술부터 연결 재화로 학습하는 방향은 사용자 확인(D-038/039). 효과·횟수·비용은 검증안이다. 기존 명중 기반 게임은 변경하지 않았다.

중앙 → 스토리 → 시스템 → 실제 구현·제한 → 플레이 테스트 순으로 읽는다. 새 결정을 반영할 때에는 결정대장과 해당 분야의 본문을 함께 고친다.

- **확정:** 사용자 결정. 기능 완료·최종 수치 확정과 다르다.
- **현재 구현:** f5a5a3b의 코드에서 확인한 동작. 사람의 재미 검증을 뜻하지 않는다.
- **검증안:** 현재 코드에 들어 있어도 바뀔 수 있는 슬롯 수·적 수·효과·요구량·세부 대사.
- **후속/미정:** 현재 신규 여정에 연결하지 않는 범위. 폐기와 구분한다.
- **보관:** 이전 설정·버전별 계획·실행 기록. 현재 개발 지시로 사용하지 않는다.

## 이전 문서

[별도 보관 폴더](../archive/README.md)에 원문을 보존했다. 현행 문서에는 상충하는 옛 본문을 계속 덧붙이지 않는다. 옛 경로를 받은 경우 [이동 대장](자료/20_문서이동대장.md)에서 찾는다.

기존 3~10장, 별도 화산 전수자 경로, 즉시 현실 왕복, 양방향 재화 초안, 투자 초기화 허용안은 새 여정의 기준이 아니다. 보관한 완료 설계 중 지금도 유효한 규칙은 이 폴더의 해당 주제에 통합했다.

이 폴더를 통째로 받으면 현행 문서와 화면 자료를 함께 볼 수 있다. 코드·이전 원문 링크까지 보려면 저장소 전체가 필요하다. GitHub 시작 주소는 `docs/planning/`을 유지한다. 외부 Word·MindMap은 자동 동기화되지 않는다.
