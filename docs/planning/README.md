## 링크가 안 열릴 때

GitHub에서는 이 페이지의 문서명을 클릭한다. 로컬에서는 **이 폴더 전체**를 받고 Markdown 미리보기로 연다. 중앙 파일 하나만 다운로드하면 상대 링크의 대상 파일이 없으므로 열리지 않는다.

고정 온라인 시작 주소: https://github.com/herothgf-cell/project-a/tree/main/docs/planning

문서는 UTF-8 Markdown이다. Word v1.0은 과거 검토본이며 이번 결정이 자동 반영되지 않는다. 최신 기준은 이 폴더의 Markdown과 결정대장이다.

## 지속 갱신 규칙

문서 ID와 파일명은 가급적 유지한다. 사용자 답변을 DOC-11에 기록한 다음 영향받는 상세 문서, 중앙 문서, 변경 이력을 함께 갱신한다. 새 버전마다 폴더를 복제하지 않고 Git 변경 이력으로 과거를 보존한다.

`[확정]`은 기획 결정이며 구현 완료 표시가 아니다. `[방향 합의]`, `[검증 후 결정]`, `[부분 확정]`, `[질문]`, `[후속 보류]`, `[제안]`, `[현재 코드]`를 구분한다. 후속 보류를 현재 개발의 필수 선행조건으로 만들지 않는다.

기존 `docs/`의 테스트 안내는 해당 게임 버전의 구현 근거다. 이 폴더는 목표 기획의 기준이다. 서로 다르면 DOC-10에 차이를 적으며, 기획을 반영했다고 게임이 수정되었다고 쓰지 않는다.

MindMap AI는 보조 탐색 지도다. Markdown과 자동 동기화되지 않는다. 기획 판단이 충돌하면 DOC-11의 최신 사용자 결정이 우선한다. 문서만 갱신하는 이번 커밋은 게임 코드·아트·세이브·워크플로를 변경하지 않는다.
