## D-001. 양세계와 회귀·전생의 관계

> [방향 합의] 핵심 장치는 양세계. 전체 스토리 최종 확정 아님.

**사용자 답변:** “권장안 OK, 세계관 핵심은 양세계로 유지, 현재 사건은 정리될 수 있음 (확정은 아니나 스토리와 여러가지를 유기적으로 짜봐야 알 것 같음)”

**반영:** 양세계 왕복을 중심에 두고 주인공 회귀·전생은 현재 기본안에서 제외한다. 인트로, 경계석, 인물의 과거, 흑조회 사건은 서로 연결해 재작성할 수 있다. 모든 사건을 이미 승인받았다고 처리하지 않는다.

**남은 것:** 사건별 설득력·인과·대사 검토. 같은 장르 선택을 지금 다시 묻지 않는다.

**영향:** DOC-01, DOC-07. **기록일:** 2026-10-08.

## D-002. 실제 서비스의 플레이 형태

> [확정] 싱글 재미 검증이 현재 단계, MMO는 장기 지향.

**사용자 답변:** “싱글 -> MMO를 지향하고자 하나 현 단계는 재미 검증이 우선”

**반영:** 싱글에서 일반 성장·기연·양세계의 재미를 검증한다. MMO에 필요한 공유 경제·소유권·동시성은 후속 설계다. 개인 시연에서 특정 분기를 노출하는 것과 실제 서버 희소성 검증을 구분한다.

**남은 것:** 네트워크 전환 시점과 서비스 규모는 후속. 현재 서버 구현 착수 없음.

**영향:** DOC-01, DOC-09, DOC-10. **기록일:** 2026-10-08.

## D-003. 독점 범위와 강한 격차

> [미답변][후속 검토] 현재의 강한 성능 차이 목표는 유지. 실제 서버 소유 범위는 미정.

**기존 질문:** 서버 유일/서버 N인/전 서버 유일과 유지 기간.

**사용자 답변:** 이번 답변에 없음.

**처리:** D-002의 현재 범위에 따라 실제 서버 범위는 싱글 재미 검증의 선행조건에서 제외한다. D-005의 [유일] 배지가 서버 동시 1인을 자동 확정하지 않는다. 성능 차이를 실제로 허용한다는 기존 목표는 그대로다.

**다시 결정할 시점:** 공유 서버 실증 직전. 지금 수·기간을 임의 지정하지 않는다.

**영향:** DOC-02, DOC-09.

## D-004. PvP에 기연 격차 적용

> [단계 방침 확정] 첫 검증은 PvE·협동, PvP 정책은 후속.

**사용자 답변:** “첫 검증은 PvE·협동, PvP 정책은 뒤에서 확정.”

**반영:** PvP, PK, 경쟁 랭킹, 정규화, 기연 PvP 배수는 현재 기획 확정 범위에서 제외한다. PvP 영구 미도입으로 해석하지 않는다. 실제 협동 구현 시점도 D-002의 싱글 우선과 충돌시키지 않는다.

**영향:** DOC-01, DOC-09, DOC-10. **기록일:** 2026-10-08.

## D-005. 단독 퀘스트 표기

> [수정 확정] 현재 표기는 **[유일]** 한 종류.

**사용자 답변:** “현재는 우선 [유일] 퀘스트 1종으로 통합해서 진행”

**반영:** [개인 전용]/[서버 유일]/[서버 최초]를 현재 플레이 UI에 여러 배지로 노출하는 기존안을 대체한다. 표시 예시는 `[유일] 메아리 없는 바위`다. 향후 소유권 의미는 내부 검토로 남기되 지금 메뉴를 복잡하게 만들지 않는다.

**유지 제안:** 발견 전에는 환경 징후만, 발견한 뒤 [유일]로 등록한다. 사용자가 명확히 확정한 것은 분류 통합이며 세밀한 노출 타이밍은 UX 테스트 항목이다.

**범위 고지:** 테스트 안내에서 싱글 시연임을 설명한다. 실제 서버가 없는데 ‘전 서버 1명 획득’ 같은 문구는 추가하지 않는다.

**영향:** DOC-02, DOC-08, DOC-09, DOC-13. **기록일:** 2026-10-08.

## D-006. 첫 기연의 실제 보상

> [검증 방향 합의] 파문 중심으로 시도. 최종 보상·수치·사건은 미확정.

**사용자 답변:** “첫 기연을 어떻게 설정하냐에 따라 다름 -> 파문을 중점으로 기연 설정 시도해보는 건 이견 없음 (이후에 어떤 기연을 배치할 것인지 체크 필요)”

**반영:** OPP-001 파문 계열의 첫 체득을 상세화한다. 최초에는 핵심 행동 하나(Q 역할)만 제공한다. 후속 R/F는 같은 비전의 수련으로 구분하고 별도 기연을 여러 개 얻었다고 세지 않는다.

**추가 자료:** DOC-13에서 첫 기연과 후속 독립 비전·매화 변형·성장 가속·혼합 심법·유물 후보를 비교한다. 후보 추가는 제작량 증가 승인과 다르다.

**영향:** DOC-02, DOC-05, DOC-07, DOC-13. **기록일:** 2026-10-08.

## D-007. 필수 첫 성장과 비보장 기연

> [확정] 일반 수련으로 본편·경지 성장 가능. 희귀 기연은 더 강한 힘과 특별한 해법.

**사용자 답변:** 상세 설명을 요청한 뒤, “‘일반 수련으로도 본편과 경지 성장이 가능하고, 희귀 기연은 별도로 더 강한 힘과 특별한 해법을 주는 구조’로 오키”라고 답변.

**쉽게 풀면:** A는 기연을 못 얻어도 화산의 기본 검법·심법·장비·회피를 수련해 적을 쓰러뜨리고 이류로 올라간다. B는 같은 수련에 더해 파문을 얻어 적의 충격을 받아 되돌리므로 더 빨리 이기거나 다른 사람까지 보호한다. A에게 파문이나 동등 보상을 반드시 주지 않는다. B의 우월함도 없애지 않는다.

**없앨 조건:** ‘파문/기연을 얻었는가?’를 본편 입장과 기본 경지의 공통 필수 조건으로 쓰는 것.

**남길 조건:** ‘이 전장에 대응할 기본 실력과 수련을 증명했는가?’ 일반 기술·회피·장치와 기연 기술 중 실제 성공한 경로로 증명한다.

**예외:** 기연 소유자 전용 수련·특별 분기·추가 보상은 존재할 수 있다. 이것이 모든 유저가 밟는 기본 성장을 잠그지만 않으면 된다.

**영향:** DOC-01, DOC-02, DOC-04, DOC-07, DOC-10. **기록일:** 2026-10-08.

## D-008. 현실의 시대·판타지 정도

> [확정] 현대 퓨전 판타지, 과한 SF 제거. 대량 아트 제작 보류.

**사용자 답변:** “현대 생활권+헌터+마법·성력/마력·유물+악마,괴물 등, 과한 SF 요소 제거 -> 새 아트 대량은 제작 보류 OK”

**반영:** 초월 기술을 우주문명 장치로 설명하는 기본 방향을 버린다. 도시·기지·지하역·항만의 현대 생활감은 유지하고 위협은 마수·괴물·악마·주술·계약으로 재설계한다. ‘특수 적이면 SF를 예외로 써도 된다’는 구안도 자동 유지하지 않는다.

**영향:** DOC-03, DOC-07, DOC-08. **기록일:** 2026-10-08.

## D-009. 문파·무공명·백련의 소속

> [부분 확정] 실명 문파를 사용. 상세 계보·초식은 미정. 백련은 D-024에서 독립 첫 스승으로 확정.

**사용자 답변:** 문파·무공 목록 참고 링크를 제공하고 “실명 문파로 변형”, “위내용 말고도 체크”를 요청.

**반영:** 소림·무당파·화산파·아미파·남궁세가 등 익숙한 명칭으로 개편한다. 전통 이름의 채택과 특정 작품의 초식·정파/사파 구도·계보 전체 복제는 구분한다. 추가 검토는 DOC-14에 기록한다.

**후속 확정:** D-024 B로 백련은 독립 첫 스승, 화산 전수자는 별도 인물로 결정했다.

**접근 한계:** 제공된 나무위키 2개 URL은 이번 도구에서 본문 열람에 실패했다. 읽었다고 간주하지 않으며, 원문 확인 필요 항목을 남긴다.

**영향:** DOC-04, DOC-05, DOC-07, DOC-14. **기록일:** 2026-10-08.

## D-010. 마기·성력의 데이터 의미

> [질문] 성장 구조 상세화를 위해 남아 있는 질문.

**사용자 답변:** 이번 답변에 없음.

**선택 A — 별도 에너지:** 성력을 얻으면 성력 자원·최대치·효율이 열린다. 마력과 사용 기술을 구분하고 미획득 계열은 숨긴다.

**선택 B — 영구 배분 스탯:** 공격·체력처럼 마기/성력에도 포인트를 영구 배분한다. D-016 때문에 확정 후 되돌릴 수 없다.

**선택 C — 속성만:** 새 게이지나 배분 항목 없이 기술에 마기/성력 속성과 사용 자격만 붙인다.

**권장:** A를 비교 실험의 출발점으로 두되 아직 확정하지 않는다. 현재 화산+파문 검증을 위해 네 에너지 체계를 동시에 구현할 필요는 없다.

**영향:** DOC-03, DOC-04, DOC-06. **답변 전:** 새 영구 배분 필드·소모 수치 확정 보류.

## D-011. 마기와 성력의 공존

> [부분 확정] 초기 운용 분리, 혼합·공존은 별도 기연을 통해 가능.

**사용자 답변:** “초기 운용 분리하나 혼합으로 별도 기연을 통해 공존 가능”

**반영:** 혼합 기연 전에는 마기와 성력을 동시에 섞어 쓰지 않는다. 혼합 기연 이후 전용 연계/통합 운용을 설계한다. 이 이벤트가 마기 또는 성력을 초기화해 환급하는 기능은 아니다.

**남은 작은 질문 D-011-A:** 기연 전에도 두 힘을 ‘보유만’ 하되 하나씩 사용할 수 있는가, 아니면 두 힘의 동시 보유 자체가 혼합 기연 이후에만 가능한가? 기존 권장안의 ‘보유 공존’까지 승인된 것으로 단정하지 않는다.

**임시 처리:** 자동 삭제·합산·정화 없음. 실제 복수 에너지 획득 콘텐츠는 이 세부 의미를 확인한 뒤 만든다.

사용자가 권장안 A를 확정했다. DOC-07/13/15와 구현은 선행 체득·실전 증거를 따른다. 기연 자체의 희소 획득 조건·실패·재발견 정책과 **이미 얻은 비전의 후속 수련 기회**를 구분한다. 미보유자가 후반에 왔다고 기연을 자동 지급하지 않는다.
