# 14. 문파·무공 레퍼런스 검토

## 1. 결정과 조사 범위

> [부분 확정 D-009] 실명 문파로 개편한다. 사용자가 제공한 문파·무공 목록 외의 자료도 검토한다. 백련의 소속과 구체 초식·계보는 미확정이다.

이 문서는 명칭·플레이 심상·실제 전수 자료·특정 작품 설정을 구분하기 위한 조사 기록이다. 모든 문파 무공을 검증한 백과사전이나 사용 권리의 확인서가 아니다. 조사하지 못한 내용을 정설처럼 채우지 않는다.

## 2. 사용자 제공 자료의 접근 결과

| 자료 | 이번 확인 결과 | 처리 |
|---|---|---|
| [문파](https://namu.wiki/w/%EB%AC%B8%ED%8C%8C) | 도구에서 본문 열람 실패 | 참고 위치만 등록, 전체 내용 확인했다고 쓰지 않음 |
| [무공/목록](https://namu.wiki/w/%EB%AC%B4%EA%B3%B5/%EB%AA%A9%EB%A1%9D#s-2.1) | 도구에서 본문 열람 실패 | 무공명·초식·선행 관계를 검증한 출처로 아직 쓰지 않음 |

접근 실패는 해당 문서가 없다는 뜻이 아니다. 현재 확인 가능한 범위의 한계다. 두 자료의 설명을 임의로 재구성하거나 다른 작품의 무공 목록을 같은 자료에서 읽은 것처럼 사용하지 않는다.

## 3. 추가로 확인한 자료와 활용

### 3.1 UNESCO — Taijiquan

[UNESCO 공식 소개](https://ich.unesco.org/en/RL/taijiquan-00424)와 [등재 결정문](https://ich.unesco.org/en/Decisions/15.COM/8.b.21)의 공개 설명은 태극권의 이완된 원형 동작, 호흡 조절, 수련과 사제/가계 전수를 다룬다. 소개 페이지 직접 열람에서 자동접속 확인이 나타나기도 하므로 공식 검색에 노출된 설명과 결정문을 함께 참고했다.

**설계에 활용할 부분:** 기술의 모습뿐 아니라 호흡·기본 동작·상대와의 수련·사제 관계를 게임의 학습 과정으로 연결한다. 무당 계열의 원형 대응을 기획할 때 ‘빛나는 태극 문양’만 붙이기보다 실제 자세와 타이밍을 구분하는 근거로 삼을 수 있다.

**이 자료로 증명하지 않는 것:** 문학적 무당파가 태극검·양의검·특정 내공을 어떤 순서로 전수한다는 허구의 계보. 특정 무협 작품의 초식 목록이나 화경의 보편 단계도 설명하지 않는다.

### 3.2 Shaolin Wushu Training Center — 교육기관의 자체 소개

[교육 소개 페이지](https://www.shaolinwushu.org/training-center/)는 해당 기관의 교육을 전통 형, 무기, 실전 대련 계열, 기공 등으로 나누어 소개한다. 이는 교육기관 자체 설명이며 소림 전체의 고전 계보를 인증한 자료로 확대하지 않는다.

**설계에 활용할 부분:** 기본 동작·형·무기 운용·실전 적용을 나누고, 한 번의 포인트 지급으로 모든 수련이 끝나는 느낌을 줄이는 구성. 소림 후보 계열을 권·봉·방어의 실제 행동으로 구분하는 발상에 참고한다.

**이 자료로 증명하지 않는 것:** 금강불괴·역근경 같은 판타지 능력의 실제 효과, 특정 소설의 전수 자격, 고대 계보의 일관성, 교육기관의 모든 홍보 주장. 설립·인증·학생 수 같은 부수 주장도 기획 근거로 사용하지 않는다.

## 4. 문파별 적용·보류표

아래 ‘심상/명칭 후보’는 게임 기획의 검토 목록이다. 출처가 아직 충분하지 않은 이름은 확정 무공으로 표시하지 않는다.

| 문파 | 이번 게임의 방향 | 심상·명칭 후보 | 아직 확인할 것 |
|---|---|---|---|
| 소림 | 견고한 기본기·권·장·봉·방어 후 대응 | 나한·금강·역근의 이미지 | 구체 무공명·효과·선행, 작품별 차이 |
| 무당파 | 흘림·원형 전환·타이밍 | 태극권·태극검·양의 계열 후보 | 실제 전통과 소설상의 전수 체계를 분리 |
| 화산파 | 기초 검로에서 매화 계열로 발전 | 24수 매화검법, 자하 계열 후보 | 정확한 선행 무공·초식·전수권·표현 출처 |
| 아미파 | 정밀한 검·보법·경혈 대응 | 균형·절제·정밀성 | 특정 작품의 초식과 여성/치유 전용 고정관념 구분 |
| 남궁세가 | 큰 검세와 공간 압박·기세 | 창궁무애검법·제왕검형 검토 후보 | 명칭의 작품별 사용과 실제 게임 채택 범위 |
| 마교 | 마기 운용·비전·대가·선택 | 금기·고출력·특수 심법 | 소속과 악행·마기 보유를 자동 동일시하지 않기 |

[확정 D-014] 화산 계열1+기연1만 우선 검증한다. 위 표는 다른 문파의 존재감을 보존하기 위한 것으로 모든 트리를 동시에 구현하는 목록이 아니다.

## 5. 화산 계보를 정할 때의 기준

사용자는 24수 매화검법까지 앞 단계를 밟아 성장하길 원한다. 이 목표는 유지한다. 그러나 ‘기초 검로→화산 기본 검법→분화 검로’ 같은 현재 문서의 이름은 **기능 가칭**이다. 이를 실제 무협의 정식 선행 계보라고 단정하지 않는다.

최종 데이터에는 명칭, 참고 작품/자료, 일반 장르 표현인지 특정 작품 고유 조합인지, 이번 게임이 새로 만든 효과, 선행 조건, 전수 인물을 함께 기록한다. 24개 초식의 문장을 그대로 채워 넣거나 대표 작품 하나의 서사를 복제하는 방식으로 작업하지 않는다.

D-012에 따라 선행 성수·대성 조건·퀘스트·수련 방식은 구현 테스트 뒤 확정한다. 문헌의 이름을 확인하는 것과 게임 밸런스를 확정하는 것은 다른 작업이다.

## 6. 화경과 무공 대성

화경을 1차 설정 상한으로 두는 것은 사용자 방향이다. 모든 무협 작품에 같은 단계·동일 능력이 있다고 전제하지 않는다. 원본 v1.0의 비공식 화경 용어 자료는 탐색 기록으로만 남긴다.

이번 게임에서는 **무공 하나의 완성인 대성**, **인물 전체의 경지인 화경**, **협회의 공식 평가인 S**를 별도로 설계한다. 10장 완료에 최고 경지·등급을 강제하지 않는 원칙은 D-015에서 합의됐다. 실제 효과·시련·도달 시점은 후속 설계·검증 대상이다.

## 7. 백련의 소속과 전수 연결

백련이 첫 스승이라는 역할은 유지할 수 있다. 그러나 실명 문파 사용에 동의했다는 이유만으로 백련을 화산의 장문인이나 고위 제자로 확정하지 않는다.

후보는 ‘화산과 인연이 있는 전수자’, ‘독립 무인이며 정식 화산 전수자에게 연결’, ‘다른 문파의 인물로 제한된 외부 전수를 해 주는 첫 스승’이다. 어떤 안이 3장 기연·4장 인연·장기 문파 선택과 가장 자연스럽게 이어지는지 스토리에서 검토한다. 소속 변경을 기술 초기화 우회로 사용하지 않는다. [D-009/D-013/D-016]

## 8. 후속 조사 기록 양식

`대상 명칭 / 원문 출처 / 실제 확인한 범위 / 작품별 차이 / 게임에서 가져올 원리 / 새로 창작한 부분 / 선행·전수 관계 / 검토 상태`를 한 묶음으로 기록한다.

현재 미진한 것은 사용자 제공 두 페이지의 본문과 화산·아미·남궁 등 세부 무공명/계보의 작품별 대조다. 이번에 확인한 전통 수련 자료는 동작·전수의 참고로는 유용하지만 그 세부 목록을 대신 검증하지는 못한다. 그 차이를 명시한 상태에서 첫 화산 성장의 기능 구조와 파문 기연의 재미 검증안은 계속 정리할 수 있다.
