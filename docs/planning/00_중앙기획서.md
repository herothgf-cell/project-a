# 쌍계 — 중앙 기획서

갱신: 2026-10-12 (KST) · 구현 대조: `main f5a5a3b` / 게임 `v0.15.0`

[기획 시작](README.md)

## 게임의 목표

일반 전투와 수련으로 성장하는 RPG 위에, 일부 여정에서 얻는 강한 기연을 더한다. 무림에서 배운 것과 쌓은 성취가 현실의 성장·행동·역할을 바꾼다. 단순 퀘스트 왕복이나 같은 공격력의 복사만으로 두 세계를 설명하지 않는다.

현재는 싱글 PvE 재미 검증이다. 협동은 필요할 때, MMO는 장기 지향이다. 회귀·전생을 기본 설정에 섞지 않는다.

## 현재 우선하는 진행

현실 지하역 출발 → 경계석 반응 → 무림 도착·백련 구조 → 삼재검법 응급 전수 → 이동/공격/회피 튜토리얼 → 화산행 10개 던전과 문파 만남 → 백련 치료 → 정식 제자 수락/거절 → 천흔 귀환길·선택 기연 → 수문장 제압 → 첫 현실 귀환.

**이미지·대사 → 준비 → 다음 던전**을 기본으로 한다. 성장 메뉴·목적지 선택만을 위한 NPC와 반복 보고를 필수 동선에 두지 않는다. 기존 현실 출발 인트로는 유지하되 첫 현실 귀환은 2장 보스 이후다. 상세 사건은 [스토리](스토리/07_인트로와_1~2장.md) 한 곳에서 관리한다.

## 변경하지 않는 성장 계약

| 항목 | 현재 규칙 |
|---|---|
| 일반 성장 | 기연 없이도 본편·기본 경지 진행 가능. 현재 신규 1~2장은 미투자·제자 거절도 완료 가능하도록 검증 |
| 기연 | 실제로 더 강한 성장과 별도 해법. 모든 플레이어에게 보장하거나 동등 보상을 자동 지급하지 않음 |
| 무림 투자 | 공통 기초 후 검술·보법·내공에 자유 분산. 정식 제자 선택은 별도 |
| 매화검법 | 치료 후 백련의 제자 제안 수락 시 검법 해금과 제1초식. 거절 시 미획득, 귀환은 가능 |
| 성취 | 기본형 1~9성, 무공마다 고유 구조 허용. 이십사수매화검법은 초식별 성취 |
| 영구성 | 확정 스탯·스킬 투자 초기화/환불 금지. 미확정 초안 취소와 장착 변경은 허용 |
| 편성 | 배운 기술을 직접 배치. 미습득/미장착 기술은 전투 단축키에 비노출. 트리의 선행·다음 효과는 유지 |
| 알림 | 획득·학습 소식을 읽으면 레드닷 해제. 재료 전량 소비 요구 없음 |
| 양세계 | 성장·투자·성취 분리, 무림→현실 연계. 현실→무림 성장 재화는 제공하지 않음 |
| 저장 | 완료·투자·성취·보상 이력 보존. 구 캠페인 저장을 새 경로로 강제 전환하지 않음 |

## 현재 구현과 남은 범위

게임 v0.15.0은 위 장면 연결, 기술 편성, 읽음 기반 알림을 구현했다. 화산행 10개 지역, 귀환길 3개 지역과 선택 기연 전장을 사용한다. 2슬롯·튜토리얼 3웨이브 7명·세부 보상/대사는 검증안이다. 신규 여정의 기연은 검증용 **천흔 호흡**이며, 후속 **파문 비전 전체 성장**과 같은 구현이 아니다.

현실 전투/트리와 3~10장의 신규 연결, 나머지 매화 23초식, 화경 시련, 복수 에너지, 공유 서버, 대량 신규 아트·동행 AI는 현재 범위 밖이다. 기존 코드에 후속 캠페인이 있다는 사실을 신규 여정의 완성으로 세지 않는다.

[현재 구현과 제한](개발방향/18_현재구현과_제한.md)에는 코드 근거와 과거 검사 기록을 분리했다. 이번 문서 정리에서 게임 플레이·배포를 새로 검증한 것은 아니다.

## 기준의 우선순위

최신 사용자 결정 → 현행 분야 문서 → 후속 제안 → 보관 원문 → 외부 참고 순으로 목표 기획을 해석한다. 구현 사실은 코드·실행 근거로 따로 판정한다. 서로 다르면 로드맵에 차이를 기록한다.

D-028~032가 신규 1~2장의 기준이다. D-024의 별도 화산 전수자 초반 경로는 대체됐고, D-021은 **기본 1~9성과 무공별 예외**로 정정된 상태다. 옛 문서의 테스트 수·구현 전 표기·당시 푸시 허가는 현재 상태나 새 배포 허가가 아니다.
