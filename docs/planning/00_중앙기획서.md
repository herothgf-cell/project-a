## 게임의 목표

일반 전투와 수련으로 성장하는 RPG 위에, 일부 여정에서 얻는 강한 기연을 더한다. 무림에서 배운 것과 쌓은 성취가 현실의 성장·행동·역할을 바꾼다. 단순 퀘스트 왕복이나 같은 공격력의 복사만으로 두 세계를 설명하지 않는다.

현재는 싱글 PvE 재미 검증이다. 협동은 필요할 때, MMO는 장기 지향이다. 회귀·전생을 기본 설정에 섞지 않는다.

## 현재 우선하는 진행

현실 지하역 출발 → 경계석 반응 → 무림 도착·백련 구조 → 삼재검법 응급 전수 → 이동/공격/회피 튜토리얼 → 화산행 10개 던전과 문파 만남 → 백련 치료 → 정식 제자 수락/거절 → 천흔 귀환길·선택 기연 → 수문장 제압 → 첫 현실 귀환.

**이미지·대사 → 현장 준비 → 다음 맵**을 기본으로 한다. 이미지 때문에 대사를 스크롤해서 찾지 않도록 함께 배치한다. 전장을 확보하면 시작점 대신 전방 출구로 이어지고, 대화·성장 중 현재 위치와 배경을 유지한다. 화산행 10개 맵은 유지하며 다른 문파 만남은 길 안내 1회로 줄인다. 만남은 스킬 해금과 무관하다. 기존 현실 출발 인트로는 유지하되 첫 현실 귀환은 2장 보스 이후다. 상세 사건은 [스토리](스토리/07_인트로와_1~2장.md) 한 곳에서 관리한다.

## 변경하지 않는 성장 계약

이 표는 `9681ec7`의 기존 진행·구현 기준을 포함한다. **새 목표 기획(D-038/039)**에서는 매화 숙련을 유효 사용한 전투·수련의 완료 단위로 바꾸며, 첫 현실 연결 기술부터 기존 연결 재화로 학습한다. 개인 제자 관계와 영구 투자는 유지한다. [매화 상세 검토안](시스템/22_매화검법_고유트리와_편성_검토안.md)의 새 효과·비용·횟수는 미확정이고, 현재 코드나 저장을 바꾼 것은 아니다. 문파 운영은 이번 기획에서 보류한다.

## 현재 구현과 남은 범위

### 첫 귀환 이후 목표 기획 — 현재 구현과 구분

사용자 요청에 따라 [대표 현실 레이드](시스템/23_현실_지하역_레이드와_스킬_검토안.md), [양세계 반복 성장·보상](시스템/24_양세계_반복성장과_보상경제_검토안.md), [귀환 이후 이야기·평가](스토리/25_첫귀환이후_왕복과_레이드_검토안.md)를 함께 정리했다. 짧은 안정화 후 비전투 거점 왕복, 일반/연결 공용 2슬롯, 현실도 완료 단위 숙련, 레이드의 공명 결정 공급이 목표로 확인됐다. 각인은 무림 성취에서만 얻으며 첫 연결 학습도 유료다. 숫자·보스 패턴·세부 대사는 검증안이다. 문파 운영·실제 유저 랭킹·MMO를 이번 설계의 선행조건으로 삼지 않는다.

게임 v0.15.0은 위 장면 연결, 기술 편성, 읽음 기반 알림을 구현했다. 화산행 10개 지역, 귀환길 3개 지역과 선택 기연 전장을 사용한다. 2슬롯·튜토리얼 3웨이브 7명·세부 보상/대사는 검증안이다. 신규 여정의 기연은 검증용 **천흔 호흡**이며, 후속 **파문 비전 전체 성장**과 같은 구현이 아니다.

현실 전투/트리와 3~10장의 신규 연결, 매화 제4~24초식, 화경 시련, 복수 에너지, 공유 서버, 대량 신규 아트·동행 AI는 현재 범위 밖이다. 다른 문파 고유 트리는 잠김으로 표시하며 여행 중 만남으로 열리지 않는다. 추가 초식의 효과·재료·실전 요구량은 검증안이다. 기존 코드에 후속 캠페인이 있다는 사실을 신규 여정의 완성으로 세지 않는다.

[현재 구현과 제한](개발방향/18_현재구현과_제한.md)에는 코드 근거와 과거 검사 기록을 분리했다. 이번 문서 정리에서 게임 플레이·배포를 새로 검증한 것은 아니다.

## 기준의 우선순위

최신 사용자 결정 → 현행 분야 문서 → 후속 제안 → 보관 원문 → 외부 참고 순으로 목표 기획을 해석한다. 구현 사실은 코드·실행 근거로 따로 판정한다. 서로 다르면 로드맵에 차이를 기록한다.

D-028~032가 신규 1~2장의 기준이다. D-024의 별도 화산 전수자 초반 경로는 대체됐고, D-021은 **기본 1~9성과 무공별 예외**로 정정된 상태다. 옛 문서의 테스트 수·구현 전 표기·당시 푸시 허가는 현재 상태나 새 배포 허가가 아니다.
