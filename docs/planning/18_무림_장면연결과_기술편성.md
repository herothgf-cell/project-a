## 확정 요구와 검증안

현실 출발과 첫 무림 도착을 보여 준 뒤 백련 구조·삼재검법 응급 전수·튜토리얼, 화산행 10개 던전, 치료와 제자 선택, 천흔 보스와 첫 현실 귀환을 연결한다. 새 여정의 본편은 **이미지·대사 장면 → 준비 → 다음 던전**으로 이어진다. 성장 메뉴나 다음 목적지를 여는 기능 안내 NPC는 두지 않는다. 인물은 사건 속에서 만난다.

성장 소식은 스탯·무공 화면의 레드닷으로 안내한다. 해당 정보를 읽으면 표시가 해제되며 재료를 모두 쓸 필요는 없다. 스킬 트리는 선행 조건과 다음 효과를 계속 보여 준다. 전투 HUD에는 **배우고 직접 배치한 기술만** 표시한다. 배치·교환·해제는 영구 투자 환불과 다르며 성취도와 재사용 시간을 초기화하지 않는다.

자유 분산 투자, 확정 투자 초기화 금지, 제자 거절·기연 미획득·미투자 진행, 기존 저장 이력 보존은 유지한다. 선택 기술 **2슬롯**, 튜토리얼 **3웨이브(2/2/3명)**, 문파 만남의 구체 대사와 배치는 이번 구현의 **검증안**이며 새 세계관 확정값이 아니다.

## 실제 구현

| 항목 | 이번 작업 범위 | 확인 상태 |
|---|---|---|
| 인트로·이동 | 현실 출발/첫 도착 뒤 신규 장면 ID, 10개 길목과 귀환길 연결 | 실제 공격을 사용하는 브라우저 첫 귀환 흐름 확인 |
| 이미지·대사 | 기존 이미지 자산과 화자 표현을 새 사건에 연결 | 표시·로드 실패/재시도·360px 확인; 사건별 신규 그림은 제작하지 않음 |
| 튜토리얼 | 이동·명중·회피를 단계별로 학습, 전멸 뒤 미완료 조작 보완 | 3웨이브(2/2/3명) 적용; 정밀 회피·투자 미강제 |
| 기술 편성 | 안전한 준비 구간의 2슬롯 배치·교환·해제, 키보드/터치 공통 해석 | 실제 발동·키 재지정·저장·기술별 쿨다운 및 저장 실패 복구 확인 |

구현 근거는 장면 카탈로그/진행·이행, 편성, 알림 모델과 새 브라우저 검사다. DOC-16/17의 이전 테스트 개수를 이번 변경의 검증 결과로 재사용하지 않는다.

## 검증 근거와 남은 체감 검토

- **최종 통과:** Node 단위 검사 **801/801**, 구문·리비전·세계 검사 **3종**, Node 브라우저 검사 **50/50**, Python 브라우저 검사 **7/7**. Node 브라우저 전체는 테스트 도구 수정 후 새로 실행해 통과했다.
- **개별 확인:** `tests/murim-scenes.browser.cjs`에서 장면 이미지 실패/재시도, 저장 실패 시 변경 복구, 슬롯 배치·교환·해제·키 재지정·쿨다운, 읽음 알림 저장, 360px 화면, 첫 귀환 자산 준비 실패 시 상태 보존을 확인했다. 모델 검사는 `tests/murim-scenes.test.cjs`, `murim-loadout.test.cjs`, `murim-notices.test.cjs`에 있다.
- **독립 검토 수정:** 저장 실패한 슬롯 교환의 쿨다운 복구, 첫 현실 귀환의 자산 준비 실패 처리, 철수 뒤 옛 설정 도움말 노출의 P2 세 건을 수정하고 해당 재현 검사를 통과했다.
- **추가 혼입 수정:** 메뉴의 조작 안내, 장 제목·저장 가져오기 미리보기, 목표 대체 안내에 남은 옛 설정을 수정했다. 목표 대체 안내 회귀 검사를 추가했으며 후속 집중 검토에서 남은 지적이 없음을 확인했다.
- **체감 검토:** 자동 완주는 실제 공격·피해·상호작용을 사용하지만 위치와 재사용 시간을 통제한다. 사람의 조작감·난이도·전투량·장면 길이가 재미있다는 증거는 아니다. 별도 플레이 검토는 남아 있다.
- **실제 키 입력 관찰:** 별도 스크립트가 적을 따라가며 공격 유지·회피 키를 입력하고 위치·HP·쿨다운을 직접 바꾸지 않은 검사에서 3웨이브 7명을 약 **4.9초**, HP **120→120**으로 완료했다(`.purpose-growth-review/live-input-review.json` 로컬 실행 기록). 사람의 재미 평가가 아니며, 효율적인 입력에서 전투가 짧게 끝나는 점은 후속 밸런스 검토 대상이다.
- **출시:** 로컬 구현·검증 기록이다. 배포 결과는 릴리스 실행에서 확인한다.

## 플레이 확인 순서

1. **새로운 여정**에서 현실 출발 → 경계석 반응 → 무림 도착을 읽는다. 인트로를 건너뛴 경우에도 실전 튜토리얼이 남고 제자 선택이 자동 수락되지 않는지 확인한다.
2. 추적자 습격에서 이동·기본 공격·회피를 익힌다. 적을 먼저 모두 쓰러뜨려도 남은 조작 안내를 완료할 수 있어야 한다. 정밀 회피 성공이나 기술 투자는 본편의 필수 잠금이 아니다.
3. 안전한 준비 화면에서 레드닷이 있는 **캐릭터 / 무공·스킬**을 연다. 내용을 확인한 뒤 재료를 남겨도 알림이 사라지고, 새 획득이 있을 때 다시 나타나는지 본다.
4. 기술을 습득하면 **단축키 설정**에서 원하는 슬롯에 배치한다. 기존 배치를 바꾸거나 해제한 뒤 HUD와 실제 발동이 같아야 한다. 미습득 기술은 트리에서 조건을 볼 수 있지만 전투 버튼이나 옛 단축키로 사용할 수 없어야 한다.
5. 장면을 마친 뒤 **다음 던전**으로 화산행 10개 길목을 순서대로 진행한다. 문파 인물의 사건과 배움은 연결되지만 특정 분기 투자나 반복 NPC 보고를 통행 조건으로 요구하지 않는다.
6. 화산 치료 뒤 제자를 **수락 또는 거절**한다. 수락 시 매화 제1초식을 배우되 사용하려면 직접 배치한다. 거절해도 천흔 귀환길이 열린다.
7. 귀환길에서 선택 기연을 진행하거나 건너뛰고, 천흔 수문장 제압 뒤 첫 현실 귀환을 확인한다. 그 이전에 현실 왕복·성장 과제나 3장 이후 안내가 나타나면 오류다.
8. 장면 도중과 전투 일부 완료 뒤 저장·재접속하고, 사망·철수·입장 취소·준비 실패 재시도를 확인한다. 진행·성취·투자는 보존되고 보상은 한 번만 지급되어야 한다. 기존 v0.14 저장에는 완료 튜토리얼이나 이미 한 제자 선택을 다시 요구하지 않는다.

실제 키는 현재 입력 설정과 슬롯 표시를 따른다. 기술을 다른 슬롯에 옮기거나 해제했다가 다시 배치해도 그 기술의 남은 재사용 시간이 유지되어야 한다. 자동화 완주와 사람의 조작감·난이도·장면 길이 평가는 구분한다.

## 남은 제한

- 이번 범위는 무림 인트로~2장과 첫 현실 귀환이다. 신규 현실 전투·현실 트리·3~10장 개편, 나머지 23초식은 포함하지 않는다.
- 장면 이미지는 기존 정지 이미지 자산을 재사용했다. 사건별로 새 그림을 제작한 것은 아니다. 백련 동행 AI·대량 신규 아트·인물 개인 과거 확정은 포함하지 않는다.
- 전투 수치·재료 지급량·슬롯 수·전투량은 플레이 검토 뒤 조정할 수 있다. 자동 검사만으로 재미나 최종 밸런스를 확정하지 않는다.
- 이전 캠페인은 기존 저장 보존용 경로로 남는다. 보존된 코드나 문서가 새 여정에서 옛 설정을 보여 줄 근거가 되지 않는다.
- 사람의 재미 평가와 최종 밸런스 확정은 여전히 남아 있다. 배포 결과는 릴리스 실행에서 확인한다.
