# 본편 무공 수련

기존 게임의 **무공 수련** 메뉴에서 **무공 습득**과 **무공 창안**을 구분한다. 개발 실험 페이지와 달리 본편 저장 기록에 반영된다.

## 플레이 순서

1. 새 여정에서 청운촌의 백련을 만난다. 월영참의 형(베기)·기(기본 운기)·운(즉시 전개)·의(전방 범위)를 순서대로 선택하고 구성한다.
2. **목인 수련 시작**으로 창을 닫고 앞의 목인에 월영참을 적중시킨다. 기본 키는 **Q**이며 화면의 현재 설정을 따른다. 실제 적중 후 월영참을 습득하고 이야기가 진행된다.
3. 3장 통로 방어와 백련의 안내를 거쳐 무명 비경에 진입한다. 부러진 검 / 겹친 발자국 / 봉합된 비석을 조사하면 각각 파문세 / 잔영각 / 쇄경진의 요소와 일부 조합법을 얻는다.
4. 청운촌으로 돌아와 해당 무공의 **단서 해독 · 지도 받기**로 나머지 조합법을 해독하고 네 요소를 구성한다. **기본 무공 실습**에서 공격 예고에 대응해야 습득된다. 기본 키는 **E**다.
5. **무공 창안**에서 두 체득 무공의 연결 원리와 대가를 확인하고 초안을 저장한다. **무림 연계 실습**에서 E 대응 후 Q 검격으로 실제 연결을 증명한다.
6. 현실의 헌터 기지로 돌아와 증명된 창안을 **현실에 적용**한다. **현실 연계 실습**으로 같은 연결을 시험할 수 있다.

| 선행 무공 + 월영참 | 창안 | 실전 증명 조건 |
|---|---|---|
| 파문세 | 반류일선 | 공격 직전 받아낸 뒤 직선에 놓인 두 적을 검격으로 관통 |
| 잔영각 | 유영잔참 | 예고 범위 밖으로 이탈한 뒤 출발점에 남긴 지연 검격을 적중 |
| 쇄경진 | 이맥봉류 | 공격 예고를 끊고 해당 적을 베어 가까운 다음 적에게 억제를 전이 |

잔영각은 조준 방향으로 이동하므로 적의 예고에서 벗어날 방향을 먼저 잡는다. 유영잔참은 출발점을 공격한다. 준비 효과는 일반 공격 또는 연계에 한 번만 사용된다.

## 제한과 지원

- 각 축 하나씩, 보유한 요소와 해독한 고정 조합법으로 습득한다. 실패해도 재료는 소멸하지 않는다.
- 월영참은 기초, 세 대응 무공은 상승 등급이다. 절학은 확장 예정이며 이번에 별도 절학을 추가하지 않는다.
- 창안은 두 습득 무공와 하나의 연결 원리를 요구한다. 창안끼리 중첩할 수 없다. 원래 효과 일부를 포기하며 후속 검격에 내력을 추가로 소모한다.
- 처음 체득한 단계에서도 세 창안을 시험할 수 있다. 실제 무림 숙련이 쌓이면 조정 범위가 넓어진다.
- 수련 지원이 기본으로 켜진다. 받는 피해 완화, 긴 공격 예고, 빠른 내력 회복을 제공한다. 거점에서 끌 수 있다.
- 수련 표적은 재화·경험치를 주지 않는다. 학습 기록은 저장되고 재접속·지역 이동 시 일시 준비와 예약 검격은 초기화된다.
- 기존 저장의 습득 무공은 유지된다. 독립 개발 실험의 저장 기록을 본편으로 가져오지는 않는다.

## 검증

`node --test tests/*.test.cjs`는 조합·실전 증명·저장·기존 스토리 회귀를 검사한다. `npm run test:browser:training`은 본편 UI에서 네 무공과 세 창안, 무림/현실 실습 및 모바일 화면을 검사한다.
