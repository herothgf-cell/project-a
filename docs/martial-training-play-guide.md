# 본편 무공 수련

이 문서는 로컬 구현 기준이며, 요소 획득 시스템 변경은 아직 공개 배포하지 않았다.

기존 게임의 **무공 수련** 메뉴에서 **무공 습득**과 **무공 창안**을 구분한다. 개발 실험 페이지와 달리 본편 저장 기록에 반영된다.

## 어디서 시작하나요?

- 공개 본편: https://herothgf-cell.github.io/project-a/ → **새 여정**. 기존 기록이 있다면 이어하기로 들어가 **무공 수련**에서 이미 습득한 항목을 확인한다.
- 로컬 본편: http://127.0.0.1:3103/art-play.html?dev=1 → **새 게임부터**. `/__dev/skillform?dev=1`은 별도 실험 화면이며 본편 스토리 검증에는 위 본편 주소를 사용한다.
- 로컬에서 이번 기능을 순서대로 시험하려면 **무공 순차 테스트 → 이어하기**를 선택한다. 일반 플레이·기존 개발 기록과 분리된 전용 슬롯이며, 이 버튼을 다시 누르면 순차 시험만 처음부터 시작한다. 도중에 새로고침했다면 **이어하기**로 재개한다.

## 스토리를 건너뛰는 순차 테스트

수련 창 위의 **시험으로 이동**을 누르면 아직 완료하지 않은 다음 단계의 장소로 이동한다. 무공이나 성공 기록은 자동 지급하지 않는다.

1. **월영참**: 베기 / 기본 운기 / 즉시 전개 / 전방 범위 → 구성 확인 → 목인 수련 시작 → **Q 적중**.
2. **천뢰격**: 다음 시험으로 이동 → 내려치기 / 뇌기 / 폭발 전개 / 주변 범위 → 구성 확인 → 목인 수련 시작 → **W 적중**.
3. **파문세 → 잔영각 → 쇄경진**: 각각 시험으로 이동 → 앞의 흔적 **G 조사** → 청운촌으로 돌아가 구성하기 → 다음 시험에서 운 체득 → 다음 시험에서 의뢰 목표 달성 → 수련 종료 → 퀘스트 보고 · 의 획득 → 다음 시험에서 아래 표의 네 요소 구성 → 기본 무공 실습 → **E로 대응 성공**.
4. **반류일선 → 유영잔참 → 이맥봉류**: 각각 시험으로 이동 → 창안 초안 저장 → 무림 연계 실습 → **E 대응 후 Q 검격**으로 실제 연계 성공.
5. **세 창안의 현실 연계**: 각각 시험으로 이동 → 현실에 적용 → 현실 연계 실습 → **E 대응 후 Q 검격**으로 성공. 모두 마치면 **20 / 20 완료**가 표시된다.

천뢰격은 이번에 기초 습득 항목으로 추가했으며, 세 창안의 재료는 기존대로 월영참과 각 대응 무공이다. 조작키는 기본 설정 기준이다. 로컬 개발 시작점과 이동 버튼은 공개 빌드에 포함하지 않는다.

수련에 성공하면 습득·증명 기록을 즉시 저장하지만 팝업은 자동으로 열지 않는다. 연출을 보거나 계속 연습한 뒤 전투 화면의 **수련 종료**를 직접 누르면 거점과 해당 무공 화면으로 돌아온다. 성공 전에도 종료할 수 있으며, 이때 미완료 무공은 습득되지 않는다.

## 비경까지의 이동 순서

청운촌 백련에게 월영참 습득 → 흑풍 죽림 완료 → 백련 보고 → 현실 서린 보고 → D급 균열 완료 → 서린 보고 → 백련 대화 → 월영 폐사 완료 → 백련 보고 → 현실 서린 대화 → 침식된 항만 완료 → 서린 대화 → **균열 재조사 · 귀환 통로 방어** → 긴급 철수 후 서린 보고 → 청운촌 백련 대화 → **무명 비경**.

통로 방어는 최대 12초 후 긴급 철수하는 이야기 단계다. ‘통로 방어 실패’가 표시되어도 정상 진행이며, 서린에게 보고하면 다음 단계가 열린다. 폐사의 보스 보호막은 세 인장을 먼저 해제해야 한다.

## 플레이 순서

1. 새 여정에서 청운촌의 백련을 만난다. 월영참의 형(베기)·기(기본 운기)·운(즉시 전개)·의(전방 범위)를 순서대로 선택하고 구성한다.
2. **목인 수련 시작**으로 창을 닫고 앞의 목인에 월영참을 적중시킨다. 기본 키는 **Q**이며 화면의 현재 설정을 따른다. 실제 적중 후 월영참을 습득하고 이야기가 진행된다.
   흑풍 죽림 완료 후 백련에게 보고하면 천뢰격 조합법을 배운다. 내려치기 / 뇌기 / 폭발 전개 / 주변 범위를 구성하고 목인에 **W**를 적중하여 습득한다. 이전 버전에서 이미 배운 천뢰격은 유지된다.
3. 3장 통로 방어와 백련의 안내를 거쳐 무명 비경에 진입한다. 부러진 검 / 겹친 발자국 / 봉합된 비석을 조사하면 각각 파문세 / 잔영각 / 쇄경진의 형·기와 일부 조합법만 얻는다.
4. 청운촌의 **무공 수련 → 무공 습득**에서 해당 무공을 선택한다. **운 체득 실습** 또는 일반 전투로 운을 얻고, **의 획득 퀘스트 시작**으로 목표를 수행한 뒤 **수련 종료 → 퀘스트 보고 · 의 획득**을 누른다. 배운 요소를 각 선택창에서 직접 선택하고 구성한다. **단서 해독 · 지도 받기**는 선택 사항으로 정답만 공개하며 요소는 지급하지 않는다. **기본 무공 실습**에서 공격 예고에 대응해야 습득된다. 기본 키는 **E**다.
5. **무공 창안**에서 두 체득 무공의 연결 원리와 대가를 확인하고 초안을 저장한다. **무림 연계 실습**에서 E 대응 후 Q 검격으로 실제 연결을 증명한다.
6. 현실의 헌터 기지로 돌아와 증명된 창안을 **현실에 적용**한다. **현실 연계 실습**으로 같은 연결을 시험할 수 있다.

| 조사할 흔적 → 습득 무공 | 형 / 기 / 운 / 의 | 월영참과 창안 | 실전 증명 조건 |
|---|---|---|---|
| 부러진 검 → 파문세 | 받아내기 / 반탄기 / 충격 축적 / 자신 중심 | 반류일선 | 공격 직전 E로 받아낸 뒤 Q로 직선의 두 적을 관통 |
| 겹친 발자국 → 잔영각 | 보법 / 잔향 / 순간 전개 / 출발점에 흔적 | 유영잔참 | E로 예고 밖에 이탈한 뒤 Q로 출발점의 지연 검격을 적중 |
| 봉합된 비석 → 쇄경진 | 진법 / 봉합기 / 유지 / 지정 지점 | 이맥봉류 | E로 예고를 끊고 Q로 해당 적을 베어 다음 적에게 억제를 전이 |

잔영각은 조준 방향으로 이동하므로 적의 예고에서 벗어날 방향을 먼저 잡는다. 유영잔참은 출발점을 공격한다. 준비 효과는 일반 공격 또는 연계에 한 번만 사용된다.

## 운·의 획득 경로

| 무공 | 운 · 실제 전투 성공 3회 | 의 · 시나리오 의뢰 |
|---|---|---|
| 파문세 | S 대시로 예고 밖으로 회피 후 2초 안에 같은 적 반격 | 마을 방어: 습격자 3명 제압 후 보고 |
| 잔영각 | S 대시로 예고 밖으로 벗어나 공격 발동을 회피 | 인질 구출: 경비 2명 제압 → 주민 G → 귀환 지점 G → 보고 |
| 쇄경진 | 공격 예고 중인 적에게 W 천뢰격 적중 | 비석 봉인: 경비 2명 제압 → 비석 3곳 G → 보고 |

운 체득 실습은 안전하게 행동을 연습할 수 있는 전용 전투이며, 목인·기본 무공 실습·창안 실습에서는 운을 지급하지 않는다. 의뢰는 청운촌에서 수주하고 별도의 비경 현장에서 진행하는 짧은 시나리오다. 전투 목표와 다음 지점은 화면에 표시한다. 성공해도 자동 팝업이 뜨지 않으며 **수련 종료**를 직접 누른다.

**내가 배운 요소와 획득 경로**를 펼치면 축별 보유 목록을 볼 수 있다. 조합법을 해독하지 않았어도 보유 요소로 정답을 맞추면 구성할 수 있다. 요소는 소비되지 않는다. 운의 성공 횟수·획득 요소·보고 대기 상태는 저장되며, 진행 중인 의뢰는 다시 시작할 수 있다.

## 제한과 지원

- 각 축 하나씩, 보유한 요소를 직접 선택하여 고정 조합법으로 습득한다. 실패해도 재료는 소멸하지 않는다.
- 월영참·천뢰격은 기초, 세 대응 무공은 상승 등급이다. 절학은 확장 예정이며 이번에 별도 절학을 추가하지 않는다.
- 창안은 두 습득 무공과 하나의 연결 원리를 요구한다. 창안끼리 중첩할 수 없다. 원래 효과 일부를 포기하며 후속 검격에 내력을 추가로 소모한다.
- 처음 체득한 단계에서도 세 창안을 시험할 수 있다. 실제 무림 숙련이 쌓이면 조정 범위가 넓어진다.
- 수련 지원이 기본으로 켜진다. 일반 몬스터·보스에게 주는 피해 **4배**, 받는 피해 완화, 긴 공격 예고, 빠른 내력 회복을 제공한다. 기존 저장에도 지원이 켜져 있으면 즉시 적용된다. 꺼 둔 경우 거점의 **무공 수련 → 수련 지원 켜기**로 활성화한다.
- 목인·연계 실습·증명용 표적의 피해 배율은 유지해 연계 전에 표적이 죽지 않게 한다. 보스 보호막이나 이야기상 대응 조건은 그대로 수행해야 한다.
- 수련 표적은 재화·경험치를 주지 않는다. 학습 기록은 저장되고 재접속·지역 이동 시 일시 준비와 예약 검격은 초기화된다.
- 기존 저장의 습득 무공은 유지된다. 독립 개발 실험의 저장 기록을 본편으로 가져오지는 않는다.

## 검증

`node --test tests/*.test.cjs`는 조합·실전 증명·저장·기존 스토리 회귀를 검사한다. `npm run test:browser:training`은 본편 UI에서 다섯 무공과 세 창안, 무림/현실 실습 및 모바일 화면을 검사한다.

`npm run test:browser:training-route`는 새 시작점에서 요소 획득을 포함한 20단계, 다섯 무공과 세 창안의 무림·현실 증명을 실제 UI/전투 입력으로 완료하고, 새로고침·시험 재시작·저장 분리·모바일 화면을 검사한다.
