# 새 이야기 테스트 안내

「쌍계 홀로 건너는 사람」을 기존 게임 UI에서 시작한다. 구 이야기 저장은 가져오지 않으며, 새 저장 슬롯 `exclusive-v1`을 쓴다. 이 변경은 로컬 개발 상태이며 공개 배포하지 않았다.

## 시작과 왕래

- 로컬 `http://127.0.0.1:3103/art-play.html?dev=1`에서 **새 이야기 처음부터**를 선택하고 새 게임을 시작한다.
- 화면의 **이야기 · 왕래** 또는 **임무**에서 현재 사건과 다음 장소를 확인한다. 대화는 **이야기 진행**, 전투는 **전투 계속하기**를 눌러 진행한다.
- **인트로 건너뛰기 · 조합 수업부터**는 월영참의 요소만 받은 수업으로 이동한다. 무공 습득이나 전투 보상은 대신 지급하지 않는다.
- 왕래는 **자취방 ↔ 폐사당**에서만 가능하다. 도착 후 360게임 분을 기다리고 10초 동안 멈춰 호흡한다. 1초 플레이는 게임 시간 10초다. 메뉴·비활성 시간은 포함하지 않는다.
- 거점의 **휴식 · 남은 대기 시간 보내기**는 남은 시간을 즉시 보내고 회복한다. 이동 자체는 체력·내력을 회복하지 않는다. 움직임·피격·메뉴·창 비활성화는 호흡을 취소한다.
- 왕래 저장에 실패하면 출발 전 위치·시간으로 복구한다.

## 장별 확인 순서

| 장 | 확인할 내용 |
|---|---|
| 1 | 회수 전투, 소진된 문석 사고, 진료, 자취방에서 첫 왕래, 소연과 여울장 |
| 2 | 귀환 대기, 출근 일정, 자발적 재방문, 백련의 형·기·운·의 수업, 월영참 직접 구성 |
| 3 | 남쪽 길 전투, 현대 경계 업무, 천뢰격 조합법 및 선택 전승 무공 |
| 4 | 백련과 민재의 별도 관찰, 선택한 무공 창안, 무림 효과 검증, 현실 적용 후 실제 재현 |
| 5 | 소연·서하와 북쪽 탐사 계약, 현대 일정 조정, 북쪽 조사로 확보 |
| 6 | 정맥진 조사, 현대의 별도 계측, 백련에게만 비밀 공개, 동행 왕래 거부 |
| 7 | 작은 순환 수업, 직접 가져온 기록 비교, 현대 실험 현장 검증 |
| 8 | 서하의 감금, 정맥진 외곽에서 한계 확인, 각 세계의 별도 준비 |
| 9 | 우회로 → 공급 차단 → 서하 구조 → 순환 차단 → 백련·소연 엄호 → 부상을 안고 대기 |
| 10 | 귀환, 지우의 역할 확인, 민재 장비 엄호. 지우와 전투조가 마지막 공격을 맡음 |
| 11 | 현실 보고, 무림 정산, 두 권의 수첩과 다음 탐험 |

엄호전은 12초 생존과 서로 다른 실제 위협에 세 번 대응해야 완료된다. 한 번의 광역 공격으로 세 번을 채울 수 없다. 실패한 전투는 다시 시작하며 이전 사건은 유지된다.

## 유지되는 무공 기능

무공 수련은 **습득 / 창안**을 구분한다. 요소 전체 목록과 획득 필터, 구성 즉시 습득, 습득·창안 연출, 선택 실습과 수동 종료를 유지한다. 비경에서는 형·기, 실제 대응에서는 운, 지역 의뢰 보고에서는 의를 얻는다. 기존 세 창안과 축산참·주작측검 모두 선택 가능하며 이야기에서 특정 창안 이름을 강제하지 않는다.

서하 구조 이후 여울장에서 후속 운용 실습을 선택할 수 있다. 후속 기술이 실제로 적중하면 R 운용을 체득한다. F는 정맥진 위기를 넘긴 뒤 열린다. 심법 보상은 새 이야기 사건을 기준으로 한 번만 지급한다. 플레이 스타일 숙련도는 별도 기획으로 남긴다.

## 로컬 전용 순차 테스트

개발 시작점의 **새 이야기 · 무공 순차**는 월영참부터 기존 5개 습득, 기존 3개 창안, 추가 원형 4개와 창안 2개까지 36단계로 안내한다. 각 단계에서 획득·구성·실제 효과·현실 재현을 직접 수행한다. 이 모드의 장소 이동은 중간 이야기를 건너뛰는 개발 편의 기능이다. 개발 시작점과 테스트 코드는 공개 빌드에 포함되지 않는다.
