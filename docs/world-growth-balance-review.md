# 세계별 성장·전투 초기 검수 — v0.12.0

2026-10-01 자동 시뮬레이션과 Chrome 실제 프레임 검사. 사람이 직접 조작한 플레이테스트를 대신하지 않는다.

## 적용 기준

- 죽림·균열 7명, 폐사·항만·귀환로·귀환 부두·관측소 9명, 6~7장 각 전장 6명. 보스는 지역마다 1명이며 비교 현장은 보상 없는 적 2명이다.
- 두 일반 무리와 보스 무리로 구분. 접근 350 또는 피격으로 활성화, 원점에서 600 이탈하면 귀환. 같은 무리의 동시 근접 예고는 최대 2개.
- 압박 18, 강타 24, 사격 15, 보스 30 피해. 기본 체력 120 대비 12.5~25%. 무림 경감·일시 보호는 별도 적용.
- 강타 1.15초, 사격 1초 예고. 사격은 표시한 선분과 같은 좌표/폭으로 판정한다. 기존 동작 아트를 재사용한다.
- 적 능력치는 플레이어 레벨이나 반복 입장에 비례하여 증가하지 않는다. 처치 경험치와 골드는 기존 지급량을 유지한다.

## 같은 적과 비교

`tests/world-combat.test.cjs`의 같은 현실 Lv1, 같은 균열 압박 적, 같은 기본 능력치, 같은 시뮬레이션 시간 기준:

| 입력 | 처치 시간 | 받은 피해 | 처치 XP |
| --- | ---: | ---: | ---: |
| 기본 공격 유지 | 1.75초 | 18 | 32 |
| 수동 타격 + 실제 흡수 후 압축 반격 | 1.40초 | 0 | 32 |

처치 시간 20% 단축, 피해 100% 감소. 승인 기준인 ‘어느 한 지표 25% 이상 개선, 다른 지표 악화 없음’을 피해 기준으로 충족한다. 이는 단일 적에 대한 재현 가능한 점검이지, 전체 게임의 재미나 난이도 보증이 아니다. 첫 비교부터 기준을 만족했으므로 수치 조작으로 실패를 만들지 않았다. 현실 숙련이 피해에 빠진 오류는 실패 검사를 추가해 +12% 적용을 수정했다.

## 확인한 범위와 남은 한계

모든 새 배치의 벽 충돌·좌표 중첩·플레이어 반경 경로 연결을 검사했다. 청운 귀환로는 이야기상 다리 개방 이후의 연결을 검사한다. 브라우저에서는 사격·강타 예고, 실제 피해 18, 회복약 미자동사용, 7명 유지와 시간 진행을 확인했다. 데스크톱과 모바일 폭 화면을 캡처해 검수했다.

전체 무리 교전의 긴장감, 첫 플레이어의 약 소비, 저사양 모바일 성능, 다양한 숙련도에서의 재미는 후속 사람 플레이테스트가 필요하다. 새 원본 아트 후보는 사용하지 않았다.
