# 아트 디렉션 — 두 세계, 하나의 작품

## 공통 화풍
특정 게임의 자산 복제가 아니라 다음 특성을 가진 오리지널 2D RPG를 목표로 한다.
- 3/4 탑다운 또는 아이소메트릭에 가까운 읽기 쉬운 시점.
- 핸드페인팅 질감, 자연광/환경광, 과도하지 않은 외곽선.
- 캐릭터는 SD보다 늘씬한 인체 비율. 작은 필드 실루엣에서도 무기/복장이 읽혀야 한다.
- 배경은 장식 밀도가 높되 이동 가능 영역과 충돌물은 명확.
- 컷신/초상은 필드보다 디테일을 올리되 동일 인물로 보여야 한다.

## 현실 세계 — R01
키워드: 현대 헌터 행정 / 콘크리트 / 유리 / 금속 / 젖은 도로 / 청회색 / 비상등 / 청백색 균열.

### 주인공
- 검은 머리, 현대 헌터 재킷/전술복/부츠.
- ID, 통신 장치, 파우치, 장비 벨트.
- 검집/고정구가 현대 장비에 논리적으로 연결.
- 무림 도포/전통 장신구 금지.

### NPC
관리관, 현장 헌터, 연구원, 의무요원, 보급/정비, 시민/대피자.

### 배경
관리국, 연구동, 통제 게이트, 산업구역, 대피 주거, 현대 도심.
도로 차선/횡단보도/볼라드/콘테이너/차량/펜스/경고표지.

### 몬스터
생물 + 결정 + 차원 잔재 + 기계/감시 장치. 무림 도적/검객/요괴 실루엣 재사용 금지.

## 무림 세계 — R02
키워드: 기와 / 목재 / 흙길 / 돌계단 / 대숲 / 산맥 / 안개 / 등불 / 따뜻한 자연광 / 먹색과 천의 질감.

### 주인공
- 장발 또는 묶은 머리.
- 흰/회색/남청 도포와 겹옷.
- 천 허리띠, 가죽 끈, 장검/검집.
- 현대 ID/통신기/플라스틱 장비 금지.

### NPC
객잔 주인 / 문파 제자 / 의원 / 나룻꾼 / 떠도는 검객 / 노고수 / 약방 상인.

### 배경
민가 / 약방 / 주막 / 문루 / 사찰 / 산중 사원 / 포구 / 장터.

### 몬스터
산적/마교/타락 무인/요괴/영물/원혼. 현실 홀로그램/기계 관절/관리국 장비 재사용 금지.

## 포털
- 현실 → 무림: 물리적 격리 구조물 + 균열, 내부에 자연/산세 preview.
- 무림 → 현실: 비석/문주/진법 + 경계, 내부에 도시의 차가운 빛 preview.
- 일반 지역 출입구보다 1.5~2배 큰 silhouette + 주변 입자/음영 왜곡 + 목적지 라벨.

## 금지
- 현실 NPC에 무림 머리/도포를 붙이는 fallback.
- 한 세계 몬스터를 색만 바꿔 재사용.
- 컨셉 보드의 텍스트/로고를 런타임 UI로 잘라 쓰기.
- 특정 상용 작품의 캐릭터/건물/아이콘을 그대로 재현.
