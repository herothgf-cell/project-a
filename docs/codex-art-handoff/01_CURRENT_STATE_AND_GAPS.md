# 현재 구현 상태와 미구현/부분 구현 구분

## 이미 구현 — 보존
### 콘텐츠 / 진행
- 12개 지역, 5개 챕터.
- 현실 ↔ 무림 이동.
- 제1~5장 진행과 기존 저장 migration.
- 기감 `B`, 상호작용 `E`, 관찰 수첩 `N`, 도움말 `H`.
- 환서정 탐험과 여정별 단서 seed.
- 세 기연 계열: 파문검 / 잔영보 / 경계봉인.
- 여섯 해석: 반전검, 수호진, 회향 귀환보, 재현검, 불동인, 도류인.
- 숙련, 심법, 첫 경지 돌파, 마정석, 관측 렌즈, 도겸 동행.
- 소식 UI 5개 탭과 `실제 멀티 채팅이 아닌 연출 시뮬레이션입니다.` 고지.

### 전투 규칙
- 기본 3연격.
- 월영참 / 천뢰격 / 회피.
- 개인 무공 9개.
- 보스 보호막, 공격 예고, 피격/경직, 데미지 숫자, hit-stop, camera shake.
- 현재 판정/쿨다운/내력 소비/저장 상태는 아트 교체 때문에 변경하지 않는다.

## 부분 구현 — 제작용 아트로 교체
### 캐릭터
현재 `presentation.js`는 실제 이동거리로 보행 리듬을 계산하고 `realm-art.js`는 손/검 위치를 절차적으로 붙인다. 이는 모션 일치 보정이지 완전한 애니메이션이 아니다.

미구현:
- 현실 윤서 전용 8방향 전신 세트.
- 무림 윤서 전용 8방향 전신 세트.
- idle / walk / fast-walk 또는 run / dodge / attack1 / attack2 / attack3 / cast / hit / down.
- 손/무기 socket이 포함된 frame metadata.
- 캐릭터 초상과 필드 외형의 얼굴/복장 일치.

### NPC
현실 NPC는 role 중심 공통 uniform 절차형 몸체를 공유하는 부분이 크다.

미구현:
- `reality.npc.seorin`, `reality.npc.dogyeom`, `reality.npc.supply`, researcher, medic.
- `murim.npc.baekryun`, `murim.npc.yeonhwa`, 문파 제자, 객잔/시장 주민.
- 초상/필드 스프라이트 일관성.
- 주요 NPC 감정 표정 3~5종.

### 몬스터
현재 여러 적이 넓은 kind 분기 또는 절차형 형태를 공유한다.

미구현:
- 현실: 결정 오염체, 이형 인간체, 차원 잔재, 오염 하운드, 감시 드론, 게이트 출현체.
- 무림: 산적, 마교 무인, 설혈랑/영물, 원혼귀, 독혈요, 타락 무인.
- 현재 실제 스폰되는 적의 idle / move / telegraph / attack / hit / death.
- 실루엣만 봐도 어느 세계 적인지 구분.

### 배경 / 건물
현재 현실은 절차형 flat roof / concrete, 무림은 painted/procedural 혼합. 구조 분리는 됐지만 아트 완성이 아니다.

미구현:
- 현실 헌터관리국, 연구 별관, 주거/대피 단지, 도심, 산업 시설, 항만, 관측소.
- 무림 민가, 약방, 객잔, 문파 문루, 사찰/폐사, 시장, 포구, 환서정.
- world-specific props와 foreground/background depth layer.
- 반복 타일 티가 덜 나는 지형 세트.

### 포털
- 현실 게이트: 금속 격리 프레임 + 장치 + 청백색 공간 균열.
- 무림 경계문: 비석/문주 + 진법 + 먹빛/금빛/청색 기운.
- locked / available / active / transition 상태.
- 세계 이동 전/중/후 화면 전환.

### UI
현재 정보 구조는 컨셉에 맞게 재배치했지만 최종 제작 UI가 아니다.
- HUD frame/button/tab/icon/quest tracker/minimap markers.
- 현실/무림 world accent.
- 대화창 감정 초상/컷인.
- 기연/수첩/성장 패널.

## 후속 콘텐츠 — 그래픽 교체와 혼동 금지
컨셉에 있지만 현재 게임 기능이 아닌 후속 후보:
- 설산/그림자 시장 등 신규 지역.
- 신규 몬스터 전체 세트의 실제 스폰/AI/드롭.
- 헌터 C 이후 B/A/S.
- 무림 경지 다단계.
- 실제 온라인 멀티/채팅/서버 최초.
- 다인 파티/경매장/길드 경제.

아트가 있다고 자동으로 게임에 추가하지 않는다.
