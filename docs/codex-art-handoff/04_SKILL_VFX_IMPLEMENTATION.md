# 현재 구현 무공 / 스킬 아트·연출 명세

Reference: R03.

## 공통 원칙
- **Damage timing is authoritative.** 컨셉 때문에 판정 시점을 바꾸지 않는다.
- 몸 → 손 → 검 → 검기 → 타격점이 같은 action instance를 참조한다.
- contact frame은 현재 게임이 피해를 적용하는 순간과 일치.
- hit-stop / camera shake / enemy flash를 함께 검수.
- 이미 생성된 잔향/검기/결계는 플레이어 이동을 따라오지 않는다.
- residual VFX는 추가 피해를 만들지 않는다.

## 현재 보존 수치
`game.js` 기준:
- dash 이동 0.17s, invulnerability 0.33s, dash effect 0.3s.
- 기본 attack hit-stop 약 0.025s, 기술 약 0.045s.
- moon range 215, storm range 250.

## 연환검 — 3연격
1타 낮은 횡베기 → 2타 반대 방향 회수 베기 → 3타 큰 몸통 회전/넓은 궤적.
공격 버튼 시 캐릭터 body는 idle인데 검기만 먼저 나오는 현상 금지.

## 월영참
현재 기능은 **전방 광역 단일 베기**. 다단히트로 바꾸지 않는다.
- 준비: 검을 낮게 당김.
- contact: 큰 초승달 검기 1개.
- 0.1~0.25s 잔광.
- 은백 + 옅은 청색.

## 천뢰격
피해는 발동 순간 광역 판정, 이펙트는 약 0.6s.
- contact: 첫 낙뢰.
- 이후 잔류 전기는 시각 효과만.
- 남청 + 백색 코어 + 보라 포인트.

## 회피
발로 밀어내는 pose → 실제 dash displacement → 착지/복귀.
빠른 afterimage 1~2개.

# 파문검
### Q 파문세
0.7s 받아내기. 준비 자세 → 얇은 ripple → 실제 성공 시 큰 파문. 실패/만료 시 큰 이펙트 금지.

### R 역류참
축적 기운이 손잡이→검날로 흐른 뒤 전방 반월 1회. 축적량은 밝기/폭으로 표현.

### F 파천반월
full-body wind-up, 넓은 반월, stance-break와 지면 먼지.

# 잔영보
### Q 잔영각
출발 순간 pose/facing을 보존한 잔향. opacity 단계 감소.

### R 귀환보
잔향과 본체 연결 → 실제 path가 열릴 때만 이동 → 도착 협공.

### F 월흔난무
세 잔향이 실제 hit schedule에 맞춰 시간차 베기.

# 경계봉인
### Q 쇄경진
손/부적/검끝 문양 → 바닥 원진 → 4s 고정 영역. telegraph 억제 순간 sealing line.

### R 봉맥인
가까운 최대 2개 대상과 연결, 발밑 봉인 고리.

### F 만경고정
대형 원진 + 발동 충격 + 이후 남는 제어장 분리.

# 여섯 해석
- 역파·반전검: R 후 다음 기본 공격에만 charge line. 빗나가도 소모.
- 잔파·수호진: Q 위치에 4s 고정 공간. 플레이어를 따라가지 않음.
- 회향·귀환보: 귀환 지점 원형 검격 + 짧은 무적 sheen.
- 먹향·재현검: **본체 이동 없음.** 0.45s 뒤 잔향 위치에서 베기.
- 정박·불동인: Q field 6s, 첫 실제 telegraph 억제 순간 잠금.
- 유전·도류인: R 방향성 표시, 공격 예고를 끊었을 때만 후속 유도 검기.

# SFX
연환검: 마른 금속/바람. 월영참: 낮은 공명 + 긴 slash. 천뢰격: rumble + 큰 crack + 잔전기. 파문검: 단단한 금속 공명. 잔영보: 바람/옷자락. 경계봉인: 종/부적/낮은 공명.
