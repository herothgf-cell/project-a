# 귀환 대응 프로토타입 · 사람 플레이테스트

상태: **미실행**. 자동 검사로 성장 체감, 인정, 재미, 20~30분 소요 또는 사업성을 판정하지 않는다.

## 진행

목표 인원은 PC 4명·모바일 4명, 각 20~30분이다. 자발적으로 동의한 익명 기록만 사용한다. 이름·연락처·원본 게임 저장을 관찰 로그에 넣지 않는다. 이번 작업에는 모집이나 외부 연락이 포함되지 않았다.

로컬에서 `ART_REVIEW=1 node server.cjs`를 실행하고 `http://127.0.0.1:3000/art-play.html?dev=1`에 접속한다. **2장 보고 후부터**는 기연 미보유 상태이며 `dualworld.test.v10`만 사용한다. 1~2장 학습을 생략했으므로 신규 사용자의 자연 도달 시간은 별도 새 게임 테스트로 측정한다.

1. 기본 설정과 조작을 확인한다. 관찰 로그는 동의를 받은 경우에만 켠다. 기본은 꺼짐이다.
2. 현실 던전 입구에서 첫 체험을 선택한다. 목표·실패·질문을 유도하지 않고 관찰한다.
3. 기존 백련→비경→계승→현실 귀환 경로를 진행한다. 선택 연습 도움 사용 여부를 기록한다.
4. 귀환 카드와 장착 후 같은 현장에 재입장한다. 실제 효과를 봤는지 설명을 먼저 주지 않는다.
5. 직접 보고, 선택 미리보기, 확정, 현장 적용을 진행한다.
6. 2분 이상 같은 지점에서 진전이 없으면 “지금 무엇을 하려 하나요?”만 묻고 개입 여부·문구·시점을 기록한다. 이후 필요한 최소 도움을 준다.
7. 체험 종료 후 아래 비유도 질문을 한다.

## 질문과 관찰 기준

| 가설 | 질문 | 기록할 관찰 | 현재 판정 |
| --- | --- | --- | --- |
| H1 성장 인식 | 전과 후에 무엇이 달라졌나요? | 자발적으로 언급한 기술·행동·수치 | 미실행 |
| H2 대응 재미 | 가장 기억나는 전투 순간은 무엇인가요? | 예고 관찰, 받아내기, 후속타, 재시도 | 미실행 |
| H3 인정 | 서린과의 대화 뒤 무엇이 바뀌었나요? | 맡은 판단·선택 배치의 실제 현장 변화 | 미실행 |
| H4 이해 | 새 능력을 얻은 뒤 무엇을 했나요? | 정착·장착·실전 증명 구분, 도움 없이 장착·입장 수행 | 미실행 |
| H5 지속 | 지금 이어서 무엇을 하고 싶나요? | 자발적 재도전·다른 계열 플레이를 실제 시작하는지 | 미실행 |

기획서의 탐색 기준은 H1 전후 행동 설명·H2 독립적 유효 대응·H3 역할 이해·H4 장착/입장 각각 8명 중 6명 이상, H5 자발적 선택 플레이 실제 시작은 8명 중 4명 이상이다. 성공 뒤 반복 사용 횟수와 조작 불만도 원자료로 기록한다. 소표본 방향성 관찰이며 통계적 효용을 주장하지 않는다.

진행자용 성공 기준을 참가자에게 사전에 읽어 주지 않는다. 임무 승리만으로 기술 효과를 이해했다고 판정하지 않는다. 이미 성장한 저장의 즉시 처치는 별도 표본으로 분류한다.

## A/B 비교

개발 화면의 **피드백 A/B**는 신규 상태 안내와 대응 타격 정지의 사용 여부를 바꾼다. 스킬 수치·피해·적 프로필은 동일하다. 동일 저장 복사본으로 비교하며 학습 효과를 위해 순서를 AB/BA로 4명씩 분산한다. A/B 각각 시작 시 로그를 새로 켜 메타데이터를 맞춘다. 저효과 설정과 장치 크기를 함께 기록한다. 자동 비교는 동일한 시뮬레이션 행동의 수치만 확인하며 체감 우열은 판정하지 않는다.

## 참가자별 양식

- 익명 ID / 동의 여부 / 날짜 / 빌드 커밋:
- PC·모바일 / 화면 크기 / 입력 / 저효과 / A/B 순서:
- 새 게임 또는 2장 시작점 / 이전 경험 / 시작 능력치:
- E1 시작·완료 / E2 체득 / E3 장착 / E4 실제 효과·완료 / E5 보고·선택 / E6 완료 시각:
- 실패·후퇴·도움 개입 횟수와 실제 문구:
- 무효 입력 / 기본 공격 강화 소비 / 쿨·자원 혼동:
- 참가자 발언 원문 / 관찰자 해석(별도):
- H1~H5: 미실행 → 관찰 후 근거와 판정:
- 다시 해 보고 싶은 부분 / 멈추고 싶은 부분 / 기타 의견:

로그는 최대 2,000건이며 오래된 항목부터 제거하고 누락 건수를 표시한다. **익명 로그 내보내기**는 로컬 JSON 다운로드만 수행한다. 원본 저장은 자동 포함하지 않으며 서버로 전송하지 않는다. 기록을 공유할지는 참가자가 결정한다.
