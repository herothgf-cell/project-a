# 경계공명 — 무림의 성취가 현실의 힘으로

2026-10-06 · 검토용 기획 시안 · 제품 구현 전

[최신 개정 기획](../../superpowers/specs/2026-10-06-boundary-resonance-redesign.md)

이번 방향은 무림→현실 단방향이다. 경계공명 원핵은 영구 기록이며, 공명 결정과 무공 각인은 현실 능력치/기술 투자의 매개체다. 현실→무림용 C/D 재화는 현재 범위에 없다.

[UI 콘셉트 원본](ui-concept.png)은 이미지 생성 도구로 제작해 채팅에 직접 첨부했다. 이전 SVG/PNG의 로컬 링크가 사용자에게 표시되지 않는 문제가 있어 전달 방식을 바꿨다. 네이티브 첨부의 실제 클라이언트 표시 여부는 사용자의 환경에 따라 별도로 확인해야 한다.

시안은 목표 선택 → 공명 보관 → 현실 기술이라는 정보 구조와 게임 아트 방향을 보여준다. 버튼은 동작하지 않으며 개념 이미지의 선행 연결·문구·숫자가 구현 계약이 아니다. 예를 들어 R 후속 노드의 선행 조건은 문서에 명시한 Q 방향 **둘 중 하나 해금**이다. 생명/공격 예시는 다른 성장 보너스를 제외한 레벨 1 기준이고, 각인 잔액은 전체 누적 지급량이 아닌 예시다. 실제 최종 수치·구매 가능 여부·보유량은 데이터 모델을 따라 표시해야 한다.

이미지를 볼 수 없어도 읽을 수 있는 텍스트 구조도가 개정 기획의 UI 절에 있다.
