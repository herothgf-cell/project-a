## 0. 읽는 법과 기획 요약

문서의 상태 표시는 다음과 같다. 3~10장의 규칙·사례·수치는 별도 표기가 없으면 모두 **[권장 제안]**이다. 구현 완료를 뜻하지 않는다.

| 표시 | 의미 |
|---|---|
| [사용자 확정] | 이번 요청으로 정해진 방향과 금지 조건 |
| [현재 구현] | 기준 커밋의 실행 코드에서 확인한 사실. 조사 근거는 2장 |
| [기존 문서] | 이전 기획의 주장. 현재 실행 기능과 동일하다고 간주하지 않음 |
| [권장 제안] | 검토 가능한 초안을 위해 이번에 선택한 설계 |
| [미결정] | 본편 편입 전에 검토할 핵심 결정. 마지막 11장에 모음 |

**접목 방식은 ‘형·기·운·의로 기본 초식 만들기 → 체득한 초식 2개와 연결 원리 1개로 연계 무공 만들기’의 두 단계다.** 앞 초식이 만든 축적·잔향·억제 상태를 뒤 초식이 소비하거나 바꾸어, 같은 버튼을 차례로 누르는 것과 다른 결과를 만든다. 현실에서는 그 원리를 호환되는 기존 스킬 하나에 적용한다. 요소·초식은 없어지지 않고, 숙련도는 소비하지 않으며, 창작물별 경험치도 만들지 않는다.

**[사용자 확정·후속 방향]** 첫 경험은 백련의 안내에 따라 형·기·운·의를 하나씩 조합해 월영참을 완성하는 튜토리얼이다. 이후 파문세·잔영각·쇄경진도 요소 조합으로 만들 기회를 제공하고, 반류일선·유영잔참·이맥봉류까지 시험할 수 있는 실험을 계획한다. 무제한 조합을 막는 구체적인 제한 규칙을 둔다. 세 계열 모두 시험하는 실험 범위와 본편의 점진적 습득 속도는 구분한다.

‘언제 공격할지’는 플레이어가 입력하고 ‘어떻게 이어지는지’는 설계한 무공이 정한다. 형·기·운·의는 처음부터 배우되 첫 화면에 모든 선택지를 펼치지 않고 네 번의 짧은 안내로 익힌다. R/F 일괄 지급은 하지 않는다.

현행 공명 결정·각인 투자와 레벨·심법은 수치 성장의 기반으로 남긴다. 창작은 **범위·위치·발동 조건·대상 상태 활용을 바꾸는 운용 선택**을 담당한다. 이름을 바꾸거나 작품을 늘려도 공명 재화·능력치·등급을 지급하지 않는다.

핵심 흐름:

> 현실에서 통로를 지킬 수 없는 이유를 경험한다 → 무림에서 필요한 원리를 선택해 익힌다 → 초식의 유효 사용으로 성취를 남긴다 → 연결 결과와 대가를 보고 조합한다 → 안전한 시험에서 수정한다 → 현실 기존 스킬에 원리를 적용한다 → 같은 압력에 다른 방식으로 대응한다 → 현장 실적을 보고하고 역할을 인정받는다.

산출물은 이 기획서 하나다. 코드·게임 데이터·저장 형식·브랜치·배포를 바꾸지 않는다. 기존 문서 구조에 맞춰 `docs/design/skillform`에 둔다.

## 1. 사용자 확정 방향과 해석 원칙

**[사용자 확정]** 창작 방향은 플레이어가 선택한다. 전투 경험은 숙련·성취의 근거지만, 숨은 행동 분석으로 원치 않는 무공을 확정하지 않는다. 조합은 피해량 외의 기능 차이를 만들며, 현실 성장과 임무 수행으로 이어져야 한다. 낮은 숙련의 확률 실패, 재료 소멸, 같은 해금을 위한 양 세계의 반복 수련, 작품마다 별도 하드코딩하는 무제한 조합을 피한다.

**[사용자 확정]** 무공 공통 1~9성과 초식·특징별 성취를 함께 고려한다. 심법·경지·현실 스킬·헌터 등급의 역할을 구분하고 새 게이지와 재화를 최소화한다. 기존 문파와 무공의 정체성을 유지한다.

**[사용자 확정·후속 방향]** 월영참을 완성품으로 받는 대신 형·기·운·의 튜토리얼로 만든다. 파문세·잔영각·쇄경진도 조합으로 완성하고 다음 조합의 재료로 쓴다. 아래 요소 이름·레시피·제한 수량은 이 방향을 구체화한 권장 제안이며 확정된 게임 데이터가 아니다.

**[권장 제안] 행동에 따른 성질 변화의 해석:** ‘회피 후 자주 사용하면 반격이 강화’되는 예시는 **공개된 성취가 해당 운용의 조정 폭을 넓히는 것**으로 적용한다. 회피 성취가 높은 플레이어는 자신이 선택한 회피 연계의 시간·거리 범위를 더 잘 조정한다. 수호 운용을 선택한 사람이 회피를 많이 했다고 반격 무공으로 바뀌지 않는다. 다수 적 대응·보스 파훼도 선택 가능한 특징을 열 뿐 자동 장착하지 않는다.

**[권장 제안] 확률과 범위:** 요청의 ‘회피 관련 결과 확률 상승 또는 효과 강화’ 중 초기에는 **효과·조정 범위 강화**를 채택한다. 조합 결과의 종류와 설정값은 결정적이다. min~max는 개인의 현재 숙련에서 선택할 수 있는 범위이며, 매번 무작위로 뽑는 성능이 아니다. 확률적 기연은 향후 새 원리를 발견하는 서사에만 검토하고 핵심 제작 결과에는 넣지 않는다.

## 3. 핵심 선택 8개와 권장 이유

| 결정 항목 | 권장안 | 선택 이유·주요 대안 |
|---|---|---|
| 1. 기본 단위 | 기본 초식은 **형·기·운·의 요소**, 연계 무공은 **체득한 초식**이 재료 | 배우는 단계부터 직접 만든다는 후속 방향을 반영한다. 초식은 동작·조건이 검증된 단위로 재사용한다. |
| 2. 조합 방식 | **네 축으로 기본 초식 구성 → 2초식 순차 연결 + 원리 1개** | 요소 생성과 초식 연결을 같은 화면에서 섞지 않는다. 첫 단계의 이해가 두 번째 단계의 상태 활용으로 이어진다. |
| 3. 숙련 구조 | 1~9성은 무공 공통 숙련의 단계, 초식 성취는 해당 운용을 증명한 기록 | 9단계×초식별 경험치를 따로 만들지 않는다. 공통 단계는 조정의 폭, 성취는 구체적 연결 권한을 담당한다. |
| 4. 창작 완성도 | 재료 숙련·성취·현재 설정에서 **계산** | 창작물마다 별도 숙련을 쌓으면 교체가 손해이고 재학습이 반복된다. 시험은 판정 확인이고 경험치 막대가 아니다. |

| 6. 장소·교체 | 청운촌에서 조합/장착, 비경에서 시험, 현실 기지에서 적용·무료 교체 | 비용으로 실험을 막지 않는다. 필드에서는 읽기만 가능하고 전투 중 교체는 불가다. 원본·기존 설계는 보존한다. |
| 7. 제한·대가 | 배운 요소·축별 1요소·기본 초식의 핵심 기능 1개·연계 2초식·자원·호환성 | 새 제작 재화 없이 조합의 의미와 운용 한도로 제한한다. 범위를 얻으면 방어를 잃는 등 교환이 있어야 단순 기술도 가치가 있다. |
| 8. 세계관 | 몸에 익힌 ‘호흡·위치·힘의 시간 구조’가 경계공명으로 현실 능력에 번역됨 | 기존 이야기의 몸에 남은 무공·현실 대응과 맞는다. 속성 마법까지의 전이는 별도 적성/매개체 설정이 필요해 후속으로 둔다. |

가장 영향이 큰 대안은 ‘무공 자체를 현실 신규 스킬로 지급’하는 방식이다. 획득의 극적 느낌은 크지만 키·튜토리얼·개별 밸런스·저장 부담이 크다. 초기 검증에는 기존 스킬의 운용 변화를 채택하고, 기존 스킬로 표현할 수 없는 새 역할에만 신규 스킬을 검토한다.

## 4. 시스템 상세 규칙

### 4.1 재료, 정체성, 형·기·운·의

재료는 배운 요소 또는 체득한 초식의 **사용 권리**다. 소모 아이템이 아니며 여러 설계에 사용할 수 있다. 기본 초식은 배운 요소로 초안을 만들고 시험에서 기능을 증명한 뒤 체득한다. 체득한 초식만 연계 무공의 영구 재료가 된다. 아직 만들지 못한 초식의 숙련을 제작 조건으로 요구하지 않는다.

기존 기술명은 배우는 원리의 표준형 이름으로 보존한다. 월영참 기본형을 만든 뒤 배운 요소와 조정 범위 안에서 개인 변형을 저장할 수 있다. 정체성을 바꿀 정도의 변경은 다른 원형으로 취급하며, 이름만 월영참으로 유지해 제한을 우회하지 못한다. 작품 카드에는 ‘백련의 검술 원리 / 월영참 기반 / 개인 변형’처럼 출처를 남긴다. 신규 문파를 이미 존재하는 것처럼 만들지 않는다.

초식 정의에는 안정 ID, 소속 무공, 해금 증거, 동작 유형, 시작 조건, 생성 상태, 소비 가능한 상태, 표적 방식, 자원·회복 시간, 변경 허용 범위를 둔다. 현재 `PATHS.skills`의 배열 위치를 영구 초식 ID로 쓰지 않는다. 이 데이터 모델은 신규 제안이다.

형·기·운·의는 기본 초식 편집의 실제 네 축이다. 각 축에서 하나씩 고른다. ‘기본 운기’, ‘즉시 전개’, ‘전방’처럼 특별한 추가 효과가 없는 요소도 정상 선택이며 속성·추적 같은 고급 효과를 강요하지 않는다.

| 축 | 플레이어가 정하는 것 | 초반 요소 예시 |
|---|---|---|
| 형(形) | 몸이 어떻게 움직이는가 | 베기, 받아내기, 보법, 진법 |
| 기(氣) | 어떤 힘의 성질을 쓰는가 | 기본 운기, 반탄기, 잔향, 봉합기 |
| 운(運) | 언제·어떤 방식으로 힘을 운용하는가 | 즉시 전개, 받아낸 충격 축적, 순간 전개, 유지 |
| 의(意) | 힘을 어디에 작용시키는가 | 전방 범위, 자신 중심, 출발점에 흔적, 지정 지점 |

#### 4.1.1 기본 초식 네 가지를 만드는 과정

아래는 **신규 제안 레시피**다. 현재 코드에 요소 조합이나 ‘반탄기/봉합기’ 재료가 구현되어 있는 것은 아니다. 이름은 최종 설정 검토 전 임시 용어다.

| 완성할 초식 | 형 | 기 | 운 | 의 | 배움과 완성 장소 |
|---|---|---|---|---|---|
| 월영참 | 베기 | 기본 운기 | 즉시 전개 | 전방 범위 | 청운촌 백련: 각 요소를 짧게 체험 → 안내대로 구성 → 전방 표적에 유효 검격 → 체득 |
| 파문세 | 받아내기 | 반탄기 | 받아낸 충격 축적 | 자신 중심 | 비경의 부러진 호위검: 충격 원리 관찰·연습 → 직접 구성 → 예고 받아내기 → 체득 |
| 잔영각 | 보법 | 잔향 | 순간 전개 | 출발점에 흔적 | 비경의 겹친 발자국: 이동·잔향 관찰·연습 → 직접 구성 → 예고를 벗어나 잔향 남기기 → 체득 |
| 쇄경진 | 진법 | 봉합기 | 유지 | 지정 지점 | 비경의 봉합된 비석: 기운을 붙잡는 원리 관찰·연습 → 직접 구성 → 진 안의 실제 예고 억제 → 체득 |

월영참 튜토리얼은 한 축씩 추가할 때 동작과 예상 효과를 보여준다. 마지막 실습에서 전체 무공이 작동한다. 튜토리얼은 기본형 하나로 문법을 가르치고, 완료 직후 같은 베기에서 ‘전방 범위 ↔ 좁은 직선’을 바꿔 보는 작은 선택을 제공한다. 직선은 닿는 길이가 늘지만 옆 적을 놓친다. 이 무속성 조준 변경은 충격의 저장·방출을 주지 않으므로 반류일선을 선지급하지 않는다.

파문세 등에서는 완성 기술 대신 유물 관찰과 지도 연습이 **사용 가능한 요소와 호환 힌트**를 연다. 요소 학습 기록은 획득 여부와 실제 체험 증거만 가지며 요소별 경험치 바를 만들지 않는다. 무작위 조합 발견을 요구하지 않고 결과·부족 조건을 미리 보여준다. 청운촌에서 설계하고 비경의 지도 시험에서 임시 실행·수정할 수 있다.

시험 성공 시 기본 초식을 체득하고 계열의 입문 증거를 남긴다. 백련은 배운 원리를 정리하며 계승 확인은 한 번만 처리한다. 기존 `fate.proven`/계승 원장에 대응시킬 때 같은 계열의 다른 개인 변형을 새 계승 보상으로 지급하지 않는다. 유물 조사만으로 완성 기술이 생기지 않는다.

#### 4.1.2 마구잡이 조합을 막는 장치: 운기 규칙

권장 장치는 별도 제작 화폐 대신 **‘배운 원리 안에서 몸으로 운용할 수 있는 구조’**다. 다음 제한은 작품 이름과 무관하게 적용한다.

| 제한 | 구체 규칙 | 플레이어에게 보이는 이유 |
|---|---|---|
| 배운 요소 | 관찰·지도 연습으로 습득한 요소만 영구 설계에 사용. 미습득은 미리보기·획득 경로 확인 가능 | ‘잔향 원리를 아직 배우지 않았습니다. 겹친 발자국에서 체험’ |
| 축별 선택 | 기본 초식은 형·기·운·의 각 1개. 같은 축의 효과를 여러 개 쌓지 못함 | ‘베기와 보법을 한 형에 넣을 수 없습니다. 두 초식으로 나누세요’ |
| 원리 호환 | 기의 출력, 운의 필요 상태, 형·의의 위치/표적 조건이 연결되어야 함 | ‘충격 축적에는 실제 받아내기가 필요합니다. 현재 베기는 충격을 받지 않습니다’ |
| 핵심 기능 수 | 기본 초식은 검격/충격 대응/잔향 이동/예고 억제 중 한 원형. 흡수+잔향+봉합을 한 초식에 넣지 못함 | ‘충격 대응과 잔향은 별도 초식으로 만드세요’ |
| 연계 한도 | 체득한 기본 초식 최대 2개 + 연결 원리 1개. 연계 무공을 다른 연계의 재료로 넣지 못함 | ‘반류일선은 이미 두 초식의 연계입니다. 세 번째 기능을 추가할 수 없습니다’ |
| 수치 한도 | 숙련은 시간·거리의 선택 범위를 넓힘. 범위·유지 증가에 비용·후딜 또는 즉시 효과 포기 | ‘범위 증가: 비용 증가·좁은 공격 폭’ |
| 실제 사용 | 내력·쿨다운·유효 상태가 충족되어야 실행. 낮은 숙련의 확률 실패 없음 | ‘내력 부족’, ‘받아낸 충격 없음’ |
| 장착 | 기본 초식은 기존 행동 슬롯, 기연 Q 계열은 한 번에 하나. 연계 변형과 현실 원리도 각 하나만 활성 | ‘현재 파문 운용 중. 잔영으로 바꾸려면 거점에서 교체’ |

‘축별 1개·기본 원형 1개·연계 2초식’은 초기 실험용 한도다. 성취가 높다고 흡수·이동·봉합이 모두 들어가는 무공을 허용하지 않는다. 두 초식을 한 이름으로 저장해도 구성 요소 수는 그대로 세어 중첩을 차단한다. 불가능한 조합은 제작 시 이유를 알려주고 필드 장착을 막으며, 사용할 때 임의로 폭발하거나 실패하지 않는다.

예를 들어 **베기+반탄기+충격 축적+전방**은 받아내는 동작이 없어 불가다. **받아내기+반탄기+충격 축적+자신 중심**은 파문세 원형으로 성립한다. 월영참을 연결하면 검격과 충격 대응이라는 두 기능의 허용된 연계가 되며, 방어 성공·한 번 소비·추가 비용이라는 대가가 붙는다. 원형별 허용 태그와 매개변수 범위를 검사하므로 결과 이름마다 별도 코드를 만들 필요는 없다.

제작권·일일 제작 횟수·재료 파괴는 시행착오를 막아 권장하지 않는다. 정확한 레시피 일치만 허용하는 방식은 정답 복사가 되기 쉬워, **원형과 호환 규칙을 지키는 범위 내의 변형**을 권장한다. 월영참을 만든 뒤 공격 폭·거리 등을 바꿔볼 실제 선택은 남긴다.

문파 핵심 운용을 지우는 변형은 불허한다. 파문은 충격을 받아내야 축적되고, 잔영은 실제 이동과 남긴 위치를 활용하며, 봉인은 대상의 예고·흐름을 억제해야 한다. ‘파문 재료를 넣었으니 조건 없는 관통 공격’은 호환 불가다.

### 4.2 호환 조건과 결과 결정

기본 초식은 4.1.2의 요소·원형 호환 검사 뒤 지도 시험으로 체득한다. **체득한 초식의 연계 조합**은 다음 순서로 검사한다.

1. 두 초식을 실제로 배웠는지, 이야기 잠금이 풀렸는지 확인한다. 미습득 R을 Q의 ‘원리’라는 이름으로 우회하지 않는다.
2. 앞 초식의 출력 상태와 뒤 초식의 수신 어댑터가 맞는지 확인한다. 맞지 않으면 부족한 재료·성취 또는 미지원 이유를 표시한다.
3. 선택한 연결 원리의 공개 성취를 확인한다. 계열 공통 숙련만 높다고 모든 원리를 허용하지 않는다.
4. 최소 실행 비용·현재 숙련의 설정 범위·장착 한도를 확인한다.
5. 같은 재료·원리·숙련·설정은 항상 같은 결과를 만든다. 미리보기와 실제 실행은 같은 규칙에서 계산한다.

| 출력 상태 | 허용할 입력·연결 | 허용하지 않는 예 |
|---|---|---|
| 받아낸 충격 | 공통 검격에 관통 방출 또는 수호 전환 | 받지 않은 충격 생성, 공격과 방어에 같은 충격 이중 사용 |
| 이동으로 남긴 잔향 | 공통 검격을 잔향 위치에 지연 배치 | 도달 불가능한 벽 너머 타격, 위치와 무관한 전장 전체 추적 |
| 실제 예고 억제 표식 | 공통 검격이 표식의 남은 시간을 가까운 다음 대상에 전이 | 보스 영구 경직, 중첩 전이로 지속 시간 증식 |

호환 불가는 확률적 실패가 아니다. 이미 유효하게 저장·장착된 저숙련 조합은 설정한 규칙대로 발동한다. 실전에서 사거리·예고 타이밍·자원·위치 조건을 놓쳐 효과가 나지 않는 것은 일반 전투 실패이며 UI에 원인을 남긴다.

아직 연결 원리를 증명하지 않은 경우에도 재료 습득과 기본 초식 체득이 확인되면 **초안 작성과 지도 시험**은 가능하다. 시험 안에서만 임시 원리를 빌려 일회 연결 성취를 얻고, 그 뒤 필드 장착을 허용한다. ‘조합해야 성취를 얻는데 성취가 없어 시험도 못 하는’ 순환 잠금은 만들지 않는다. 파문 관통/수호는 공통 ‘충격을 검격으로 소비’ 증거를 공유하므로 두 운용을 바꿀 때 같은 시험을 반복하지 않는다.

### 4.3 조작과 실행: 자동 연타와의 차이

요소로 만든 기본 초식은 기존 해당 행동 슬롯에서 한 번의 입력으로 사용한다. 연계 무공은 **한 작품 안의 두 단계 수동 연계**다. Q로 준비하고 기존 공통 검격 입력으로 방출한다. 새 전투 버튼을 추가하지 않는다. 화면의 Q/K 등은 설명용이며 실제 표시는 `Controls`의 현재 키 설정을 따른다.

후속 입력 시 준비 상태가 유효하면 선택한 변환을 실행하고 원본 후속 효과를 대체한다. 준비 상태가 없거나 만료되면 기존 공통 검격만 실행한다. ‘연결 없음: 충격을 받아내지 못함’처럼 짧게 알린다. 이미 준비된 상태가 있어도 회피·이동·기다림으로 연결을 포기할 수 있다.

공격 피해를 그대로 합산한 뒤 보너스를 더하지 않는다. 관통 방출은 무림에서는 넓은 전방 검격을 더 긴 좁은 선으로, 현실에서는 단일 검격을 선형 복수 타격으로 바꾼다. 무림의 즉시 반격 피해도 후속 행동으로 옮겨 중복 합산하지 않는다. 앞 초식이 만든 전투 상태를 실제로 사용하기 때문에 원본 Q→공통 검격과 결과가 다르다.

두 초식의 연계를 한 버튼으로 완결하는 방식은 후속 범위다. 도입한다면 두 단계 전체 비용·예고·취소 지점을 명시하고 수동 판단을 없애지 않는지 별도 검증한다. 기본 초식의 한 번 입력과 구분한다.

### 4.4 숙련과 성취의 역할

초기에 숙련에 맡길 역할은 **① 연결·조정의 허용 범위, ② 연결 시간·거리의 조절 폭** 두 가지다. 피해 추가 증가, 자동 비용 감소, 초식 수 증가를 한꺼번에 부여하지 않는다. 비용과 회복 시간은 선택한 결과의 대가로 먼저 고정한다. 고급 성에서 틈이나 소비를 조정하는 기능은 후속 검증 대상이다.

| 성장 요소 | 담당 역할 | 맡기지 않는 역할 |
|---|---|---|
| 무공 공통 1~9성 | 해당 무공의 폭넓은 운용 숙련, 선택 가능한 시간·거리 범위 | 작품마다 별도 경험치, 공식 사회적 자격 |
| 초식·특징 성취 | ‘충격을 받아내 방출’, ‘실제 예고 회피 후 검격’ 등 연결 원리를 이해했다는 증거 | 숨은 성향 판정, 반복 제작 보상 |
| 심법 | 자원 회복·준비 일격·기존 6장 연계 강화 | 조합 레시피 구매권, 필수 제작 재화 |
| 경지 | 신체적 성장 단계와 시련, 후속 복잡한 운용의 장기 문맥 | 초식 성취 대체, 첫 2초식 조합의 추가 관문 |
| 현실 스킬 숙련·성취 | 현실의 사거리·위협을 활용한 운용 발전, 현실 현장 기록 | 이미 배운 무림 원리의 재해금 |
| 헌터 등급·현장 자격 | 실전 평가·보고에 따른 권한과 사회적 신뢰 | 창작 수·이름 수·제작 숙련의 보상 |

**1~9성의 잠정 연결:** 기존 계열 숙련 `m=0~30`을 원본으로 유지하고, 습득한 무공만 아래와 같이 표시한다. 미습득은 ‘미습득’이며 1성이 아니다. 원본 값과 기존 피해 보정·공명 지급 경계를 바꾸지 않는다.

| 성 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| 숙련 하한 m | 0 | 1 | 3 | 5 | 8 | 12 | 17 | 23 | 30 |

이는 **임시 조정값**이다. 기존 저장을 손실 없이 읽으면서 첫 조합에 장시간 숙련을 요구하지 않고, 후반 조정 폭에 여지를 두는지 확인하려는 표다. 5성=경지 일류처럼 서로 연결하지 않는다. 초기 원형은 원본 성취가 있으면 1성에서도 만들 수 있고, 2성부터 개인 조정 폭이 열리도록 한다.

성취는 각 초식/특징에 ‘미확인 → 체득 → 응용’의 작고 유한한 기록으로 둔다. 무한 경험치 바가 아니다. 초기 판정은 다음처럼 공개한다.

- 파문세 체득: 실제 공격 예고에 받아내기 성공. 관통/수호 연결 체득: 그 충격을 공통 검격으로 한 번 유효하게 소비.
- 잔영각 체득: 실제 예고를 벗어나는 이동 성공. 잔향 지연 체득: 남긴 잔향의 타격 위치를 예측해 한 번 적중.
- 쇄경진 체득: 실제 진행 중 예고 억제. 억제 전이 체득: 후속 검격으로 다른 유효 대상에 남은 억제를 옮김.
- 응용: 같은 원리를 서로 다른 위협 형태 두 가지에 유효 사용. 예: 근접 예고와 원거리 예고. ‘다수전 100회’처럼 양을 요구하지 않는다.

체득의 첫 일회 기록은 지도 수련에서도 인정한다. **현재 시험이 수치 숙련을 주지 않는 규칙은 유지**하며, 새로 인정하는 것은 원리의 일회 증명이다. 반복 시험은 경험치·계열 숙련·재화·성취 보상을 늘리지 않는다. 실제 필드의 유효 사용은 기존 계열 숙련과 해당 초식 성취를 함께 기록하므로 별도 작업을 요구하지 않는다.

자동 후속 타격, 지연 타격, 여러 적 적중은 원래 수동 행동의 ID를 공유한다. 계열 숙련은 기존 `credit` 한도를 넘겨 지급하지 않고, 같은 시전으로 반복 초식 성취를 수집하지 않는다. 조건을 충족하지 못한 시도는 최근 결과에 이유를 보여주되 성취를 깎지 않는다. 시간 경과·오프라인 수련·숙련 소모는 없다.

### 4.5 개인별 min~max와 완성도

도감에는 전체 설계 한계, 편집기에는 **내가 현재 고를 수 있는 범위**, 결과 카드에는 **이번 설정값**을 구분한다. 예: ‘설계 한계 260~380 / 현재 260~290 / 선택 280’. 모든 숫자는 조정 전 제안이며 실측된 밸런스가 아니다.

간단한 실험 공식은 다음과 같다. 연계에서는 재료가 속한 두 무공의 성 중 낮은 값을 `S`로 하고, 선택 원리의 모든 필수 성취가 응용이면 `A=1`, 아니면 `A=0`으로 둔다. 기본 초식의 개인 조정은 소속 무공 하나의 성과 해당 초식 성취를 사용한다. 아직 체득 전인 지도 시험에서는 원형 기본값만 사용해 선행 숙련의 순환 조건을 만들지 않는다.

> 조절 계수 C = min(1, (S−1)/8 + 0.25×A)
>
> 현재 최대 범위 = 기본 하한 + (전체 상한−기본 하한)×C

파문검 3성·공통 검술 5성, 체득 단계라면 C=0.25다. 관통 거리의 설계 한계가 260~380이면 현재 선택 범위는 260~290이다. 회피 응용 성취는 잔향 관련 원리에만 A로 적용하고 파문 관통에는 적용하지 않는다. 이 공식은 **가장 익숙하지 않은 재료가 조절 폭을 제한한다**는 이해 가능성을 검증하기 위한 임시안이다.

완성도는 점수·등급·추가 숙련 바 대신 ‘설계 가능 / 시험에서 확인 / 현실 적용 가능’을 보여준다. 성취를 이미 증명한 뒤 설정값만 조절했다면 재시험은 선택 사항이다. 새 연결 원리를 처음 쓰는 경우에만 짧은 일회 시험을 요구한다. 동일 원리의 다른 작품·개명·슬롯 이동은 시험을 다시 요구하지 않는다.

숙련이 올라가도 저장한 설정을 몰래 바꾸지 않는다. 확장된 범위를 표시하고 사용자가 조정한다. 후속 밸런스 패치로 설정이 무효가 될 때도 자동 대체하지 않고 원본과 사유를 보관한다.

### 4.6 자원·빈틈·제한

- 초기 장착은 무림 연계 변형 1개, 현실 활성 원리 1개·수신 스킬 1개다. 직접 만든 기본 초식은 기존 행동 슬롯을 사용하고 기연 Q 계열은 한 번에 하나다. ‘월영참과 파문세 중 하나만 장착’하는 제한이 아니다. 두 세계 장착은 독립적으로 선택한다.
- 두 초식의 기존 자원·쿨다운을 유지하고, 원리별 추가 비용/회복 시간을 명시한다. 범위 등 조절을 높이면 그에 비례한 대가를 함께 미리 본다. 공짜 최대 설정을 피한다.
- 앞 초식 비용은 앞 입력에서, 뒤 초식 비용과 변환 추가분은 후속 입력에서 지급한다. 자원이 부족하면 후속 입력은 실행되지 않고 자원·쿨다운을 쓰지 않는다. 준비 상태는 원래 기한까지만 남는다.
- 유효 실행 뒤 빗나가거나 적이 사라진 경우 이미 쓴 비용은 환급하지 않는다. 취소·피격으로 잃는 부분도 미리보기에서 표시한다.
- 준비 상태는 하나이며 한 번만 소비한다. 관통과 수호를 동시에 얻거나, 다른 스킬의 축적 강화와 겹쳐 두 번 쓰지 못한다.
- 현실에서 같은 행동에 기존 해석과 창작 원리가 동시에 영향을 주면 **운용 변형 슬롯 하나를 공유**한다. 둘 중 하나를 고르며 기존 해석 발견 기록은 남긴다. 기존 공명 수치 투자·심법은 유지한다.
- 비용 계산 순서는 기본 비용 + 창작 추가 비용 → 기존 비용 감소 → 정수 올림·최저 1이다. 시간·범위는 원리 프로필에서 정하고 동일 항목의 해석 배율을 중복 곱하지 않는다. 6장 연계 효과는 원래 수동 행동당 한 번 판정한다.

‘초식 3개 이상’과 복수 원리 동시 적용은 최소 검증에서 제외한다. 복잡도가 강함을 보장하지 않아야 한다. 단순 원본은 적이 적거나 급하게 대응해야 할 때 낮은 비용·짧은 후딜·준비 불필요라는 장점을 가진다.

### 4.7 현실 적용과 현실 자체의 성장

무림에서 증명한 원리는 정상 현실 귀환 뒤 ‘적용 가능’으로 보인다. 적용은 현실 기지에서 수신 스킬을 직접 선택한다. 원리를 소모해 추출하는 아이템이나 별도 포인트는 만들지 않는다. 원본 작품을 보관·삭제해도 배운 원리의 증명 기록은 남는다.

수신 조건은 ① 스킬 습득, ② 호환 상태/표적 방식 보유, ③ 해당 원리 증명, ④ 이야기 잠금 충족이다. 초기에는 공통 `moon`인 **집중 타격**을 우선 수신자로 쓴다. 현실 Q가 준비한 흡수/회피/억제 상태를 집중 타격이 다른 방식으로 활용한다. 기존 Q 정착과 R/F 해금은 그대로 유지한다.

첫 현실 적용은 무림 원리의 재학습 시험을 요구하지 않는다. 즉시 운용할 수 있고 첫 유효 현장 사용은 ‘현실에서 재현됨’ 기록·소식으로 남는다. 이미 무림에서 획득한 연결 권한을 잠갔다가 현실에서 다시 푸는 구조가 아니다.

현실의 기존 숙련 0~30·피해 보정은 유지한다. 추가 발전은 같은 원리를 현실의 대상과 지형에 적절히 쓰는 **현장 응용 성취**로 표현한다. 예컨대 관통으로 통로의 두 위협을 동시에 끊으면 ‘선형 위협 통제’가 남고 관련 임무 추천·보고 근거가 된다. 후속에는 조준 편의 등 소규모 운용 옵션을 검토할 수 있지만 무림의 거리 상한을 다시 해금하지 않는다. 실제 재현과 사회적 인정은 전투 결과에서 생기며 적용 버튼을 누르는 보상이 아니다.

**신규 현실 스킬 예외:** 기존 스킬에 붙이면 동작·대상·자원 체계가 성립하지 않는 능력에 한정한다. 무림의 해당 원리 체득 + 현실 적성/매개체 확보 + 기능이 다른 일회 실습을 조건으로 한다. 동일한 무림 숙련 횟수를 재요구하지 않는다. 속성 스킬은 원리 ID별 최초 한 번만 획득하며 레시피명과 작품 수로 지급하지 않는다.

요청 예시인 **베기+냉기+지연**은 방향성은 적합하지만, 조사한 현재 스킬 표에는 냉기 초식·냉기 마법·속성 성장 모델이 없다. 후속 신규 재료로 제안한다. ‘빙흔 원리 체득 → 현실 냉기 매개체/적성 확인 → 보유 냉기 기술에 지연 폭발 운용 적용’, 또는 보유 기술이 없을 때만 ‘서리 부여’ 최초 습득을 검토한다. 창작마다 냉기 수치를 영구 가산하거나 모든 기존 물리 기술을 냉기화하지 않는다. 이번 최소 실험에는 포함하지 않는다.

### 4.8 수정·해제·보존·보상 중복 방지

청운촌 작업대는 기존 무공 화면의 하위 기능으로 연다. 시험은 무명 비경의 별도 훈련 상태, 현실 적용은 헌터 기지에서 한다. 안전 거점의 변경은 무료다. 전투 중 읽기·후속 성장 목표 표시만 허용한다. 실패·죽음으로 설계나 성취를 잃지 않는다.

원본 무공은 불변이며, 작품은 재료 ID·원리 ID·설정·출처의 조합으로 저장한다. 작품 복제·이름 변경·기본 운용 복귀를 지원한다. 활성 작품은 직접 삭제 전에 장착 해제를 안내하고, 이전 저장 원문에는 손대지 않는다. 실험 보관함은 임시 12칸으로 충분한지 확인하되 칸 수는 성장 보상과 무관하다.

표시 이름과 별개로 원리 증거에는 안정 ID를 사용한다. 동일 원리의 재료 순서·이름·설정 변경은 새 성장 보상이 아니다. 순서를 바꾸어 기능이 달라지는 유효 조합은 새 설계로 보관할 수 있지만, 공명 재화·능력치·숙련을 제작 행위만으로 지급하지 않는다. 기존 `inherit:*`, `murim-mastery:*`, `challenge:*` 보상 원장을 재발행하지 않는다.

## 5. 구체적인 조합 사례 3개

아래 작품명·연결 원리·초식별 성취·수치는 모두 신규 제안이다. **재료 초식과 현실 스킬 이름만 현재 저장소에서 가져왔다.** 재료 초식도 이번 개정안에서는 4.1.1의 요소 조합으로 직접 만든 뒤 체득한다. 수치는 비교 실험의 출발점이며 픽셀 거리는 현재 전장 좌표 단위를 따른다. 원본 피해 배율을 더한 값이 아니라 변환된 후속 행동의 최종 기본 배율이며 기존 숙련/능력치 보정은 그 뒤 적용한다.

### 사례 1. 반류일선 — 충격을 선으로 내보내 통로를 연다

| 항목 | 규칙 |
|---|---|
| 현실 목표 | 통로 앞뒤로 겹친 적 때문에 접근이 막힌다. 한 번의 방어 성공으로 두 위협을 같은 선에서 처리하고 싶다. |
| 기존 재료 | 파문검의 **파문세** (`FateRules.PATHS.ripple.skills[0]`) + 공통 **월영참** (`moon`) |
| 숙련 조건 | 두 초식 습득, 파문세 받아내기 체득 + ‘충격을 검격으로 소비’ 일회 연결 증명. 기본형은 1성에서 가능, 2성부터 거리 조절. |
| 조합 방식 | `받아낸 충격 → 월영참 → 관통 방출`. 파문세 성공 시 즉시 반격 피해를 보류하고 충격 1회를 저장한다. |
| 무림 작동 | Q 받아내기는 기존 방어 판정을 사용한다. 2~4초의 설정 기한 안에 월영참을 쓰면 보관 충격을 소비해 전방 선형 타격. 축적을 늘려 발수·피해를 증식시키지 않는다. 무림 원본 파문세의 즉시 반격은 이 작품에서 나오지 않는다. |
| 임시 범위·대가 | 거리 260~380, 선의 반폭 45, 가까운 순 최대 2대상, 각 1.8배. 후속 추가 내력 2~4(거리 선택에 선형 비례), 후딜 +0.2초. 무림 원본 월영참의 넓은 전방 215 범위·2.4배 타격을 포기하고 더 먼 직선을 얻는다. 연결 기한은 기본 2초에서 같은 C로 최대 4초까지 조정한다. 긴 기한은 시간 여유만 주며 추가 피해는 없다. |
| 현실 변화 | 기존 Q **충격 흡수** 뒤 **집중 타격**이 같은 선의 최대 2대상을 친다. 집중 타격 1.8배에 기존 흡수 강화 배율을 다시 곱하지 않는다. 충격은 소비되므로 기본 공격 강화나 R 압축 반격에 다시 쓸 수 없다. |
| 유리한 상황 | 일렬의 근접+원거리 적, 좁은 길의 호위, 방어 뒤 자리를 크게 움직이지 않고 길을 열 때 |
| 약점 | 받아낼 공격이 없거나 적이 옆으로 흩어지면 이득이 없다. 즉시 반격을 잃고 후속까지 자원을 확보해야 한다. 보스 단일전은 원본 R이나 단순 검격이 유리할 수 있다. |
| 다른 선택 이유 | 같은 재료의 **수호 전환**은 관통을 포기하고 방어 직후의 안전을 산다. 이동이 많은 현장은 사례 2, 예고를 끊어야 하는 현장은 사례 3이 낫다. |

시각 구분은 ‘받아낸 충격의 작은 표식 → 선형 궤적 → 표식 소멸’이다. 단순 피해 숫자 외에 두 번째 적 적중과 대가인 즉시 반격 상실이 보인다.

**추가 대조안 ‘반류수호’:** 동일한 재료와 성취로 관통 대신 선택한다. 후속은 단일 1.2배 검격으로 바뀌고 충격 소비 뒤 자신에게 2~4초간 20% 피해 감소를 준다. 후속 추가 내력 2~4는 지속 시간에 비례하며 주변 아군 보호는 아직 없다. 원본 파문세의 즉시 반격도 보류한다. 기존 `ripple-guard` 해석과 중복 장착하지 않는다. 세 연계 사례의 시험을 우선하고 이 대조안은 추가 비교에 사용한다.

### 사례 2. 유영잔참 — 피한 자리에 검을 남긴다

| 항목 | 규칙 |
|---|---|
| 현실 목표 | 예고를 피하면 구출 대상에게 달려가는 적을 다시 쫓느라 늦는다. 이동으로 안전을 확보하면서 이전 위치의 길목을 공격하고 싶다. |
| 기존 재료 | 잔영보 **잔영각** (`PATHS.echo.skills[0]`) + **월영참**. 기존 `echo-replay`는 지연 타격의 표현 참고이며 R 해석을 조기 해금하는 재료로 쓰지 않는다. |

| 조합 방식 | `예고를 피하며 남긴 잔향 → 월영참 → 잔향 지연`. 체득이 낮아도 선택한 지연 시간은 확정적으로 적용된다. |
| 무림 작동 | 잔영각으로 실제 예고를 벗어나면 기존 잔향을 후속 입력의 기준점으로 쓸 수 있다. 3초 안의 월영참이 현재 위치 검격 대신 잔향 위치에 한 번의 지연 베기를 남긴다. 귀환 이동·협공·R 사용은 발생하지 않는다. |

| 현실 변화 | **긴급 가속**의 실제 회피 성공 후 **집중 타격**을 쓰면 가속 시작 위치에 지연 타격을 남긴다. 기존 현실 R **추격 타격**이나 `echo-replay`의 적중 위치 반복과 다르게, 적에게 다시 접근하지 않는 운용이다. 회피 후 기본 공격 강화 기회는 이 연결이 소비한다. |
| 유리한 상황 | 추격 적의 진입로, 넓은 예고를 피하면서 구출 방향으로 이동할 때, 이동과 공격 위치를 나누고 싶을 때 |
| 약점 | 정지 원거리 적은 잔향 위치에 오지 않는다. 적이 지점을 벗어나면 빗나간다. 현재 눈앞의 위협을 즉시 끊기 어렵고 벽을 관통하지 않는다. |
| 다른 선택 이유 | 직접 쫓아가야 하는 적은 원본 추격 타격, 직선의 여러 위협은 반류일선, 재생 억제가 필요한 적은 사례 3을 고른다. |

잔향의 윤곽·남은 지연 표시·실제 타격 위치를 분리해 보여준다. 회피 실패 시 원본 월영참/집중 타격만 실행되고 자동으로 새로운 회피 원리를 만들지 않는다.

| 현실 변화 | **균열 억제**가 실제 예고를 끊은 적을 **집중 타격**으로 치면 첫 적의 재생 억제를 끝내고 두 번째 적에게 남은 억제를 최대 2초 전달한다. 두 번째 적의 끊을 수 있는 예고는 한 번 취소하지만 이동 경직·피해 추가는 없다. |
| 유리한 상황 | 구조 지점의 교대 공격, 재생 적+원거리 적, 첫 위협을 처리하고 다음 예고를 늦춰야 하는 호위 |
| 약점 | 두 번째 유효 대상이 없으면 후속은 원본 검격이고 표식은 원래 기한까지 보존된다. 첫 대상 재생이 다시 시작될 수 있다. 보스의 취소 불가 예고는 옮겨도 취소되지 않으며 재생 억제만 남는다. |
| 다른 선택 이유 | 한 보스의 재생을 오래 막으려면 원본 억제/정박, 피해가 급하면 관통, 움직이며 길목을 비우려면 잔향을 선택한다. |

표식이 첫 적에서 꺼지고 두 번째 적으로 이동하는 효과를 보여준다. 보스·정예의 제어 저항을 무시하는 무한 연쇄 봉쇄는 지원하지 않는다.

## 6. 첫 성장 사이클: 월영참 제작부터 3장 연계까지

### 6.1 유지·수정 구분

**[현재 구현]** `GrowthArc`는 1·2장 승리를 보존한 채 3장 직전 `rift` 통로 방어를 시작한다. 최대 12초 또는 전투 조건에서 철수하며 손실 없이 복귀한다. Q를 익힌 뒤 `heart`의 같은 압력에 실제 흡수/회피/억제 효과를 내야 첫 재현이 된다. 보스는 `returnProven` 전 직접 피해가 막히므로 버튼만 누르는 진행이 아니다.

| 단계 | 유지할 사건 | 수정·추가 제안과 플레이어 행동 |
|---|---|---|
| 첫 제작 튜토리얼 | 도입부 이후 청운촌에서 백련의 기본기를 배움 | 월영참 즉시 지급을 형·기·운·의의 순차 체험·조립·유효 타격으로 바꾼다. 성공 뒤 기존 기본기 습득 진행과 보상을 한 번만 처리한다. |
| 작은 자유 조합 | 첫 수련 이후 실제 전투 | 월영참의 전방 범위/좁은 직선 변형을 무료로 비교한다. 아직 모르는 반탄기·잔향·봉합기는 결과와 배울 장소만 미리 보여준다. |
| 한계 발견 | 통로 압력 증가, 인원 회수, 긴급 철수, 서린 보고 | 별도 패배를 추가하지 않는다. 보고에서 ‘적 처치만으로 통로 압력을 풀 수 없었다’와 실제 대응 기록을 짧게 보여준다. |
| 기연 요소 습득 | 백련 대화, 비경의 세 흔적 | 유물에서 받아내기/잔향/억제의 구성 요소를 체험하고 직접 기본 Q 초식을 조합한다. 완성품 Q를 자동 지급하지 않는다. |
| 기본 초식 체득 | Q의 실제 효과 시험과 계승 확인 | 자신이 구성한 파문세/잔영각/쇄경진으로 기능을 증명한다. 일회 체득·계승을 기록하며 허공 반복은 요구하지 않는다. |
| 첫 연계 조합 | 백련의 후속 수련과 비경 시험 | 직접 만든 Q와 월영참을 연결한다. 파문은 관통/수호, 잔영은 지연, 봉인은 전이를 시험한다. 모든 계열을 먼저 모을 필요는 없다. |
| 시험·수정 | 비경 시험 장소 재사용 | 좁은 선의 적 2명과 교대 압박 상황을 번갈아 보여준다. 관통과 수호를 바꿔 볼 수 있고 실패 즉시 초기 상태로 재시도한다. 재화·수치 숙련 보상 없음. |
| 현실 적용 | 첫 귀환 Q 자동 장착, 현실 스킬 별도 명칭 | Q는 그대로 확보한다. 기지에서 창작 원리를 **집중 타격**에 적용하도록 한 번 안내한다. R/F는 계속 잠겨 있다. 원리 적용 전후 카드에 공격 위치·대상·소모 차이만 보여준다. |
| 재도전 | 서린 안내, 경계의 심장, 호위→매듭→포식자 순서 | Q의 압력 대응뿐 아니라 선택한 후속 변환의 실효를 보여줄 배치를 실험한다. 관통은 호위 선형 배치, 수호는 연속 압박에서 유리하다. 단순히 ‘창작 장착’ 플래그로 무적을 끄지 않는다. |
| 인정과 다음 목표 | 귀환 보고와 이후 구조 이야기, 등급/자격 구분 | 이전 한계와 지금의 실제 결과를 나란히 기록한다. 창작 횟수로 승급하지 않는다. 후속 구조에서 ‘더 오래 버티기/다른 지점 공격하기’ 필요를 만들고 R 실습은 기존 4장 뒤에 둔다. |

월영참의 네 축 튜토리얼은 약 3~5분, 이후 한 계열의 요소 체험→Q 구성→연계 시험은 약 5~8분을 **임시 실험 목표**로 삼는다. 강제 제한이 아니며 세 계열을 모두 시험하는 총시간과는 다르다. 처음에는 네 축을 한 단계씩 안내하고 복잡한 수치 편집·여러 슬롯·속성 마법을 함께 열지 않는다. 이름은 성공 후 선택적으로 붙인다.

### 6.2 첫 원형을 잘못 고르거나 실패했을 때

실패한 공격의 이유를 구체적으로 남긴다. ‘숙련 부족’ 대신 ‘받아낸 충격 없음’, ‘연결 기한 만료’, ‘두 번째 적이 선 밖에 있음’을 보여준다. 무료로 원리·거리 설정을 바꾸고 같은 적 배치로 다시 시험한다. 월영참 제작은 기본 학습 단계지만 이후 연계는 선택 수련을 권장한다. 체득한 기본형으로도 본편을 진행할 수 있게 한다.

실험에서는 관통의 두 번째 적 적중/수호의 실제 피해 감소/잔향의 원위치 적중/전이 후 다른 적의 예고 변화처럼 **효과 사건**을 기록한다. 본편의 3장 완료 조건을 ‘세 계열 모두 제작’으로 바꾸지 않는다. 첫 연계까지 의무 튜토리얼로 할지는 마지막 결정 항목에 남긴다.

## 7. UI와 사용자 이해

무림 무공 화면에 ‘조합’ 하위 진입을 추가하고 기존 성장 화면의 심법·돌파·공명 기능은 유지한다. 모바일에서 노드를 드래그해 선을 잇는 방식 대신 재료 선택→연결 선택→비교→시험의 순차 화면을 쓴다.

조합 진입은 **‘초식 만들기’와 ‘초식 연결하기’**로 나눈다. 첫 화면은 월영참의 형→기→운→의 네 단계만 안내한다. 이후 요소 카드에 배운 곳·허용 원형·호환하지 않는 이유를 표시한다. 연결 화면에는 체득한 기본 초식만 재료로 보이고 이미 두 초식을 연결한 작품은 재료에서 제외한다. 제한은 숨은 제작 실패가 아니라 선택 전에 읽을 수 있어야 한다.

| 화면·순서 | 꼭 보이는 정보 | 조작과 다음 행동 |
|---|---|---|
| 현실 목표 메모 | ‘통로의 두 위협을 함께 처리하고 싶다’ 같은 선택 목표, 현재 스킬의 한계 | 목표는 추천 정렬만 바꾸고 조합 결과를 자동 결정하지 않는다. |
| 재료 목록 | 보유 초식, 소속 무공·성, 생성 상태, 미습득/체득 부족 이유 | 부족 재료를 누르면 습득 장소 또는 성취 조건으로 이동한다. 숨은 총 사용 횟수는 요구하지 않는다. |
| 연결 선택 | 가능한 원리와 결과 그림/문장, 불가능한 항목의 이유 | ‘관통’ 선택 후에만 관통 성능을 계산한다. 회피 성취가 높아도 자동 선택하지 않는다. |
| 조정·비교 | 원본→창작의 발동·거리·대상·비용·빈틈, 전체 범위/현재 범위/선택값 | 최대 거리로 조절하면 추가 비용도 같은 화면에서 바뀐다. 첫 조합은 기본 설정을 우선한다. |
| 시험 | 유효 준비→후속→소비의 세 상태, 최근 한 시도의 결과 | 재시도/편집으로 복귀. 사망·실패에서 어떤 조건이 끊겼는지 알려준다. |
| 현실 적용 | 원리 출처, 호환 기존 스킬, 대체되는 해석, 유지되는 Q/R/F 잠금 | 직접 수신 스킬 선택→변화 확인→적용. 환불 재화나 새 숙련 게이지 없음. |
| 재도전 결과 | 기존 시도와 새 시도의 목표 달성·보호 대상·자원·피격·효과 횟수 | 목표를 달성한 뒤 보고 장소를 안내한다. DPS 하나로 우열을 결론 내리지 않는다. |

텍스트 화면 예시(제안):

```text

파문세 [체득] → 월영참 [체득]
연결 원리  ● 관통 방출  ○ 수호 전환

받아낸 충격 1회를 다음 검격에 사용합니다.
현재 거리 260~290 / 설계 한계 260~380 / 선택 280
대상: 전방 선형 최대 2명 / 즉시 반격: 없음
대가: 후속 내력 추가 3(올림 표시) / 회복 시간 +0.2초
부족한 성장: 파문검 4성 또는 이 원리의 응용 성취

현실 적용: 충격 흡수 성공 후 집중 타격의 대상 방식 변경
[시험하기] [초안 보관] [원본과 비교]
```

위 비용은 할인 없는 상태의 예시다. 4.6의 비용 계산 순서로 최종 소모량을 구하고 카드와 실행에 동일하게 표시한다. 현재 값·허용 범위·대가를 서로 다른 반올림으로 표시하지 않는다.

전투 HUD에는 준비 상태와 만료만 작게 표시한다. 전체 편집 규칙은 거점에서 읽는다. 성공·실패를 색만으로 구분하지 않고 문구·모양·효과 위치를 함께 쓴다. 키보드 선택/확정/취소, 모바일 단일 열, 뒤로 가기 초안 보존, 200% 글자 확대를 검증한다. 미습득 초식은 실제 이름 공개가 스포일러일 경우 기능과 획득 경로만 표시하되 조합의 부족 조건은 숨기지 않는다.

## 8. 세계관·사회적 역할

### 8.1 기존 설정으로 설명할 수 있는 범위

**[현재 구현·기존 문서]** ‘몸에 새긴 무공은 다른 세계에서도 사라지지 않는다’는 대사, 무림 원리가 현실의 충격 흡수·긴급 가속·균열 억제로 바뀌는 별도 스킬, `JourneyData.facts['station-sense']`의 같은 간격 관측, 실제 효과 재현과 보고 구조가 있다. 물리 동작이 복사되는 것보다 운용 원리가 현실의 몸에 맞게 나타난다는 설명에 근거가 있다.

**[권장 제안]** 창작 무공은 새로운 기운을 무한 생성하는 주문이 아니라, 어떤 자극을 받아 언제·어디로 힘을 내보낼지 몸에 새기는 방법이다. 무림에서는 내력과 초식이, 현실에서는 기력과 기존 각성 능력이 같은 구조를 구현한다. 따라서 동일 작품도 무림의 잔향 귀환과 현실의 긴급 가속처럼 표현이 다를 수 있다.

### 8.2 새 설정이 필요한 범위

냉기·화염 등 속성 전이, 현실 마법 적성, 속성의 상한과 매개체는 신규 설정이다. 무림 냉기 수련만으로 현실에 없는 에너지를 무조건 생성한다고 단정하지 않는다. 현실의 해당 속성에 반응할 수 있는 몸/장비/마력 환경이 필요하다는 제한을 권장한다. 이 설명은 본편 대사로 확정된 정사가 아니라 검토안이다.

### 8.3 능력에서 역할로 이어지는 인정

선형 제압은 ‘통로 확보’, 잔향 지연은 ‘이동 중 엄호’, 억제 전이는 ‘교대 위협 통제’ 임무에 유리하다. 이는 신규 임무 태그 제안이며 현행 퀘스트가 이미 이 태그를 검사한다고 주장하지 않는다.

현장 자격은 특정 조건에서 실제 임무를 안전하게 수행했다는 기록이고, 헌터 등급은 `Advancement`의 공식 평가·보고 절차다. 원리를 체득한 즉시 임무 추천은 열 수 있지만 역할 인정·접근 권한·보급은 실적 확인 이후다. ‘반류일선 제작 3회 → D급’은 금지한다. 특정 레시피만 정답이 되지 않도록 같은 구조 임무를 방어·기동·통제 각 방식으로 해결할 수 있는 조건을 둔다.

서린은 현실에서 관측하거나 윤서에게 보고받은 것만 말한다. 무림의 편집 과정과 숙련 숫자를 원격으로 아는 듯 설명하지 않는다. 백련은 이미 배운 원리를 다시 허가하는 인물이 아니라 실패 원인과 연결 방법을 가르치는 역할을 유지한다.

## 9. 기존 시스템 영향과 저장 호환

### 9.1 유지·확장·수정·신규

| 분류 | 대상 | 영향·대응 |
|---|---|---|
| 유지 | 두 세계 레벨·경험치, 원본 무공, Q/R/F 이야기 잠금, 공명 원장·기존 투자 | 숫자 성장과 창작을 분리한다. 추가 제작 재화를 넣지 않고 기존 잔액·지급 기록을 유지한다. |
| 유지 | 심법·경지·헌터 평가·현장 보고 | 초기 조합의 필수 재료로 만들지 않는다. 성취 합계를 경지와 등급에 이중 지급하지 않는다. |
| 확장 | 숙련 표시, 무공/현실 스킬 화면, 효과 이벤트 | 1~9성 표시·초식 성취·부족 조건·후속 소비 결과를 제공한다. 기존 0~30 값·보정은 초기 실험에서 보존한다. |
| 확장 | 비경 시험·현실 비교 전투 | 원본/관통/수호의 같은 조건 비교, 새 공간 효과 기록을 추가한다. 시험의 영구 보상은 기존대로 차단한다. |
| 수정 | 행동 기연 안내 | `LegendRules`의 관찰 기록은 배움의 단서로 남기되 조합 추천과 선택을 분리한다. 새 작품의 성질을 행동만으로 결정하지 않는다. |
| 수정 | 첫 수련·계승·귀환 튜토리얼 | 월영참 요소 조합 → 기연 요소 배움과 Q 제작 → 두 초식 연결 → 현실 적용으로 바꾼다. R/F를 조기 지급하지 않는다. |
| 수정 | 해석·창작 동시 적용 | 변형 슬롯을 공유해 충돌을 해결한다. 기존 해석은 사라지지 않고 교체 가능한 완성 운용으로 남는다. |
| 신규 | 요소 정의·원형 호환·초식 재료 정의·연결 규칙·창작 설계·현실 어댑터·성취 증거 | 축별 선택과 구성 깊이를 검증하고 작품 ID별 실행 분기 대신 유한한 상태 변환 연산을 사용한다. |
| 신규 | 실험 전용 장면·저장 래퍼 | 본편 원문과 별도 저장, 본편 보상 유입 차단. 이번에는 설계만 한다. |

### 9.2 구현을 위한 최소 연결점 제안

전체 `Game` 계층을 먼저 재작성하지 않는다. 추후 별도 규칙 모듈이 ‘재료/원리/현재 숙련 → 실행 명세’를 반환하고, 기존 `FateRules.act`·`RealitySkills.act`가 해당 명세를 실행하도록 좁게 연결하는 방식을 검토한다. 신규 개념 이름은 `TechniqueDefinition`, `LinkRule`, `SkillformPlan`, `RealityAdapter`, `TechniqueProof`이며 현재 존재하는 클래스명이 아니다.

요소 정의에는 축·학습 증거·입출력 상태·원형 호환 태그를 추가한다. 기본 초식의 요소 초안을 실행 명세로 검증한 뒤 기존 검술/파문/잔영/봉인 원형에 연결한다. 임의 주문 언어나 무한 효과 생성기를 먼저 만들지 않는다. 연계 무공의 재료에는 기본 초식만 허용하며 저장 시에도 구성 깊이를 검사한다.

공통 연산은 상태 생성·단일 소비·선형 타격·지점 지연 타격·남은 억제 전이로 한정한다. 현재 준비 상태를 또 하나의 독립 강화 게이지로 복제하지 않고 기존 상태와 소유권·소비 규칙을 일치시킨다. 상태에 출처 시전 ID를 붙여 지연 효과·심법 연계·숙련 인정이 중복되지 않게 한다.

새 **원리 연산**이 생길 때 코드와 검증을 추가하는 것은 허용한다. 사용자가 이름을 붙인 각 **작품**마다 코드가 필요한 구조는 허용하지 않는다. 허용 연산의 조합 수·표적 수·지연 큐 수에 상한을 둬 모바일 부하와 무한 연쇄를 제한한다.

### 9.3 저장 원칙

실험은 본편 저장을 덮어쓰지 않는 별도 래퍼를 사용한다. 예시 형식은 `experiment:'skillform'`, `schemaVersion:1`, 기준 커밋, 복제한 본편 `baseSave`, 초식 성취, 작품 목록, 세계별 장착, 현실 적용 기록, 원리 증명 목록이다. 이 필드명과 키는 **신규 제안**이다. 기존 `SaveV10`에 모르는 필드를 추가하면 `validateWorldState`의 화이트리스트 과정에서 유실될 수 있으므로 임의 주입하지 않는다.

- 정식 저장 키 `dualworld.save.proto49859ea`, 백업, `dualworld.save.v10`, v1 원문·보관판, 기존 개발 테스트 키에 쓰지 않는다. 실험 후보 키는 `dualworld.experiment.skillform.v1`이다.
- 가져오기는 읽기 전용 복사→기존 로더 검증→실험 변환 검증→별도 키 저장 순서다. 성공하기 전 원본·기존 실험 저장을 덮어쓰지 않는다. 실패 이유와 원본 내보내기 경로를 제공한다.
- 기존 숙련 0~30은 그대로 복사하고 1~9성은 계산한다. 과거 계열 숙련만으로 확인할 수 없는 초식 성취를 임의 생성하지 않는다. 기존 `fate.proven`으로 확인 가능한 기본 체득만 인정하고, 새로운 연결 증명은 짧은 일회 지도 시험으로 보완한다.
- 원본 해석·공명 투자·정착 보너스·R/F·등급·자격을 보존한다. 구 레시피가 없다고 캐릭터를 약화하거나 작품 보상으로 과거 성취를 재지급하지 않는다.
- 기존 월영참·계승 Q 보유자는 기술을 회수해 재제작시키지 않는다. 보유 증거로 해당 표준형을 ‘기존 체득’으로 복원하고 편집에 필요한 기본 요소 권리를 연결한다. 새로운 원리까지 임의로 지급하지 않는다. 월영참 튜토리얼은 보상 없는 재체험으로 제공하고 요소 학습 기록에는 구 저장에서 인정한 출처를 남긴다.
- 저장 시 재료 ID/해금 증거/원리 호환/설정 범위/활성 슬롯 수를 검증하고 이름은 일반 텍스트로 표시한다. 알 수 없는 원리 버전은 원문을 보존한 채 불러오기 거부 또는 비활성 보관한다.
- 시험 중 저장은 영구 설계·성취만 보관하고 전장은 시험 시작 상태로 돌아온다. 실험의 필드 재접속도 체크포인트부터 재시작하며 준비 충격·지연 큐는 초기화한다. 보상 없는 실험이므로 재접속으로 영구 성장하지 않는다. 본편의 전장 중 저장을 지원할 경우에는 자원·큐·중복 사건 ID까지 별도로 설계해야 한다.
- 실험→본편 역수입은 지원하지 않는다. 본편 편입 시 정식 스키마와 변환 테스트를 별도 승인·검토한다.

### 9.4 밸런스와 튜토리얼 위험

기존 현실 Q는 이미 다음 타격 강화/억제를 제공한다. 창작이 이 효과 위에 무료 범위·지연·전이를 더하면 모든 상황에서 정답이 된다. 사례처럼 기존 강화 기회 소비, 즉시 효과 포기, 추가 자원, 대상 제한을 실제 실행에서 확인해야 한다.

기존 해석 6종과 기능이 겹칠 수 있다. 초기에는 일부 겹침을 허용하되 해석을 삭제하지 않고 ‘간편한 완성 운용’, 창작을 ‘재료와 조건이 필요한 조정 운용’으로 비교한다. 사용자에게 실질 차이가 없으면 새 조합 수를 늘리기 전에 해당 원리를 수정하거나 제외한다.

1~9성, 계열 0~30, 초식 성취를 모두 상시 표시하면 혼란스럽다. 기본 화면에는 성과 다음 가능한 조정만, 상세에 원본 수치와 기존 피해 보정을 둔다. 수치 성장·원리 체득·현장 보고 알림도 한 번에 겹치지 않게 첫 조합을 단계적으로 안내한다.

## 10. 최소 검증 계획 — 쌍계 기반 별도 실험

### 10.1 최소 범위와 제외 범위

**사용자 검토용 실험 범위는 월영참 제작부터 세 연계 사례까지다.** 월영참의 네 축 튜토리얼을 끝내고 비경의 세 배움 경로를 각각 시험해 파문세·잔영각·쇄경진을 만든다. 이후 반류일선·유영잔참·이맥봉류와 현실 적용까지 시험한다. 모든 계열을 한꺼번에 장착하지 않고 거점에서 교체한다. 파문 수호형은 비용이 허용되면 비교용 추가 선택으로 둔다.

실험은 신규 사용자의 1성 기본형과 조절 폭이 열린 3성/5성 fixture를 준비한다. 숙련 재료를 수십 분 모으는 과정은 생략하되, 한 번의 실제 효과 증명과 ‘지금 조절할 수 없는 이유’는 플레이한다. R/F·새 속성·새 문파·3초식·다중 원리·전체 본편 개편·신규 재화·신규 정식 승급은 제외한다.

추후 제작 순서는 월영참→파문·관통으로 전체 흐름을 먼저 연결한 다음 잔영·지연과 봉인·전이를 추가하는 것이 좋다. 이는 내부 단계일 뿐 파문 하나만으로 사용자가 요청한 전체 시험 범위를 완료했다고 하지 않는다. 실험에서는 배움 장소를 가깝게 배치하고 숙련 2·3성 비교 fixture를 명시적으로 제공해 세 사례를 시험할 수 있게 한다. 본편 성장 속도와 저장에는 반영하지 않는다.

### 10.2 실험 구간과 비교 조건

‘청운촌 첫 월영참 제작 → 자유 변형 → 기존 통로 철수 요약 → 비경의 세 요소 배움·Q 제작 → 세 연계 시험 → 현실 기지 적용 → 재도전’의 독립 구간을 만든다. 사건을 한 번 더 실패시키지 않는다. 새 실험 지역 ID 예시는 `skillformWorkshop`, `skillformTrial`, `skillformRealityTrial`이며 모두 현재 미구현이다.

| 전장 | 기대하는 선택 차이 | 기록할 것 |
|---|---|---|
| 전방 선형의 두 적 | 관통은 두 번째 위협까지 처리하기 유리 | 두 번째 적 적중, 통로가 열린 시간, 소비 자원 |
| 교대 공격과 고정 방어 위치 | 수호는 자리를 지키며 생존하기 유리 | 실제 감소 피해, 이탈 시간, 후속 공격 기회 |
| 예고가 드문 단일 표적 | 원본은 낮은 비용·준비 불필요로 유리 | 처치 시간, 준비 실패·낭비, 남은 자원 |
| 피한 자리를 뒤따라오는 추격 적 | 잔향 지연은 이동과 공격 위치를 분리 | 가속 시작점 타격, 현재 위치의 안전, 지연 명중·낭비 |
| 가까운 두 적의 교대 예고 | 억제 전이는 다음 위협 대응에 유리 | 첫 억제 종료, 두 번째 예고 취소, 남은 시간 보존 |

레벨·숙련·장비·심법·공명 투자·적 체력·예고·초기 자원·난도 보조를 동일하게 고정하고 장착 원리만 바꾼다. 시도 순서를 바꿔 익숙해진 효과를 통제한다. 저장된 현실 비교 기록 `ResonanceProof`의 방식을 참고하되 실험 별도 기록에 남긴다. 기록은 로컬에 보관하고 외부 전송은 하지 않는다.

### 10.3 검증 질문과 잠정 통과 기준

아래 표는 소규모 형성 평가의 **임시 기준**이다. 5명 정도의 신규 참여자로 문제를 찾는 것이 목적이며 통계적 성공률을 확정하지 않는다. 숫자를 맞추기 위해 플레이어 선택을 강제하지 않는다.

| 질문 | 확인 방법 | 잠정 통과 기준·실패 시 조치 |
|---|---|---|
| 원하는 결과를 예상하는가? | 시험 전 예상 기능·대가를 말하고 선택하게 한다 | 5명 중 4명이 대상 방식과 대가를 맞히는지 확인. 틀리면 재료 이름보다 결과·출력 상태 설명을 먼저 수정 |
| 숙련이 필요한 이유를 이해하는가? | 같은 재료의 기본형/성장형을 보여주고 달라지는 것을 설명하게 한다 | 4명이 ‘확률 성공’이 아니라 조절 폭/성취 권한이라고 설명. 실패하면 1~9성 표시와 성취 안내를 줄임 |
| 상황별 선택이 있는가? | 세 전장을 세 운용으로 교차 비교 | 관통·수호·원본 각각 적어도 한 상황에서 실질 장점 확인. 모두 관통이 좋으면 추가 피해보다 대가·전장 조건부터 조정 |
| 실제 전투 방식이 바뀌는가? | 공격 위치·타이밍·상태 소비·자원과 플레이 설명을 함께 본다 | 피해 숫자 외 선형 적중/피해 감소가 실제 발생하고 플레이어가 그 차이를 지목. 설명만 다르면 원리 재설계 |
| 현실에서 써보고 싶은가? | 무림 시험 뒤 다음 행동을 강요하지 않고 선택/이유를 관찰 | 4명이 자신의 선택을 현실에서 시험하려고 이동하며 기대 효과를 설명하는지 확인. 단순 보상 수령 동기와 구분 |
| 반복 부담이 없는가? | 원리를 바꾸고 다시 현실 적용하게 한다 | 두 번째 제작·동일 원리 적용에 재파밍·동일 증명 반복 없음. 실패 원인을 보고 재시도 방향을 정할 수 있음 |

평가자는 플레이어가 선택 이유를 말할 기회를 주고, 실패를 ‘센스 부족’으로 처리하지 않는다. 첫 5~8분 목표를 넘기는 원인이 읽기 부담인지 수련 반복인지 구분한다. 재미가 확인되지 않으면 기존 시스템을 전면 개편하기 전에 연결 원리·첫 시험·UI를 축소해 다시 검증한다.

### 10.4 자동·수동 검증 항목 제안

구현 시 기존 `node:test` 구조에 다음 핵심 계약을 검증한다. 이번 작업에서는 신규 테스트·코드를 작성하지 않았다.

- 같은 입력의 결정적 결과, 미습득/잠긴 R 재료 거부, 호환 불가의 명확한 이유, 개인 범위 상한·하한.
- 월영참 요소 구성 전후의 습득 진행, 축별 중복·미습득 요소·맞지 않는 입출력 거부, 기본 초식 미체득 상태의 필드 장착 차단, 지도 시험 허용, 연계 무공 재료 중첩 거부.
- 숙련은 소비되지 않고 제작 자체로 증가하지 않음, 원리 체득은 한 번, 동일 시전 지연 타격의 중복 성취 없음.
- 관통 최대 대상·방향·벽 판정, 수호 실제 피해 감소, 축적 한 번 소비, 비용 부족 시 무소모, 빗나감 시 환급 없음.
- 현실 적용 즉시 사용 가능, Q의 기존 정착은 유효 효과로 기록, 기존 해석 중복 방지, 공명·심법 감소와 최저 비용 일치.
- 개명·복제·재장착·순서 변경·재접속으로 보상/등급 증가 없음, 기존 6장 유효 연계의 시전 중복 없음.
- 저장 원본 바이트 보존, 실패 시 롤백, 알 수 없는 ID/잠금 위조/범위 밖 설정 거부, 신규와 구 저장 복사 비교.
- 브라우저에서는 재료 선택→부족 조건→시험 실패→수정→현실 적용→재접속까지 실제 입력으로 확인. 키보드·모바일·확대·초안 복귀·입력 누수를 포함.

관련 회귀군은 `growth-arc`, `reality-skills`, `world-achievements`, `resonance-*`, `v12-reality-evolution`, `v12-advancement*`, `dual-breath`, `save-v10`이다. 구현 뒤 변경에 맞는 검사를 거쳐 전체 `npm test`와 문법 검사, 영향받는 브라우저 흐름으로 확대한다. 테스트 통과와 사람의 선택·동기 검증을 별도 결과로 보고한다.

### 10.5 브랜치·장면·저장 분리 계획

이번 기획은 `main`에서 문서만 작성한다. **현재 지침상 별도 브랜치·워크트리를 만들지 않는다.** 추후 사용자가 실험 브랜치를 명시 요청하면 `codex/skillform-prototype` 같은 이름을 검토할 수 있다. 요청이 없다면 main 안에서도 개발 전용 진입·모듈·별도 저장으로 분리하는 계획을 사용한다.

실험 진입은 개발 서버에서만 허용하고 공개 빌드 포함 목록에서 제외한다. 기존 `/art-play.html?dev=1`와 개발 fixture 패턴을 참고하되 별도 장면·별도 저장 키·보상 차단을 모두 검사한다. 브랜치만 달라도 같은 브라우저 origin에서는 저장이 공유되므로 브랜치 분리는 저장 격리를 대신하지 못한다. 기존 테스트 슬롯도 재사용하지 않는다.

실험 종료 시 본편은 기존 저장으로 계속할 수 있고 실험은 자기 키만 삭제·초기화한다. 본편 장면·전투·경제·일반 세이브 로더를 바꾸는 작업은 실험이 유효하다고 판단된 이후 별도 범위다. 푸시·배포는 별도 요청 전까지 하지 않는다.

## 11. 검토가 필요한 핵심 결정

완성된 초안의 기본값은 위 권장안을 따른다. 아래 항목의 미결정 상태를 이유로 기획서를 질문 목록으로 대체하지 않는다.

| 우선순위 | 미결정 사항 | 현재 권장 기본값 | 결정에 필요한 근거 |
|---|---|---|---|
| 1 | 첫 연계까지 필수 이야기 단계로 할지 선택 수련으로 할지 | 월영참 제작 튜토리얼은 후속 방향으로 반영. 연계는 선택 수련을 권장하고 실험에서는 세 사례 모두 제공 | 플레이어가 기본 초식을 만든 뒤 자발적으로 연계하고 현실로 돌아가려는지 |
| 2 | 1~9성이 기존 0~30의 표시 확장으로 충분한지 | 초기에는 원본 수치 유지·파생 단계 사용 | 성취와 성의 역할을 이해하는지, 기존 저장 보존·성장 속도 |
| 3 | 기존 해석과 창작을 어떻게 장기적으로 공존시킬지 | 같은 행동의 변형 슬롯 공유, 기존 해석은 완성 운용으로 보존 | 해석보다 창작만 고르는지, 차이가 기능적으로 인지되는지 |
| 4 | 현실 원리 활성 수를 늘릴 시점 | 초기 1원리·1스킬, 다중 적용은 후속 | 한 슬롯만으로 선택이 충분한지, 중첩 비용·밸런스 검증 |
| 5 | 속성 성장·새 현실 마법을 언제 포함할지 | 냉기 사례는 후속, 적성/매개체 설정과 신규 스킬 필요성부터 확정 | 기존 기술 변형으로 표현할 수 없는 역할이 실제 필요한지 |
| 6 | 운기 한도를 어느 범위까지 열지 | 축별 1요소·기본 원형 1개·연계 2초식, 중첩 금지 | 호환 설명으로 제한을 납득하는지, 제한 안에서 실제 다른 결과를 만들 수 있는지 |

제작 결과 확률화, 저숙련 확률 실패, 새 제작 화폐, 창작물별 숙련 바는 초기 권장안에서 제외했다. 나중에 이 방향을 바꾸려면 사용자 확정 원칙과 충돌하지 않는 이유를 먼저 검토해야 한다.
