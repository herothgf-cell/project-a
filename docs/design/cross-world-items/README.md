## 현재 브랜치에서 게임 실행

이 체크아웃은 이미 `v0.2_proto_patch`입니다. `git branch --show-current`로 확인하세요. 다른 환경에서는 브랜치가 원격에 푸시된 뒤 `git fetch origin`과 `git switch v0.2_proto_patch`로 가져올 수 있습니다. 현재 단계에서는 원격 v0.2 브랜치를 게시하지 않았습니다.

```bash
cd /workspace/project-a
node --version
ART_REVIEW=1 node server.cjs
```

개발 서버에서 `/art-play.html?dev=1` 경로를 여세요. 서버 출력에 실제 포트가 나옵니다. 개발 모드는 루프백 접속만 지원합니다. 클라우드 미리보기 제공 여부는 별도 환경 기능에 달려 있습니다.

`npm: command not found`가 나와도 `node`가 설치되어 있다면 위 명령으로 현재 게임 실행은 가능합니다. `node`도 없다면 Node.js 20 이상을 설치하고 터미널을 다시 여세요. 이 클라우드 인스턴스에는 Node v24.19.0 / npm 11.9.0이 있습니다. 다른 PC나 새 환경에 자동 적용된다는 뜻은 아닙니다.

기존 기능 테스트 방법은 [main 첫 성장 테스트 안내](../../growth-arc-test-guide.md)를 참고하세요. main 흐름은 ‘귀환 통로 방어 → 철수 → 첫 Q 체득’이며, v0.1의 ‘귀환 전 · 같은 위협 체험’ 메뉴를 기대하면 안 됩니다.

## 구현 후 사용할 수동 테스트 시나리오

아래는 준비된 검증 시나리오이며 지금 실행할 수 있는 새 기능이 아닙니다.

1. 신규 v0.2 전용 시험 슬롯으로 시작하고 네 재화가 모두 0인지 확인한다.
2. 정상 현실 균열 완료로 C 2개·D 1개를 획득한다. 재보고해도 수량이 늘지 않는지 확인한다.
3. 무림 거점에서 C로 능력치를 배분한다. 해당 기술 체득 후 D로 파문 노드에 투자한다. 현실 능력치는 변하지 않아야 한다.
4. 정상 무림 탐사 완료로 A 2개·B 1개를 획득하고 현실로 귀환한다.
5. 현실에서 A로 능력치, B로 체득한 파문의 강화에 투자한다. 비용·변화·잔액을 확인한다.
6. 같은 적 구성으로 재전투해 기본 공격과 Q 운용의 차이를 기록한다. R/F 이야기 잠금은 유지한다.
7. 숙련 전후와 소비 전후를 비교해 서로를 대신 지급하지 않는지 확인한다.
8. 재접속·완료 재처리·연속 구매·초기화 후 수량과 배분이 유지되는지 확인한다.
9. 기존 저장을 별도 슬롯으로 가져와 기존 효과와 원본 파일이 유지되는지 확인한다.

게임 코드 검증은 구현 단계에서 `npm test`, `npm run check`, `npm run check:revision`, `npm run check:world` 및 관련 브라우저 테스트로 수행합니다. 이번 기획 단계에서 해당 게임 테스트를 새로 통과했다고 주장하지 않습니다.
