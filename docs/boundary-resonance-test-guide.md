# v0.2 경계공명 테스트 안내

작업 브랜치: `v0.2_proto_patch`. 이 기능은 해당 브랜치의 로컬 실행에서 확인합니다. 공개 Pages 주소는 main의 배포 상태를 따르므로 이 변경이 자동 반영되지 않습니다.

## 실행

Node.js 20 이상이 필요합니다. `npm`이 없더라도 `node --version`이 정상이라면 서버를 직접 실행할 수 있습니다. `node`도 없다면 Node.js LTS를 설치하고 터미널을 다시 여세요.

```bash
git switch v0.2_proto_patch
ART_REVIEW=1 node server.cjs
```

PowerShell:

```powershell
git switch v0.2_proto_patch
$env:ART_REVIEW='1'
node server.cjs
```

주소: `http://127.0.0.1:3000/art-play.html?dev=1`

아래쪽 개발 시작점에서 **첫 계승 후** → 새로고침 뒤 **이어하기**를 선택합니다. 개발 버튼은 로컬 서버의 `ART_REVIEW=1`과 `?dev=1`에서만 나타납니다. 이 화면은 `dualworld.test.v02`를 사용하며 일반 플레이 저장과 분리됩니다.

## 첫 확인 순서

1. **성장 → 경계공명**에서 결정·각인 보유량을 확인합니다. 첫 계승은 결정 8·각인 1이며 이미 달성한 기본기·레벨 성취도 함께 표시될 수 있습니다.
2. **능력치**에서 공격 4·체력 4를 배분하고 적용합니다. 적용 전후 공격 +4·체력 +24를 확인합니다. 남는 결정은 보관됩니다.
3. **현실 스킬**에서 파문의 **안정 흡수**를 해금합니다. Q 흡수 판정이 0.7 → 0.9초로 바뀝니다. R/F는 이야기에서 체득하기 전까지 잠겨 있습니다.
4. **보관함·기록 → 현실 비교 전투**에서 Q로 공격 예고에 대응하고 적 2종을 제압합니다. 결과의 실제 시간·피해·타격·기술 사용·Q 성공/시도·자원 부족을 확인합니다. 최근 2개 결과가 남습니다.
5. 현실 기지에서 스탯/각인을 무료 환불하고 다른 배분을 시험합니다. 체력·기력의 현재 비율이 유지되므로 환불로 회복을 반복할 수 없습니다.
6. 무림 청운촌으로 이동하거나 개발 시작점의 **공명 도전부터**를 선택합니다. 시작점 변경은 현재 테스트 기록을 교체합니다.
7. **성장 목표 → 버티는 힘 → 흑풍 죽림 입장**. 적 3종 제압 후 청색 공명 기록 지점 근처에서 2초를 확보합니다. 최초 결정 1·각인 1이 지급됩니다.
8. 연속 운용은 **적중한 유료 무공 3회**, 정확한 대응은 **실제 예고에 대응 2회**와 적 제압을 요구합니다. 허공 입력은 제외됩니다. 조건 전에 적을 모두 죽였다면 귀환해 재시도합니다.
9. 청운촌 귀환·재접속 후 기록을 확인합니다. 같은 도전 재완료에는 추가 공명이 지급되지 않습니다. 도전에서 사용한 회복약은 귀환 때 복원되며 사망 시 금화를 잃지 않습니다.
10. 현실 기지에서 새 공명을 투자하고 비교 전투를 반복합니다. 무림에서는 투자 화면을 조회할 수 있지만 현실 능력치·스킬을 바꿀 수 없습니다.

## 시작점

- **공명 정착 전**: 2장 보고 후, 첫 기연 영구 계승 전. 기존 통로 방어 → Q 체득 흐름을 확인합니다.
- **첫 계승 후**: 파문을 영구 계승하고 현실 기지로 귀환. 공명 배분·Q 강화 확인에 적합합니다.
- **공명 도전부터**: 같은 계승 상태에서 청운촌. 죽림·폐사의 도전 6개가 열립니다.
- 귀환 통로 도전 3개는 4장 지역 개방 뒤 이용합니다. **5장 완료부터**로 9개 전체와 R 강화도 확인할 수 있습니다.
- **새 게임부터 / 5장 완료부터 / 6장 완료부터**도 유지합니다.

시작점은 실제 상호작용과 전투를 수행하는 테스트 여정으로 생성하고 저장 검증을 통과시킵니다.

## 저장 이전과 경계

일반 v0.2 저장: `dualworld.save.v02`. 기존 v0.12 저장 `dualworld.save.v10`이 같은 주소에 있으면 타이틀에 **이전 v0.12 기록 가져오기**가 나타납니다. 복사를 선택해야 새 슬롯에 기록하며 원본은 바꾸지 않습니다. 이미 적용된 옛 능력치·현실 심법 효과는 유지하고 같은 성취를 새 공명으로 중복 지급하지 않습니다. 옛 고정 보너스는 상한에 포함되며 환불되지 않습니다.

다른 주소/기기의 기록은 설정에서 파일 다운로드 후 불러옵니다. 손상된 파일, 지원하지 않는 v0.1 귀환 검증 전용 저장, 저장 공간 부족은 성공 처리하지 않습니다. 능력치/각인 투자 저장 실패 시 변경을 취소합니다. 도전 보상 저장 실패 시 기록 지점에서 E로 다시 시도할 수 있습니다.

현재 선택 도전은 최초 보상이 있는 유한 콘텐츠이며 무한 파밍 구조가 아닙니다. 비교 기록은 레벨·장착·숙련·플레이 차이의 영향도 받으므로 수치만으로 투자 효과를 단정하지 마세요. 무림 기록과 현실 비교 기록은 별도로 표시합니다.
